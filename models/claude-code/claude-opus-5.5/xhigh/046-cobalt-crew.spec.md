## 产品边界

- 实现：项目任务列表（分组、筛选、统计）、新建任务（标题、负责人、优先级、截止）、分派、状态推进、活动记录、跨团队任务的只读权限控制、权限申请与安全返回。
- 不包含：评论与附件、子任务、看板拖拽、真实审批流、通知中心与成员管理。

## 正常流程

1. 点「＋ 新建任务」→ 输入「首页首屏动效评审」，负责人选「周岚」→「创建」→ 新任务 WEB-128 出现在待办组首行并被选中，记录「创建了任务」「把任务分派给 周岚」。
2. 在详情「负责人」改为「林小满」→ 记录「把任务分派给 林小满」，行头像更新。
3. 点详情状态「进行中」（或行内胶囊 / →）→ 任务移入进行中组，记录「把状态从 待办 改为 进行中」，底部提示「WEB-128 → 进行中」。

## 异常触发与恢复

- 触发：点侧栏「财务 · Q4 预算」或在列表中找到 FIN-031（🔒 财务组专属），点其「→」、状态胶囊、详情中的状态段或修改负责人。
- 反馈：弹出「你没有权限修改这项任务」，说明任务属于财务组、你的角色是「设计组 · 成员」，红色块写明「本次操作：把状态改为『已完成』· 需要权限：财务组 · 编辑者 · 这次修改没有写入，任务保持原状」；FIN-031 的状态与负责人不变，记录中新增红色「尝试…未生效」。
- 恢复 A：点「申请编辑权限」（可编辑理由）→ 提示「访问申请已发送给 吴桐」，记录新增紫色申请条目；再次触发时弹窗显示待审批信息。
- 恢复 B：点「返回我的任务」→ 筛选切到「分给我的」并选中自己的未完成任务（如 WEB-122）→ 点「待审核」→ 变更成功并写入记录。

## 人工验收步骤

正常闭环：
1. 点「＋ 新建任务」→ 输入标题、负责人选「周岚」→「创建」。
2. 在右侧把负责人改为「林小满」→ 点状态「进行中」。
3. 看到任务移入「进行中」组，右侧活动记录依次有创建、分派、状态变更三条。

异常恢复：
1. 点侧栏「财务 · Q4 预算」→ 右侧显示 FIN-031 且标注只有查看权限。
2. 点详情中的「已完成」→ 弹出权限不足，写明未写入；关闭后状态仍为「待审核」。
3. 再次触发，点「申请编辑权限」→ 看到「访问申请已发送给 吴桐」与紫色记录。
4. 再触发一次 → 点「返回我的任务」→ 列表切到「分给我的」，选中 WEB-122。
5. 点「待审核」→ 任务移入待审核组，记录新增「把状态从 进行中 改为 待审核」。
