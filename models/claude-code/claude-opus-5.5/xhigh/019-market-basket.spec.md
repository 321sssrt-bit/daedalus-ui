# 019 购物车

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`019-market-basket.html`
- 复现范围：早市到家生鲜购物车，含免配送费进度、5 件商品（按件或称重加减、删除与撤销）、推荐加购、右侧热敏小票式结算（小计、配送费、优惠码、应付与去结算）。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 数量步进 | 胶囊，两个 36×36px 按钮 + 最小宽 64px 数值（带单位） | 白底绿色符号 | 称重商品每次 ±0.5 斤，其他 ±1；到下限（一个步长）或上限 10 时按钮禁用；变化即刻更新行小计、小票明细、小计、配送费、免邮进度与应付 |
| 删除 | 36px 圆形「✕」 | 灰字 | 悬停浅红底红字；点击行右移 30px 淡出 0.22s 后移除，原位置出现红色虚线撤销条「已移除…」+「撤销」 |
| 免邮进度条 | 文案 + 8px 进度 | 未满 ¥59 显示「再买 ¥x 免配送费」 | 满 ¥59 变为绿色「✓ 已免配送费…」，进度 100%；小票配送费从 ¥6.00 变「免费」 |
| 优惠码 | 输入框 + 「使用」 | 提示「试试 FRESH10，满 ¥60 减 ¥10」 | 错码红字「优惠码无效或已过期」；不满 60 红字提示差额；成功绿字并在小票加入红色减免行；之后小计跌破 60 自动移除并提示 |
| 去结算 | 宽 100%、高 56px，带 6px 实体厚度 | 绿底白字「去结算 · ¥应付」 | 悬停 `#358a38`；按下下沉 4px；购物车为空时禁用并显示「菜篮子是空的」；点击后文案「正在为你挑选最新鲜的…」 |
| 推荐卡 | 白卡，44px 图 + 名称 + 说明 + 价格 + 「＋ 加入」 | — | 加入后进入列表（已存在则数量 +1），按钮变「✓ 已加入」 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |

| 窄于 680px | 内边距 20px 16px；商品行改为三行布局（图 / 名称 / 删除 → 价签 → 步进与小计） | 地址隐藏 |

## 内容与数据

- 商品与初始数量：崇明番茄 ¥6.8/斤 × 1.5 斤；林下散养土鸡蛋 ¥22/盒 × 1；上海青 ¥4.5/斤 × 1.0 斤；鲜活鲈鱼 ¥36/条 × 1；石磨老豆腐 ¥5.5/块 × 2。
- 初始小计 ¥83.70，已满 ¥59 免配送费，应付 ¥83.70。
- 推荐：香葱 ¥2/把、糯玉米 ¥7.9/袋、巴氏鲜奶 ¥15.8/瓶、咸鸭蛋 ¥12.5/盒。
- 小票抬头「早市到家 · 康定路店 · 2026-10-23 14:32」。
- 金额统一保留两位小数，前缀 ¥。

## 复现验收清单

- [ ] 1280 宽下左侧商品列表、右侧 380px 白色小票，小票底部有锯齿边并吸顶。
- [ ] 每件商品有墨绿色打孔价签、胶囊步进器和右侧小计。
- [ ] 把番茄加到 2.0 斤，行小计变为 ¥13.60，小票明细与应付同步增加 ¥3.40。
- [ ] 删除鲈鱼后小计跌破 ¥59，出现「再买 ¥x 免配送费」，配送费变为 ¥6.00；点撤销恢复。
- [ ] 输入 FRESH10 并使用后，小票出现红色「-¥10.00」行。
- [ ] 删除全部商品后「去结算」禁用并显示「菜篮子是空的」。
- [ ] 窄于 1060px 时小票排到列表下方。
