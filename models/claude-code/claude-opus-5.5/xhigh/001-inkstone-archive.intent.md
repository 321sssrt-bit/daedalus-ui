# 001 登录

## 设计意图

登录是读者每天推开的那扇门，所以把它做成一本书的扉页：左侧竖排书名和印章交代"这里是书库"，右侧只留一张安静的表单。取舍上放弃投影、渐变按钮和插画，只用纸色、墨色、朱砂三色和细线分层，让"进入书库"成为唯一最重的东西；忘记密码给出三条真实出路，而不是一个空链接。

## 适用场景与目标用户

城市公共图书馆、高校图书馆或古籍数字化平台的读者端登录；用户是持借阅证的常客，多在电脑上续借、查批注、约座位，年龄跨度大，需要大字号、清晰的错误提示和人工兜底渠道。

## 非目标

- 不做第三方社交登录墙、营销轮播或会员促销。
- 不用玻璃拟态、霓虹渐变或卡通插画。
- 不在本页处理注册流程与密码重设的完整步骤，只给出入口。

## 复刻提示词

做一张图书馆读者登录页：米色宣纸底带极淡横格线，左侧 520px 竖排宋体大字"墨册"、竖排两行诗句、左下角朱砂方印；右侧 420px 宽表单，宋体标题、苹方正文，输入框直角细边，主按钮墨黑满宽、字距拉开写"进入书库"。支持密码/短信验证码两个页签、60 秒重发倒计时、忘记密码展开三条出路，全页无投影只用 1px 细线。
