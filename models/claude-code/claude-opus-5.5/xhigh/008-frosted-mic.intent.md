# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-frosted-mic.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

麦克风权限最怕"先要再说"。这里在系统弹窗之前先给一层预请求：毛玻璃面板浮在真实会议页上方，让人看清"要它来干什么"；三条事实回答何时录、存多久、怎么撤回。拒绝也有体面的出口：给出上传录音和手动笔记两种替代方案，而不是把人关在门外。

## 适用场景与目标用户

会议转写、语音笔记、在线面试等需要麦克风的桌面 Web 应用；用户是职场人，在意隐私、怕被"偷听"，但也希望少花力气做会议记录。

## 非目标

- 不伪造操作系统原生权限弹窗。
- 不在一次弹窗里同时申请摄像头、通知等多项权限。
- 不做纯白扁平的系统设置风格。

## 复刻提示词

黄昏渐变毛玻璃风权限预请求：背景是橙→玫紫→深紫→夜蓝的径向渐变，后面隐约是模糊的会议纪要应用；中央 480px 圆角 28px 半透明玻璃面板，带白色描边麦克风图标和跳动声波，标题"听记想使用你的麦克风"，三条绿色对勾事实清单放在深色内嵌块中；整行暖黄主按钮"允许使用麦克风"，下方并排"仅本次会议""暂不允许"。允许后背景清晰、状态点变绿；拒绝后给出上传录音等替代方案。
