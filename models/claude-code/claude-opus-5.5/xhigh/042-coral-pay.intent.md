# 042 钱包支付产品

## 意图元数据

- 意图版本：1
- 对应规范：`042-coral-pay.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

转账最怕两件事：转错人、转不出去。所以收款人始终以头像和手机号尾号出现在金额上方；金额页把"可用余额"贴在数字下面，超额时数字立即变红提醒，但仍允许进入确认，在确认时给出明确的拦截和两条出路：换一个够钱的资金来源，或改金额，整个过程中金额与收款人都保留。珊瑚色与海军蓝的组合让钱包温暖又可信，主按钮永远写着要付的金额。

## 适用场景与目标用户

移动钱包、银行 App、社交支付的转账流程；用户是日常给朋友 AA、给房东交租、给家人转钱的上班族，单手操作，关注到账速度和是否出错。

## 非目标

- 不做理财营销、红包玩法与信用借贷入口。
- 不用冷峻的深色金融终端风格。
- 不实现支付密码、风控验证与银行卡绑定流程。

## 复刻提示词

珊瑚海军蓝手机转账原型（390px 手机框）：暖白底，首页是海军蓝圆角余额卡（右上珊瑚色大圆）配珊瑚"转账"和半透明"收款码"，下面两格资金来源、一排彩色圆形联系人头像和账单卡；选人后进入金额页：顶部收款人条、52px 圆体大金额与"可用余额"（超额变红）、常用金额胶囊 ¥200/¥500/¥3,000、两格资金来源选择、备注框、3×4 白色圆角数字键盘和珊瑚色"下一步 · ¥金额"；确认弹层从底部滑出显示明细，余额不足时出现抖动的红框提示与"改用招商银行储蓄卡 / 修改金额"，成功后是带绿色对勾和锯齿底边的转账凭证。
