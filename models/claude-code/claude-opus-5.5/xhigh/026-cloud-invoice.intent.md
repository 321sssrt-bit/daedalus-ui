# 026 账单

## 意图元数据

- 意图版本：1
- 对应规范：`026-cloud-invoice.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

云服务的账单读者是工程负责人和财务，他们要的是"可核对"。冷灰蓝控制台底色、等宽金额右对齐、紧凑的表格，把每一分钱的来源摆在计量条里；预算条同时画出已用、预计和上限，一眼看出月底会不会超；待支付和发票状态用小徽标区分，操作就在行尾。

## 适用场景与目标用户

云计算、SaaS 基础设施、API 平台、广告投放平台的费用中心；用户是 DevOps 负责人、技术经理和企业财务，月度对账、报销开票、控制成本。

## 非目标

- 不做营销式的升级推销横幅。
- 不用圆润可爱的消费级风格。
- 不实现费用明细下钻和预算规则编辑。

## 复刻提示词

云服务控制台账单页：顶部 48px 深海军蓝栏，白色标题区带蓝色下划线页签；冷灰蓝底上 12 栏卡片网格，第一行三卡：当前方案（等宽键值对、蓝色升级按钮）、本月费用（34px 等宽金额、渐变已用 + 斜纹预计 + 红色上限线的预算条）、支付方式（深色渐变银行卡示意 + "更换支付方式"）；第二行四格用量计量（等宽数值、细进度条，超 90% 变琥珀）；最下方账单记录表，等宽编号与右对齐金额、绿/红/琥珀状态徽标、"申请发票""下载 PDF"文字按钮和"立即支付"。
