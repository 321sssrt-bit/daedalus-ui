## 内容与数据

- 面包屑：「搜索 · 日期范围选择器 带时区 · 在 v4.2 文档中检索了 186 个页面」。
- 空态标题：「没有找到与【日期范围选择器 带时区】匹配的组件或文档」，搜索词以荧光底标出；说明给出 `DatePicker` 的 `range` 模式 + `TimezoneSelect` 的组合方案。
- 纠错建议：「日期范围选择 · DatePicker.Range — 支持预设区间和禁用日期」。
- 改搜标签：日期范围（删除线「带时区」）/ 时区 / DatePicker（英文名）/ 只搜「日期」。
- 相关组件：日期选择 DatePicker、时间选择 TimePicker、日历 Calendar。
- 最近搜索：表格 固定列 / Toast / 上传 拖拽。
