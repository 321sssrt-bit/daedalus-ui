# 044 社交社区产品

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`044-pebble-feed.html`
- 复现范围：「石子」同城兴趣社区的手机单页原型：浏览动态（点赞）→ 写新动态（文字、配图、话题、可见范围）→ 发布并在动态顶部看到结果；以及打开「演示：让本次发布失败」后发布失败、草稿与可见范围完整保留、点击「重新发布」成功。

## 产品边界

- 实现：同城动态浏览、点赞、新建动态（文字、单张配图、单个话题）、四种可见范围、发布与结果展示、发布失败模拟、草稿保留与重新发布。
- 不包含：评论详情、关注与私信、多图与视频上传、位置选择、内容审核与举报。

## 正常流程

1. 动态页浏览 3 条动态，可点赞（数字 +1、心形变橘）。
2. 点右下「＋」→ 编辑页，作者行「发布到 🌍 公开」，发布按钮禁用。
3. 输入「北山街的银杏开始黄了，周六一起去走走？」→ 字数显示、发布可用、「草稿已自动保存」。
4. 选第 1 张配图、话题「#城市散步」、可见范围「仅『周末爬山』圈子」→ 作者行更新。
5. 点「发布」→「发布中…」→ 回到动态页：新卡置顶、橘色描边、标签「🫧 仅『周末爬山』圈子」，顶部提示「发布成功 · 仅『周末爬山』圈子」。

## 异常触发与恢复

- 触发：在编辑页底部虚线卡片中打开「演示：让本次发布失败」（开关变红），然后点「发布」。
- 反馈：0.9s 后留在编辑页，顶部出现抖动的红色提示「发布未完成 · 网络开小差了，你的文字、图片、话题和可见范围（…）都已保留在草稿里」；文本框、配图、话题和可见范围选择全部保持原样；动态流中不出现任何新内容。
- 恢复：点提示中的「重新发布」→ 演示开关自动关闭（视为网络恢复）→ 发布中 → 成功回到动态页，新动态置顶并显示原先选择的可见范围。

## 人工验收步骤

正常闭环：
1. 打开页面 → 点右下「＋」。
2. 输入一句话 → 选配图 1、话题「#城市散步」、可见范围「仅关注我的人」。
3. 点「发布」→ 回到动态页，新卡置顶，标签为「👥 仅关注我的人」，顶部提示发布成功。

异常恢复：
1. 再次点「＋」→ 输入文字 → 选可见范围「仅『周末爬山』圈子」。
2. 打开「演示：让本次发布失败」→ 点「发布」→ 看到红色「发布未完成」，草稿与范围仍在。
3. 点「重新发布」→ 回到动态页，新动态置顶，标签为「🫧 仅『周末爬山』圈子」。
