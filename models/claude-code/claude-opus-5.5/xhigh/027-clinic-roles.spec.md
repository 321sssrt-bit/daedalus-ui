# 027 角色权限

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`027-clinic-roles.html`
- 复现范围：仁和医院信息平台的「角色与权限」管理：5 个角色列表、8 模块 × 4 操作的权限矩阵（含依赖与敏感标记）、未保存修改提示、保存 / 撤销，以及右侧「修改后 / 已保存」菜单预览。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 权限复选格 | 22×22px，1.5px 边，圆角 6px | 白底 `#b9d3cf` 边 | 悬停边变青；勾选青底白勾；与已保存值不同时外加琥珀光圈；「查看」未勾选时同行其余三格禁用（灰底），取消「查看」会清空整行 |
| 角色项 | 34px 彩色首字头像 + 名称与说明 + 右侧已授予数 | — | 悬停 `--mint-2`；选中 `--mint` 底 + 3px 青色左条；有未保存修改时右侧显示 7px 琥珀点 |
| 主操作「保存权限」 | 高 34px，内边距 0 16px | 青底白字；无修改时禁用（不透明度 0.45） | 有修改可点，悬停 `--teal-dk`；保存后琥珀标记消失，顶部提示「已保存『角色』的 n 项权限变更 · 审计编号 AU-1023-xxxx」 |
| 撤销修改 | 同尺寸描边 | 无修改时禁用 | 恢复为已保存值 |
| 底栏提示 | 左侧文字 | 「所有修改会记入审计日志」 | 有修改时变「n 项修改未保存 · 涉及敏感模块的变更需信息科主任复核」（数字琥珀色） |
| 切换预览 | 分段：修改后 / 已保存；模拟菜单 8 项 | 修改后 | 每项按权限显示：可审批 / 可编辑（薄荷底）、只读（灰字）、隐藏（删除线 + 红色「隐藏」）；切换分段或改动矩阵即时刷新 |

## 内容与数据

- 角色：主任医师（科室负责人）/ 住院医师（临床一线）/ 护士长（护理管理）/ 药剂师（药房）/ 挂号收费员（门诊前台）。
- 模块：电子病历 / 医嘱与处方（敏感）/ 检验检查 / 药房发药 / 护理记录 / 排班管理 / 费用结算（敏感）/ 患者隐私信息（敏感）。
- 默认选中主任医师，已授予 17 / 32 项。
- 管理员「信息科 · 管理员 吴桐」。

## 复现验收清单

- [ ] 1280 宽下三栏宽度为 240px / 自适应 / 300px，主色为青绿 `#0f8b80`。
- [ ] 矩阵为 8 行 × 4 列复选格，三个敏感模块名后有红色「敏感」标。
- [ ] 默认「保存权限」与「撤销修改」都禁用。
- [ ] 勾选主任医师「药房发药 · 新建 / 编辑」后格子出现琥珀光圈、角色项出现琥珀点、底栏提示「1 项修改未保存」，右侧预览「药房发药」变为「可编辑」。
- [ ] 取消某行「查看」后同行其余格子清空并禁用，预览显示该模块「隐藏」。
- [ ] 点「保存权限」后琥珀标记消失并出现审计编号提示。
- [ ] 切到预览「已保存」时显示保存前的菜单状态。
- [ ] 窄于 1180px 时预览栏移到下方。
