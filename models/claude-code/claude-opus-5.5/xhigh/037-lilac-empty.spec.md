# 037 列表空态

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |

## 内容与数据

- 头部「今天」「10 月 23 日 · 周五 · 霜降」，头像「糖」。
- 周条 19–25 日（周一至周日），今天为 23 日。
- 空态标题「今天还没有待办」；说明「清单空空，云朵在打盹。写下第一件想完成的小事，哪怕只是『喝一杯水』。」
- 模板：晨间例行（起床后喝一杯温水 / 拉伸 10 分钟 / 吃早餐不看手机）、专注工作、睡前放松。
