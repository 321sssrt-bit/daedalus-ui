## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 键帽 | 3 列网格，每键高 56px，圆角 12px；最后一行「删除 / 0 / 验证」 | `#3a3f46`→`#2c3035` 渐变 | 悬停变亮；按下或实体键盘按同一数字时下沉 3px、底部厚度消失（0.06s）；焦点 2px 琥珀描边 |
| 主操作「验证」 | 键盘右下键 | 琥珀渐变 `#ffbf33`→`#e09a00`，深色字 15px 700 | 未满 6 位禁用（暗褐渐变、`#7a7260` 字）；满 6 位启用；回车同效；核对中 500ms |
| 数码屏 | 内边距 16px 18px 14px，6 个 48×54px 位（第 3 位后多 14px 间隔），扫描线叠层 | 琥珀字，当前位下划线闪烁 | 错误：数字变红、输入器抖动 0.35s、提示「✕ 验证码不正确，还可尝试 N 次」并清空；成功：数字变绿、提示「✓ 验证通过…」、所有键禁用；3 次错误后显示「已锁定 05:00」逐秒倒数，键盘禁用 |
| 方式切换 | 3 等分分段控件，高 34px | 透明底灰字 | 选中底 `--panel-hi` 带内高光；切换时清空输入、更新屏幕标签和提示；仅短信显示倒计时行；锁定状态下只有「恢复码」可点并解除锁定 |
| 重发倒计时 | 30px 圆环（半径 12，周长 75.4）+ 文案 + 「重新发送」按钮 | 60 秒 | 环每秒按比例走完；归零后按钮可用并重新弹出通知 |
