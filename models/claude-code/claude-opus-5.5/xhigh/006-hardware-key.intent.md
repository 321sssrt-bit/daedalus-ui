# 006 二次验证

## 意图元数据

- 意图版本：1
- 对应规范：`006-hardware-key.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

二次验证本质是"再拧一道锁"，所以把输入区做成一台实体密钥器：琥珀数码屏、有厚度的键帽、走秒的倒计时环。硬件隐喻让高权限用户感到稳重可靠；错误、剩余次数和锁定都直接显示在屏幕上，并给出恢复码和管理员两条退路。

## 适用场景与目标用户

企业密钥托管、云控制台、交易所后台、运维堡垒机等高权限系统的二次验证；用户是安全管理员和工程师，熟悉 TOTP 与恢复码，在意可控性和明确的失败原因。

## 非目标

- 不做面向大众的轻量验证弹窗。
- 不使用明亮扁平或卡通锁头插画。
- 不实现硬件 U 盾、生物识别等其他认证方式。

## 复刻提示词

石墨深灰拉丝底的企业二次验证页：中央 440px 圆角 22px 的实体设备面板，顶部三段分段控件（短信 / 验证器 App / 恢复码），下方近黑数码屏显示 6 位琥珀发光等宽数字和扫描线，再下是 30px 倒计时圆环和"重新发送"，底部 3×4 有厚度的深灰键帽键盘，右下角琥珀色"验证"键。输错数字变红抖动，三次锁定 5 分钟；右上角模拟短信通知滑入显示验证码。
