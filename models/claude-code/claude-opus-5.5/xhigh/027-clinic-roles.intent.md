# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-clinic-roles.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

医院信息系统的权限配置一旦出错，要么医生开不了处方，要么隐私泄露。所以界面要"改之前看得见后果"：矩阵里每个改动的格子都带琥珀光圈，角色列表标出未保存，右侧直接模拟这个角色登录后的菜单，并可在"修改后/已保存"之间对照。薄荷青的临床配色干净、低刺激，敏感模块用红字单独标出。

## 适用场景与目标用户

医院 HIS、诊所管理、药房系统、企业后台等多角色系统的权限管理页；用户是信息科管理员或 IT 运维，配置频率低但责任重，需要审计留痕。

## 非目标

- 不做细粒度到字段级、数据行级的权限规则编辑器。
- 不用深色科技风或高饱和配色。
- 不实现角色创建向导与用户分配。

## 复刻提示词

医院信息系统风角色权限页：淡薄荷底、白色圆角面板三栏。左栏角色列表带彩色首字头像，选中项薄荷底加青色左条，未保存时出现琥珀小点；中栏是 8 个功能模块 × 查看/编辑/审批/导出的复选矩阵，青色圆角勾选框，敏感模块旁红色"敏感"小标，改动过的格子带琥珀光圈，未勾"查看"则整行禁用；底栏显示"n 项修改未保存"和青色"保存权限"；右栏吸顶"切换预览"，模拟工作站菜单按可编辑/只读/隐藏三态显示，可在"修改后/已保存"间切换。
