# 034 正在播放

## 意图元数据

- 意图版本：1
- 对应规范：`034-vinyl-player.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

"正在听"是一种状态而不是一个列表，所以主视觉是一张会转、会停的黑胶：播放时唱臂落下，暂停时抬起，比一个小图标更直观地说明此刻的状态。每首歌带自己的配色，切歌时整屏背景跟着换色，像换了一张唱片封套。控件按使用频率由中间向两侧递减，播放键最大最亮。

## 适用场景与目标用户

音乐流媒体、播客、有声书、电台 App 的全屏播放页；用户在通勤或居家时听歌，常单手操作，偶尔看一眼歌名和进度。

## 非目标

- 不做歌词滚动、评论区与社交分享。
- 不用扁平极简白底播放器。
- 不实现真实音频播放与均衡器。

## 复刻提示词

复古黑胶播放器手机页（390px 手机框）：整屏是焦橙到深棕的纵向渐变叠细噪点；顶部收起按钮、"正在播放 · 专辑 夏夜电台"；中间一张 300px 带细密纹路和高光的黑胶唱片，中心黄色标签写专辑名，右上角奶油色唱臂播放时落下、暂停时抬起；下方 26px Baskerville 曲名、歌手、圆形心形按钮；琥珀色进度条和时间；控制条为随机、上一首、78px 奶油色圆形播放键、下一首、循环；底部显示输出设备和"播放队列"胶囊，点开从底部滑出毛玻璃队列，切歌时背景整体换色。
