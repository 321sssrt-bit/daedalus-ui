# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-foil-ticket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

抢到演唱会门票是值得庆祝的时刻，凭证应该像一张想收藏的实体票：彩虹镭射票头、打孔线和半圆缺口、点阵入场码。信息层级按入场时最常看的顺序排：日期与时间 → 座位（最大）→ 票档与观演人 → 订单编号；费用明细和入场须知收进折叠，不抢主角；底部一个荧光绿"完成"收尾，彩纸只在进入时撒一次。

## 适用场景与目标用户

演出、电影、展览、体育赛事、火车与航班等带座位或场次的购票成功页；用户是年轻观众，常截图分享，入场时需要快速出示座位与入场码。

## 非目标

- 不做加购推荐、优惠券弹窗与广告位。
- 不用白底绿勾的通用支付成功模板。
- 不实现真实二维码生成与转赠流程。
