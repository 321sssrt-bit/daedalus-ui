## 设计意图

户外装备的购买决策集中在"规格对不对、库存有没有"。整套设计系统用橄榄绿、沙色、卡其和一抹落日橙，像一家实体户外店的木架与帆布；规格选择把库存直接写在尺码按钮上（缺货斜纹、剩 n 件），提交前再做一次库存校验。缺货不是一个弹窗报错，而是把问题行就地展开成"修复区"：减量、改选有货规格或移除，修好即可重新提交，购物车内容一件不丢。

## 适用场景与目标用户

户外运动、服装鞋履、数码配件等多规格、库存敏感的垂直电商；用户是周末徒步、露营的城市青年，熟悉网购，最怕付款时才发现"没货了"。

## 非目标

- 不做直播带货、秒杀倒计时与满减叠加计算。
- 不用白底红色促销的平台电商风格。
- 不实现登录、真实支付、物流追踪与售后。

## 复刻提示词

户外装备商店单页原型：橄榄绿吸顶顶栏（山形字标、分类胶囊、半透明搜索、橙色计数的"装备袋"），沙色页面；首页是橄榄渐变头图配山脉剪影和三格权益，下方 4 列圆角商品卡（SVG 装备插画、颜色点、Avenir 粗体价格）；详情页左大图右选项，圆形色块、带"剩 n"角标和缺货斜纹的尺码按钮、黑框步进器、橙色"加入装备袋 · ¥金额"；装备袋与结算是左明细右吸顶合计卡，每行有虚线"⚡ 演示：模拟此规格被他人抢购"；提交时库存不足会出现抖动的红色提示，问题行展开"减到 n 件 / 改选有货规格 / 移除"，修好后提交得到带橄榄卡其条纹顶边的订单回执。
