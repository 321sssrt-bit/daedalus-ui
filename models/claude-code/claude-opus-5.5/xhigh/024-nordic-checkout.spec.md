# 024 结账

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`024-nordic-checkout.html`
- 复现范围：木隅家居的支付确认页，含步骤条、收货地址、配送与安装选项、三种支付方式（银行卡展开表单）、发票开关，以及右侧吸顶的订单摘要、强调金额与确认支付和成功态。
