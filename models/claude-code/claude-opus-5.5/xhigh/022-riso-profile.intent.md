# 022 个人主页

## 意图元数据

- 意图版本：1
- 对应规范：`022-riso-profile.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

插画师的主页本身就该是一件作品。借用 Riso 双色印刷的语言：荧光粉、中蓝与黄正片叠底，字名故意套色错版，全页蒙一层纸张颗粒，让页面像一本手工小志。功能上把"关注"和"约稿"放在最显眼的位置，约稿直接给表单和档期，作品、动态、商店三条路径分开。

## 适用场景与目标用户

插画师、漫画作者、独立设计师、手作人的个人主页或创作者平台主页；访客是粉丝、出版社编辑和品牌方，前者想关注，后者想快速判断风格并发起合作。

## 非目标

- 不做简历式时间线和技能条。
- 不用极简白底大图作品集模板。
- 不实现私信、粉丝列表等社交功能。

## 复刻提示词

Riso 印刷小志风插画师主页：米色纸底叠细噪点，左侧 260px 圆形头像由荧光粉网点、中蓝圆和黄色椭圆正片叠底组成，中间 120px Futura 粗体蓝色"AYOU"带粉色错版副本，下方中文名、黄色高亮身份和三枚歪斜贴纸；右侧黑框数据三格、粉色"＋ 关注"和黄色"约稿 / 合作"直角按钮（蓝色硬阴影）。下方粗黑线页签"作品/动态/商店"，选中项粉色粗下划线；作品为 4 列黑框三色几何插画，悬停微微歪斜，点击弹出带粉色硬阴影的大图。
