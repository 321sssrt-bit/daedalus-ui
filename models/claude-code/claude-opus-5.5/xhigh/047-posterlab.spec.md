## 内容与数据

- 文档「我的设计 / 秋日市集 · 主视觉 · 1080 × 1350」。
- 图层：主标题（「秋日市集」，132px，#2b1d14）/ 副标题（「11.02 — 11.03 · 西溪湿地 · 32 家摊主」）/ 图形 · 太阳（直径 300，水平 540，#e8622c）/ 背景（#f2e3c6）；画布顶部固定小字「AUTUMN MARKET · 2026」，底部两层山丘。
- 导出倍率：1×（1080 × 1350）/ 2×（2160 × 2700）。
- 冲突规则：JPG 不支持透明背景；PNG、JPG 不能保存动画；SVG 可同时保留透明与动画。
- 文件名格式「秋日市集-主视觉@{倍率}x.{格式}」。

## 正常流程

1. 选中「主标题」，把文字改为「秋日集市」→ 画布标题即时改变。
2. 选中「图形 · 太阳」，拖动「大小」滑杆 → 太阳实时变大。
3. 在导出区保持 PNG、倍率 1×，点「导出」→「正在导出…」→ 结果卡显示「秋日市集-主视觉@1x.png · 1080 × 1350 · n KB」、缩略图与「⤓ 下载文件」，最近导出新增一条。

## 异常触发与恢复

- 触发：打开「透明背景」，选择导出格式「JPG」，点「导出」（或打开「呼吸动画」后选择 PNG / JPG 导出）。
- 反馈：不生成任何文件；导出区出现抖动的红色块「无法导出：设置互相冲突」，逐条写明冲突（「JPG 不支持透明背景，透明区域会被填成白色」或「PNG 是静态位图格式，无法保存『呼吸动画』」），提示行变为「请先处理上面的冲突」。
- 恢复：点修复按钮「关闭透明背景」「改用 PNG」「关闭动画」或「改用 SVG（保留动画）」，也可手动切换格式 / 开关；冲突消失后红块隐藏，提示「✓ 冲突已解决，可以重新导出」。
- 重新成功：再次点「导出」→ 生成文件并显示结果卡（例如透明 PNG，或含动画的 SVG）。

## 人工验收步骤

正常闭环：
1. 打开页面 → 在属性栏把主标题改成任意文字 → 画布同步变化。
2. 选「图形 · 太阳」→ 调大小滑杆 → 太阳变大。
3. 保持 PNG → 点「导出」→ 看到绿色结果卡，点「⤓ 下载文件」可保存 PNG。

异常恢复：
1. 打开「透明背景」→ 画板变棋盘格。
2. 选「JPG」→ 点「导出」→ 出现红色冲突块，没有结果卡。
3. 点「改用 PNG」→ 提示冲突已解决 → 点「导出」→ 得到透明 PNG 结果卡。
4. 打开「呼吸动画」→ 点「导出」→ 再次被拦截 → 点「改用 SVG（保留动画）」→ 点「导出」→ 结果卡标注「含动画 · 透明」。
