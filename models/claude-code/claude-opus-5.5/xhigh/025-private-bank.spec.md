# 025 账号设置

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`025-private-bank.html`
- 复现范围：恒誉私人银行的账户设置页，含海军蓝侧栏与客户经理、客户身份行、三组可展开设置（个人资料 / 登录与安全 / 通知偏好）及其表单、开关、设备移除与保存反馈。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 设置行（点开出现详情） | 整行按钮 + 展开区 | 收起，箭头朝下 | 悬停底 `#faf6ec`；点击展开（同时只展开一行，`aria-expanded`），箭头旋转朝上 0.2s，展开区 0.22s 下滑淡入；焦点 2px 金色内描边；默认展开「称谓与姓名」 |
| 主操作「保存修改 / 更新密码」 | 高 38px，内边距 0 20px，直角 | `--navy` 底白字 13px 600 | 悬停 `--navy-2`；手机号不合法、当前密码为空、新密码不足 10 位或两次不一致时对应输入边框变 `--warn` 并显示红字原因；通过后右侧显示绿色「✓ 已保存」1.8s，并更新行值与状态（如「刚刚修改 / 已更新」「138 **** 0000 / 待验证」） |
| 次按钮「取消」 | 同尺寸描边 | 透明底 | 悬停边变深；点击收起该行 |
| 开关 | 44×24px，圆钮 18px | 关闭米灰轨 | 开启海军蓝轨、金色圆钮右移 20px（0.2s）；硬件令牌开关为必选、禁用（不透明度 0.5） |
| 受信任设备 | 设备名 + 位置 / 时间；非当前设备有「移除」 | 2 台 | 「移除」悬停浅红底；点击后该设备消失，行值变「1 台」 |
| 侧栏导航 | 每项内边距 11px 28px，左 3px 透明边 | 灰蓝字 | 悬停变白；当前项白字、金色左边、`--navy-2` 底 |
