# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-private-bank.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

私人银行客户希望设置页像一份装帧讲究的档案：海军蓝、象牙白、细金线和 Palatino 衬线带来稳重与私密感。信息组织上把每项设置做成"标签—当前值—状态"的一行，点开才出现表单，所以页面平时安静；"建议更新"这类状态直接写在行尾，让安全提醒不用弹窗。客户经理始终在侧栏底部，提醒客户有人可以找。

## 适用场景与目标用户

私人银行、财富管理、高端保险、家族办公室的客户端设置页；用户是高净值客户及其助理，年龄偏大，重视隐私与可信度，操作频率低但每次都很谨慎。

## 非目标

- 不做游戏化积分、营销弹窗和花哨插画。
- 不用年轻化的圆角卡片与高饱和色。
- 不实现证件上传与线下业务办理。

## 复刻提示词

私人银行账户设置页：左侧 248px 海军蓝 #13233f 侧栏，衬线行名"恒誉私人银行"、金色英文副标，当前导航项金色左竖条，底部固定客户经理信息；右侧象牙白底，34px Palatino 标题，身份行是带 4px 金色左条的纸色卡片（海军蓝圆形金字字母徽、"◆ 鉴藏级客户"金框标签、衬线资产数字）；三组设置用金色字距拉开的小标题加细线分隔，每行"标签 / 当前值 / 状态 / 箭头"，点开在米色区域展开直角表单与海军蓝金钮开关。
