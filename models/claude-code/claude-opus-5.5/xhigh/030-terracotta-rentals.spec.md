## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`030-terracotta-rentals.html`
- 复现范围：栖岸租房的找房页：顶部搜索、左侧吸顶筛选面板（区域、租金双滑块、户型、朝向、三个开关）、结果计数与已选条件、排序、房源结果卡与收藏、无结果状态与清除。

## 内容与数据

- 城市：厦门（可选泉州、福州）；顶栏说明「个人房东直租 · 0 中介费」。
- 区域：思明 / 湖里 / 集美 / 海沧；户型：一室 / 两室 / 三室+；朝向：朝南 / 南北通透 / 朝东 / 朝西。
- 7 套房源，如「中山路 · 骑楼改造一室 带小露台」思明 · 38㎡ · ¥3,200/月（近地铁、可养宠物、可月付）；「五缘湾 · 海景三室」湖里 · 118㎡ · ¥9,800/月；「曾厝垵 · 文艺一室」¥2,400/月。
- 排序：最新发布 / 租金从低到高 / 租金从高到低 / 面积从大到小。
- 卡片附「押一付一 / 押一付三」与每平米单价。

## 复现验收清单

- [ ] 1280 宽下左侧 300px 白色圆角筛选面板吸顶，含至少 4 组筛选。
- [ ] 默认显示「7 套房源」，「清除全部」为灰色禁用。
- [ ] 选择「湖里」后计数变 2，头部出现橄榄色「湖里 ✕」胶囊。
- [ ] 把最高租金拖到 ¥3,000 后只剩月租不超过 3000 的房源，计数同步。
- [ ] 打开「可养宠物」开关后计数再次减少。
- [ ] 条件过严时显示虚线无结果卡，点「清除全部条件」恢复 7 套。
- [ ] 排序选「租金从低到高」后第一张为 ¥2,400 的房源。
- [ ] 窄于 820px 时筛选面板移到列表上方。
