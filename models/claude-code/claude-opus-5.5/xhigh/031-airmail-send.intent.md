# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-airmail-send.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

群发邮件和寄信一样：一旦投进邮筒就拿不回来，但它不是"删除"，不需要恐吓式的红色警告。航空信封的红蓝斜纹边、邮票和邮戳把"寄出"这个动作具象化；后果用一句人话讲清；确认门槛是两件真正该做的检查加上输入期号，防止发错期。寄出后信封飞走、投递数字滚动，给人确定的完成感。

## 适用场景与目标用户

Newsletter 群发、App 推送、版本发布、公告推送、批量短信等不可撤回但非破坏性的操作确认；用户是内容编辑和运营，操作熟练，最怕的是手滑发错版本。

## 非目标

- 不做危险删除式的黑红警示风格。
- 不在此页编辑邮件内容或选择受众分组。
- 不实现 A/B 测试与发送数据报表。

## 复刻提示词

航空信封风群发确认页：浅灰蓝点阵桌面上一张 860px 米黄信封卡，四周是红蓝相间的 45° 航空斜纹边框，顶部打字机字体"PAR AVION · 航空 · 第 128 期"和虚线；左侧宋体大标题"这一封寄出去，就收不回来了"，红色左条后果说明，打字机字体的寄件人/收件人/标题信息，"立即发送/定时发送"直角分段，两项方框勾选和"请输入期号 128"输入框；红色硬阴影按钮"确认发送给 12,480 人"在条件满足前禁用，旁边描边"返回修改"；右侧一枚齿孔邮票和墨绿圆形邮戳。确认后信封飞出，显示投递进度。
