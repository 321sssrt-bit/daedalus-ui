# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-corkboard-board.spec.md`

## 设计意图

小编辑部的选题会本来就围着一块软木板开。把看板还原成实物：木框、软木颗粒、图钉、牛皮纸列名和四色便签，让"挪一张便签"的动作有手感；负责人用便签颜色和圆章表示，逾期用红字直接写在纸上。拖拽之外提供菜单和方向键，保证不用鼠标也能移动。

## 适用场景与目标用户

独立杂志、自媒体工作室、设计小组、课题小组的选题或任务看板；团队 3–8 人，习惯线下便签墙，想要轻量、有温度的线上替代。

## 非目标

- 不做企业级泳道、工时统计、甘特图。
- 不用扁平白卡片加彩色标签的通用 SaaS 看板样式。
- 不实现便签详情页与评论。

## 复刻提示词

拟物软木板选题看板：深棕木纹墙上挂一块 14px 木框的软木板，软木用两层错位小圆点做出颗粒；四列标题是斜贴的牛皮纸条加半透明胶带，楷体字；便签为黄/粉/蓝/绿四色，顶部一枚红色立体图钉，奇偶微微左右倾斜，悬停回正上浮。便签可拖拽换列，右上角"⋯"打开移动菜单，列底有白色虚线"＋ 新便签"，点开变成可填写的黄色草稿便签。
