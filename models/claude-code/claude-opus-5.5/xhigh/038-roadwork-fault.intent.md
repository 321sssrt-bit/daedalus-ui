# 038 故障

## 意图元数据

- 意图版本：1
- 对应规范：`038-roadwork-fault.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

"这条路暂时走不通"本身就是一个路况比喻，所以干脆把故障页做成一块施工告示牌：满屏施工黄、黑色粗字、斜纹路障和闪灯。比可爱插画更直接地说明"不是你的问题，是我们在修路"。人话说明先安抚（包裹没事），工单号方便报给客服，预计时间给出等待的终点，重试和回首页始终吸在底部触手可及。

## 适用场景与目标用户

物流、出行、外卖、银行等移动 App 的服务故障页与降级页；用户在着急查东西时撞上故障，需要立即知道是谁的问题、要等多久、还能做什么。

## 非目标

- 不做抱歉卡通人物和大段道歉文案。
- 不展示技术堆栈信息或原始报错。
- 不实现客服对话与故障订阅管理。

## 复刻提示词

施工告示牌风手机故障页（390px 手机框）：整屏施工黄 #ffcc00，外围深灰斜纹；顶部一幅扁平插画：沥青路面、白色车道线、橙白斜纹路障写着"前方施工"、两盏交替闪烁的橙灯和锥桶；下方黑底黄字等宽错误码"ERR 503 · 物流轨迹服务"，38px 窄体粗黑标题"这条路暂时走不通"，说明里的关键词用黑底黄字；白色粗黑边工单卡显示等宽工单号和黄色"复制"按钮，橙点预计恢复时间，可展开的"现在还能做什么"；底部吸附黑底黄字"重试一次"和黑框"回到首页"，第二次重试成功后标题变"路通了"并显示物流轨迹。
