# 046 团队协作产品

## 意图元数据

- 意图版本：1
- 对应规范：`046-cobalt-crew.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

团队任务工具每天被高频使用，所以界面要密、要快：暖灰底、白色任务行、钴蓝只用于"当前""进行中"和主操作。每一次变更都能在右侧时间线里追溯到"谁、把什么、从哪改成哪"。权限问题不靠静默失败：锁定任务用斜纹底和锁标提前告知，真去改时弹窗讲清缺什么权限、这次没写入，并给出两条出路：申请，或回到自己能做的事。

## 适用场景与目标用户

设计团队、产品研发团队、市场部的项目任务管理；用户是团队成员与组长，需要跨团队查看但不越权修改，重视操作可追溯。

## 非目标

- 不做甘特图、工时统计与 OKR 对齐。
- 不用彩色卡片看板与插画式空态。
- 不实现评论、附件、审批流和通知中心。

## 复刻提示词

钴蓝暖灰团队协作原型：三栏布局，左侧 220px 浅暖灰项目栏（当前项目白底高亮，其他团队项目带紫色"🔒 只读"），中间白色顶栏写"官网改版"、叠放成员头像和钴蓝"＋ 新建任务"，任务按"待办/进行中/待审核/已完成"分组为紧凑白色行：优先级小色块、等宽编号、标题、头像负责人、彩色圆角状态胶囊、等宽截止日期和"→"推进键，财务专属任务为浅紫斜纹底带锁标；右侧 340px 详情含负责人下拉、四段状态按钮和带彩色节点的活动记录时间线。修改锁定任务会弹出写明"需要财务组 · 编辑者，这次修改没有写入"的弹窗，可"申请编辑权限"或"返回我的任务"。
