# 044 社交社区产品

## 意图元数据

- 意图版本：1
- 对应规范：`044-pebble-feed.spec.md`

## 设计意图

同城兴趣社区应该像河滩上的石子：圆润、温和、各不相同。卵石形头像、28px 大圆角卡片和石灰底让信息流不吵闹。发布时最敏感的是"谁能看到"，所以可见范围做成四个带说明的大选项，选择会同步显示在作者行和发布后的标签上；发布失败时不跳走、不清空，用一句话告诉人"草稿和范围都还在"，一个按钮重新发布。

## 适用场景与目标用户

同城社区、兴趣圈子、校园论坛、邻里群的手机端动态流与发布；用户是喜欢户外、咖啡、散步的城市青年，会根据内容私密程度选择发给谁。

## 非目标

- 不做算法推荐流、直播与带货。
- 不用高饱和渐变和霓虹社交风格。
- 不实现评论详情、私信与多媒体上传。

## 复刻提示词

卵石风同城社区手机原型（390px 手机框）：暖石灰 #f4f1ea 底，左上卵石形标志与粗体"石子"，黑底胶囊分类"同城/关注/圈子"；动态是 28px 大圆角白卡，卵石形彩色头像、可见范围小标签、扁平山丘或街景插画、"♡ 💬 ↗"操作；右下橘色卵石形"＋"，底部白色圆角标签栏。编辑页：顶部"取消 / 新动态 / 橘色发布胶囊"，大圆角文本框与字数，三张插画配图格、话题胶囊、四个带图标说明的可见范围大选项，底部虚线卡片"演示：让本次发布失败"开关；失败时红框提示草稿已保留并可"重新发布"，成功后新卡带橘色光晕置顶。
