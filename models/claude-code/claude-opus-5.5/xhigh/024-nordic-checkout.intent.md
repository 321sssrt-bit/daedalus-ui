# 024 结账

## 设计意图

买大件家具时，付款前的那一眼最需要安心。北欧家居的语言是留白、细线和自然材质色：冷调米白底、白卡片、橡木与鼠尾草点缀，金额用细体大字安静地放大，而不是用红色喊出来。所有影响金额的选择（配送、安装、支付方式、分期）都即时反映在右侧摘要和按钮文案上，确认按钮上直接写出将要支付的数额。

## 适用场景与目标用户

家居、家电、高客单价生活方式品牌的结账页；用户是装修或换新的城市家庭，单笔金额较高，会仔细核对配送、安装和发票。

## 非目标

- 不做倒计时催单、凑单推荐和弹窗优惠券。
- 不用高饱和电商红与密集信息。
- 不实现地址编辑、真实支付渠道对接。

## 复刻提示词

北欧家居风结账页：冷调米白 #f6f5f2 底，顶部极细字标"木隅 MUYU"字距拉开和三步圆点步骤条；左侧 34px 细体标题"付款前，最后看一眼"，下面按"送至 / 配送与安装 / 支付方式 / 开具发票"分节，选项是白色细边卡片，带圆形单选和小色块图标，选中时黑色双线描边，银行卡可展开三栏卡号表单，发票用灰绿开关；右侧 420px 吸顶白色订单摘要，橡木椅子与落地灯线描缩略图，44px 细体应付金额，深炭色满宽按钮写明"用微信支付支付 ¥3,870"。
