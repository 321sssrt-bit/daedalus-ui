# 023 收藏夹

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`023-nightwall-saves.html`
- 复现范围：夜廊灵感收藏页：深色画廊墙上的瀑布流收藏卡（图片、色板、字体样张、文章、摘录），分类切换、排序、搜索、置顶与取消收藏（可撤销）。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 100% 宽 | 纵向：标题栏 → 分类条 → 瀑布墙 | 背景 `--wall`；页面滚动 |
| 标题栏 | 内边距 32px 48px 20px | flex 底部对齐，间距 28px：54px 衬线标题 / 等宽统计 / 搜索框（宽 260px、高 40px，`margin-left:auto`） | — |
| 分类条 | 内边距 0 48px 22px，下边框 1px `--line` | flex 换行，间距 10px：6 个分类胶囊 / 排序（右对齐） | — |
| 瀑布墙 | 内边距 28px 48px 64px | CSS 多列 `columns: 4 260px`，列间距 20px；卡片 `break-inside: avoid`，下外边距 20px | — |
| 撤销条 | 底部居中，距底 24px | flex 文案 + 按钮 | z-index 10，5s 后消失 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 收藏卡 | 媒体区（SVG 图片 / 5 格色板 120px 高 / 字体样张 / 文章摘要 / 衬线摘录）+ 说明（标题、来源、日期）；左上类别标；右上两个 32px 圆形操作 | `--card` 底 | 悬停上浮 3px 并显示操作按钮（键盘聚焦卡内元素时同样显示）；取消收藏：缩小到 0.96 淡出 0.22s 后移除，出现撤销条；置顶：2px 紫描边、类别标变紫底并显示「置顶 · 」，排序到最前 |
| 分类胶囊 | 高 34px：全部 / 摄影 / 建筑 / 字体 / 配色 / 文章，附等宽计数 | 透明底灰字 | 悬停字变亮；选中 `--text` 底深色字；计数随移除与撤销变化 |
| 排序 | 等宽文字按钮：最近收藏 / 最早收藏 | 「最近收藏」紫色 | 切换后按收藏时间重排（置顶始终在前） |
| 搜索框 | 宽 260px、高 40px 胶囊 | `--card` 底 | 聚焦边框紫色；按标题与来源实时过滤；无结果显示斜体「这里还空着」与说明 |
| 撤销条 | 浅底深字胶囊，内含深色「撤销」 | 隐藏 | 移除后上移淡入，5s 自动消失；点击撤销恢复该卡 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 px | 4 列瀑布 | 标题 54px |
| 多列规则 | 每列最小 260px，宽度不足时自动减列 | — |
| 窄于 860px | 标题栏换行，搜索框满宽；内边距 20px；瀑布 `columns: 2 160px`，列间距 14px | 标题 40px；排序不再右对齐 |

## 内容与数据

- 标题「我的收藏」，统计「10 件 · 6 个分类 · 最近同步 14:32」。
- 10 件收藏（按最近）：清晨六点的巴黎屋顶（摄影）/ 为什么好的界面会"消失"（文章）/ 苔藓与锈（配色）/ Baskerville 斜体（字体）/ 光之教堂的十字窗（建筑）/ 原研哉谈留白（文章摘录）/ 京都雨后的苔寺（摄影）/ 混凝土楼梯的阴影（建筑）/ 午夜霓虹（配色）/ 思源宋体 Heavy（字体）。
- 每类 2 件；日期从「3 天前」到「2 个月前」。

## 复现验收清单

- [ ] 页面为 `#161616` 深底，标题「我的收藏」为 54px Baskerville，「收藏」为紫色斜体。
- [ ] 1280 宽下收藏卡排成 4 列瀑布流，卡片高度各不相同。
- [ ] 至少包含图片、色板、字体样张、文章和摘录五种卡片形态。
- [ ] 点「配色」分类只剩 2 张色板卡，胶囊计数为 2。
- [ ] 悬停卡片点「✕」后卡片淡出，底部出现撤销条，点「撤销」恢复。
- [ ] 点「☆」置顶后卡片出现紫色描边并排到最前。
- [ ] 窄于 860px 时变为 2 列。
