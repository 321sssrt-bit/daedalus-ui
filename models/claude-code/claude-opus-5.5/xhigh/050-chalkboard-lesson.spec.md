## 内容与数据

- 面包屑「初中物理 / 第四章 光现象 / 光的折射」；本周学习初始 120 分。
- 目录：光的直线传播 ✓ / 光的反射 ✓ / 光的折射（12 分钟 · 讲解 + 3 道练习）/ 平面镜成像 / 透镜初识。
- 讲解：筷子「折断」现象、偏折方向、规律框「空气 → 水：折射角 < 入射角」、示意图（入射角粉色、折射角蓝色、法线虚线）。
- 练习：① 空气斜射入水时折射角与入射角关系（正确 B）；② 岸边看池底比实际（正确 C 更浅）；③ 30° 入射时反射角（正确 30）。每个错误选项都有专属解释。
- 计分：一次答对 10 分，订正成功 5 分，满分 30。

## 产品边界

- 实现：课程目录与进度、知识讲解（文字 + 示意图）、选择题与填空题作答、结果与解释、错误答案状态、再次作答（排除已试选项）、订正成功反馈、本节结果汇总与积分。
- 不包含：视频课、错题本独立页面、老师批改、讨论区、学习计划与排行榜。

## 正常流程

1. 讲解页阅读折射规律与示意图，点「开始练习 · 3 题 →」。
2. 第 1 题选 B「折射角小于入射角」→ 提交 → 绿框「答对了！」与解释、+10 分 → 「下一题 →」。
3. 第 2 题选 C「更浅」→ 答对 → 「下一题 →」。
4. 第 3 题填 30 → 答对 → 「查看本节结果 →」→ 汇总 30 / 30，目录第 3 节变为已完成、进度 3 / 5。

## 异常触发与恢复

- 触发：在任一题提交页面提供的错误选项或错误数值（例如第 1 题选 A「折射角大于入射角」，或第 3 题填 22）。
- 反馈：所选选项（或输入框）变红，所有选项禁用；出现红框「✗ 答错了，先别急」，给出针对该错误的解释（例如「光进入更『密』的介质（水）时会向法线方向偏折，所以折射角会变小」），并说明可回到题目再答且不扣分。
- 恢复：点「↺ 再试一次」回到同一题，错过的选项变为虚线「（已试过）」并禁用（填空题提示上次填写的值），重新选择正确答案提交。
- 订正成功：出现蓝框「↻ 订正成功！」与正确解释、+5 分，进度点变蓝；汇总中该题标记「订正成功」。

## 人工验收步骤

正常闭环：
1. 打开页面 → 点「开始练习 · 3 题 →」。
2. 第 1 题选 B → 提交 → 绿框「答对了！」→「下一题」。
3. 第 2 题选 C → 提交 →「下一题」；第 3 题填 30 → 提交 →「查看本节结果」。
4. 看到 30 / 30 与「已完成 3 / 5 节」。

异常恢复：
1. 在汇总页点「重新练习」。
2. 第 1 题选 A → 提交 → 看到 A 变红与红框解释。
3. 点「再试一次」→ A 显示「（已试过）」不可选 → 选 B → 提交 → 蓝框「订正成功！」，进度点变蓝。
4. 完成其余两题后，汇总中第 1 题标记为「订正成功」。
