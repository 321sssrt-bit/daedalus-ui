# 007 欢迎空态

## 意图元数据

- 意图版本：1
- 对应规范：`007-seedling-empty.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态的任务是把"什么都没有"变成"马上开始"。植物养护天然适合"种下第一株"的比喻：一只空花盆里刚冒出的芽，配一句手写问候，减轻冷启动的冷感。主按钮只要一个名字就能完成；次要行动让犹豫的人先看示例，不必承诺。

## 适用场景与目标用户

家庭植物养护、宠物照护、习惯记录等生活类 SaaS 的首次进入空态；用户是刚下载应用的城市租房青年，对植物了解有限，需要低门槛开始与温和的提醒。

## 非目标

- 不做强制品种识别、拍照上传或账号资料填写。
- 不用冷色科技感或深色模式。
- 不实现浇水日历、日记等其他页面。

## 复刻提示词

温和鼠尾草绿的植物养护应用空态：左侧 232px 浅绿侧栏，顶部 68px 顶栏写城市天气；中央插画是陶土色花盆和轻轻摇摆的两片绿叶、右上角一轮淡黄太阳，下面楷体手写问候"早上好，阿禾"、34px 粗标题"花园还空着，先种下第一株吧"；一个绿色胶囊主按钮"＋ 种下第一株"和一个描边胶囊"先逛逛示例花园"，下方三张圆角说明卡用楷体陶土色序号。点击主按钮弹出圆角 24px 对话框，添加后变成植物卡片网格。
