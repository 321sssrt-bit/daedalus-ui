# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-oxblood-mail.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

出版社编辑每天读大量作者来信，信件本身是文学性的。界面用酒红封皮色侧栏、米色列表和纸色阅读区，正文换成宋体和宽行距，让"读信"回到阅读的节奏；效率功能（过滤、星标、归档撤销、快捷键）照样齐全，但退到安静的工具条里。

## 适用场景与目标用户

出版社、文学经纪、律所、咨询公司等以长邮件沟通为主的专业团队；用户是编辑和顾问，每封信都要细读和回复，重视语气和附件。

## 非目标

- 不做营销邮件分类、AI 摘要或聊天式会话视图。
- 不用纯白冷色的通用企业邮箱风格。
- 不实现写信完整编辑器与联系人管理。

## 复刻提示词

酒红书卷气的三栏邮箱：左侧 220px 深酒红侧栏，社名用宋体、金色描边"写 信"按钮与金色计数；中间 380px 米色邮件列表，顶部宋体标题、搜索框和酒红胶囊过滤，未读邮件带红点并加粗，选中项纸色底加酒红左条；右侧纸色阅读区，28px 宋体信件标题，16px 宋体正文行高 1.95，附件卡片和圆角回复框。归档后底部弹出可撤销提示。
