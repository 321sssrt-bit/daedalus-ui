# 043 即时通讯产品

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`043-nightowl-chat.html`
- 复现范围：夜枭手机即时通讯的单页原型：会话列表（搜索、未读、在线）→ 会话页（消息气泡、输入、发送中 / 已送达 / 已读）；以及会话页顶部「演示：模拟断网」使下一条消息发送失败、失败消息保留原文并可在恢复网络后重试为已送达。

## 产品边界

- 实现：会话列表与搜索、未读与在线状态、会话页消息流、文本输入（多行、草稿）、快捷回复、发送状态（发送中 / 已送达 / 已读）、断网模拟、失败保留与重试。
- 不包含：图片 / 语音 / 文件消息、群管理、消息撤回与引用、音视频通话、端到端加密设置。

## 状态地图

| 状态 | 进入方式 | 退出方式 |
| --- | --- | --- |
| 会话列表 list | 初始；会话页「‹」 | 点会话行 → 会话页 |
| 会话页 chat（在线） | 点会话行 | 「‹」返回列表 |
| 断网（异常前置） | 会话页点「演示：模拟断网」 | 再次点击开关恢复在线 |

| 消息：已送达 / 已读 | 在线发送成功 | — |
| 消息：发送失败（异常态） | 断网状态下发送或重试 | 恢复网络后点「重试」 |

## 正常流程

1. 列表点「林小满」→ 进入会话，未读徽标清零，滚动到最新消息。
2. 在输入框输入「我到入口了」→ 发送按钮可用。
3. 点发送（或回车）→ 气泡出现在右侧，状态「发送中」。
4. 0.9s 后状态变「✓ 已送达」；对方在线，再 1.4s 变「✓✓ 已读」。

## 异常触发与恢复

- 触发：会话页右上角胶囊「演示：模拟断网」→ 变红「已断网 · 点恢复」，并出现横幅「⚠ 网络不可用，接下来发出的消息会失败…」。
- 反馈：发送下一条（例如「排队的人好多」）→ 发送中 0.9s 后失败：气泡改为红底红边，左侧出现红色「↻ 重试」，下方说明「发送失败 · 内容已保留…」；会话列表预览显示「⚠ 有消息发送失败」。原文不丢失，不会被清空。
- 恢复：点「已断网 · 点恢复」恢复在线 → 点该消息的「↻ 重试」→ 发送中 → 「✓ 已送达」（对方在线时随后变已读）。
- 若仍在断网状态点重试：再次失败并保留，直到恢复网络。

## 数据变化

| 时点 | 消息记录 | 状态 | 草稿 |
| --- | --- | --- | --- |
| 发送 | 末尾追加一条我方消息 | sending | 清空 |
| 在线 0.9s 后 | 不变 | sent（已送达） | — |
| 对方在线再 1.4s | 不变 | read（已读） | — |
| 断网发送 | 追加一条 | sending → fail，文本保留 | 清空 |
| 恢复后重试 | 同一条消息，不新增 | sending → sent | — |

## 人工验收步骤

正常闭环：
1. 打开页面 → 点「林小满」。
2. 输入「我到入口了」→ 点「↑」→ 看到「发送中」。
3. 约 1 秒后显示「✓ 已送达」，再约 1.5 秒显示「✓✓ 已读」。

异常恢复：
1. 在会话页点右上「演示：模拟断网」→ 看到红色横幅。
2. 输入「排队的人好多」→ 发送 → 约 1 秒后气泡变红，出现「↻ 重试」与「内容已保留」说明。
3. 点「已断网 · 点恢复」→ 横幅消失。
4. 点该消息的「↻ 重试」→ 发送中 → 「✓ 已送达」，气泡恢复蓝色。
