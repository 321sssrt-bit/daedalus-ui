# 023 收藏夹

## 意图元数据

- 意图版本：1
- 对应规范：`023-nightwall-saves.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

人攒下来的灵感应该像挂在墙上的作品一样被好好陈列。深色画廊墙让图片、色板、字体样张这些不同形态的收藏都能各自发光；瀑布流保留原始比例，不强行裁成方块。界面元素压到最低：分类胶囊、等宽小字和悬停才出现的操作；取消收藏可以撤销，置顶用一圈紫色描边标出。

## 适用场景与目标用户

设计师灵感库、稍后读、摄影收藏、Moodboard 工具的收藏页；用户是设计师、摄影师和内容创作者，收藏量大、类型杂，需要偶尔回顾和整理。

## 非目标

- 不做社交化的点赞、评论与推荐流。
- 不用白底卡片加彩色标签的效率工具风格。
- 不实现文件夹层级与批量编辑。

## 复刻提示词

深色画廊墙风收藏夹：#161616 底，左上 54px Baskerville 标题"我的收藏"（"收藏"薰衣草紫斜体），旁边等宽小字统计，右侧胶囊搜索框；下方一排描边胶囊分类（带等宽计数，选中反白）和右侧"最近收藏/最早收藏"文字排序；主体是 4 列 CSS 瀑布流，卡片形态各异：渐变剪影照片、5 格色板、米色字体样张、文章摘要、衬线斜体摘录，左上黑色半透明类别标，悬停出现圆形"☆ 置顶""✕ 移除"按钮，移除后底部浮出可撤销的浅色胶囊。
