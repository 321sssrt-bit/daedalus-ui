# 016 成员目录

## 意图元数据

- 意图版本：1
- 对应规范：`016-studio-roster.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

建筑事务所的成员页本身就是作品集的一部分。清水混凝土灰、窄体大字和安全橙来自工地与图纸的语言；头像统一做成灰度剪影，悬停才显出个人色，让网格整齐而不呆板。筛选按工作室、专业、状态三条真实维度组织，点开后的简介强调年限和代表项目。

## 适用场景与目标用户

建筑、设计、咨询类事务所的内部通讯录或官网团队页；访问者是新同事、合作方和潜在客户，需要按城市或专业快速找到对的人。

## 非目标

- 不做组织架构树或汇报关系图。
- 不用圆形头像加彩色徽章的通用 HR 系统风格。
- 不实现即时通讯与日程。

## 复刻提示词

建筑事务所风成员目录：清水混凝土灰底，左上 64px 窄体粗黑标题"垣筑·成员"中间橙点，右侧 2px 黑框直角搜索框；左侧 240px 筛选栏用方形黑框复选框（选中黑底中心橙点）；右侧 4 列卡片网格以 2px 灰缝拼接，头像是灰度渐变剪影加右下角窄体首字，悬停恢复彩色，状态点绿/橙/灰；点击从右侧滑出 440px 白色面板，大首字头图、三格事实、简介和代表项目，橙色"发消息"按钮。全页无圆角、无阴影。
