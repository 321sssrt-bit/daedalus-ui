## 设计意图

在手机上写长一点的文字，最需要的是专注和安全感。暖黑底、米白宋体、宽行距和琥珀色光标，像夜里在台灯下写字；界面把干扰压到边缘：顶部一行状态告诉你"已经保存"，底部一行字数和阅读时长告诉你"写了多少"。发布前再用一个弹层确认可见范围，避免把私人日记误发到首页。

## 适用场景与目标用户

写作社区、博客、长文 App、日记 App 的手机编辑器；用户是业余写作者，常在通勤和睡前写作，担心丢稿、在意排版和读者反馈。

## 非目标

- 不做富文本复杂排版、多图拼贴与模板。
- 不用白底蓝色按钮的通用表单风格。
- 不实现图片上传与 Markdown 预览。

## 复刻提示词

暖黑专注写作手机页（390px 手机框）：#1a1714 暖黑底，顶栏左"取消"、中间带绿点的"草稿已保存 14:32"、右侧琥珀色胶囊"发布"；编辑区顶部一块虚线封面占位，26px 宋体粗标题"外婆的旧缝纫机"，一排描边话题胶囊（选中琥珀色），下面 17px 宋体米白正文、行高 1.95、琥珀光标；底部深色工具区有 B / 「」/ — / ※ 格式键，22px 琥珀字数环与"n / 2000 字 · 约 m 分钟读完"和描边"存草稿"。点发布从底部滑出可见范围选择，确认后出现琥珀印章"墨"的发布成功页。
