# 033 钱包首页

## 意图元数据

- 意图版本：1
- 对应规范：`033-jade-wallet.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

钱包首页要同时给人"安心"和"顺手"。深翡翠配奶油色和一点金，比常见的蓝色金融 App 更有私人感；余额是唯一的大字，旁边就是隐藏开关，方便在公共场合使用。四个快捷入口压在头部边缘，转账作为最常用动作单独加深；流水按日期分组，收入用绿色、支出用中性深色，不让每一笔消费都显得像警报。

## 适用场景与目标用户

移动支付钱包、银行 App 首页、记账 App；用户是日常高频使用手机支付的都市白领，每天查看余额与最近消费，偶尔转账收款。

## 非目标

- 不做信息流广告、理财产品推荐轮播与红包营销。
- 不用高饱和渐变卡面与 3D 金币插画。
- 不实现完整转账流程与账单分析页。

## 复刻提示词

翡翠奶油色手机钱包首页（390px 手机框）：顶部深翡翠绿圆角头部，金色圆形头像、"下午好 沈宁"、带红点的铃铛，"总资产（元）"旁一个可隐藏金额的眼睛按钮，42px Avenir 余额"¥48,260.35"（小数较小较浅）和金色昨日收益；一张奶油色白卡片向上压住头部底边，内含四个圆角方形快捷入口（转账为深绿底金色图标）；下面是翡翠渐变的月预算条和"最近流水"列表（日期分组、彩色圆角图标、收入绿色）；底部 84px 白色四项导航；点击入口或流水从底部滑出圆角弹层。
