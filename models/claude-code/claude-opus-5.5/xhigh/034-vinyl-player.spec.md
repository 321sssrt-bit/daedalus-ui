## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 播放 / 暂停 | 78px 圆，奶油底深棕字 | 载入后即播放（显示「❚❚」） | 点击切换；按下缩放 0.94；播放时唱片 3.2s 一圈旋转、唱臂从 -24° 落到 -4°（0.7s）；暂停时唱片停转、唱臂抬起；空格键同效 |
| 进度条 | range，4px 高，已播段 `--accent`，16px 奶油圆钮 | 1:12 / 4:03 | 播放中每秒前进；拖动即时更新时间；播完自动下一首（循环开启则从头） |
| 上一首 / 下一首 | 56px 图标按钮 | — | 下一首：切换曲名、歌手、专辑名、唱片标签色与背景渐变（0.6s）；上一首：已播放超过 3 秒先回到开头，否则切上一首 |
| 随机 / 循环 | 40px 图标 | `--dim` | 激活变 `--accent`（`aria-pressed`）；随机时下一首跳一首，队列标题显示「随机」 |
| 喜欢 | 44px 圆，1.5px 半透明边 | 「♡」 | 点击变琥珀底深色「♥」 |
| 播放队列 | 底部「播放队列 ☰」胶囊 → 弹层 5 行（44px 迷你唱片 + 曲名歌手 + 时长） | 隐藏 | 0.3s 上滑；当前曲行高亮且曲名琥珀色；点任一行立即播放并收起；Esc 关闭 |
