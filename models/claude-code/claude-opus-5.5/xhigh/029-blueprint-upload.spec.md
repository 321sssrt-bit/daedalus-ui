## 内容与数据

- 顶栏「造物工坊 ／ 3D PRINT」，步骤「01 上传模型 / 02 选择材料 / 03 确认下单」，草稿「PRJ-2610-0458」。
- 初始队列 3 个：齿轮箱_外壳_v3.stl 18.4 MB（✓ 检查通过 · 网格封闭，约 46 g · 3.2 h）；台灯底座_镂空.3mf 42.7 MB（⚠ 壁厚 0.6 mm 低于建议 0.8 mm）；无人机支架_左.obj 6.1 MB（上传中 42%）。

## 复现验收清单

- [ ] 页面为深蓝图纸底，可见 100px 主网格与 20px 细网格。
- [ ] 拖放区为 2px 虚线框，左上与右下有直角对位标，含「选择文件…」按钮。
- [ ] 队列至少两行，每行显示文件名、大小（MB）与状态。
- [ ] 上传中的文件进度条持续增长，完成后变为绿色「✓ 检查通过」。
- [ ] 点「载入示例模型」后新行上传完成并显示红色失败与「重试」。
- [ ] 删除一个文件后队列计数与右侧预估同步变化。
- [ ] 把层厚切到 0.1 mm 后预计工时增加；点「开始处理」后文件变为「排队切片中…」。
- [ ] 窄于 1060px 时参数卡移到下方。
