# 021 内容目录

## 设计意图

文学刊物的目录是"读前的第一次阅读"。沿用纸本杂志的目录页制度：大号 Didot 编号、宋体标题、页码靠右，黑白之外只留一种红。左侧封面栏用主题和卷首语交代这一期的情绪；点开条目看到的是作品里的一段引文，而不是营销式简介，让读者凭文字决定先读哪篇。

## 适用场景与目标用户

文学杂志、独立出版、Newsletter 合集、播客季目录、学术期刊的期目录页；读者是爱阅读的人和文学从业者，习惯纸质杂志，愿意慢慢挑。

## 非目标

- 不做无限滚动信息流和推荐算法排序。
- 不用卡片网格配大图缩略。
- 不实现正文阅读器与付费墙。

## 复刻提示词

文学季刊目录页：纸白底黑字，唯一强调色为红 #d7261e。左侧 400px 吸顶封面栏，96px Didot 刊名"回声."（红句点），粗细双线期号条，34px 宋体主题"迁徙与留下"，首字下沉的宋体卷首语，底部四格 Didot 数字和黑色订阅按钮。右侧目录每行：46px Didot 编号、红色小字体裁、23px 宋体标题、"文 / 作者"、右对齐页码，1px 浅灰分隔；悬停编号变红，点击展开带红色竖线的宋体引文与"在线试读"。顶部文字过滤用红色下划线标示选中。
