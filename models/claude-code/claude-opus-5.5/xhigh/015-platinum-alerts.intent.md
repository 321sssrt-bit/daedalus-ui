# 015 通知中心

## 意图元数据

- 意图版本：1
- 对应规范：`015-platinum-alerts.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

通知中心本质是一张"事件清单"。借用 90 年代白金色桌面系统的语言：斜面按钮、条纹标题栏、表格式列表和便笺黄的展开详情。复古外观背后是很现代的功能：类型图标、未读点、过滤、批量已读确认，以及"需处理"视图，让系统事件和人发来的事分得清。

## 适用场景与目标用户

桌面操作系统、远程桌面、企业内网门户或怀旧主题的生产力工具的通知面板；用户是办公室职员和对复古界面有好感的极客，需要快速扫一遍、只处理要紧的几条。

## 非目标

- 不做移动端卡片流式通知。
- 不使用毛玻璃、大圆角和渐变。
- 不实现通知偏好设置与推送渠道管理。

## 复刻提示词

90 年代白金色桌面风通知中心：蓝灰棋盘抖动纹桌面，顶部 24px 浅灰菜单栏右侧有带红色角标的"通知"；中央 780px 浅灰窗口，1px 黑边加硬阴影，标题栏为横向细条纹；工具条上有斜面分段按钮"全部/未读/需处理"和双环默认按钮"全部标为已读"；白色表格列表含展开三角、16px 像素风类型图标、内容、来源和等宽时间，未读行加粗带蓝点，选中行整行蓝底白字，展开后是便笺黄详情和操作按钮。
