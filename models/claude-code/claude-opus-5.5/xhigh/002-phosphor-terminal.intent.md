# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-phosphor-terminal.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

开发者对"注册"最大的疑问是"注册完我能马上干什么"。所以左边放一段真实终端会话，把注册后的第一条命令先写出来；右边表单用等宽标签和「›」提示符延续命令行语感。荧光绿只给主按钮、光标和通过态，其余全部压暗，减少营销感，保留工具感。

## 适用场景与目标用户

面向后端与全栈开发者的 SaaS 工具（隧道、日志、API 网关、CI）的注册页；用户习惯终端和深色编辑器，注重速度与透明度，讨厌冗长的问卷式注册。

## 非目标

- 不做大幅插画、3D 渲染或渐变光斑背景。
- 不在注册时收集公司规模、职位等营销字段。
- 不实现第三方 OAuth 授权流程。

## 复刻提示词

深色开发者工具注册页：近黑底加 24px 点阵，左侧大标题"一行命令，把 webhook 接到本地"，下面一个带三圆点标题栏的终端窗口，最后一行是闪烁的荧光绿方块光标；右侧 460px 深灰卡片表单，字段标签用小写等宽英文 + 右侧中文说明，输入框带「›」前缀，有子域名实时预览和 4 段密码强度条；荧光绿主按钮在全部合法前禁用，成功后终端日志同步变绿。
