## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 粒度切换 | 1px 黑框分段：按日 / 按周 / 按月，每段内边距 6px 14px | 透明底黑字 13px 600；默认「按周」 | 悬停底 `--paper-2`；选中黑底纸色字；切换后折线重绘（30 / 12 / 12 个点）且四个关键数字及其对比口径同步更新（「较上周同日」或「环比」） |
| 指标切换 | 同样式：营收 / 订单 | 默认营收 | 切换后纵轴与提示改为订单数（单位 k / 单） |
| 折线主图 | 本期 3px 实线 `--claret` + 7% 同色面积；上期 2px 虚线（5 4）`--teal`；5 条水平虚线网格；末点 5px 实心圆 | 横轴最多 8 个标签，纵轴刻度在右侧 | 悬停任一点：出现 1px 竖向十字线（不透明度 0.35）与黑底提示框，显示标签、本期值、上期值和涨跌百分比 |
| 门店排行行 | 3 列：名次门店 / 条形 + 营收 / 环比 | 行间 1px 点线 | 悬停底 `--paper-2`；选中字色 `--claret` 加粗；点击或 Enter 后下方点评更新 |
| 关键数字 | 标签 12px → 数值 34px 衬线 → 增减 13px 600 | 上升 `--up`、下降 `--down` | 随粒度切换刷新 |
