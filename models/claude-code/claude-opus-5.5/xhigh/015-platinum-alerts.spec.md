# 015 通知中心

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`015-platinum-alerts.html`
- 复现范围：方舟 OS 桌面上的「通知中心」窗口：菜单栏通知铃与角标、过滤分段、8 条不同类型通知、展开详情、单条已读切换、全部标为已读确认框。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 通知行 | 5 列网格，偶数行底 `#f4f4f8`；未读行内容加粗、左侧 7px 实心蓝点，已读为空心灰圈 | — | 单击选中（蓝底白字）；点三角或双击、Enter、空格展开 / 收起并标为已读；三角展开时旋转 90°（0.12s）；↑ / ↓ 移动选中 |
| 详情区 | 整行宽，内边距 10px 12px 12px 54px，上边 1px 虚线 `#b9a24a` | 便笺黄底 | 显示说明与 1–2 个操作按钮（首个为默认按钮）；点操作后按钮前加「✓」并把该条标为已读、移出「需处理」 |
| 「全部标为已读」 | 默认按钮（双环），高 22px | 有未读时可用 | 点击弹出确认框「要把所有未读通知标为已读吗？」；确认后全部变已读、角标消失、按钮禁用（字色 `--plat-lo`） |
| 过滤分段 | 全部 / 未读 / 需处理，相邻按钮共用边 | 「全部」按下（`#9a9a9a` 底、内凹、白字） | 切换过滤列表；计数「n 条 · m 未读」更新 |
| 标为已读 / 未读 | 工具条按钮 | 文案跟随当前选中项状态 | 切换选中项的已读状态 |
| 菜单栏通知铃 | 「通知」文字按钮 + 红色圆角标 | 按下态蓝底白字 | 角标显示未读数，为 0 时隐藏；点击显示或隐藏窗口 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 px | 窗口 780px 居中，右侧三个桌面图标 | 列表 5 列 |
| 窄于 860px | 桌面图标隐藏；窗口宽 `100% - 24px` | 列表去掉「来源」列，变 4 列 |

## 内容与数据

- 8 条通知（时间倒序）：磁盘空间不足（警告、需处理）/ 林以安的信使消息 / 夜间备份失败（错误、需处理）/ 15:00 产品周会日程 / 方舟 OS 8.6.1 更新 / 打印完成 / 周岚共享文件夹 / 已连接无线网络。
- 初始前 5 条未读，角标 5；第 1 条默认展开。
- 状态栏：「8 条通知」「勿扰模式：关」「上次同步 下午 2:32」。

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |

## 复现验收清单

- [ ] 桌面为蓝灰 `#5d7fa8` 棋盘抖动纹，顶部 24px 白金色菜单栏，右侧有带红色角标的「通知」。
- [ ] 窗口宽 780px，标题栏为横向细条纹，中间白金底标题「通知中心」。
- [ ] 列表有 8 条不同图标的通知，未读行加粗并带蓝点。
- [ ] 点击某行三角，下方展开便笺黄详情，该行变为已读，角标数减 1。
- [ ] 点「需处理」只剩 2 条；点详情里的操作后该条移出。
- [ ] 点「全部标为已读」弹出确认框，确认后角标消失、按钮变灰。
- [ ] 窄于 860px 时「来源」列隐藏。
