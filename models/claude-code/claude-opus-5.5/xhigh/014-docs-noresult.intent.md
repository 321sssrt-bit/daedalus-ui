# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-docs-noresult.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

开发者搜不到组件时，真正想知道的是"有没有替代方案"。所以无结果页不是一张空白插画，而是一页排查清单：先承认没有，并直接给出组合实现的思路；再依次给出纠错、减词、按分类浏览，最后给提需求的出口。原搜索词始终留在搜索框和标题里，减少重新输入。

## 适用场景与目标用户

组件库、API 文档、开发者中心、知识库的站内搜索；用户是前端工程师和设计师，搜索词往往很具体，期望被引导而不是被说教。

## 非目标

- 不做全站营销推荐或"热门文章"填充。
- 不用大面积插画和情绪化文案。
- 不实现真实的全文索引或 AI 问答。

## 复刻提示词

现代开发者文档风搜索无结果页：白底三栏（左 240px 浅灰目录、中间内容、右 220px 本页目录），顶部吸顶搜索框紫色描边并保留原词"日期范围选择器 带时区"；内容区左侧一枚淡紫放大镜插画，26px 标题里用荧光黄标出搜索词，下面依次是浅紫"你是不是要找"建议条（带紫色按钮）、可点击的胶囊改搜标签（第一个对多余词加删除线）、三张带迷你预览的相关组件卡，以及虚线框"提交组件需求"。点建议可得到结果并能回到原搜索。
