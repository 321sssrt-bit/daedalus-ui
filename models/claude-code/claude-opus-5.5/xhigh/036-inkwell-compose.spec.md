# 036 编辑发布

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`036-inkwell-compose.html`
- 复现范围：墨水瓶写作 App 的手机编辑页：顶部取消 / 保存状态 / 发布，封面、标题、话题、正文，格式工具条与字数状态、存草稿，发布可见范围弹层与发布成功页。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 发布 | 顶栏右侧，高 34px，内边距 0 16px | 琥珀底深字 14px 700 | 标题为空、正文少于 20 字或超过 2000 字时禁用（`--line` 底）；可用时点击打开发布弹层 |
| 标题 / 正文 | 无边框文本区，随内容自动增高；标题最长 40 字 | 宋体 26px / 17px，琥珀色光标 | 输入时保存状态变「正在编辑…」（琥珀点），停 1.2s 后变「已自动保存 HH:MM」（绿点）；错误提示清空 |
| 字数状态 | 22px 进度环（周长 56.5）+「n / 2000 字 · 约 m 分钟读完」 | 环琥珀色按字数比例 | 超过 2000 字时数字与环变红；阅读时长按 400 字 / 分钟 |
| 格式工具 | B / 「」/ — / ※ 四个按钮 | 灰字 | 悬停浅底；在光标处插入或包裹选中文字（加粗 `**…**`、直角引号、破折号、分隔符） |
| 存草稿 | 高 32px 描边胶囊 | — | 点击状态变「已存入草稿箱 · 共 4 篇草稿」 |
| 发布弹层 | 三个单选：所有人可见（默认）/ 仅关注我的人 / 仅自己 | 选中项琥珀边与淡琥珀底 | 「再改改」或点遮罩关闭；「确认发布」进入成功页，文案随可见范围变化 |
| 封面与话题 | 封面 120px 虚线占位；话题胶囊 28px | #家族记忆 已选 | 封面点击切换为渐变封面；话题点击切换选中，「＋ 话题」变为「#回忆」 |

## 内容与数据

- 标题「外婆的旧缝纫机」；话题：#家族记忆（已选）/ #散文 / #物件 / ＋ 话题。
- 正文三段约 140 字，从「外婆家的那台缝纫机是蝴蝶牌的」开始。
- 初始状态「草稿已保存 14:32」；字数上限 2000。
- 发布弹层摘要：「n 字 · 已选话题 · 有封面（如有）」。
- 成功页：所有人可见「你的第 23 篇文章已经和读者见面了」；仅关注「已推送给 1,284 位关注你的人」；仅自己「已存为仅自己可见的私密日记」。
