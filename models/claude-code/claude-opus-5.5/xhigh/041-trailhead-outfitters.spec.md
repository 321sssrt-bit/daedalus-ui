## 正常流程

1. 浏览页点击「雾凇 3L 冲锋衣」→ 进入详情，默认颜色「苔绿」，尺码未选，主按钮禁用并提示「请先选择尺码」。
2. 选择尺码「M」→ 库存行显示「现货 12 件」；点「＋」数量变 2 → 主按钮显示「加入装备袋 · ¥2,598」。
3. 点击「加入装备袋」→ 顶栏计数变 2 并回弹，右下提示「已加入装备袋…」。
4. 点「去结算」进入装备袋 → 合计显示小计 ¥2,598、免运费、应付 ¥2,598；可加减数量，合计即时变化。
5. 点「去结算」→ 确认订单，选择配送（标准 / 次日达 +¥25）与支付方式，摘要同步。
6. 点「提交订单 · ¥x」→ 0.7s「正在核对库存…」→ 回执页显示订单号、明细、实付；对应规格库存扣减。

## 异常触发与恢复

- 触发：装备袋每行都有虚线胶囊「⚡ 演示：模拟此规格被他人抢购」。点击后该规格库存被改为 1（数量 >1 时）或 0（数量 =1 时），按钮变为「已模拟：他人刚抢购了该规格」并出现提示。
- 反馈：进入确认订单点「提交订单」，校验失败：顶部红色提示「库存不足，订单未提交」并列出「商品名（颜色 · 尺码）：已售罄 / 仅剩 n 件，需要 m 件」；问题行以红边浅红底展开；摘要中该行标「库存不足」；提交按钮禁用为「请先处理库存问题」。订单不生成，库存不扣减。
- 恢复：在问题行选择「减到 n 件」，或在「改选有货规格」下拉中选另一颜色 / 尺码（只列有货规格），或「移除这件」。每次操作后重新校验，全部满足时提示消失、提交按钮恢复。
- 重新成功：再次点击「提交订单」→ 回执页，明细显示修正后的规格与数量。

## 人工验收步骤

正常闭环：
1. 打开页面 → 看到头图与 8 件商品。
2. 点「雾凇 3L 冲锋衣」→ 选「苔绿」「M」→ 点一次「＋」→ 按钮显示 ¥2,598。
3. 点「加入装备袋」→ 顶栏计数 2；点提示中的「去结算」→ 装备袋应付 ¥2,598。
4. 点「去结算」→ 选「次日达」→ 应付变 ¥2,623。
5. 点「提交订单」→ 回执页显示订单号与实付 ¥2,623。

异常恢复：
1. 回到浏览，任选商品加入装备袋（例如「雾凇 3L 冲锋衣」苔绿 · M × 2）。
2. 在装备袋点该行「⚡ 演示：模拟此规格被他人抢购」→ 按钮变为「已模拟…」。
3. 点「去结算」→「提交订单」→ 看到红色「库存不足，订单未提交」，指出「苔绿 · M：仅剩 1 件，需要 2 件」，提交按钮禁用。
4. 点「减到 1 件」（或在下拉中改选「苔绿 · L」）→ 提示消失，提交按钮恢复金额。
5. 点「提交订单」→ 回执页显示修正后的数量 / 规格与实付金额。
