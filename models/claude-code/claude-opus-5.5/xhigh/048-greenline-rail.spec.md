## 正常流程

1. 搜索页默认「杭州东 → 上海虹桥 · 10/24 明天」，点「查询车次」→ 0.5s 后显示 5 趟车次。
2. 点「G7535 08:15 → 09:20」→ 选座页默认二等座 05 车，选择一个可选座位（如 06F）→ 底栏「¥73 座位 06F」，「下一步」可用。
3. 点「下一步」→ 确认页显示车次、区间、日期、席位、乘车人与票价。
4. 点「提交并支付」→「正在锁座…」0.9s → 行程凭证：出票成功、电子客票（时间、车次、05 车 06F、二等座、¥73、检票口 A12、订单号）。

## 异常触发与恢复

- 触发：结果页中带黄色虚线和「⚠ 二等座余票紧张 · 确认订单时会再次校验」标注的 G7311，选择二等座任一座位 → 下一步 → 「提交并支付」。
- 反馈：校验失败，确认页顶部出现抖动的红色块「G7311 二等座已售罄 · 就在刚才，05 车 xxX 及本车次剩余二等座已被抢完，订单未生成，也不会扣款。你的路线和日期都已保留」；提交按钮禁用为「该座位不可售」；该车次二等座余票置 0，该座位标为已售。
- 恢复：点「返回结果改选」→ 结果页保留原路线与日期，顶部提示「已为你保留路线…」，筛选切到「只看有票」；G7311 二等座显示「售罄」（一等座仍可选）。
- 重新成功：改选 G7535（或 G7311 一等座）并选座 → 下一步 → 提交 → 生成电子客票。

## 人工验收步骤

正常闭环：
1. 打开页面 → 点「查询车次」。
2. 点「G7535」→ 任选一个浅绿座位 → 点「下一步」。
3. 点「提交并支付」→ 看到「出票成功」与电子客票，车厢座位与所选一致。

异常恢复：
1. 点「再订一张」→「查询车次」。
2. 点带黄色虚线的「G7311」→ 二等座任选座位 → 「下一步」→「提交并支付」。
3. 看到红色「G7311 二等座已售罄」与「订单未生成」，提交按钮禁用。
4. 点「返回结果改选」→ 顶部显示保留的「杭州东 → 上海虹桥 · 10/24」，G7311 二等座为售罄。
5. 点「G7535」→ 选座 → 下一步 → 提交 → 得到电子客票。
