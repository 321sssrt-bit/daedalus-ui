# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-blueprint-upload.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

3D 打印的用户是做东西的人，模型文件就是他们的图纸。整页用工程蓝图语言：深蓝底、双层网格、粉笔白线稿和对位角标，让上传区像一张等待放置零件的图纸。上传之后最重要的是"能不能打"，所以每个文件不仅显示大小和进度，还显示几何检查结论（通过、壁厚警告、破洞失败可重试），右侧参数改动即时反映到耗材、工时和价格。

## 适用场景与目标用户

3D 打印服务、CNC 加工、PCB 打样、印刷文件交付等需要上传工程文件并自动预检的平台；用户是创客、工业设计师和小型硬件团队，熟悉文件格式，关心可制造性与报价。

## 非目标

- 不做通用网盘式的文件夹管理。
- 不用柔和插画与圆角卡片风。
- 不实现 3D 模型实时预览与支付。

## 复刻提示词

工程蓝图风 3D 打印上传页：深蓝 #0b3c6f 底叠 100px 主网格与 20px 细网格，粉笔白线稿和等宽字；左侧 2px 虚线拖放区，左上右下有直角对位标，中间一个线稿立方体和"把 STL / OBJ / 3MF 文件拖到这里"，两个直角描边按钮；下方实线框上传队列，每行有线稿缩略图、等宽文件名、MB 大小和状态（青色进度条、绿色通过、黄色警告、红色失败带重试）及删除；右侧 360px 参数卡带"SHEET 1/1"图签、材料下拉、层厚与填充率分段、等宽预估汇总和满宽亮黄"开始处理"按钮。
