# 032 危险删除

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`032-slate-delete.html`
- 复现范围：棱镜数据平台删除整个工作区：将失去什么清单与导出备份建议、输入工作区名称与勾选确认、显著的取消与默认禁用的删除、10 秒可取消倒计时与删除完成态。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |

| 删除「删除工作区」 | 居中，高 44px，内边距 0 18px，1.5px 边 | 默认禁用：`--line` 边、`--faint` 字 | 名称完全一致且勾选后启用为红色描边红字；悬停红底白字；点击进入 10 秒倒计时 |
| 名称输入 | 高 46px，等宽字 | 深底 1.5px 边 | 聚焦蓝边 + 光；完全匹配变红边红光，提示「名称一致…」；部分前缀提示「继续输入…」；不一致提示检查拼写；禁止粘贴并提示「为防止误操作，请手动输入名称」 |

| 导出备份 | 琥珀描边小按钮 | — | 点击后禁用并显示「备份已开始 · 完成后邮件通知」 |

## 内容与数据

- 标题「永久删除工作区 prism-analytics」；说明「删除后…24 小时内从所有节点清除，无法恢复，客服也无法找回」。
- 将失去：数据库与数据表 184（3 个数据库 · 约 2.3 TB）/ 看板与报表 67（含 12 个公开链接）/ 定时任务与数据管道 23 / 成员与访问权限 18。
- 备份建议「建议先导出一份完整备份（约 40 分钟）」。
- 确认词：`prism-analytics`（区分大小写）；勾选文案「我了解删除后数据无法恢复，且本操作会通知全部 18 位成员」。
- 小字：「只有工作区所有者可以执行此操作 · 操作将记录在审计日志 · 当前账号：林砚（所有者）」。

## 复现验收清单

- [ ] 页面为深板岩灰，标题中的工作区名以红色等宽字高亮。
- [ ] 左侧清单列出 4 类将失去的内容及数量，底部有琥珀色备份建议。
- [ ] 右侧「不删了，返回设置」为满宽 54px 浅色按钮，比下方删除按钮更大更亮。
- [ ] 删除按钮默认禁用；只输入正确名称而不勾选时仍禁用。
- [ ] 输入「prism-analytics」并勾选后删除按钮变为红色描边可点。
- [ ] 点击删除出现 10 秒倒计时圆环，可点「取消删除」返回。
- [ ] 窄于 980px 时确认面板移到清单下方。
