# 004 新手引导

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`004-bauhaus-steps.html`
- 复现范围：方块白板首次打开的四步引导，含左侧几何构成画面、右侧步骤文案、步骤点、上一步/下一步、跳过与完成浮层。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 100% 宽、100% 高，最小高 640px | `grid-template-columns: 1fr 1fr`（1280 下各 640px） | 背景 `--paper` |
| 构成画面 | 左半 640×800px | 内部元素绝对定位；以 600×720 设计坐标按 `min(宽/600, 高/720)` 等比缩放 | 背景 `--ink`，`overflow:hidden` |
| 步骤侧栏 | 右半，左右内边距 `clamp(28px,5vw,64px)`（1280 下 64px） | `grid-template-rows: 72px 1fr 96px`：顶栏 / 正文 / 底栏 | 顶栏下边、底栏上边各 2px 黑线 |
| 正文区 | 最大宽 480px | flex 纵向垂直居中：大号步骤数 → 标题 → 说明 → 要点或模板 | `aria-live="polite"` |
| 完成浮层 | 固定全屏 | flex 居中纵向，间距 12px | z-index 5，背景 `--paper` |

## 内容与数据

1. 01「一块没有边的白板」：要点「滚轮缩放，空格拖动画布 / 双击任意空白处直接打字 / 所有改动自动保存」。
2. 02「用形状说话」：要点「按 S 放便签，按 L 拉连线 / 框选后按 G 合成分组 / 右键把便签一键转成任务」。
3. 03「和团队画在同一张纸上」：画面出现两枚协作光标「阿岚」（红标签）「老周」（蓝标签）。
4. 04「挑一个起手式」：模板「头脑风暴 · 便签墙 + 投票」「周会看板 · 三列推进」「空白画布 · 从零开始」。
- 完成浮层：标题「白板已准备好」，副文按所选模板或跳过动态变化；按钮「重新看一遍引导」回到第 1 步。
- 键盘：→ 下一步（最后一步即完成），← 上一步。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 切换步骤（几何） | 0.6s `cubic-bezier(.65,0,.35,1)` | 圆、方、三角、横条、半圆移动并缩放到新构图，光标淡入淡出 | 直接跳到新位置 |
| 切换步骤（文案） | 0.45s ease-out | 正文从右 16px 滑入淡入 | 无位移 |
| 按钮 / 模板卡 | 0.12s / 0.15s | 位移与硬阴影变化 | 立即切换 |
