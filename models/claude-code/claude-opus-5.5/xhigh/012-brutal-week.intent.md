# 012 日历

## 意图元数据

- 意图版本：1
- 对应规范：`012-brutal-week.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

共享空间的排期是给一群创意从业者看的，他们喜欢有态度的东西。新粗野主义的粗黑线、荧光黄和硬阴影让周历像一张印在墙上的海报，四种饱和色块一眼区分会议、工作坊、活动和工位。信息密度不高，留给每件事足够的块面，点开后再在抽屉里看细节。

## 适用场景与目标用户

联合办公空间、工作室、创意社区、独立书店的活动与场地排期；用户是会员和运营人员，关心"这周有什么、哪间房空着、我能不能参加"。

## 非目标

- 不做月视图、年视图或复杂的重复事件规则。
- 不用柔和圆角卡片和低饱和配色。
- 不实现预订冲突检测与支付。

## 复刻提示词

新粗野主义共享空间周历：纯白底，所有分隔用 2–3px 纯黑线；顶栏中段铺荧光黄，写 40px 粗黑日期范围"10.19 — 10.25"和黑框周次标签，右侧三个格子按钮"← 本周 →"；下方一排带硬阴影的类别筛选按钮；7 列时间网格每小时 46px，今天整列淡黄、表头反白，一条橙色当前时间线；事件块用蓝、橙、粉、绿实色填充，黑边加 4px 硬阴影。点击事件从右侧滑出 380px 黑边抽屉显示详情。
