# 032 危险删除

## 意图元数据

- 意图版本：1
- 对应规范：`032-slate-delete.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

真正的危险操作不需要满屏红色，而需要冷静和摩擦。深板岩灰让页面严肃，红色只出现在工作区名和删除按钮上；左侧用具体数字列出将失去的东西，并先建议备份。视觉权重被刻意倒置：最亮、最大的是"不删了"，删除按钮小、描边、默认禁用，要手动输入名称（禁止粘贴）并勾选确认才亮起，最后还有 10 秒可反悔的倒计时。

## 适用场景与目标用户

数据平台、云服务、代码托管、SaaS 的删除工作区 / 删除账号 / 清空数据库页；用户是管理员或所有者，可能在情绪化或疲惫时操作，需要防误触，也需要确定的结果。

## 非目标

- 不做恐吓式警告、闪烁动画或倒计时催促。
- 不提供批量删除或部分删除选项。
- 不实现身份二次验证与数据导出流程。

## 复刻提示词

深板岩灰危险删除页：顶部细面包屑"工作区设置 / 危险操作 / 删除工作区"，左上淡红方形警示图标，28px 标题"永久删除工作区"后接红色等宽高亮的"prism-analytics"；左侧圆角面板列出"你将失去"的 4 类内容（图标、说明、等宽数量）和琥珀色"建议先导出备份"条；右侧 400px 吸顶确认面板：输入工作区名称（完全匹配才变红框，禁止粘贴）、勾选确认，下面是满宽 54px 浅色主按钮"不删了，返回设置"，以及更小的居中红色描边"删除工作区"（默认禁用）。删除后进入 10 秒可取消的红色圆环倒计时。
