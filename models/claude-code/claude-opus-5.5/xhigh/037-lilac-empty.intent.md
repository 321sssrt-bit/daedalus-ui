# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-lilac-empty.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

待办清单空着，可能是"刚开始用"，也可能是"今天全做完了"。两种情况都不该让人有压力，所以用一朵打盹的黏土云和一句轻松的话来说明：空着也没关系。主按钮够大够软，紧接着给出三个习惯模板，让不知道写什么的人一键起步；中间凸起的新建键保证在任何时候都能随手加一条。

## 适用场景与目标用户

待办、习惯打卡、购物清单、阅读清单等列表型 App 的首次空态或清空状态；用户是年轻上班族与学生，喜欢可爱、柔和的界面，希望工具"不催人"。

## 非目标

- 不做效率焦虑式的统计与提醒轰炸。
- 不用冷色线框图标与严肃商务风格。
- 不实现提醒推送、重复规则与协作分享。

## 复刻提示词

淡紫黏土风待办空态手机页（390px 手机框）：#f1edff 淡紫底，左上 32px 圆体"今天"和日期节气，右上桃色圆形头像；一排 7 个白色圆角周日期格，今天紫底白字；中央一朵立体黏土云朵，有黑豆眼、小笑嘴和桃色腮红，旁边漂浮的紫色"z"和三颗彩色小球；下方 22px 标题"今天还没有待办"和温柔说明，满宽 56px 紫色厚底按钮"＋ 新建第一条待办"，再下面横向滑动的习惯模板卡；底部是悬浮的白色圆角底栏，中间一个凸起的深紫方圆"＋"。
