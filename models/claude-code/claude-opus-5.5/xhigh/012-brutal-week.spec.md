# 012 日历

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`012-brutal-week.html`
- 复现范围：砖厂共享空间的周排期日历，含周切换、类别筛选、08:00–20:00 时间网格、事件块、当前时间线和右侧事件详情抽屉。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 事件块 | 绝对定位，高度 = 时长 × 46px - 6px；标题 + 时间 | 按类别填色，黑边硬阴影 | 悬停左上移 2px、阴影 6px；选中 3px 黑色外描边偏移 3px（`aria-pressed`）；点击打开抽屉 |
| 周导航 | 「←」「本周」「→」三个格子按钮 | 白底黑字 15px 800 | 悬停黑底黄字；切换后日期范围、周次、事件分布与统计更新，并关闭抽屉；只有本周显示今日标记与时间线 |
| 类别筛选 | 4 个按钮，2px 黑边 + 2px 硬阴影，左侧 10px 色块 | 全部开启 | 关闭时去掉阴影、不透明度 0.45、文字删除线；日历同步隐藏该类事件，统计数减少 |
| 详情抽屉 | 类别徽章 + 标题；时间 / 地点 / 发起 / 参与定义列表；虚线框备注；「复制邀请」「我要参加」 | 隐藏在右侧 | 打开滑入 0.22s 并聚焦关闭按钮；Esc 或 ✕ 关闭；「我要参加」点击后变「已加入 ✓」，工位类显示「续订一周」；「复制邀请」1.4s 内显示「已复制」 |
| 当前时间线 | 3px 橙线横跨 7 列，左端 14:32 标签 | 位于 14:32 处 | 仅本周显示 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 px | 7 列等分 | 日期范围 40px |
| 窄于 1024px | 时间列 52px，日列最小 84px，日历可横向滚动 | 日期范围 28px；抽屉宽 340px |
| 窄于 760px | 顶栏去掉品牌格；日历最小宽 760px 横向滚动 | 日期范围 22px |

## 内容与数据

- 默认周：2026 年第 43 周「10.19 — 10.25」，今天为 23 日周五。
- 14 个事件，如「产品评审 · 小红楼」周一 09:00–10:30 A 会议室；「独立出版物交换会」周三 15:00–18:00 中庭；「周五啤酒时间」周五 17:00–19:30 屋顶露台；「木工：做一只托盘」周日 15:00–16:30。
- 统计文案「本周 14 项 · 会议室占用率 62%」，筛选或换周后实时变化。
- 类别名称：会议室 / 工作坊 / 社区活动 / 工位预订。

## 复现验收清单

- [ ] 顶栏中间为荧光黄 `#ffe500` 区块，日期范围「10.19 — 10.25」为 40px 粗黑字。
- [ ] 日历左侧 64px 时间列，08:00–19:00 共 12 行，每行 46px，以 1px 黑线分隔。
- [ ] 23 日周五表头为黑底，整列浅黄；14:32 处有一条橙色时间线。
- [ ] 事件块有 2.5px 黑边和 4px 硬阴影，四类颜色分别为蓝、橙、粉、绿。
- [ ] 点击任一事件，右侧 380px 抽屉滑入并显示时间、地点、发起人与备注。
- [ ] 关闭「工作坊」筛选后橙色事件全部消失，统计数减少。
- [ ] 点「→」后日期范围变为「10.26 — 11.01」，时间线消失。
- [ ] 减少动态模式下抽屉无滑动过渡。
