# 017 商店首页

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`017-oolong-house.html`

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
