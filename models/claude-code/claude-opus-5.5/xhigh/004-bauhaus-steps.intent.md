# 004 新手引导

## 意图元数据

- 意图版本：1
- 对应规范：`004-bauhaus-steps.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

白板产品的核心就是形状，所以引导本身就用包豪斯的圆、方、三角讲故事：每一步左侧几何重新构图，暗示画布的自由度；右侧巨大的步骤数让人知道还剩几步。最后一步不是空洞的"完成"，而是让用户挑一个起手模板，把引导和第一次使用接起来。

## 适用场景与目标用户

协作白板、思维导图、设计稿评审类工具的首次启动；用户是第一次打开产品的知识工作者、产品经理和老师，希望 30 秒内知道能干什么，随时可以跳过。

## 非目标

- 不做视频教程、长篇功能清单或强制填写个人资料。
- 不用插画人物、3D 渲染或渐变玻璃。
- 不在引导中真正创建白板内容。

## 复刻提示词

包豪斯风新手引导：左半屏黑底上用红圆、黄方、蓝三角、米色横条和蓝半圆做构成画面，每换一步就平滑重排；右半屏米色纸底，顶部和底部各一条 2px 黑线，中间 160px Futura 大号步骤数"01 / 04"、粗黑标题和三个几何符号要点。底部左侧四个形状不同的步骤点，右侧直角硬阴影按钮"← 上一步""下一步 →"，最后一步变蓝"开始用方块 ✓"并提供三张模板卡；右上角有"跳过引导"。
