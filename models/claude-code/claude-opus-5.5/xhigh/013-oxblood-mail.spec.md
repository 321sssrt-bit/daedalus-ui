# 013 收件箱

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`013-oxblood-mail.html`
- 复现范围：青梧出版社编辑的三栏收件箱：文件夹侧栏、可搜索与过滤的邮件列表、阅读区（星标、归档与撤销、已读切换、附件、回复）。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 100vw × 100vh，最小高 600px | `grid-template-columns: 220px 380px minmax(0,1fr)` | body `overflow:hidden`，各栏独立滚动 |
| 文件夹侧栏 | 宽 220px，内边距 22px 14px | flex 纵向，间距 2px：社名 → 用户 → 写信按钮（高 42px）→ 文件夹 → 书稿分组 | 背景 `--oxblood` |
| 邮件列表 | 宽 380px，右边框 1px `--line` | 列头（内边距 18px 18px 10px：标题、36px 搜索框、过滤胶囊）+ 可滚动列表 | 背景 `--cream`；列表 `overflow:auto` |
| 阅读区 | 剩余宽度 | 工具条（内边距 12px 28px）+ 信件区（内边距 30px 56px 40px） | 背景 `--paper`；信件区 `overflow:auto`；正文最大宽 640px |
| 撤销提示 | 底部居中，距底 24px | flex 文案 + 撤销 | 深色，4s 后消失 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 邮件行 | 3 列网格：7px 未读点 / 发件人 / 时间；下两行主题与预览单行省略；星标在右下 | 奶油底 | 悬停底 `#efe4d4`；选中 `--paper` 底 + 3px 酒红左条；未读加粗并显示红点；打开即标为已读；↑ / ↓ 键切换 |
| 过滤胶囊 | 全部 / 未读 / 星标，内边距 5px 12px | 灰字透明底 | 选中酒红底米色字；悬停 `#e9dccb`；切换后列表与位置计数「n / 总数」更新；无结果时显示宋体空态「这里没有符合条件的信。喝口茶吧。」 |
| 阅读工具条按钮 | 高 32px，1px 边，圆角 6px：星标 / 归档 / 标为未读 | 纸色底 | 悬停边与字变酒红；星标按下态底 `#fbf1dd`、边 `--gold`、文案「★ 已星标」；归档后邮件移出列表、选中下一封，底部提示「已归档…」带「撤销」；已读切换文案随状态变 |
| 回复框 | 最大宽 640px，文本区最小高 80px，底部提示 + 发送按钮（高 34px） | 发送禁用 `#cdb8aa` | 聚焦边框酒红 + 3px 浅光；有内容后发送可用；Ctrl/⌘ + Enter 发送；发送后清空并提示「回复已发送给…」 |
| 搜索框 | 宽 100%，高 36px | 纸色底 | 聚焦边框酒红；按发件人、主题、预览实时过滤 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 px | 220px + 380px + 阅读区 | 侧栏显示文字与计数 |
| 窄于 1180px | 侧栏缩为 72px 图标栏，列表 340px | 侧栏只剩色点；写信按钮显示「✎」；信件区内边距 24px 32px |
| 窄于 820px | 单栏：先显示列表，点开邮件后切换到阅读区 | 工具条出现「← 返回」；页面可滚动 |

## 内容与数据

- 用户「何砚 · 文学编辑部」；文件夹：收件箱（未读数）/ 星标 / 已发送 / 草稿 1 / 已归档 138；书稿分组：《北方的河流》《盐与糖》年度诗选。
- 6 封邮件（时间倒序）：苏迟《北方的河流》第三稿（星标、2 个附件）；鸿印印务打样色差；林浅封面书脊（星标）；版权部授权书；匿名读者来信；发行部销量简报。
- 初始选中第一封并标为已读，列表标题显示「6 封 · 3 未读」。
- 归档会把已归档计数从 138 变为 139，撤销恢复。

## 复现验收清单

- [ ] 1280 宽下三栏宽度为 220px / 380px / 剩余，侧栏为酒红 `#5a1a1f`。
- [ ] 未读邮件左侧有红点、发件人与主题加粗；选中邮件有 3px 酒红左条。
- [ ] 信件正文为 16px 宋体、行高 1.95，最大宽 640px。
- [ ] 点击「未读」过滤只剩未读邮件；在搜索框输入「封面」只剩相关邮件。
- [ ] 点击「归档」后邮件从列表消失，底部出现带「撤销」的提示，撤销后恢复。
- [ ] 在回复框输入文字后发送按钮可用，发送后出现提示。
- [ ] 窄于 1180px 时侧栏缩成 72px 图标栏。
