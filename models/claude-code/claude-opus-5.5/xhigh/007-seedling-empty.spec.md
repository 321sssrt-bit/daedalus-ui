# 007 欢迎空态

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`007-seedling-empty.html`
- 复现范围：苗圃植物养护应用首次进入「我的花园」的空态，含侧栏、顶栏、插画空态、主次行动、添加植物对话框与添加后的花园网格、示例花园。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 主操作「＋ 种下第一株」 | 高 50px，左右内边距 26px，胶囊 | `--leaf` 底白字 16px 600，绿色投影 | 悬停底 `--leaf-deep` 上浮 1px；按下下移 1px；焦点 3px `--sun` 描边；点击打开对话框并聚焦名称 |
| 次要行动「先逛逛示例花园」 | 同尺寸，1.5px `#b9c5ae` 边 | 透明底 | 悬停底 `--surface`、边 `--leaf`；点击载入 5 株示例并显示黄色虚线提示条 |
| 名称输入 | 高 44px，圆角 12px，1.5px 边 | 白底 | 聚焦边 `--leaf` + 4px 浅绿光；空名称提交时显示 12px 赭色「给它起个名字吧」并阻止关闭 |
| 品种标签 | 高 34px 胶囊，间距 8px | 白底 1.5px 边 | 选中 `--leaf` 底白字、`aria-pressed="true"`；默认绿萝 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 px | 侧栏 232px + 主区 | 说明卡与植物网格 3 列 |
| 窄于 980px | 侧栏隐藏；顶栏左右内边距 24px；内容区内边距 28px 24px | 说明卡与网格 2 列 |
| 窄于 640px | — | 单列；主次按钮纵向堆叠；天气文字隐藏 |

## 内容与数据

- 导航：我的花园（计数，初始 0）/ 浇水日历 / 生长日记 / 植物百科 / 设置；提示卡「多数室内植物死于浇水太勤，而不是太少。」
- 顶栏天气：「杭州 · 今日 22°C 湿度 64%」「适合给喜湿植物喷雾」。
- 空态：问候「早上好，阿禾」，标题「花园还空着，先种下第一株吧」，三张说明卡「一 拍照或手动添加 / 二 收到恰好的提醒 / 三 看着它长大」。
- 示例植物 5 株：客厅的龟背竹（2 天后）、窗台迷迭香（今天）、书桌上的熊童子（9 天后）、卫生间的绿萝（4 天后）、阳台三角梅（今天）。
- 添加后：计数 +1，空态隐藏，网格出现新卡，浇水天数等于所选间隔；在示例状态下添加会先清空示例。

## 复现验收清单

- [ ] 1280 宽下左侧 232px 侧栏、顶栏 68px，空态内容最大宽 760px 居中。
- [ ] 插画为陶土色花盆与两片绿叶，手写体问候为 22px 楷体绿色。

- [ ] 点击主按钮弹出 440px 对话框；空名称提交出现错误提示。
- [ ] 填入名称提交后侧栏计数变 1，空态消失，出现植物卡与「＋ 再种一株」。
- [ ] 点击「先逛逛示例花园」出现 5 张卡和黄色虚线提示条，「清空示例」恢复空态。
- [ ] 窄于 980px 时侧栏隐藏、说明卡变 2 列。
- [ ] 减少动态模式下叶片不摆动。
