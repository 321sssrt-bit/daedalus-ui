## 正常流程

1. 首页点「转账」→ 收款人列表；点「林小满」→ 金额页，显示「转给 林小满」和「珊瑚余额 可用 ¥2,368.40」。
2. 用键盘输入「500」或点「¥500」→ 金额显示 ¥500，按钮「下一步 · ¥500.00」；可填写备注。
3. 点「下一步」→ 确认弹层显示金额、收款人、付款方式「珊瑚余额」、手续费免费、实时到账。
4. 点「确认转账」→ 0.8s「正在转账…」→ 转账凭证：绿色对勾、¥500.00、交易单号、对方已到账。
5. 点「完成」→ 首页珊瑚余额变为 ¥1,868.40，账单顶部新增「林小满 −500.00 刚刚」。

## 异常触发与恢复

- 触发：在金额页输入超过所选来源可用额的金额（例如点常用金额「¥3,000」，珊瑚余额只有 ¥2,368.40），金额变红但允许进入确认；在弹层点「确认转账」。
- 反馈：校验失败，弹层内出现红色「余额不足，转账未完成」，写明「珊瑚余额可用 ¥2,368.40，本次需 ¥3,000.00，还差 ¥631.60」；确认按钮禁用为「请先处理余额问题」；余额与账单不变化。
- 恢复：点「改用招商银行储蓄卡」（付款方式立即切换，提示消失，确认按钮恢复），或点「修改金额」回到金额页降低金额。
- 重新成功：再次「确认转账」→ 凭证页显示付款方式「招商银行储蓄卡」；回首页可见储蓄卡余额减少 ¥3,000。

## 人工验收步骤

正常闭环：
1. 首页点「转账」→ 点「林小满」。
2. 点「¥500」→ 点「下一步 · ¥500.00」→ 确认弹层显示珊瑚余额付款。
3. 点「确认转账」→ 看到「转账成功 ¥500.00」与交易单号。
4. 点「完成」→ 首页珊瑚余额为 ¥1,868.40，账单首条为林小满 −500.00。

异常恢复：
1. 首页点「转账」→ 点「房东 王阿姨」。
2. 点「¥3,000」→ 金额与可用余额变红 → 点「下一步」。
3. 点「确认转账」→ 看到「余额不足，转账未完成」与差额 ¥631.60，确认按钮禁用。
4. 点「改用招商银行储蓄卡」→ 付款方式更新，按钮恢复「确认转账」。
5. 点「确认转账」→ 凭证页显示 ¥3,000.00、付款方式招商银行储蓄卡；回首页储蓄卡变为 ¥15,000.00。
