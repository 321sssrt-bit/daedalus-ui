# 047 创作工具产品

## 意图元数据

- 意图版本：1

## 设计意图

创作工具的界面应该退后，把舞台让给作品：深色中性面板、品红只用于选中与导出，画板居中并在透明时显示棋盘格。导出是创作的终点，所以这里真的在浏览器里生成文件并给出实际体积和下载链接；冲突不是事后才发现的坏文件，而是在导出前就点名"哪两个设置打架"，并提供一键修复按钮，修好就能重新导出。

## 适用场景与目标用户

海报、社媒配图、活动物料的在线设计工具；用户是运营、小商家和独立设计师，需要快速出图，常在格式、透明度和动画之间犯迷糊。

## 非目标

- 不做完整的矢量编辑器、钢笔工具与模板市场。
- 不用明亮可爱的消费级配色。
- 不实现云端保存、协作和视频导出。

## 复刻提示词

深色专业设计工具原型：48px 深灰顶栏（彩色锥形渐变方块标志、文档路径、缩放比例、撤销），左侧 232px 图层栏（把手、小图标、名称、眼睛；选中项品红左条），中间深灰径向背景上居中一张 4:5 海报画板（米色底、橙色太阳、粗黑大字"秋日市集"、山丘剪影，透明时显示棋盘格），右上绿色"实时预览"；右侧 300px 属性栏分三段：图层参数（文本框、品红滑杆、色块）、画面效果（透明背景 / 呼吸动画开关）、导出（PNG / JPG / SVG 三张等宽字格式卡、倍率下拉、品红满宽"导出"）。冲突时出现抖动的红框写明冲突并给出修复按钮；成功后显示绿框结果卡、缩略图、真实体积和"⤓ 下载文件"。
