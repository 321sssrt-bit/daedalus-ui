# 045 音视频平台

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`045-marquee-stream.html`
- 复现范围：放映厅纪录片与播客平台的单页原型：发现（今晚放映灯箱、继续观看、本周片单）→ 播放器（播放 / 暂停、拖动进度、±秒跳转、倍速、下一个）→ 队列调整（上移、下移、移出、加入）→ 自动保存并在首页「继续观看」显示进度；以及播放器内「演示：模拟网络中断」后暂停、保留进度、重新连接并从原位置继续。

## 产品边界

- 实现：内容发现（灯箱、继续观看、片单）、播放控制（播放暂停、拖动、跳转、倍速、下一个）、字幕示意、播放队列编辑、播放进度自动保存与续播、网络中断模拟与恢复。
- 不包含：真实音视频解码、清晰度切换、弹幕评论、下载缓存、会员购买与账号管理。

## 正常流程

1. 首页点「本周片单」中的「长江之源」→ 播放器从 0:00 开始播放，时间每秒前进，字幕出现。
2. 拖动进度到 10:00 → 时间与字幕跳转，状态行「播放状态已保存：长江之源 · 10:00」。
3. 在队列中把「手艺人」下移一位 → 队列顺序变为「星空下的牧场 / 手艺人 / 慢读书」；可点「＋ 城市考古」加入末尾。
4. 播放中每 5 秒自动保存；点字标返回首页 → 自动暂停并保存，「继续观看」首位出现「长江之源 · 看到 10:0x」及进度条。

## 异常触发与恢复

- 触发：播放器控制条右侧红色虚线按钮「⚡ 演示：模拟网络中断」（仅播放中可用）。
- 反馈：播放立即暂停，时间停止；画面覆盖深色遮罩「网络连接中断 · 播放已在 m:ss 暂停，进度已保留。恢复网络后会从这里继续」；进度条与控制按钮禁用；状态行变红「离线 · 进度已保留在 m:ss」。
- 恢复：点遮罩中的「重新连接」→ 「正在重新连接… 将从 m:ss 继续播放」→ 1.2s 后遮罩消失，从保留的 m:ss 继续播放，时间继续前进。

## 人工验收步骤

正常闭环：
1. 打开页面 → 点片单中的「长江之源」。
2. 观察时间从 0:00 开始走动 → 拖动进度条到约 10:00 → 状态行显示已保存。
3. 在右侧队列点「手艺人」的「▼」→ 顺序变化。
4. 点左上「放映厅」→ 首页「继续观看」首位为长江之源，显示「看到 10:xx」。

异常恢复：
1. 在继续观看中点「深夜电台」→ 从 14:22 继续播放。
2. 等 2 秒后点「⚡ 演示：模拟网络中断」→ 遮罩显示「播放已在 14:2x 暂停」，时间不再变化。
3. 点「重新连接」→ 约 1 秒后遮罩消失，时间从 14:2x 继续增加。
