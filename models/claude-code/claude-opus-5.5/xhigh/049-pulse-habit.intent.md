# 049 健康习惯产品

## 意图元数据

- 意图版本：1
- 对应规范：`049-pulse-habit.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

运动习惯 App 靠"看得见的进步"留住人：日出渐变的目标环和趋势柱在每次记录后都会从旧值长到新值，让一次 40 分钟的跑步立刻变成可见的成就。数据可信同样重要：每个输入框旁直接写着合理范围，超出时不偷偷保存，而是把错误定位到具体字段，并明确告诉你"今天的进度没有被改动"，改好后再重新计算。

## 适用场景与目标用户

运动打卡、健身记录、睡眠与饮水等健康习惯类手机 App；用户是想养成运动习惯的上班族，常手动补录数据，偶尔手滑多打一个 0。

## 非目标

- 不做医疗诊断、饮食计划与付费课程推荐。
- 不用暗黑运动手表风或荧光绿配色。
- 不实现设备同步、GPS 轨迹与社交排行。

## 复刻提示词

日出渐变运动习惯手机原型（390px 手机框）：浅灰白 #f6f6f4 底，左上 30px 粗体"今天"和日期，右上"🔥 连续达标 n 天"白色胶囊；大圆角白色目标卡左侧是珊瑚到杏黄渐变的外环（活动分钟）和紫色内环（千卡），中心 32px 数字"30 / 45 分钟"，右侧百分比与千卡；趋势卡是 7 根圆角柱，达标日渐变色、今天黑框，带"目标 45"红色虚线；底部悬浮黑色"＋ 记录一次活动"。弹层有 5 种运动类型卡、带"合理范围 1–300 分钟"说明的大号数值输入、表情感受和渐变"保存记录"；无效时字段标红并提示进度未改变，保存成功后圆环与柱子动画重算。
