# 009 工作台总览

## 意图元数据

- 意图版本：1
- 对应规范：`009-dispatch-console.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

调度员盯一整天屏幕，需要的是"一屏看完、哪里有问题一眼跳出"。深海军蓝底让长时间注视不刺眼，信息用高密度网格和等宽数字排齐；颜色只承担状态语义（青在途、琥珀风险、红异常），从不做装饰。队列、地图、详情三者联动，点一下就能顺着问题查到底。

## 适用场景与目标用户

物流调度、外卖运力、网约车运营、仓储作业等需要实时监控的运营中台；用户是坐在大屏前的调度员和值班主管，熟练、追求效率，同时处理多个异常。

## 非目标

- 不做面向老板的展示型数据大屏，不加炫光与 3D 地球。
- 不提供运单编辑、派车等写操作的完整流程。
- 不用浅色卡片式消费级仪表盘风格。

## 复刻提示词

深海军蓝高密度物流调度总览：左侧 64px 图标导航轨，顶部 52px 栏带实时同步绿点和逐秒走动的等宽时钟；第一行 6 张指标卡（等宽大数字 + 增减 + 迷你折线），下方左 7 栏是带分段筛选的发车队列表格，状态用青/琥珀/红/绿小圆点标签和细进度条表示；右侧上方是以杭州为中心、虚线流动的六向线路态势图，下方是车次详情与时间线。点行联动详情，单屏不滚动。
