# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-terracotta-rentals.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

找房是在一堆约束之间做取舍，用户需要随时看清"我现在用了哪些条件、还剩几套"。左侧筛选面板吸顶常驻，右侧结果计数用大号陶土色数字放在最显眼处，已选条件变成可点掉的橄榄色胶囊；条件过严时不是空白，而是建议放宽并一键清除。陶土、沙色、橄榄和天空蓝取自海边老城的墙与窗，让租房这件事少一点焦虑。

## 适用场景与目标用户

租房、二手房、民宿、二手车等多条件检索的列表页；用户是刚到新城市工作的年轻人和小家庭，会反复调整预算、区域与通勤条件。

## 非目标

- 不做地图找房和 VR 看房。
- 不用中介平台式的密集广告位与红色促销角标。
- 不实现预约看房与在线签约。

## 复刻提示词

地中海陶土风租房检索页：沙色底，白色顶栏带拱门形标志、城市胶囊和长胶囊搜索框；左侧 300px 白色圆角吸顶筛选面板，区域/户型/朝向为沙色胶囊（选中陶土红白字），月租金是陶土色双钮滑块，底部三个橄榄绿开关；右侧顶部 26px 粗体"7 套房源"（数字陶土红）、可点掉的橄榄色已选条件胶囊和排序下拉；房源结果为白色圆角横卡，左侧是天空蓝/暖黄/陶土配色的扁平房间插画，中间标题、户型面积和标签，右侧大号陶土红月租和圆形心形收藏。
