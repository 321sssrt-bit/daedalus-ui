# 045 音视频平台

## 意图元数据

- 意图版本：1
- 对应规范：`045-marquee-stream.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

纪录片与播客是"坐下来好好看"的内容，所以把平台做成一座装饰艺术风的老电影院：酒红丝绒、金色双框、灯箱上一圈会闪的灯泡，海报像影院门口的片单。体验上最重要的承诺是"不会让你从头再来"：播放进度频繁自动保存，首页"继续观看"带进度条；断网时画面停在原处，明确告诉你停在几分几秒，重连后从那里接着放。

## 适用场景与目标用户

纪录片、播客、有声书、公开课等长内容平台的桌面端；用户是晚上下班后在电脑前看片、听节目的成年人，经常中途离开或在不稳定的网络下观看。

## 非目标

- 不做短视频信息流、弹幕和打赏。
- 不用科技感深蓝与霓虹配色。
- 不实现真实媒体播放、清晰度与字幕语言切换。

## 复刻提示词

装饰艺术风老电影院流媒体原型：酒红 #3a0f14 底叠细竖纹，黑红顶栏左侧金色菱形字标"放映厅"（Copperplate 字体、字距拉开）；首页顶部是金色双框灯箱，上下两排会交替闪烁的黄色灯泡，写"NOW SHOWING · 今晚放映 长江之源"和黄色"▶ 开始观看"；下方"继续观看"横卡带黄色进度条，"本周片单"5 列金框海报。播放器为 2px 金边 16:9 画面、字幕条、黄色播放键、↺15 / 30↻ / 下一个 / 倍速和红色虚线"⚡ 演示：模拟网络中断"，状态行显示"播放状态已保存"；右侧金色小标题"接下来"的队列可上下移动与移出；中断时画面盖上深色遮罩写明暂停时间和"重新连接"。
