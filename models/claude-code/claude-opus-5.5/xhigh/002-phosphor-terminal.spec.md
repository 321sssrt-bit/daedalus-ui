## 内容与数据

- 主标题两行「一行命令，/ 把 webhook 接到本地。」，「本地」为绿色。
- 数据条：48,210 活跃开发者 / 11 ms 香港节点中位延迟 / 99.98% 近 90 天可用率。
- 表单字段顺序：email（工作邮箱）→ handle（子域名前缀）→ password（至少 10 位）→ 条款勾选 → 主按钮 →「已经有账号？去登录 →」。
- 校验：邮箱格式；前缀 3–20 位、小写字母开头、仅含小写字母数字连字符，输入时自动转小写并去掉非法字符；密码至少 10 位。
- 成功态替换表单：标题「账号已创建」（绿色）、终端两行「$ relay login / ✓ 已登录为 邮箱」、「重新发送」链接。
