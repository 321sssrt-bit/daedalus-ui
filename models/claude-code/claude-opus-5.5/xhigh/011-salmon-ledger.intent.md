# 011 数据看板

## 意图元数据

- 意图版本：1
- 对应规范：`011-salmon-ledger.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

经营数据最终要被"读懂"，而不仅是被看见。借鉴财经报纸的版式：报头、要闻标题先用一句话讲清结论，再给数字和图表作证据。鲑鱼粉纸色和衬线数字让周报像一份值得细读的报纸；颜色克制，只用酒红与青色区分本期和上期。

## 适用场景与目标用户

连锁餐饮、零售、内容平台的经营周报或月报看板；读者是区域经理、老板和投资人，每周固定时间阅读，需要结论和证据并存，并愿意花几分钟细看。

## 非目标

- 不做实时刷新的运营大屏或深色科技风。
- 不堆十几个小图表、仪表盘和饼图。
- 不提供自定义报表搭建能力。

## 复刻提示词

财经报纸风经营看板：鲑鱼粉 #fff1e5 纸底，顶部居中衬线报名和 4px 黑色粗线，下面一条日期细线；导语区 36px 衬线大标题写结论，右侧署名栏；四个关键数字以竖线分隔、34px 衬线数字配绿涨红跌；主图是酒红实线（带淡面积）对比青色虚线的营收折线，上方有黑框直角分段切换"按日/按周/按月"和"营收/订单"，悬停出黑底提示；右栏门店排行表格带青色小条形和分析师点评。全页无圆角、无阴影。
