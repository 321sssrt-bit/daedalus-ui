## 复现验收清单

- [ ] 能输入分钟并保存，进度与趋势变
- [ ] 输入 0 或 300 被拦，进度不变
- [ ] 改回合法值再保存，进度重算
- [ ] 目标与范围写在页面上
- [ ] 宽屏手机框
- [ ] 减少动态模式无呼吸动画

## 产品边界

只记分钟与进度。不含社交排行、硬件同步。

## 状态地图

浏览进度、输入、无效、已保存重算。

## 正常流程

1. 默认 16 分钟保存。
2. 累计 32，进度 80%，趋势多一根柱。

## 异常触发与恢复

- 触发：输入 0 或 300 保存。
- 反馈：定位分钟字段错误，累计仍为原值。
- 恢复：输入 20 再保存，累计与百分比更新。

## 数据变化

合法才 done += v 且 hist.push。非法 done/hist 不变。

## 人工验收步骤

正常：保存 16 → 进度到 80%。

异常：保存 300 → 进度仍 80% → 改 10 保存 → 进度 100% 封顶。
