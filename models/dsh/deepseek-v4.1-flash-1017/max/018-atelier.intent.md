# 018 商品详情

## 意图元数据

- 意图版本：1
- 对应规范：`018-atelier.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把它做成一页陶艺工作室的器物档案：左侧整块米灰展台、右手边是尺寸与价格的冷静标注。瓶身没有摄影，只有一只用 CSS 拉出来的影青瓶和一道浅浅的修坯线。留白很大，让「贵」来自安静，而不是金色边框。

## 适用场景与目标用户

面向手作陶器、器物买手店的高单价单品页，顾客在桌面端仔细看尺寸、产地与养护。用户已经愿意买，需要的是被尊重的信息密度与可信的细节，而不是促销话术。

## 非目标

不做放大镜与 360° 旋转、不做搭配推荐、不做分期免息；不承担购物车页、支付与物流追踪。

## 复刻提示词

象牙底与米灰展台的陶器详情页，左侧一只 CSS 白瓷梅瓶立于底座，右侧宋体商品名、三档尺寸与数量步进，细描边与等宽产地标注，安静、贵气、像一页器物档案。
