以下为产品原型补充章节。

## 产品边界

本原型实现一次移动转账：选择收款人、输入金额、选择资金来源、核对确认、得到凭证；异常限定为「余额不足」。不包含添加收款人、转账限额设置、真实银行扣款、撤回与客服工单。

## 状态地图

| 状态 | 触发 | 界面表现 |
| --- | --- | --- |
| 转账填写 | 初始 | 收款人三选一、金额输入、两种来源、下一步 |
| 余额不足 | 金额大于当前来源可用额 | 金额卡下方错误条，停留填写页 |
| 确认 | 金额合法点下一步 | 确认页显示金额、收款人、来源、手续费与到账时间 |
| 处理中 | 确认页点确认转账 | 按钮禁用并显示「正在转账…」 |
| 成功 | 900 ms 后 | 凭证页显示金额、收款人、编号、时间 |
| 返回填写 | 确认页点返回修改 | 回到填写页，金额与选择保留 |
| 完成 | 凭证页点完成 | 回填写页，清空金额，刷新可用余额 |

## 正常流程

1. 默认选中陈默与账户余额，输入金额 500。
2. 点「下一步」，进入确认页：¥500.00、给陈默 · 招商银行 6688、账户余额、手续费 ¥0.00。
3. 点「确认转账」，按钮显示「正在转账…」。
4. 900 ms 后出现「转账成功。」、金额 ¥500.00、编号 `TRF-20261017-042`。
5. 点「完成」回到填写页，金额清空，可用余额减为 ¥11,980.00。

## 异常触发与恢复

- **触发**：在资金来源选择「招商银行 储蓄卡」（可用 ¥3,200.00），输入 4000，点「下一步」。
- **反馈**：金额卡下方出现「余额不足：当前可用 ¥3,200.00，本次需要 ¥4,000.00。请降低金额，或切换其他资金来源。」停留在填写页，不进入确认。
- **保留**：收款人、金额、来源选择全部保留。
- **恢复**：点击「账户余额」切换来源，可用余额变为 ¥12,480.00；再次点「下一步」进入确认页。
- **再次成功**：点「确认转账」，900 ms 后得到凭证。

## 数据变化

| 操作 | 来源可用额 | 页面状态 |
| --- | --- | --- |
| 初始 | 余额 ¥12,480 / 卡 ¥3,200 | 填写 |

异常时不得扣减余额、不得生成凭证，也不得清空已填金额与收款人。

## 人工验收步骤

**正常闭环**
1. 打开页面，确认陈默与账户余额为选中态，可用余额 ¥12,480.00。
2. 金额输入 500 → 点「下一步」。
3. 确认页核对 ¥500.00、陈默、账户余额 → 点「确认转账」。
4. 900 ms 后确认「转账成功。」与编号；点「完成」回到填写页，金额为空、余额为 ¥11,980.00。

**异常与恢复**
1. 刷新页面，点「招商银行 储蓄卡」，确认可用余额变 ¥3,200.00。
2. 输入 4000 → 点「下一步」，确认出现余额不足错误且未跳转。
3. 点「账户余额」，确认可用余额变 ¥12,480.00、错误清除。
4. 再点「下一步」，进入确认页；确认转账并看到凭证。
