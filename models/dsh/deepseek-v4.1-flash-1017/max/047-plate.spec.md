以下为产品原型补充章节。

## 产品边界

本原型实现一次海报创作与导出：编辑内容、版式、主色与纹理，实时预览，选择格式导出并看到结果；异常限定为「导出条件不支持」。不包含图层管理、字体上传、真实画布引擎与文件下载。

## 状态地图

| 状态 | 触发 | 界面表现 |
| --- | --- | --- |
| 编辑 | 初始 | 左侧参数、中央海报、右侧导出 |
| 实时预览 | 任意参数变化 | 海报即时重绘 |
| 格式切换 | 点格式卡 | 选中态与导出按钮文案更新 |
| 导出中 | 点导出 | 按钮禁用并显示「正在排版…」 |
| 导出成功 | 900 ms 后 | 结果卡显示文件名、大小、尺寸与出血 |
| 冲突 | SVG + 颗粒开启 | 红边错误条，结果卡保持隐藏 |
| 恢复 | 关闭颗粒或改选 PDF/PNG | 错误消失，可再次导出 |
| 下载 | 点结果卡下载 | 轻提示「文件已开始下载」 |

## 正常流程

1. 页面加载，海报显示「夜航西飞」，橙色圆形位于右下。
2. 修改主标题为「夜航」，切换版式为「左」，海报文字即时左对齐、圆形移到左下。
3. 点击钴蓝色板，圆形与强调色变蓝。
4. 导出格式保持 PDF，尺寸选 840 × 1120，勾选出血，点「导出为 PDF」。
5. 900 ms 后结果卡显示 `nightflight-840×1120.pdf`、大小、尺寸与「含 3 mm 出血」；点下载出现轻提示。

## 异常触发与恢复

- **触发**：导出格式选「SVG」，保持颗粒纹理开启，点「导出为 SVG」。
- **反馈**：红边错误条出现「无法导出 SVG：当前作品含颗粒纹理……」，结果卡不出现，作品参数不变。
- **保留**：标题、版式、颜色、颗粒强度全部保留。
- **恢复**：关闭「颗粒纹理」开关，海报纹理层隐藏；再次点导出。
- **再次成功**：900 ms 后出现 SVG 结果卡，文件名与尺寸正确。

## 数据变化

| 操作 | 格式 | 颗粒 | 结果 |
| --- | --- | --- | --- |
| 初始 | PDF | 开 | 无 |
| 改标题/版式/颜色 | PDF | 开 | 无（预览更新） |
| SVG 导出 | SVG | 开 | 错误，无结果 |
| 关闭颗粒 | SVG | 关 | 预览纹理消失 |
| 再次导出 | SVG | 关 | 结果卡 `nightflight-420×560.svg` |

冲突时不得生成结果卡、不得改变当前格式与作品参数。

## 人工验收步骤

**正常闭环**
1. 打开页面，修改主标题与版式，确认海报即时变化。
2. 点钴蓝色板，确认圆形变蓝。
3. 选 PDF、840 × 1120、勾选出血，点导出。
4. 900 ms 后确认结果卡文件名、大小与出血信息；点下载出现提示。

**异常与恢复**
1. 选 SVG，保持颗粒开启，点导出。
2. 确认错误条出现且没有结果卡。
3. 关闭颗粒开关，确认海报纹理消失；再次点导出。
4. 确认出现 SVG 结果卡与文件名。
