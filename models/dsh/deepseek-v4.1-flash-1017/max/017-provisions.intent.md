# 017 商店首页

## 意图元数据

- 意图版本：1
- 对应规范：`017-provisions.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把它做成一张秋日杂货摊的货签：奶油纸、橄榄绿、陶土色的手作物件，衬线字像店招。六件商品用 CSS 画出体积与材质，不靠摄影。价格与库存用等宽字，像手写标签上的铅笔字。整体暖、慢、可以摸。

## 适用场景与目标用户

面向手作、食品、家居选物店的线上首页，顾客多为愿意为材质与来源多付一点钱的人。使用场景是傍晚的桌面浏览，先逛、再看，最后才决定买什么。

## 非目标

不做促销弹窗、不做倒计时、不做无限商品流；不承担商品详情、购物车页与真实支付。

## 复刻提示词

奶油纸与橄榄绿的秋日杂货店，六件手作商品的 CSS 静物插画，宋体店招「把日子过得慢一点」，陶土色收藏心与购物篮，温暖、克制、有纸货签的手感。
