# 041 购物零售产品

## 意图元数据

- 意图版本：1
- 对应规范：`041-bodega.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把线上买杂货做成逛一间小仓：奶油纸、墨色字、番茄红价格与青色动作，商品用 CSS 画出箱子、面包、油瓶与蜜罐。购物车像一张一直摊在右手边的拣货单。库存不足被写成一句具体的话——哪件、哪个规格、还剩几件——而不是一个红叉。

## 适用场景与目标用户

面向小批量食品、礼盒与日用杂货的桌面购买，用户在办公室或家里一次挑几件，次日收货。用户需要知道规格差价、库存与运费，而不是被倒计时推着下单。

## 非目标

不做会员积分、不做凑单推荐、不做直播带货；不承担真实支付、库存扣减、地址管理与物流追踪。

## 复刻提示词

奶油纸与番茄红的桌面杂货店，四张 CSS 静物商品卡、右侧 360 px 拣货单式购物车、墨色加购按钮与订单弹层，库存不足时给出具体规格与剩余数量，温暖、直接、像一间小仓。
