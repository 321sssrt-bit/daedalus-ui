# 013 收件箱

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`013-copper-inbox.html`
- 复现范围：三栏站务信箱，含文件夹切换、未读 / 星标过滤、关键词搜索、星标开关、阅读区与回复 / 归档 / 标为未读动作；不含撰写页与真实邮件服务。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 三栏 `158px + 330px + 1fr`，列表内部滚动 | 字段表三列一行 |
| 窄于 1080px | 两栏 `140px + 1fr`；阅读区 `grid-column:1 / -1` 换到下方并加顶部分隔线 | 字段表改两列 |
| 窄于 768px | 单列；文件夹栏转为横向滚动条、底部提示隐藏 | 列表最大高降至 `280px`；页边距降至 `14px` |
| 无结果时 | 布局不变 | 列表区显示居中提示「这里没有符合条件的信。」 |

## 内容与数据

- 页头：标题「站务信箱」+ 铜色未读徽标（实时计数，初始 `2 未读`）+ 右侧「收件人 沈砚舟 · D-04 席位 · 每 2 分钟同步」。
- 文件夹四项与计数：收件箱 4 / 星标 1 / 已归档 2 / 草稿 1；下方提示「站务信箱只受理与本班相关的事项。急事请走内线 8120，不要等回信。」
- 邮件共 8 封，字段顺序：编号 `M-88xx` → 文件夹 → 发信人 → 时间 → 事由 → 摘要 → 正文段落 → 可选引用 → 键值字段。
- 初始未读 2 封：收件箱中的 `M-8841`（延误回执）与 `M-8839`（津贴口径）；已读名单为其余 6 封。星标集合初始含 `M-8841`、`M-8830`、`M-8836`。
- 默认选中 `M-8841`（延误回执），正文三段含「预计 23:06 到站」「按预案改由区间车接管」「回信请附实际到站时间与上客人数」，引用为 21:20 郑明轩留言，键值为 关联班次 / 需要回复 / 工单。
- 空态（过滤后无结果）文案固定两句，提示换关键词或回到「全部」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 无入场动画 | 三栏与未读标记一次呈现 | 全局 `transition:none` |
| 切换文件夹 / 胶囊 / 搜索 | 即时重绘 | 列表行增减、未读徽标与文件夹计数不变（计数按全量算） | 相同 |
| 选中信件 | 即时 | 行左条转铜色、背景转白，右侧读全文并滚动到顶部区域 | 相同 |
| 星标开关 | 即时 | 星形转金并填充，阅读区标签同步出现 / 消失 | 相同 |
| 回复 / 归档 / 标为未读 | 即时 | 动作条右侧绿字状态，未读徽标随之增减 | 相同 |

## 复现验收清单

- [ ] 1280 × 800 下三栏宽度为 158px / 330px / 剩余，页头为 2px 黑粗线，未读徽标为铜底白字
- [ ] 初始收件箱显示 4 行，其中 2 行为未读（左侧 4px 黑条 + 加粗 + 铜色圆点）
- [ ] 点「未读」胶囊后只剩未读行，胶囊转铜底白字；再点「全部」恢复
- [ ] 搜索「胎压」后列表只剩 1 行且处于选中态可读全文
- [ ] 清空搜索且搜索无结果时（如输入 `zzz`）出现居中空态两行提示
- [ ] 点击某行星标后其转金并填充，「已星标」过滤中随即出现该信
- [ ] 阅读区默认显示 `M-8841`：标题、头像「调」、引用块与三组键值齐全
- [ ] 点「归档」后状态条显示「已归档到「已归档」」，该行从收件箱消失并出现在已归档夹
- [ ] 点「回复」后该信转已读，页头未读数由 2 变 1；再点「标为未读」恢复为 2
- [ ] 窄于 1080px 阅读区换到整行下方；窄于 768px 文件夹变横向滚动、列表高 280px
- [ ] 开启减少动态后所有选中、星标与状态文字反馈仍然有效
