# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-copper-inbox.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

值班信箱的关键是「哪封现在必须回」。未读用 4px 黑左条 + 圆点 + 加粗三重表达，事由行永不折行，读信区把班次、时限、工单号做成键值块放在正文之后，让回信前先看清条件。配色走温灰加铜色，避开常见的邮件蓝，减少「又一个邮箱客户端」的既视感。

## 适用场景与目标用户

内部事务收件：站务与调度联络、门店与仓库工单往来、审核与合规沟通、班级与社群事务。用户是每天处理二三十封、需要在读与不读之间快速划界的人。

## 非目标

- 不做多账号、线程折叠与标签体系，只用四个固定文件夹 + 星标。
- 不做撰写富文本编辑器，回复只落一条本机草稿状态。
- 不显示头像图片与附件缩略图，避免外部资源。
- 不做批量操作与快捷键面板。

## 复刻提示词

三栏铜色信箱：温灰底 `#f6f4f2` + 2px 黑色页头粗线，158px 文件夹（当前项黑底反白）/ 330px 列表（未读左 4px 黑条 + 铜色圆点，选中左条转 `#a2603f`）/ 阅读区 66ch 版心，引用块左 3px 竖线米底，动作条贴底并用绿色小字播报结果。
