# 010 看板

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`010-sticky-board.html`
- 复现范围：四列检修工单看板，含新建卡片、卡片在列间前进 / 后退、选中详情底栏、在做过载提示与空列占位；不含拖拽引擎、指派人选择与筛选。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | `body` 底色 `#eef0f3`；`.board` 栅格 `repeat(4,minmax(0,1fr))`、间隙 `18px`、内距 `22px 28px 40px`、`align-items:start` | 顶部通栏页头 + 四列 + 固定底栏 | 列底色 `#e6e9ee`、`border-radius:6px`、`min-height:200px`；页面纵向滚动 |
| 页头 | `padding:14px 28px`、底 `1px solid #d5dae1`、白底 | 标题 + 周次徽标 + 新建输入（`min-width:250px`）+ 优先级下拉 + 按钮 + 最右颜色图例 | 弹性换行（`flex-wrap:wrap`） |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 便利贴卡 `.note` | 宽 100%、`padding:12px`，含顶部 52×14px 胶带、标题、描述、元信息行 | 三色循环底色、`2px` 圆角、轻投影、微旋 | 悬停上移 `3px` 并回正（`160ms ease`）、投影加深；`.pinned` 选中：`2px solid #2f5fa8` 外描边偏移 2px；键盘 Enter / 空格等同点击 |
| 卡片移动按钮 `.mv button` | 22px 高小方块，位于元信息行右侧（`margin-left:auto`） | 默认 `display:none` | 悬停或选中卡片时出现；首列无「←」、末列无「→」；点击只移动该卡并整板重绘 |
| 优先级标签 `.tag` | `10.5px` 等宽、`999px` 胶囊、`1px` 半透明描边 | 可缓：透明白底 | 普通底 `#f0d9a8`；紧急底与字为 `#b0362c` 白字 |
| 新建组合 | 输入（`padding:10px 12px`、`min-width:250px`）+ 下拉 + 主按钮 | 底 `#f7f8fa`、描边 `#d5dae1` | 输入聚焦：白底 + `#2f5fa8` 描边 + `0 0 0 3px #2f5fa826`；标题为空时点新建：描边转 `#b0362c`、占位符改「先写一句要修什么，再点新建」并聚焦 |
| 主按钮「新建一条」 | `padding:10px 18px`、`3px` 圆角、粗体 | 底与描边 `#2f5fa8`、白字 | 悬停底色 `#254c8a`；焦点环 `2px #b8791f`；新卡插入待排列首，编号自 `W-321` 起递增 |
| 列 `.col` | `min-height:200px`、底 `#e6e9ee`、圆角 6px | 计数徽标白底 `1px` 描边 | 「在做」列超过 3 条时整列转警告底色与描边，并在栈底追加过载提示 |
| 空列占位 `.drop` | `1.5px dashed #b6bec8`、`padding:14px 10px`、居中 | 灰字「这一列空着，用 → 推进一条进来」 | 有卡片即消失；过载提示复用同结构但描边与文字转 `#b8791f` |
| 详情底栏按钮 | `12.5px`、`9px 14px`、底 `#f7f8fa` | 首列时「←」禁用、末列时「→」禁用 | 悬停描边与文字转 `#2f5fa8`；「标为我的」把负责人改成「沈砚舟」并同步底栏说明 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 四列等宽，间隙 18px | 卡片元信息一行五件（头像 / 编号 / 优先级 / 期限 / 移动按钮） |
| 窄于 1080px | 两列两行 | 列与卡片宽度自适应，胶带与旋转保持不变 |
| 窄于 768px | 单列堆叠，板面内距降至 `16px` | 隐藏颜色图例；输入框 `flex:1` 撑满；页头换行 |
| 悬停不可用（触屏） | 不变 | 移动按钮改为在卡片选中（`.pinned`）时常显 |

## 内容与数据

- 页头：标题「检修看板」+ 周次徽标 `第 35 周 · 08-27 至 09-02`；输入占位符「新增一条工单，例如：3 号车库门异响」（`maxlength=28`）；优先级三档 紧急 / 普通（默认）/ 可缓；图例四色对应四列。
- 四列固定顺序：待排 / 在做（上限 3）/ 待检 / 完成。
- 初始 9 张卡片：待排 3（W-311 车库门异响·紧急、W-312 雨棚积水·普通、W-313 座椅松动·可缓）、在做 2（W-304 刹车片更换·紧急、W-305 显示器闪屏）、待检 2（W-298 滤芯更换、W-299 照明延时）、完成 2（W-286、W-287）。
- 卡片字段顺序：标题 → 描述 → 元信息（负责人首字 / 编号 / 优先级 / 期限）。
- 底栏格式：`W-304 · 标题 · 在做 · 负责 马 · 期限 今晚`，并给出左右移动、标为我的、关闭四键。
- 新建卡片描述固定为「（尚未补充细节，可在卡片上继续编辑）」，期限「本周内」，负责人取当前值班人「沈」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 无入场动画 | 便利贴以静态旋转角呈现 | 取消全部旋转角（`transform:none`），颜色与投影保留 |
| 悬停卡片 | `160ms ease` | 上移 3px、回正、投影加深、出现移动按钮 | 位移取消，但移动按钮仍出现 |
| 移动卡片 | 即时重绘 | 计数徽标与列底色即时更新，过载提示出现或消失 | 相同 |
| 底栏滑入 | `220ms ease` | `translateY(110%) → 0` | 瞬时显示，无位移 |
| 新建校验失败 | 即时 | 输入描边转红并改写占位符 | 相同 |
