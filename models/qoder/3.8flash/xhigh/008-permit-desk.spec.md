# 008 权限请求

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`008-permit-desk.html`

## 内容与数据

- 页眉：盾形勾图标 + 「系统能力授权申请」，编号 `FORM · PERM-2026-0827`。
- 应用行：图标「拾」、标题「拾光集 想使用以下三项能力」、副行「开发者 砚舟科技 · 已在系统内登记，用途由开发者声明」、版本徽标 `v3.2.1`。
- 触发说明（teal 左边框块）：解释「为什么现在问」以及「不给也能用，只是不会自动分组」，并说明可在「设置 › 权限」修改。
- 表头四列固定：能力 / 用来做什么 / 发生频率 / 你的选择；表格题注 `SCOPE LIST / 申请范围`。
- 三项能力字段顺序：名称 → 用途 → 频率 → 选择，均含一段隐私说明：
  ① 大致位置：把照片按拍摄街道成组 / 每次成组时 / 精度约 1 公里、不读实时轨迹、不上传服务器；
  ② 相册读取：读取你选中的照片与拍摄参数 / 每次导入时 / 只取勾选照片并读入 EXIF；
  ③ 通知：冲扫店回片时提醒你一次 / 预计每月 1–2 次 / 不含推广，关闭后仍可在「进度」页查看（该项无「仅此一次」）。
- 默认状态：三项均为「拒绝」，汇总行初始为「3 项能力中：允许 0 项 · 仅此一次 0 项 · 拒绝 3 项。」主按钮禁用。
- 允许回执需列出被授予项与模式（例：`已授予 大致位置（仅此一次）、相册读取（一直允许）。拒绝的 1 项保持原状，随时可改。`）；全部拒绝回执需说明功能损失而非空泛道歉。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 无入场动画 | 色带、表格线与点阵底一次成型 | 全局 `transition:none`，其余不变 |
| 切换某一态 | 即时 | 分段填充 `#0d6b7a`、行名换色、汇总与主按钮文案即时重算 | 相同 |
| 展开说明 | 即时（`display` 切换） | 说明块出现、链接文案与 `aria-expanded` 变化 | 相同 |
| 提交允许 | 固定 700ms | 按钮转「提交中」，随后显示绿色回执条 | 相同，仍显示回执 |
| 全部拒绝 | 即时 | 三段选择复位为拒绝，显示红色回执条说明后果 | 相同 |
