# 005 找回密码

## 意图元数据

- 意图版本：1
- 对应规范：`005-registered-post.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

找回密码的核心焦虑是「到底寄出去没有、寄到哪、还要等多久」。于是把这一页做成挂号信投递：左栏只问一件事，右栏用常驻轨迹把待投递 / 已收寄 / 派送中 / 已签收摆在同一屏，配脱敏地址与 60 秒重投倒计时，让等待变成可核对的状态，而不是一个转圈的提示。

## 适用场景与目标用户

账号自助恢复入口：金融与政务类系统、社区与内容平台、企业 SaaS 的忘记密码页。用户处在着急且不确定的情绪里，常常怀疑自己记错了号码，因此失败文案必须说明「没有寄出任何东西」，并同时给出人工出路。

## 非目标

- 不做「猜你想找哪个账号」的多账号列表，避免暴露他人信息。
- 不用大号插画或情绪化文案降低效率，装饰只有航空条纹与牛皮纸。
- 不做真实邮件 / 短信下发与倒计时服务端校验，前端计时仅用于演示等待态。
- 不在本页完成新密码设置。

## 复刻提示词

挂号信式找回密码：天蓝底 `#dfe9f2`，顶部红白蓝斜向航空条纹，navy `#16324f` 投递台横栏，左白单 + 右牛皮 `#e7d3a8` 轨迹卡，四步竖向节点用红点脉冲表示进行中，成功显示脱敏地址与 60 秒重投倒计时，失败用 2px 红边「查无此件」条。
