# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-sticky-board.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

检修工单短、变更快、要的是「谁在弄、到哪一步」。用便利贴上板代替冷冰冰的卡片列表：胶带、微旋、三色纸让同一列里的条目天然有区分度；WIP 上限直接改变列底色，超载不靠弹窗提醒。移动只提供左右两键，把状态推进变成肌肉记忆。

## 适用场景与目标用户

设施巡检、设备报修、门店整改、内容审核队列等短任务流。用户是每班开一次板、站着快速过一遍的维修主管与值班工程师。

## 非目标

- 不做自由拖拽与多标签层级，只用确定性的列间移动。
- 不做燃尽图、累计流等统计图，本页只管「现在谁在哪」。
- 不引入手写字体与拟物纹理图片，纸感全部由 CSS 完成。
- 不做权限分级与工时录入。

## 复刻提示词

便利贴看板：冷灰板面 `#eef0f3` 上四列 `#e6e9ee` 圆角托盘，卡片三色循环（`#f7e6a8`/`#c8dcf0`/`#f3c7c8`）带 52px 半透胶带与 ±0.6° 旋转，悬停上浮回正并露出 ←→，在做过载整列转琥珀底，底部固定详情条做批量操作。
