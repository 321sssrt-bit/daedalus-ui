# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-glass-ask.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限请求的关键是「说清楚要什么、为什么」：弹窗先用一句人话讲用途，再用说明块展开边界，允许独占主色，拒绝与稍后并列但都不躲藏。底层应用虚化提醒「你正打断用户」。

## 适用场景与目标用户

桌面端效率、专注、日历类应用首次请求系统通知权限；面向对打扰敏感、需要了解边界的用户。

## 非目标

不做真实系统 API 对接、不做多权限批量索取、不做引导去系统设置的详细教程；不做恐吓式文案。

## 复刻提示词

系统级玻璃弹窗气质的权限询问：模糊应用骨架打底，深色半透遮罩，白色圆角弹窗居中，紫色主按钮允许，拒绝与稍后再问并排，三种结果各自配一条状态反馈。
