## 产品边界

实现课程入口、单题选择作答、即时判定与解释、错误状态、再次作答与订正成功；不含多题连续测验、视频课程播放、积分排行与错题本。

## 状态地图

同一 HTML：课程列 + 练习区；练习区状态：未作答 → 已选 → 已判定（正确/错误）→ 错误后再次作答复位 → 订正成功。

## 正常流程

1. 确认左侧课程选中「生活中的经济学」；2. 阅读题干选 B；3. 点提交答案；4. B 标绿，绿色判定「回答正确！」附解释；5. 进度行答对数加一。

## 异常触发与恢复

- 触发：选择错误选项（如 A 或 C 或 D），点提交答案（页面提供的错误选项直接可提交）。
- 反馈：所选标红、正确答案标绿，红色判定块给出解释并引导订正；不记入答对。
- 恢复：点「再次作答」题目复位，重新选择 B 提交，绿色判定显示「订正成功！」，进度行订正成功加一。

## 数据变化

- 首次答对累计「答对」；先错后对累计「订正成功」；判定与选项状态不跨题保留。
- 错误状态不锁定题目，始终允许再次作答。

## 人工验收步骤

正常闭环：选 B → 提交 → 回答正确 + 解释。
异常恢复：选 A → 提交 → 红字解释与再次作答 → 重选 B 提交 → 订正成功。
