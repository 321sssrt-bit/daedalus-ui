## 产品边界

本原型实现钱包内的「转账」完整闭环：查看余额与资金来源、选择收款人、输入金额、确认转账、拿到成功凭证，以及余额不足异常的触发与恢复。不包含扫码支付、收款、提现、账单明细、实名/风控、多人收款与跨行到账查询等相邻能力。

## 状态地图

| 状态 / 屏幕 | 触发操作 | 关键可见物 |
| --- | --- | --- |
| 转账首页 `#view-payee` | 初始或凭证「完成」后 | 余额卡（合计与两来源）、收款人列表、禁用「下一步」 |
| 金额输入 `#view-amount` | 选中收款人后「下一步」 | 金额显示、快捷金额、资金来源选择、数字键盘 |
| 确认转账 `#view-confirm` | 金额有效后「下一步」 | 确认卡四行、确认转账按钮 |
| 余额不足（错误面板） | 确认金额超过所选来源余额 | 红色面板、可用余额、降低金额 / 切换资金来源 |
| 成功凭证 `#view-receipt` | 余额充足时确认 | 绿色对勾、金额、单号、时间、已到账 |

## 正常流程

1. 打开页面即处于转账首页，余额卡显示合计 `¥236.50`。
2. 点击任一收款人（如林晓雨）→ 该项进入选中态，「下一步」由禁用变为可用。
3. 点击「下一步」→ 进入金额输入，顶部显示「向 林晓雨 转账」，默认来源为日常账户（可用 `¥86.50`）。
4. 用键盘或快捷金额输入 `¥50` → 金额显示更新，「下一步」可用。
5. 点击「下一步」→ 进入确认页，核对收款人、金额、来源、可用余额。
6. 点击「确认转账」→ 余额扣减至 `¥36.50`，跳转凭证页显示金额、单号、时间与「已到账」。
7. 点击「完成」→ 回到首页，余额卡合计更新为 `¥186.50`。

## 异常触发与恢复

- 主动触发：在金额输入页选择「日常账户」，输入 `¥120`（大于其 `¥86.50`），进入确认页后点击「确认转账」。
- 失败反馈：显示「余额不足」错误面板，提示「日常账户」可用余额 `¥86.50` 不足以完成转账；转账被阻止，不扣减余额、不生成凭证。
- 恢复路径 A（降低金额）：点击「降低金额」回到金额输入页，金额仍保留 `¥120`，改输入为 `¥80`，重新「下一步」→「确认转账」→ 成功。
- 恢复路径 B（切换资金来源）：点击「切换资金来源」切到零钱罐（`¥150.00`），错误面板消失，再点「确认转账」→ 成功。
- 重新成功判定：出现成功凭证且对应来源余额正确扣减。

## 数据变化

- 转账成功前：日常账户 `¥86.50`、零钱罐 `¥150.00`、合计 `¥236.50`。
- 转账成功（如日常账户转 `¥50`）后：日常账户 `¥36.50`、合计 `¥186.50`；生成 14 位转账单号与时间，凭证出现。
- 余额不足时：所选来源余额不变、合计不变、不生成单号、不出现凭证；仅错误面板可见，已输入金额与收款人、来源选择全部保留。

## 人工验收步骤

正常闭环：

1. 点击「林晓雨」→ 预期该项高亮、底部「下一步」变色可用。
2. 点「下一步」→ 预期出现金额页，顶部写「向 林晓雨 转账」。
3. 点快捷金额 `¥50` → 预期金额显示 `¥50.00`。
4. 点「下一步」→「确认转账」→ 预期出现绿色对勾凭证、单号与「已到账」。
5. 点「完成」→ 预期回首页，合计余额为 `¥186.50`，日常账户 `¥36.50`。

异常恢复：

1. 首页选「林晓雨」→「下一步」，默认来源日常账户，用键盘输入 `120`。
2. 点「下一步」→「确认转账」→ 预期显示「余额不足」面板与可用余额 `¥86.50`，且未出现凭证。
3. 点「切换资金来源」→ 预期错误面板消失，确认页来源变为「零钱罐」、可用余额 `¥150.00`。
4. 点「确认转账」→ 预期出现凭证，零钱罐余额变为 `¥30.00`。
