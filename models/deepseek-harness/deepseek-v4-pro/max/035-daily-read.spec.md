# 035 内容详情

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`035-daily-read.html`
- 复现范围：单页报纸风格文章详情，含报头、标题、带首字下沉的正文、双栏栏线排版、字号调节与收藏操作。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 满屏米色径向渐变（`#ece2cf` 至 `#cfc3ac`），body flex 居中，padding 20px | 居中手机壳 | 无页面级滚动 |
| 手机壳 `.phone` | 390 × 844 px，圆角 46px，1px 边框 `#b8a98c` | overflow hidden，相对定位 | z-index 基准层 |
| 内容区 `.screen` | 高 100%，左右 padding 24px，底部 padding 40px | 纵向流式 | overflow-y auto 内部滚动 |
| 报头 `.masthead` | padding `14px 0 10px`，上边框 3px 双线、下边框 1px | 文本居中 | 内容区首块 |
| 主图 `.figure .pic` | 高 168px，圆角 2px，1px 边框 `#d8cfbc` | 全宽，内置 SVG 占满 | 内容区中段 |

| 工具条 `.toolbar` | padding `12px 16px`，底部固定吸附 | space-between | `position: sticky; bottom: 0` |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 字号调节按钮（A−/A+） | 34 × 34 px，圆角 8px，1px 边框 `#d8cfbc` | 背景 `#fbf7ee`，文字 `#2b2620` | 按下 `:active` 背景变 `#d8cfbc`；点击在 13/14/16px 三档间增减并重排正文；到达边界时无变化 |
| 收藏按钮 | 胶囊形，padding `8px 14px`，1px 边框 `#d8cfbc` | 背景 `#fbf7ee`，描边心形 | 点击切换 `.on`：背景与边框变 `#b23a2c`、文字白色、心形实心，并弹 toast |
| 正文分栏 | 两栏，栏距 16px，1px 栏线 | 字号继承 `--body-size`（默认 14px） | 字号变化时栏高与断行自动重排；引用段 `column-span: all` 跨栏 |
| 提示 toast | 底部距工具条 90px，padding `10px 18px`，圆角 999px | 背景 `#2b2620`、文字 `#f3ede0`、透明度 0 | 显示时 0.25s 渐显，1.4s 后消失 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 px | 壳固定 390 宽，双栏正文 | 尺寸固定 |
| 宽于 430px | body 居中，壳保持 390 × 844，圆角 + 边框阴影 | 不变 |
| 窄于等于 430px | 壳 `100vw × 100vh`，圆角、边框、阴影归零 | 不变 |

## 内容与数据

- 报头固定文案：`晨钟日报`、`2024年11月4日`、`第 284 期`、`要闻版`。
- 标题：`旧码头改建计划本周进入全民投票`；作者行：`本报记者 沈若澜 · 摄影 周砚 · 字数 1,208`。
- 首段以「市」字下沉（3.2em，`#b23a2c`），正文六段，其中一段为跨栏引用。
- 字号三档状态：`小 13px` / `中 14px` / `大 16px`，默认「中」。
- 收藏按钮默认「收藏」，激活后「已收藏」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 字号切换 | 即时 | 正文字号与栏高立即变化 | 无连续动画 |
| 收藏切换 | 即时 | 胶囊变色 + toast 渐显 | toast 过渡归零，直接显示/隐藏 |
| 字号按钮按下 | 即时 | 背景变 `#d8cfbc` | 保留即时反馈 |
| 工具条吸附 | 无动画 | 滚动时底部工具条始终可见 | 不适用 |

## 复现验收清单

- [ ] 主视口下手机壳 390 × 844、圆角 46px，宽屏居中带米色渐变舞台
- [ ] 报头「晨钟日报」为衬线 34px、字距 8px，上下有双线/单线分隔
- [ ] 首段首字「市」下沉且为 `#b23a2c`，正文为双栏且栏间有 1px 栏线
- [ ] 点 A+ 后正文从 14px 变为 16px 并重排，点 A− 两次回到 13px 后不再减小
- [ ] 点收藏后胶囊变红底白字、心形实心并出现「已加入收藏」toast，再点还原
- [ ] 工具条在正文滚动时始终吸附在壳底部可见
- [ ] 窄屏（≤430px）时手机壳铺满窗口且无圆角边框
- [ ] 开启「减少动态效果」后 toast 无过渡但仍显示交互结果
