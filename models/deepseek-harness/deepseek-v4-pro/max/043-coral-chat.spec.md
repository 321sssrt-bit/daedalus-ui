## 产品边界

本原型实现即时通讯的「会话与单聊发送」闭环：会话列表、进入会话、编辑并发送消息、送达状态，以及发送失败的触发、内容保留、重试恢复。不包含群聊、语音/视频通话、图片与文件传输、消息撤回、已读回执、输入中状态、通知推送与消息搜索过滤等相邻能力。

## 状态地图

| 状态 / 屏幕 | 触发操作 | 关键可见物 |
| --- | --- | --- |
| 会话列表 `#view-list` | 初始或会话页返回 | 搜索框、三条会话、未读徽标 |
| 会话页（在线） | 点击某会话 | 顶栏「在线」绿字、绿色网络轨道、消息气泡 |
| 会话页（离线） | 关闭网络开关 | 顶部红色离线横幅、网络文字「离线」 |
| 消息发送中 | 发送消息后 0–700 ms | 灰字「发送中…」 |
| 消息已送达 | 在线发送或重试成功后 | 绿字「✓✓ 已送达」 |
| 消息发送失败 | 离线时发送消息 | 红字「发送失败」、气泡变浅红、可点按重试 |

## 正常流程

1. 打开页面处于会话列表，显示三条会话与未读徽标。
2. 点击「林晓雨」→ 进入会话页，顶栏显示名字与「在线」，未读徽标清零，历史气泡渲染。
3. 在输入框输入「周六见」→ 发送按钮由禁用变为可用。
4. 点击「发送」→ 气泡以「发送中…」出现，约 700 ms 后变为「✓✓ 已送达」，列表预览同步更新为「我：周六见」。

## 异常触发与恢复

- 主动触发：在会话页把右上角「网络」开关关闭 → 出现红色离线横幅；再输入并发送一条消息。
- 失败反馈：该消息气泡变为浅红底、红字，气泡下方显示「⚠ 发送失败 · 点按重试」，消息文字完整保留，不显示「已送达」。
- 恢复：重新打开「网络」开关（横幅消失、文字回「在线」），点按失败气泡或其状态文字 → 消息回到「发送中…」，约 600 ms 后变为「✓✓ 已送达」。
- 若仍在离线时点按重试，顶部弹出深色胶囊提示「请先开启网络再重试」，失败状态保持不变。
- 重新成功判定：失败消息的状态文字变为「✓✓ 已送达」。

## 数据变化

- 发送前：该会话消息数组长度不变；发送后：新增一条 `{from:'out', status:'sending'}`，列表预览与时间随之更新。
- 在线：状态由 `sending` → `delivered`；离线：状态由 `sending` → `failed`，消息内容不丢失、不从数组移除。
- 重试成功：`failed` → `sending` → `delivered`；重试不新增消息、不改动内容。
- 进入会话：该会话 `unread` 置 0，列表徽标消失。

## 人工验收步骤

正常闭环：

1. 在列表点「林晓雨」→ 预期进入会话页，顶栏「在线」，未读徽标消失。
2. 输入「周六见」→ 预期发送按钮可点。
3. 点「发送」→ 预期先见「发送中…」，约一秒内变「✓✓ 已送达」。

异常恢复：

1. 关闭右上角「网络」开关 → 预期出现红色离线横幅，网络文字变「离线」。
2. 输入「测试失败」并发送 → 预期消息变浅红底红字「发送失败 · 点按重试」，文字仍在。
3. 打开「网络」开关 → 预期横幅消失、文字回「在线」。
4. 点按该失败气泡 → 预期状态回到「发送中…」，随后变「✓✓ 已送达」。
