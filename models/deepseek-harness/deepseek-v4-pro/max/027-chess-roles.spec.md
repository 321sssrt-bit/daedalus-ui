# 027 角色权限 · 复现规范

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`027-chess-roles.html`
- 复现范围：单页角色权限管理界面，含四个角色、黑白棋盘权限矩阵、格位预览、切换角色与保存交互。

## 画布与区域布局

| 区域 | 位置与尺寸 | 说明 |
| --- | --- | --- |
| 应用外壳 | `display:grid; grid-template-columns:268px 1fr; min-height:100vh` | 顶部通栏 + 左侧角色栏 + 右侧棋盘主区 |
| 顶栏 | `grid-column:1 / -1`，内边距 14px 24px | 标题、副标题、未保存提示与保存按钮 |
| 角色侧栏 | 宽 268px，内边距 18px 14px，右边界 1px #dcdce1 | 4 张可选中角色卡 |
| 角色卡 | 内边距 12px，圆角 10px，gap 12px，棋子 38px | 棋子、名称、成员数与说明、锁定标记 |
| 权限棋盘 | 表格，格位高 46px，圆角 12px | 8 行权限 × 4 列角色，黑白交替格位 |
| 格位预览 | margin-top 20px，圆角 12px，内边距 16px 18px | 8 格横向预览条，随选中角色更新 |

## 组件规格与状态

| 组件 | 默认 | 悬停 / 焦点 | 选中 / 开启 | 禁用 |
| --- | --- | --- | --- | --- |
| 角色卡 | 白底、1px #dcdce1 边框 | 悬停边框变 #6b6b74 | 选中绿色边框、浅绿底 #f3faf5、棋子反色 | 不适用 |
| 棋盘格位 | 深格 #1c1c22 / 浅格 #f7f7f8 交替 | 无额外样式变化 | 已授权为实心棋子 + 2px 绿描边 | 所有者整列锁定，点击提示不可修改 |
| 保存按钮 | 深底白字 #1c1c22 | 悬停 #2a2a32 | 无 | 无未保存更改时提示无需保存 |
| 预览格 | 浅格 #f7f7f8 + 空心点 | 无 | 占据态深格 #1c1c22 + 白棋 | 不适用 |
| 未保存提示 | 隐藏 | 无 | 有更改时显示绿色圆点与文字 | 不适用 |

## 响应式规则

- 主视口 1280px：双列布局，侧栏 268px + 棋盘主区。
- ≤768px 断点：应用外壳退化单列，侧栏横置于顶部，预览条改 4 列，棋盘横向滚动。

## 内容与数据

- 角色 4 个：所有者（♔，锁定，1 名）、管理员（♕，4 名）、编辑（♗，12 名）、访客（♙，30 名）。
- 权限 8 项：查看项目、编辑内容、邀请成员、删除项目、管理计费、修改设置、导出数据、管理角色。
- 默认授权：所有者全 8 项；管理员 6 项（查看、编辑、邀请、设置、导出、角色）；编辑 3 项（查看、编辑、导出）；访客 1 项（查看）。

## 动效与反馈

- 角色切换与格位点击即时更新，无位移动画。
- 保存/锁定操作触发底部 toast，出现 2.2s 后消失。
- `prefers-reduced-motion: reduce` 时关闭全部过渡与动画。

## 复现验收清单

- [ ] 页面显示 4 个角色（所有者 / 管理员 / 编辑 / 访客）
- [ ] 权限棋盘为 8 行 × 4 列，格位黑白交替
- [ ] 每个角色列展示其权限清单（已授权为实心棋子）
- [ ] 点击角色卡切换选中态并高亮对应列
- [ ] 格位预览条随选中角色更新占据格
- [ ] 点击管理员 / 编辑 / 访客列格位可授权或收回并显示未保存提示
- [ ] 点击所有者列格位提示「所有者权限不可修改」
- [ ] 点击保存按钮后未保存提示消失并弹出保存时间 toast
