# 028 政务表单 · 设计意图

## 意图元数据

- 意图版本：1
- 对应规范：`028-civic-file.spec.md`

## 设计意图

用沉稳的政务蓝与编号分节建立「正式办事」的秩序感，把长表单拆成三张编号卡片并配左侧可跳导航，让用户随时知道自己在哪、还剩几节。最重要的取舍是：把必填校验做成「提交时才集中标红 + 顶部汇总」，而非逐字打扰，既守住正式感又不打断填写。

## 适用场景与目标用户

适用于政府服务门户、政务 App 或企业行政审批系统的长表单申报页，如社保补贴、资质申报、办证登记。主要用户是需要在线提交材料的市民与办事人员，看重流程清晰、必填明确和受理回执。

## 非目标

刻意不采用卡片浮起、渐变大色块或拟物化装饰，保持政务的克制与权威。不做自动保存、不做多页分步向导的独立路由，也不在原型内校验证件格式或真实联网提交。

## 复刻提示词

设计一个政务蓝配色的长表单页：深蓝顶栏、左侧 01/02/03 分节导航、白底编号卡片、红色必填星号；提交时缺失项标红并出现顶部错误汇总，保存草稿弹出时间 toast，成功后显示受理编号。系统字体、正式克制、无外网资源。
