# 001-terminal-pass 设计意图

## 意图元数据

- 意图版本：1
- 对应规范：`001-terminal-pass.spec.md`

## 设计意图

用复古 CRT 终端承载登录，黑底荧光绿与等宽字体制造「机房门禁」的冷峻感。高密度单列排布把账号、密码、进入、找回出口压缩在一屏，开机日志与状态行让每次操作都像在跟系统对话，最重要取舍是牺牲温暖亲和、换取极客向的专业可信。

## 适用场景与目标用户

面向开发者、运维工程师与内部工具的登录入口，适合开发者平台、SaaS 管理后台、命令行风格产品的登录页；主要用户是熟悉终端语汇、追求效率与安全感的工程人群。

## 非目标

刻意不采用暖色、圆角卡片、衬线标题等亲和皮肤；不实现真实鉴权、会话跳转或验证码发送，找回密码仅为演示出口；CRT 扫描线只做装饰，不做可开关的显示设置。

## 复刻提示词

黑底荧光绿 CRT 终端登录页：`#060a07` 背景、`#33ff66` 荧光字、等宽字体、双层像素边框、扫描线叠层与暗角；单列高密度，账号/密码/进入按钮/找回密码出口齐全；输入 demo 与 green123 成功，连续错 3 次锁定 60 秒；光标闪烁与逐字开机日志，尊重 reduced-motion。
