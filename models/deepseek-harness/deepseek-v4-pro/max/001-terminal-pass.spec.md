# 001-terminal-pass 复现规范

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`001-terminal-pass.html`
- 复现范围：复古 CRT 终端风格的登录页，含账号/密码输入、进入按钮、找回密码出口与三种反馈状态（错误 / 成功 / 锁定），全部可交互。

| 区域 | 边界与尺寸 | 说明 |
| --- | --- | --- |
| 视口画布 | 1280 × 800 px 居中，body 内边距 40px 24px | 页面背景 `#060a07`，内容垂直水平居中 |
| 终端面板 `.terminal` | 宽 760 px，边框 2 px 实线 `#33ff66`，外圈再套 4 px `#1f8f3d` 描边 | 冷色高密度，双层像素边框 |
| 标题栏 `.titlebar` | 内边距 8px 14px，底边框 2 px，字号 13px | 左侧三颗 11px 方块，中间标题，右侧 whoami |

| 主按钮 `.submit` | 宽 100%，内边距 13px，2 px 边框，字号 15px，字距 0.3em | 进入系统按钮 |

## 响应式规则

- 断点 768px：body 内边距收为 20px 12px，`.body` 内边距收为 20px 18px 22px，主按钮字距收为 0.18em。
- 终端面板 `max-width:100%`，窄于 768px 时随容器收缩，不出现横向滚动。

## 内容与数据

- 开机日志三行：`> 远航终端 v3.2 — NODE-7 已就绪`、`> 安全通道已建立：TLS 1.3 / AES-256-GCM`、`> 请输入账号与密码以继续`。
- 演示账号：账号 `demo`、密码 `green123`，输入后进入成功态。
- 校验规则：账号为空 → `[ERR] 账号不能为空`；密码为空 → `[ERR] 密码不能为空`；错误 → `[ERR] 账号或密码不正确，剩余 N 次尝试`；连续 3 次错误 → `[LOCK] 连续错误 3 次，终端已锁定 60 秒`。
- 找回密码面板：管理员邮箱 `root@voyage.internal`、自助重置路径 `node7/restore`、锁定 60 秒自动解锁说明。

## 动效与反馈

- 光标 `.caret` 以 `blink 1s steps(1)` 闪烁；CRT 闪烁层以 `flicker 4.2s steps(1)` 循环。
- 开机日志按每字符 14ms 打字机式逐字输出；`prefers-reduced-motion: reduce` 时直接一次性渲染全文。
- 交互反馈即时：提交后立即写入状态行并切换对应颜色；错误、成功、锁定三种文案各自独立可见。
