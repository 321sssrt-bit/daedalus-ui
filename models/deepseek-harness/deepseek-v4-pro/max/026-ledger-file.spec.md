# 026 账单 · 复现规范

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`026-ledger-file.html`
- 复现范围：单页账单与订阅界面，含当前方案、支付方式更换弹层、六笔账目明细与下载发票交互。

| 区域 | 位置与尺寸 | 说明 |

## 组件规格与状态

| 组件 | 默认 | 悬停 / 焦点 | 选中 / 开启 | 禁用 |
| --- | --- | --- | --- | --- |
| 下载发票链接 | 金色下划线文字 #d9a441 | 悬停 #e9c06a | 点击后变「已下载」、灰字去下划线 | 不适用 |
| 状态徽章 | 已支付绿色、待支付金色、失败红色描边 | 无 | 重试成功后变「已支付」 | 不适用 |
| 支付方式行 | 绿底 1px 表格线边框 | 悬停边框变 #46a37c | 选中绿色描边 + 圆心填充 | 不适用 |
| 主按钮 | 绿底深字 #46a37c | 悬停 #5ab58e | 无 | 不适用 |
| 更换支付按钮 | 透明底、表格线边框、灰字 | 悬停文字变白 | 打开弹层 | 不适用 |
| 支付胶囊 | 面板绿浅底，内含斜向渐变卡面 | 无 | 更换后文案与卡种更新 | 不适用 |

## 响应式规则

- 主视口 1280px：单列容器 1120px，统计条三列。
- ≤768px 断点：容器内边距改 18px 14px 40px，统计条退化为单列，账目表横向滚动。

## 内容与数据

- 当前方案：团队版 · 年度，¥1,188/年，9/12 席位，下次续费 2025-05-18。
- 账目明细 6 笔：日期、发票号、项目、金额、状态、操作；金额含两位小数右对齐。
- 支付方式：Visa 尾号 4821（默认）、Mastercard 尾号 7750、对公账户尾号 9031。
- 统计数字：本期账单 ¥1,188、本月累计 ¥2,430（3 笔）、待开票 ¥596。

## 动效与反馈

- 弹层出现为 `display:flex` 切换，无位移动画。
- toast 底部滑入，出现 2.2s 后消失。
- `prefers-reduced-motion: reduce` 时关闭全部过渡与动画。
