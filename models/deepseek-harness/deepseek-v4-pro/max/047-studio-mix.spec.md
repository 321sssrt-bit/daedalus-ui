## 产品边界

本原型实现海报创作工坊：图层显隐、四项参数实时调整、实时预览、导出格式/分辨率/透明背景选择与成功导出，以及导出条件冲突异常。不包含撤销重做历史、多画布、字体库、云端存储、批量导出与真实文件落盘等相邻能力。

## 状态地图

| 状态 / 区域 | 触发操作 |
| --- | --- |
| 默认工坊 | 页面加载即进入，四层全显、PNG / 1× / 透明开 |
| 图层隐藏 / 恢复 | 点击图层眼开关切换显隐 |
| 参数变化预览 | 拖动任一滑块实时更新海报 |
| 冲突提示态 | 格式选 JPG 且透明背景开启 |
| 导出成功态 | 无冲突时点「导出作品」 |

## 正常流程

1. 拖动「色相 / 饱和度 / 亮度 / 标题字号」任一滑块，或点击图层眼开关 → 中央海报立即实时更新。
2. 在右侧「导出格式」分段选 PNG，「分辨率」选 1×，「透明背景」保持开。
3. 点「导出作品」→ 结果区变成功态，显示文件名、尺寸、体积与海报缩略图，toast 提示已导出。
4. 可切换格式与分辨率再次导出，文件名随选择变化。

## 异常触发与恢复

- 主动触发：格式选「JPG」且保持「透明背景」开启 → 冲突提示出现、导出按钮变警示色。
- 题定反馈：点「导出作品」→ 结果区变错误态，文案「JPG 格式不支持透明背景，本次未生成文件，作品未被改动。」，toast 红色警示；不生成成功文件。
- 恢复：关闭「透明背景」开关（或改选 PNG / WebP）→ 冲突提示消失、按钮恢复主色。
- 重新成功：再次点「导出作品」→ 结果区变成功态，生成 `靛青海报-JPG-不透明-1x.jpg` 并显示缩略图。

## 数据变化

- 参数与图层修改只改变预览状态，不产生导出文件。
- 成功导出生成一条文件名 + 尺寸 + 体积结果，`state.format/res/transparent` 决定命名。
- 冲突导出时不得生成文件、不得改写作品预览；`state` 中格式与透明背景保持不变，仅展示错误反馈。

## 人工验收步骤

正常闭环：
1. 打开页面，确认三栏布局与中央 440 × 330px 海报。
2. 拖动「色相」滑块，看到海报背景色与数值标签实时变化。
3. 点「主标题」图层眼开关，看到主标题消失；再点恢复。
4. 保持 PNG / 1× / 透明开，点「导出作品」，看到绿色成功结果与文件名。

异常恢复：
1. 格式选「JPG」，保持「透明背景」开，看到冲突提示与黄色导出按钮。
2. 点「导出作品」，看到红色错误结果「JPG 格式不支持透明背景…」，确认无成功缩略图。
3. 关闭「透明背景」开关，看到冲突提示消失、按钮恢复主色。
4. 点「导出作品」，看到绿色成功结果与缩略图，确认恢复成功。
