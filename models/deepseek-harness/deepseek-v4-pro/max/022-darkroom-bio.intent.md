# 022-darkroom-bio 设计意图

## 意图元数据

- 意图版本：1
- 对应规范：`022-darkroom-bio.spec.md`

## 设计意图

用暗房的近黑、白垫相框与安全灯红点三种材料，把个人主页做成「正在冲印」的暗室感：信息稀疏、留白大方，突出人物与作品本身。最重要取舍是把所有照片做成白垫相框，用相框的留白替代花哨装饰，让红点只作为状态与主行动的焦点。

## 适用场景与目标用户

适合摄影师、插画师、独立创作者的作品主页，也适合策展人的个人介绍页。主要用户是想快速了解作者风格、浏览代表作并决定是否关注或联系的访客与潜在合作方。

## 非目标

不采用明亮商业模板、不做瀑布流或数据仪表盘；不提供登录、评论、私信、打赏等社交能力；照片为 CSS 渐变占位，不承载真实影像内容。

## 复刻提示词

做一个暗房摄影师的个人主页：近黑背景、白色相框留白、安全灯红点，低密度构图，姓名加一句身份、统计三项、关注/联系按钮、六件作品的相框网格，点击作品放大查看。
