## 产品边界

本原型实现团队协作的行动台：创建任务、分派成员、推进三段状态、查看行动日志，以及受限任务的权限不足异常与恢复。不包含多角色权限后台、实时多人协作、任务拖拽排序、附件上传、消息通知等相邻能力。

## 状态地图

| 状态 / 浮层 | 触发操作 |
| --- | --- |
| 默认行动台（三栏） | 页面加载即进入，选中 `t1` 北坡补给点测绘 |
| 选中不同任务 | 点击队列列表项切换详情 |
| 新建任务浮层 | 点击顶栏「＋ 新建任务」 |
| 权限拒绝浮层 | 选中受限任务后点击「尝试推进（受限）」 |
| 申请已提交提示 | 权限浮层点击「申请访问权限」 |
| 安全返回 | 权限浮层点击「安全返回可操作区」回到普通任务 |

## 正常流程

1. 点击「＋ 新建任务」→ 弹出新建浮层；输入任务名并选优先级 → 点「确认创建」→ 队列新增该项并自动选中，日志新增「创建任务…」。
2. 选中新任务 → 在「分派成员」区块下拉选择成员 → 点「分派」→ 铭牌显示成员胶囊，日志新增「分派成员 …」。
3. 点「推进状态」→ 步进条前进一格（待命 → 执行中），队列状态点同步变色，日志新增「状态推进：…」。
4. 连续推进至「完成」→ 推进按钮变禁用，步进三格全绿对勾，日志记录完整变更链。

## 异常触发与恢复

- 主动触发：点击队列中带 🔒 的「夜莺机密侦察路线」，详情出现权限横幅；点击「尝试推进（受限）」。
- 题定反馈：弹出权限拒绝浮层，文案「你缺少「行动指令签发」权限，本次状态变更未写入行动日志」，并高亮缺失权限名；该任务状态保持「待命」，日志只新增「尝试推进…被拒绝」而不新增推进记录。
- 恢复：浮层提供两条路径——「申请访问权限」提交申请并新增「发出访问申请…」日志；「安全返回可操作区」关闭浮层并切回普通任务。
- 重新成功：返回普通任务后点「推进状态」，状态正常前进并写入推进日志。

## 数据变化

- 新建任务：`tasks` 数组长度 +1，队列计数同步 +1，日志新增 1 条 create 记录。
- 分派成员：目标任务的 `assignee` 由 null 变为所选成员，日志新增 1 条 assign 记录。
- 推进状态：目标任务的 `status` +1，日志新增 1 条 advance 记录；完成态后按钮禁用。
- 权限拒绝：受限任务 `status` 保持不变，不得新增 advance 记录；仅允许新增 deny 或 request 记录。

## 人工验收步骤

正常闭环：
1. 打开页面，确认三栏布局与选中任务「北坡补给点测绘」的铭牌与执行中步进。
2. 点「＋ 新建任务」，输入「西线桥头警戒点复查」、选「高」，确认，看到队列第 4 项与 create 日志。
3. 选中新任务，下拉选「陈子昂」点「分派」，看到铭牌胶囊与 assign 日志。
4. 点「推进状态」，看到待命 → 执行中，步进与队列状态点变色，出现 advance 日志。

异常恢复：
1. 点队列中 🔒「夜莺机密侦察路线」，看到权限横幅与「尝试推进（受限）」按钮。
2. 点「尝试推进（受限）」，看到权限拒绝浮层与缺失权限「「行动指令签发」」；确认状态仍为待命、无推进日志。
3. 点「申请访问权限」，看到「访问申请已提交」提示与 request 日志。
4. 再次触发拒绝后点「安全返回可操作区」，自动回到普通任务。
5. 点「推进状态」，确认状态成功推进并写入 advance 日志。
