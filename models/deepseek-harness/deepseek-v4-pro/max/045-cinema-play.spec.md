# 045 音视频平台

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`045-cinema-play.html`
- 复现范围：影院风音视频播放台——内容发现货架、幕布播放器、进度/队列调整、进度保存，以及「模拟断网」中断与重新连接继续播放的完整闭环。

## 内容与数据

- 品牌：`幕间·PLAY`，副文案 `把好片留到幕间看`。
- 内容片单（5 部，每部 2–3 话，每话时长约 230–255 秒）：`夜航西飞`（3 话）、`深空来信`（2 话）、`雾都侦探`（3 话）、`极光之下`（2 话）、`午夜电台`（3 话）。
- 默认载入 `夜航西飞 · 第一话 · 起飞`，时长 `04:02`。
- 时间格式统一 `mm:ss`，进度条填充百分比 = 当前秒 / 该话时长。
- 观看记录按 `片名 · 话名 · 看到 mm:ss` 逐行列出；无记录时显示 `还没有观看记录，选一部片开始吧。`
- 控制栏：播放/暂停、上一话、下一话、模拟断网；上一/下一话在首/末话时自动夹紧边界。

## 产品边界

本原型实现「发现并选择内容 → 开始播放 → 调整进度或队列 → 保存并显示播放状态」与「模拟断网中断 → 保留进度 → 重新连接继续」两条路径。明确不包含：真实视频解码与音轨、倍速/字幕/清晰度切换、全屏与投屏、账号登录、搜索联想结果、付费与弹幕。

## 正常流程

1. 发现并选择内容：在「为你推荐」货架点击任一部片（如「深空来信」）。
2. 开始播放：播放器切到该片第一话，自动播放，时间码从 00:00 逐秒增长，顶部在线圆点呼吸。
3. 调整进度或队列：拖拽进度条到中段；或点击侧栏「接下来播放」的第二话切换到另一话。
4. 保存并显示当前播放状态：暂停或切换时，控制栏右上显示 `已保存到 mm:ss`，侧栏队列项显示金色「看过 mm:ss」，观看记录面板逐行更新。

## 异常触发与恢复

- 主动触发：在播放过程中点击控制栏「模拟断网」按钮。
- 题定反馈：播放立即暂停，幕布屏中央出现深色遮罩，标题 `网络中断，播放已暂停`，说明文字与金色 `已保留进度 mm:ss`，并给出「重新连接」按钮。
- 失败保留：中断前的当前秒数原样保留（不归零），观看进度已持久化到 `saved` 记录。
- 恢复操作：点击遮罩上的「重新连接」。
- 重新成功：遮罩消失，播放从保留的 mm:ss 继续逐秒推进，在线圆点恢复呼吸，观看记录面板出现该条。

## 数据变化

| 操作 | 变化 |
| --- | --- |
| 播放计时 | 当前秒每秒 +1，到该话时长后自动暂停 |
| 拖进度条 | 当前秒 = 比例 × 该话时长，填充与时间码同步 |
| 暂停/切换话/切换片 | 当前秒 > 0 且未播完时写入 `saved[片-话]`，保存态与记录刷新 |
| 切话 | 新话从 0 秒或该话已保存进度开始 |
| 断网中断 | 当前秒保留、不写入丢失；遮罩显示保留进度 |
| 重新连接 | 从保留进度继续计时，不重复累加 |

## 人工验收步骤

正常闭环：
1. 打开页面，确认「夜航西飞·第一话」自动播放且时间码逐秒增长。
2. 点击播放按钮，播放暂停且控制栏显示 `已保存到 mm:ss`。
3. 拖拽进度条到中部，时间码跳转到对应值。
4. 点击「为你推荐」中的「深空来信」，播放器切到该片并从头播放。
5. 点击侧栏「第二话 · 回信」，队列高亮切换，时间码从 00:00 开始。

异常恢复：
1. 回到「夜航西飞」，播放十几秒后点击「模拟断网」。
2. 确认播放暂停、遮罩出现 `网络中断，播放已暂停` 且金色进度等于中断前时间。
3. 点击「重新连接」，遮罩消失，时间码从中断前时间继续增长。
4. 查看「观看记录」面板，出现对应「片名 · 话名 · 看到 mm:ss」条目。
