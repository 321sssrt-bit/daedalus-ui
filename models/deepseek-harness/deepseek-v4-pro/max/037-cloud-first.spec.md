# 037-cloud-first 复现规范

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`037-cloud-first.html`
- 复现范围：天蓝云朵质感的「轻云笔记」列表空态页，含空态说明、新建主按钮、底栏四标签，可通过新建/示例操作把空态变为列表。

## 画布与区域布局

| 区域 | 边界与尺寸 | 说明 |
| --- | --- | --- |

## 响应式规则

- 断点 480px：body 内边距归零，手机壳占满 100%×100vh、圆角与边框归零、投影取消，界面贴合窗口。
- 手机壳内 `.screen` 纵向滚动，滚动条隐藏；内容低于 844px 时行动区与底栏固定可见。

## 内容与数据

- 空态文案：主标题「云里还没有笔记」，说明「写下第一个想法，它会被安安全全地存进云端，换台设备也能接着看。」。
- 主按钮「＋ 新建第一条笔记」；幽灵按钮「看看示例笔记」。
- 底栏四标签：首页（默认选中）、收藏、新建、我的。
- 新建弹层字段：标题、正文（高度 96px）；标题为空时提示「请先写一个标题，再保存到云端。」。
- 示例笔记数据：标题「周末去海边」、正文「记得带上防晒霜、泳镜和一本想读很久的书。」、标签「想法」。

## 动效与反馈

- 弹层出现时 `up .28s ease` 上浮淡入；提示条 0.25 秒淡入上浮。
- 保存/新建/示例即时把空态切换为列表，顶部计数随条数更新；`prefers-reduced-motion: reduce` 时全部动画与过渡关闭。

## 复现验收清单

- [ ] 打开页面可见居中 390×844 手机壳，天蓝底、白色屏幕、四标签底栏
- [ ] 空态显示云朵与太阳插图、主标题、说明文案
- [ ] 「＋ 新建第一条笔记」与「看看示例笔记」两个按钮可见
- [ ] 点「新建第一条笔记」弹出底部弹层，标题留空点保存出现红色提示
- [ ] 填写标题与正文点「保存到云端」，空态变为一条笔记卡片，出现同步提示
- [ ] 点「看看示例笔记」立即新增一条示例卡片并更新计数
- [ ] 点击底栏「收藏」「我的」「新建」有对应反馈，选中态高亮
- [ ] 缩窄到 480px 以下手机壳贴合窗口、无横向滚动
