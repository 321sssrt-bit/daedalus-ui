# 010-workyard 复现规范

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`010-workyard.html`
- 复现范围：单页桌面看板，含四列状态、可移动任务卡片、新建任务弹层与顶部实时统计。

## 响应式规则

- `max-width:768px`：看板由 4 列收为 2 列（`.board{grid-template-columns:1fr 1fr}`），顶栏允许换行，统计行占满整行。
- `max-width:560px`：看板收为单列（`.board{grid-template-columns:1fr}`）。
- 内容包裹横向 `padding` 在窄屏由 `24px` 收为 `14px`。

## 内容与数据

- 顶栏统计：本周任务、施工中、已交付三个数字，随卡片增删与移动实时更新。
- 四列依次为「待开工 / 施工中 / 待验收 / 已交付」，列头展示当前卡片数。
- 初始 6 张任务卡，含标题、优先级徽章、工区、负责人首字头像。
- 新建表单含任务名称（必填）、优先级（普通 / 高）、负责人（选填）。

## 动效与反馈

- 卡片悬停上浮 `2px`、阴影由 `0 3px 0` 加深至 `0 6px 0`，过渡 `0.1s ease`。
- 移动或新建后右下角弹出黄底提示 toast，`0.18s` 淡入，`2200ms` 后自动消失。
- 弹层打开即显示，关闭可点遮罩、取消或右上关闭。
- 尊重 `prefers-reduced-motion`：降级为关闭全部过渡与动画。

## 复现验收清单

- [ ] 页面有近黑背景与黄黑斜纹警示元素，四列状态清晰可辨。
- [ ] 顶栏三个统计数字与列头计数在移动/新建卡片后实时变化。
- [ ] 点击卡片或「▶」可将任务推进到下一列，末列禁用推进。
- [ ] 点击「◀」可将任务退回上一列，首列禁用退回。
- [ ] 点击「＋ 新建任务」弹出表单，空名称提交被拦截并提示。
- [ ] 填写名称后添加，新卡出现在「待开工」列首。
- [ ] 窄于 768px 时看板收为两列，窄于 560px 收为单列，不出现横向溢出。
