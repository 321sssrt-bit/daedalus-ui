# 026 账单 · 设计意图

## 意图元数据

- 意图版本：1
- 对应规范：`026-ledger-file.spec.md`

## 设计意图

用账房墨绿做账单页：深绿底、金色金额与表格横线营造记簿质感，把「钱」的严肃与可追溯感讲出来。最重要取舍是信息高密度——当前方案、统计、明细同屏呈现，数字统一等宽右对齐，让对账一眼可得；金色只留给金额与关键操作，避免喧宾夺主。

## 适用场景与目标用户

面向 SaaS 产品的账单与订阅管理页。主要用户是团队管理员与财务经办人，他们定期核对扣款、索取发票、更换支付方式，需要清晰可追溯的账目与明确的操作入口。

## 非目标

不做浅色商务风或渐变大图；不承载完整发票开具流程、多币种汇率或订阅升降级向导；不用数据图表，仅保留统计条。

## 复刻提示词

复刻一个账房墨绿的账单页：深绿底、金色金额、表格横线感、等宽右对齐数字，顶部当前方案与支付方式，下方六笔账目明细，点击下载发票与更换支付方式均有即时反馈。
