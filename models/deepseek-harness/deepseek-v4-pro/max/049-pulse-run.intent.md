# 049-pulse-run 设计意图

## 意图元数据

- 意图版本：1
- 对应规范：`049-pulse-run.spec.md`

## 设计意图

以暖米底与荧光绿做晨跑运动气质：大字号百分比进度、柔和圆角卡片、荧光绿主按钮，心率折线用珊瑚红突出；低密度留白让记录这件事显得轻松，把无效数据拦截做成字段级红框而非整体报错。

## 适用场景与目标用户

面向轻量运动记录 / 健康习惯 App，适合每日打卡与周目标追踪；主要用户是晨跑爱好者与自我管理型上班族，他们需要快速记一笔、看一眼进度，而不是复杂的训练计划或社交流。

## 非目标

刻意不采用深色夜跑皮肤、金属质感与高密度数据表，保持低密度与轻松感；不实现 GPS 轨迹、地图、心率硬件同步与训练课程，心率数据为手填，趋势只做单折线展示。

## 复刻提示词

暖米晨跑记录：`#f6f1e6` 底、`#fffdf8` 卡、`#5fd01f` 荧光绿主按钮、`#ff5a5f` 心率折线；390×844 手机壳 + 底部三 tab；大字号 74% 目标进度条；距离/时长/心率三字段（范围 0.1–50 km / 1–600 分钟 / 40–220 bpm）；距离填 300 触发字段红框且进度趋势不变，改回后保存重算进度与折线末点。
