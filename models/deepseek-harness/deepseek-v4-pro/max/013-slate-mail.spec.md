## 响应式规则

- 视口 ≤ 768 px 时，三栏网格改为单列（1fr），整体高度改为自适应（min-height: 100vh）。
- 侧栏在窄屏下改为横向 flex 布局并允许换行，隐藏底部用量信息。
- 列表栏与阅读区在窄屏下最小高度 60vh。
- 阅读区顶部在窄屏下改为可换行，正文内边距收窄为 20 px 16 px。

## 内容与数据

- 内置 7 封示例邮件，字段含发件人、主题、预览、正文、时间、已读、星标、归档。
- 初始 2 封未读、2 封已星标；收件箱徽标实时显示未读数。
- 邮件正文用空行分段渲染为多段文本，末尾附发件人署名。
- 文件夹「已发送」「草稿」无数据，点击仅显示 toast 占位说明。

## 动效与反馈

- 写邮件、筛选按钮、星标按钮悬停均有背景色过渡，时长 150 ms。
- 列表项星标图标默认透明度 0，悬停或已星标时过渡到透明度 1，时长 150 ms。
- 阅读区展开动画 150 ms；toast 出现/消失透明度过渡 200 ms。
- 归档、星标、筛选、占位按钮均触发底部 toast 反馈，约 1.8 s 后自动隐藏。
- 尊重 `prefers-reduced-motion`：降级时关闭全部动画与过渡，保留点击、筛选、星标、归档等交互反馈。

## 复现验收清单

- [ ] 打开页面可见左中右三栏：深色侧栏、白色列表栏、浅色阅读区
- [ ] 点击任意未读邮件，该邮件加粗变细、未读点消失、阅读区显示对应正文，收件箱徽标数字减一
- [ ] 点击「只看未读」，列表只显示未读邮件且按钮变为「显示全部」，再点恢复全量
- [ ] 在阅读区点「星标」，按钮变实心并显示「已星标」，列表对应项出现实心星标
- [ ] 点「归档」，当前邮件从列表移除、阅读区跳到下一条并出 toast 提示
- [ ] 在搜索框输入关键词，列表实时过滤，清空后恢复
- [ ] 将视口收窄到 768 px 以下，三栏收纳为单列且不溢出、无横向滚动
