# 028 长表单

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`028-section-scroll.html`
- 复现范围：三节表单侧栏跳转、必填标记、保存草稿与分节提交

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 1280×800，grid 220px + 1fr | 左节导航右表单 | 圆角 8px |
| 节导航 | 220px `#fffbeb` | 三个 sec-link 带序号圆 | 可纵向 |
| 表单区 | flex 列 | scroll 区 + 固定 foot | form-scroll 可滚动 |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#fffbeb` | 外背景、foot、nav |
| `--surface` | `#ffffff` | 表单主区 |
| `--text` | `#451a03` | 标题、标签 |
| `--muted` | `#92400e` | 副标题、sec-link 默认 |
| `--accent` | `#d97706` | 选中边、按钮、序号 active |
| `--required` | `#dc2626` | 必填星号 |
| `--done` | `#059669` | 草稿提示、完成序号 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | Georgia, Songti SC, serif | 24px / 1.3 | 700 |
| 标题 | system-ui, sans-serif | 14–15px | 600–700 |
| 正文 | system-ui, sans-serif | 14px | 400 |
| 辅助文字 | system-ui, sans-serif | 13px | 400 |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 12–48px | field margin-bottom 20px |
| 控件圆角 | 6px | input、按钮 |
| 容器圆角 | 8px | frame |
| 边框 / 阴影 | 1px `#fde68a`；shadow `0 8px 32px rgba(217,119,6,.1)` | |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 节链接 `.sec-link` | 序号圆 24px + 文字 | 琥珀 muted 字 | active 右 3px accent 边 + 浅黄底；已完成节 `.done` 序号变绿 |
| 保存草稿 | outline 琥珀边 | 白底 | 点击显示 foot 绿字「草稿已于刚刚保存」2.5s |
| 提交按钮 | 琥珀实心 | 白字 | 前两节点击跳下一节；第三节点击变「已提交」disabled |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 1280px | 220 + 1fr | 三节独立 section 切换 display |
| ≤768px | nav 横向 flex | 节链接横排 |

## 内容与数据

- 标题「项目入驻申请」；三节：基本信息、团队与联系、项目详情
- 必填字段 label 带红色 `*`：项目名称、行业、负责人、邮箱、预期上线、需求描述
- 各节含 input/select/textarea 与中文 placeholder

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 草稿保存 | 0.2s opacity | draft-msg 显示 | 压缩 |
| 节切换 | 即时 | section active 切换、scrollTop 归零 | 无 |
