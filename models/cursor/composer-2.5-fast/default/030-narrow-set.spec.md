# 030 筛选检索

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`030-narrow-set.html`
- 复现范围：四筛选项（关键词、类型 chip、授权、时间）、结果计数联动、清除、至少三条结果卡片

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 1280×800，grid 280px + 1fr | 左筛选右结果 | 圆角 12px 绿边浅底 |
| 筛选侧栏 | 280px padding 28×24px | 标题 + 计数 + 四组 filter | 可滚动 |
| 结果区 | padding 28×32px | header + 卡片列表 | 可滚动 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 类型 Chip | padding 6×12px 胶囊 | 白底绿边 | `.active` 浅绿底 accent 边加粗字 |
| 关键词 input | 全宽 padding 9×12px | 绿边 | input 实时过滤 title/desc |
| 清除按钮 | 全宽 dashed 边 | 灰字 | 重置四 filter + 计数回 8 |
| 结果卡片 | 48px 图标 + 正文 | 绿浅图标底 | hover 阴影与 `#86efac` 边 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 1280px | 280 + 1fr | 初始 8 条，筛选后 ≥0 |
| ≤768px | 单栏堆叠 | 筛选在上 |

## 内容与数据

- 标题「资源库筛选」；计数「共 N 条结果」随 filter 变
- 四筛：关键词、类型（全部/模板/图标/图片）、授权 select、更新时间 select
- 八条种子数据，筛选后至少可展示三条（默认全显）
- 空结果文案「没有匹配的资源，试试放宽筛选条件」

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 筛选变更 | 即时 | 列表 rerender + 计数 | 无 |
| 卡片 hover | 0.15s | 阴影边框 | 压缩 |

## 复现验收清单

- [ ] 「清除全部筛选」恢复初始八条
- [ ] 结果区至少三条卡片（默认八条）
