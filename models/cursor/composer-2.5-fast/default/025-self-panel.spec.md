# 025 账号设置

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`025-self-panel.html`
- 复现范围：左侧身份行与五组设置导航，右侧详情面板切换与保存反馈

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 1280×800，grid 280px + 1fr | 左 nav 右 detail | 白底圆角 12px |
| 侧栏 | 280px，含身份卡片 margin 16px | 分组 label + nav-row 列表 | 固定高 |
| 详情区 | padding 32×40px | 标题 + 描述 + 表单/开关 | `overflow-y: auto` |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#f4f4f5` | 外背景 |
| `--surface` | `#ffffff` | 面板 |
| `--text` | `#18181b` | 主文字 |
| `--muted` | `#71717a` | label、描述 |
| `--accent` | `#2563eb` | 选中 nav、开关、保存按钮 |
| `--hover` | `#fafafa` | 行 hover、身份区底 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | system-ui, sans-serif | 22px / 1.3 | 600 |
| 标题 | system-ui, sans-serif | 16–18px | 600 |
| 正文 | system-ui, sans-serif | 14px / 1.5 | 400–500 |
| 辅助文字 | system-ui, sans-serif | 11–13px | 500–600 |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 12–32px | nav-row padding 12×20px |
| 控件圆角 | 8–10px | input、按钮、身份卡 |
| 容器圆角 | 12px | frame；avatar 50% |
| 边框 / 阴影 | 1px `#e4e4e7` | 分隔 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 导航行 `.nav-row` | 全宽 button | 14px 字 + 右箭头 | active `#eff6ff` accent 字；hover `#fafafa` |
| 开关 `.switch` | 44×24px 胶囊 | 灰底圆钮左 | `.on` 蓝底，钮右移 22px；点击 toggle |
| 保存按钮 | padding 10×20px | 蓝底白字 | 点击变「已保存」disabled |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 1280px | 280 + 1fr | 五 nav 项分三组 |
| ≤768px | 单栏 | 侧栏可折叠（默认仍双栏在宽屏） |
