## 状态地图

| 屏 | 内容 | 进入 |
| --- | --- | --- |
| s1 | 余额、来源、收款人 | 默认 |
| s2 | 金额输入 | 下一步 |
| s3 | 确认摘要 | 确认转账 |
| s4 | 成功凭证 | 支付成功 |

## 正常流程

选人 → 下一步 → 输入合法金额 → 确认 → 支付 → 凭证

## 异常触发与恢复

- **触发**：金额 > 当前来源可用余额（如输入 1500 且选零钱）
- **反馈**：alert-error 显示可用余额，阻止进入成功态
- **恢复**：降低金额或切换储蓄卡 → 重新确认 → 成功凭证

## 数据变化

- 成功支付后对应来源余额减少；失败时余额不变

## 人工验收步骤

**正常**：选张明 → 100 → 确认 → 见成功凭证。

**异常**：选零钱 → 输入 2000 → 见余额不足 → 改 500 或换储蓄卡 → 成功。
