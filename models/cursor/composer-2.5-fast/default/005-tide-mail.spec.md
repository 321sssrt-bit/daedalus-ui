# 005 找回密码

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`005-tide-mail.html`
- 复现范围：联系方式输入、发送主按钮、已发送等待态、回登录链接

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 100%，min-height 100vh | Flex 行：左 flex1 + 右 480px | 背景 `#e8f4f8` |
| 左侧品牌区 | flex 1，padding 48px | Flex 底对齐；底部 wave SVG | 渐变 `#0891b2`→`#0e7490` |
| 右侧表单区 | 宽 480px，padding 56px 48px | 纵向居中内容 | 白底 `#ffffff` |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#e8f4f8` | 页面浅青 |
| `--surface` | `#ffffff` | 表单区 |
| `--text` | `#0d3d4a` | 标题 |
| `--muted` | `#5a8a96` | 说明、返回链接 |
| `--accent` | `#0891b2` | 主按钮、链接 hover |
| `--sent` | `#059669` | 已发送标题、 spinner 弧 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 发送重置邮件 | 100%×48px | 背景 accent 白字 | hover `#0e7490`；发送后表单隐藏 |
| 联系方式输入 | 高 46px | 边框 `#b8dce6` | focus accent |
| 等待态 | 居中块 | 默认 display none | show 后 spinner+「邮件已发送」；重发 60s 倒计时 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280×800 | 左右分栏 | 表单 480px |
| 窄于 768px | 纵排；侧栏 min-height 180px | 表单 width 100% |

## 内容与数据

- 产品：潮汐邮
- 字段：邮箱或手机号
- 按钮：发送重置邮件
- 等待态：邮件已发送 + 收件地址 + 重发倒计时
- 返回：← 返回登录（恢复表单态）

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| Spinner | 1.2s rotate 循环 | SVG animateTransform | reduced-motion 关闭 animation |
| 发送切换 | 即时 class | 表单↔等待态 | 无 |
| 重发倒计时 | 1s 间隔 | 按钮文案递减 | 无 |
