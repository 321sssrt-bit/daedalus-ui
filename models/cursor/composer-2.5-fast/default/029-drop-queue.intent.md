# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-drop-queue.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

深色 DevOps 上传队列：等宽数字感 + 天蓝 accent，强调文件大小与状态 pill，像 CI  artifact 上传面板而非消费级网盘。

## 适用场景与目标用户

企业内部文档批传、品牌资产入库、设计交付工具；操作者需要看清队列并批量触发处理。

## 非目标

不做断点续传进度条百分比；不做预览缩略图；不连接云存储 API。

## 复刻提示词

1280 深色文件上传，虚线 dropzone，grid 队列行含文件名大小状态 pill，删除与开始处理流水线，天蓝 accent 终端风。
