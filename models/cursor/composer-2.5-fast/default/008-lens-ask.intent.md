# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-lens-ask.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

透镜问以镜头 icon 与 glassmorphism 模态模拟系统权限弹窗：清晰列权限项与用途，三种粒度（永久/一次/拒绝）符合现代 OS 惯例，sky  accent 区别于前后题的暖/紫/工业风。

## 适用场景与目标用户

笔记、会议、创作类桌面 Web 应用首次调用麦克风；用户需要理解数据如何处理再授权。

## 非目标

不模拟浏览器原生 chrome、不请求真 OS 权限；摄像头仅文案提及。

## 复刻提示词

深蓝 glass 权限弹窗：透镜 icon，麦克风+原因说明，允许/仅此一次/拒绝，各出不同色 result 条。
