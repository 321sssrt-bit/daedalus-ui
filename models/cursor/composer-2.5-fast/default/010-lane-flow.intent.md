# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-lane-flow.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

泳道流用 highway 隐喻：三列 pastel 泳道底色（蓝/黄/绿）像分道，白卡片可 drag 在列间「流动」。明亮 B2B 看板风，与 009 暗色 dashboard 形成工作台内对比。

## 适用场景与目标用户

敏捷研发团队桌面 Kanban；PM 与工程师拖拽任务、快速新建条目。

## 非目标

不做 WIP 限制 enforcement、不做多人实时光标；筛选仅为静态 badge。

## 复刻提示词

亮色三列 Kanban：待办/进行中/已完成 pastel 底色，卡片 draggable+click 选中，新建模态加到待办，列计数联动。
