# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-narrow-set.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

清新绿色资源库筛选：左侧窄栏集中条件、右侧卡片结果，chip 类型选择比 dropdown 更可视，计数紧贴标题强化「收窄」反馈。

## 适用场景与目标用户

设计资源站、模板市场、图标库；用户用多维度条件快速找到可商用素材。

## 非目标

不做分页 infinite scroll；不做保存筛选 preset；不做排序算法切换 UI。

## 复刻提示词

1280 资源筛选页，280px 绿系侧栏四 filter 含 chip 类型，结果计数动态，清除按钮，右侧卡片列表至少八条种子，accent #16a34a。
