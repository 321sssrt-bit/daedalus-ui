## 产品边界

实现：商品浏览、规格数量选择、购物车、提交、订单回执、库存不足拦截与改选恢复。不包含：登录、支付、物流追踪、商品评价。

## 状态地图

| 状态 ID | 可见元素 | 触发 |
| --- | --- | --- |
| browse | 商品网格、缺货模拟勾选 | 默认 / 回执后继续购物 |
| detail | 规格、数量、加入购物车 | 点击商品卡片 |
| cart | 购物车列表、合计、提交 | 导航或加购后 |
| receipt | 成功回执、订单号 | 提交成功 |

## 正常流程

1. 浏览商品网格 → 点击卡片进入详情
2. 选颜色/尺码、调数量 → 加入购物车
3. 购物车核对合计 → 提交订单
4. 显示订单回执与订单号

## 异常触发与恢复

- **触发**：勾选「模拟缺货」，选「燕麦色/L」加购或购物车含该规格后提交
- **反馈**：alert-error 指出缺货 SKU，提交按钮逻辑阻止成功
- **恢复**：改选其他颜色/尺码或删除缺货项 → 重新提交 → 回执成功

## 数据变化

- 加购：cart 数组 +1，badge 数量更新，合计递增
- 缺货提交：cart 不变，无订单号生成
- 成功提交：cart 清空，生成订单号与合计

## 人工验收步骤

**正常闭环**：打开页 → 点「羊毛混纺大衣」→ 默认规格 → 加购 → 提交 → 见绿色回执。

**异常恢复**：勾选模拟缺货 → 选燕麦色+L → 加购 → 提交见红告警 → 改 M 码或删项 → 再提交成功。
