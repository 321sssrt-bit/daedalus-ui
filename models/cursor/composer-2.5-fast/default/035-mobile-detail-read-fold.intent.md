## 设计意图

折页纸感阅读器：奶油底 + 衬线正文 + 赭石 accent，像杂志专栏而非社交 feed。字号滑块是唯一的「调节一项并改内容」，立刻影响排版。

## 适用场景与目标用户

长文阅读类 App（专栏、电子书章节）；需要舒适排版与无障碍大字模式的读者。

## 非目标

无评论、无分享面板、无 TTS。

## 复刻提示词

Cream paper mobile reader：serif body with drop cap、A−/A+ font control changing live text、collect + start reading footer buttons。
