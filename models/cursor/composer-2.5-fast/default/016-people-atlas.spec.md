# 016 成员目录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`016-people-atlas.html`
- 复现范围：人员四列网格 + 部门筛选 + 右侧简介面板

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | max-width 1280px | grid 1fr + 340px | 背景 `#e8f0e4` |
| 人员网格 | 4 列；gap 16px | 卡片居中 | 随筛选重绘 |
| 简介面板 | 340px；sticky top 28px | 空态居中 / 详情 | min-height 320px 空态 |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#e8f0e4` | 背景 |
| `--surface` | `#f7faf5` | 卡片 |
| `--text` | `#1a2e1a` | 主文字 |
| `--muted` | `#5c735c` | 副文案 |

| `--border` | `#c5d4c0` | 边框 |

| 角色 | 字号 | 字重 |
| --- | --- | --- |

| 姓名 | 15–20px | 600 |

### 间距、圆角

| 令牌 | 值 |
| --- | --- |
| 卡片圆角 | 12–14px |
| 头像 | 64px / 简介 80px |

## 组件规格与状态

| 组件 | 默认 | 状态 |
| --- | --- | --- |
| 筛选 pill | 白底边框 | active：`#2d6a4f` 白字 |
| 人员卡 | 头像+姓名+角色 | hover 上浮 -2px + 阴影 |
| 简介面板 | 「点击任意成员查看简介」 | 选中后显示 bio、meta、关闭 |

## 响应式规则

1280px 四列网格；768 min-width。

## 内容与数据

- 标题：「人物图集」；副标 Atlas 实验室 12 人
- 筛选：全部 / 研究 / 工程 / 运营
- 8 人示例；每人含 bio 与 meta
- 点击后在右侧展示完整简介

## 动效与反馈

hover 卡片 translateY -2px 0.2s；reduced-motion 禁用。
