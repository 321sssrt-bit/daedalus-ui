# 001 登录

## 意图元数据

- 意图版本：1
- 对应规范：`001-ink-gate.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以水墨档案馆的暗色纸面与金字门闩为隐喻：左侧留白绘「墨」字与弧线，右侧窄栏表单如进门验帖。 serif 字体与低饱和金 accent 传达文献产品的庄重感，而非通用 SaaS 蓝白登录。

## 适用场景与目标用户

面向学术笔记、档案馆、文化 IP 管理类桌面产品；用户为研究员、编辑，需要在安静、有书卷气的界面中完成日常登录。

## 非目标

不采用 bright gradient 互联网风、不展示第三方 OAuth 图标墙、不做移动端优先的单手布局；验证码仅为字段切换演示，非真实短信流程。

## 复刻提示词

暗色水墨登录：左装饰 SVG「墨」字，右 480px 窄表单，宋体+金色 accent，密码/验证码可切换，忘记密码链接，1280 桌面感。
