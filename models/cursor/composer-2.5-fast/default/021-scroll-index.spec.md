# 021 内容目录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`021-scroll-index.html`
- 复现范围：左侧六条文章目录与右侧摘要阅读预览，含选中态与「阅读全文」反馈

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 1280×800 px 外框，body 居中 padding 24px | body flex 居中 | 背景 `#f5efe4` |
| 左侧目录 | 320px 宽 aside，全高 | flex 列：品牌区 + 可滚动 nav | `overflow-y: auto` |
| 右侧主区 | 剩余 960px main | flex 列：标题区 + 摘要区 + 页脚 | 摘要区 `overflow-y: auto` |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#f5efe4` | 页面背景 |
| `--surface` | `#fffcf7` | 主面板背景 |
| `--text` | `#2c2416` | 正文与标题 |
| `--muted` | `#7a6f5e` | 作者、辅助文字 |
| `--accent` | `#8b4513` | 序号、选中边线、主按钮 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | Songti SC, SimSun, serif | 28px / 1.35 | 700 |
| 标题 | Songti SC, SimSun, serif | 15–22px / 1.35 | 600–700 |
| 正文 | Songti SC, SimSun, serif | 17px / 1.85 | 400 |
| 辅助文字 | system-ui, sans-serif | 12–14px / 1.5 | 400 |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 8–40px | 目录项 padding 14–16px |
| 控件圆角 | 4–6px | 按钮、目录项 |
| 容器圆角 | 无（直角边框） | 1280 外框 |
| 边框 / 阴影 | 1px `#e0d5c4`；shadow `0 12px 40px rgba(44,36,22,.08)` | 分隔与浮起 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 目录项 `.index-item` | 全宽 button，padding 14px 16px | 透明底、15px 标题 | hover `#fff8ee`；active 左 3px `#8b4513` 边 + `#fff8ee` 底；focus 2px accent outline |
| 主操作 `.btn-read` | padding 8×18px | 背景 `#8b4513` 白字 | hover `#6d3610`；disabled 灰化不可点；初始 disabled |
| 内容容器 `.abstract` | flex:1 可滚动 | 17px 摘要段落 + tag 胶囊 | 随选中条目切换 innerHTML |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280px | 320 + 1fr 双栏 | 不变 |
| ≤768px | 单栏，frame 宽 100% | 目录与摘要纵向堆叠 |

## 内容与数据

- 品牌：「深读目录」「卷十二 · 2026 春刊」
- 六篇文章：编号 01–06，含标题、作者、来源、阅读时长、标签、摘要
- 初始选中第 1 篇；页脚显示篇数与预计阅读时间
- 点击「阅读全文」后按钮文案变为「已加入阅读队列」并 disabled

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 目录 hover | 0.2s ease background | 背景变浅 | 时长压缩至 0.01ms |
| 切换条目 | 即时 | 标题、摘要、标签、页脚更新 | 无动画依赖 |
