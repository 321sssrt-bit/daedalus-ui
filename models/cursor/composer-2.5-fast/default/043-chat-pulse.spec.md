# 043 即时通讯产品

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`043-chat-pulse.html`
- 复现范围：会话列表、发消息、送达状态、发送失败与重试

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 手机框 | 390×844 | 居中 | 紫系深色 |
| 工具栏 | padding 14px 16px | flex 两端 | 含失败模拟开关 |
| 会话列表 | flex 1 | 纵向 | scroll |
| 聊天区 | messages flex 1 | 气泡 column | 底部 compose 固定 |

## 组件规格与状态

| 组件 | 默认 | 状态 |
| --- | --- | --- |
| 会话行 | padding 14px | hover/active 浅紫底 |
| 我方气泡 | 右对齐紫底 | failed 红字+重试钮；delivered 绿字 |
| 发送钮 | 圆形 40px | hover 变亮 |
| 失败开关 | checkbox 16px | 勾选后下一条失败 |

## 响应式规则

主视口 390 宽；宽屏保持手机框。

## 内容与数据

3 个预设会话；发送后更新 preview；失败保留原文。

## 动效与反馈

reduced-motion 禁用 transition。

## 复现验收清单

- [ ] 列表→聊天→返回
- [ ] 发送显示已送达
- [ ] 勾选失败→下条失败+重试→已送达
- [ ] 气泡左右对齐正确
- [ ] 七色值一致

## 产品边界

含：列表、单聊、状态、失败重试。不含：群聊、语音、图片、已读回执。

## 状态地图

listScreen ↔ chatScreen；failMode 影响下次 send。

## 正常流程

选会话 → 输入 → 发送 → 已送达

## 异常触发与恢复

勾选「模拟发送失败」→ 发消息 → 失败+重试按钮 → 点重试 → 已送达；内容不丢失

## 数据变化

msgs 数组追加；失败时 s='failed'，重试改 'delivered'

## 人工验收步骤

**正常**：进设计组 → 发「测试」→ 已送达。

**异常**：勾选模拟 → 发「失败测试」→ 见失败 → 重试 → 已送达。
