# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-success-done-ticket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

绿色 perforated ticket 医疗挂号回执：成功圆勾 + 虚线票券像实体凭条，关键编号/time/席位一眼扫完。折叠明细收纳隐私与次要信息，完成钮收束流程。

## 适用场景与目标用户

预约/挂号/订票类 App 的成功页；用户需要截图留存编号与到院信息。

## 非目标

无地图导航、无添加到日历、无分享海报。

## 复刻提示词

Mint green mobile success ticket：check icon、dashed perforation card with booking ID time seat、expandable details accordion、full-width 完成 button。
