含：搜路线、选班次、选座、下单、电子票。不含：退票、身份证、多乘客。

## 状态地图

s1→s2→s3→s4→s5；route 对象保留贯穿。

## 正常流程

搜索 → 选 08:00 班次 → 选 1A → 确认 → 提交 → 凭证

选 12:30 售罄班次无效；或选座 2C（预设售罄）→ 提交见告警 → 改 1A 或换班次 → 成功凭证

## 人工验收步骤

**正常**：默认北京南-上海虹桥 → 搜 → 08:00 → 1A → 提交 → 票。

**异常**：选 2C 座 → 提交见售罄 → 改 1A → 成功。
