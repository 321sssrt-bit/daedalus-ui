# 020 定价

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`020-tier-glow.html`
- 复现范围：三档定价卡 + 权益列表 + 推荐档 + 购买/联系

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | max-width 1280px；padding 48×40px | 居中列 |  radial 渐变顶 `#1a1035` |
| .hero | margin-bottom 48px | 居中标题 | 渐变字 |
| 三档 | 3 列 grid gap 24px | 等高 flex 列 | 推荐档 glow |

### 字体

| 角色 | 字号 | 字重 |
| --- | --- | --- |
| Hero | 32px | 700 渐变 |

| 权益 | 14px | 400 |

### 间距、圆角

卡片圆角 16px；padding 32×28px；推荐 badge top -12px。

## 组件规格与状态

| 组件 | 默认 | 状态 |
| --- | --- | --- |
| 推荐档 | 边框 `#a78bfa` + glow | 「推荐」渐变 badge |
| primary CTA | 紫渐变 | hover brightness 1.1；购买后 disabled |
| secondary CTA | 描边 | 联系后文案变「已打开联系表单」 |
| off 权益 | opacity 0.4 | 前缀 — |

## 响应式规则

1280 三列并排；768 min-width。

## 内容与数据

- 标题：「选择你的 Glow 方案」
- 三档：入门 ¥0、专业 ¥199/月（推荐）、企业 定制
- 每档 ≥4 条权益；部分 off
- 专业「立即购买」、企业「联系销售」

## 动效与反馈

tier hover translateY -4px 0.3s；reduced-motion 禁用。
