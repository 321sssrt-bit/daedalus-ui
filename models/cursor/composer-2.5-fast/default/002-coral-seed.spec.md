# 002 注册

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`002-coral-seed.html`
- 复现范围：桌面注册卡片，含至少两个填写项、注册主按钮与已有账号去登录

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 100% 宽，min-height 100vh，padding 32px | Flex 居中 | 背景 `#fff5f0` |
| 注册卡片 | max-width 520px，padding 48px 40px | 块级纵向堆叠 | 白底圆角 24px，阴影 rgba(255,107,91,.12) |
| 装饰光斑 | 伪元素 180×180px 右上 | absolute 定位 | radial-gradient 珊瑚色，opacity .35 |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#fff5f0` | 页面暖粉背景 |
| `--surface` | `#ffffff` | 卡片表面 |
| `--text` | `#3d2c29` | 主文字 |
| `--muted` | `#9a7b73` | 副标题、协议说明 |
| `--accent` | `#ff6b5b` | 品牌、按钮、链接 |
| `--seed` | `#2d8f6f` | 输入 valid 边框 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | PingFang SC, Microsoft YaHei | 26px / 1.2 | 700 logo |
| 标题 | 同上 | 18px 品牌 | 700 |
| 正文 | 同上 | 15px 输入 / 14px 副标题 | 400–600 |
| 辅助文字 | 同上 | 13px 协议 | 400 |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 18px 字段间距 | 表单 |
| 控件圆角 | 14px | 输入、按钮 |
| 容器圆角 | 24px（768 下 18px） | 卡片 |
| 边框 / 阴影 | 2px `#f0ddd6`；卡片 shadow 0 12px 40px | 输入默认 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 注册并进入 | 宽 100%，高 50px | gradient `#ff6b5b`→`#ff8566` | hover translateY(-1px)；disabled 45% 透明；勾选+填完启用 |
| 文本输入 | 高 46px，padding 0 16px | 边框 2px `#f0ddd6` | focus accent 边框+4px 光晕；有内容 valid 边框 `#2d8f6f` |
| 协议勾选 | 16×16 checkbox | accent-color accent | 未勾选时主按钮 disabled |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280×800 | 卡片居中 max 520px | 标准 padding 48×40 |
| 窄于 768px | 仍居中 | 卡片 padding 32×24，圆角 18px |

## 内容与数据

- 产品名：珊瑚种
- 标题：种下你的账号；副标题：三步之内完成注册…
- 字段：昵称、邮箱、密码（至少两个填写项满足）
- 协议勾选必选
- 主按钮：注册并进入
- 底部：已有账号？去登录

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 按钮 hover | 0.15s | 上移 1px | 关闭 |
| Toast 出现 | 0.3s opacity | 底部黑底提示 | 关闭 transition |
| 输入 valid | 0.2s | 边框变绿 | 关闭 |

## 复现验收清单

- [ ] 1280px 下暖粉背景居中白卡片，宽不超过 520px
- [ ] 五个 hex 色与 spec 一致，主按钮渐变含 `#ff6b5b`
- [ ] 未勾选协议或未填完字段时「注册并进入」为 disabled
- [ ] 填完三项并勾选协议后按钮可点，提交出现底部 toast
- [ ] 768px 下卡片 padding 变为 32×24px
