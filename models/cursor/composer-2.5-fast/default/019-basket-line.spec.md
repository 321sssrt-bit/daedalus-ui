# 019 购物车

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`019-basket-line.html`
- 复现范围：≥3 件商品行 + 数量加减 + 删除 + 合计 + 去结算

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | max-width 1280px | grid 1fr + 300px | 背景 `#fefefe` |
| 商品列表 | 1fr | 行 grid 48+1fr+120+100+40 | 虚线分隔 |
| 合计侧栏 | 300px sticky top 32px | 边框 2px | 小计/运费/应付 |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#fefefe` | 背景 |
| `--text` | `#222222` | 主文字 |
| `--muted` | `#666666` | 规格 |
| `--accent` | `#222222` | 结算按钮 |
| `--border` | `#dddddd` | 虚线 |
| `--line` | `#333333` | 实线边框 |
| `--danger` | `#c0392b` | 删除 × |

### 字体

| 角色 | 字体栈 | 字号 |
| --- | --- | --- |
| 标题 | Courier New, monospace | 22px |
| 小计 | Courier New | 15–18px |
| 商品 | Segoe UI, PingFang SC | 15px |

### 间距

行 padding 20px 0；qty 按钮 32×32px。

## 组件规格与状态

| 组件 | 默认 | 状态 |
| --- | --- | --- |
| qty −/+ | 边框 `#333` | minus  qty>1 才减；plus 递增 |
| 删除 × | `#c0392b` | 移除行并重算 |
| 合计 | 运费 ¥0 | 应付=各 subtotal 之和 |
| 去结算 | 黑底白字 | click alert 应付金额 |

## 响应式规则

1280 列表+300 侧栏；768 min-width。

## 内容与数据

- 初始 4 件：台灯 ¥249×1、抱枕 ¥89×2、保温杯 ¥168×1、收纳盒 ¥56×1
- 标题显示件数 count
- 删除至 0 显示「购物车是空的」

## 动效与反馈

数量与合计即时重算；无动画。
