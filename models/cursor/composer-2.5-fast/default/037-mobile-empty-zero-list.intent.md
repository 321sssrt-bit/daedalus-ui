# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-mobile-empty-zero-list.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

薰衣草零清单：柔和紫色降低「空白」的挫败感，虚线 SVG 插画暗示「待填充」。单一主 CTA 占据视觉中心，底栏保留产品骨架让用户知道还在 App 内。

## 适用场景与目标用户

Todo/清单类 App 首次使用或清空后的空列表；需要明确下一步行动的新用户。

## 非目标

无示例数据预填、无导入引导多步骤。

## 复刻提示词

Lavender mobile empty list：dashed clipboard SVG with zero badge、headline + explanation、purple pill「去创建清单」、3-tab bottom bar with 清单 active。
