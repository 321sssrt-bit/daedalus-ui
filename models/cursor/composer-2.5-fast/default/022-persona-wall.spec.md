# 022 个人主页

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`022-persona-wall.html`
- 复现范围：创作者个人主页含身份区、作品网格、动态列表、关注与联系交互

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 1280×800，背景 `#0a0a0a` | 单列 frame，`overflow-y: auto` | 全页滚动 |
| Hero 区 | padding 48×56px，grid 120px + 1fr + auto | 头像、文案、操作按钮三列 | 底边 `#2a2a2a` |
| 作品墙 | padding 32×56px，3 列 grid gap 16px | 卡片等高 thumb 140px | 静态网格 |
| 动态区 | hero 下方 feed 列表 | 圆点 + 文字 + 时间 | 分隔线 `#2a2a2a` |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--page` | `#0a0a0a` | 页面背景 |
| `--surface` | `#141414` | 次要底 |
| `--text` | `#f5f5f5` | 主文字 |
| `--muted` | `#888888` | 辅助、日期 |
| `--accent` | `#ff4d6d` | 主按钮、圆点、hover 边 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | system-ui, sans-serif | 36px / 1.2 | 800, -0.02em |
| 标题 | system-ui, sans-serif | 15px / 1.35 | 600 |
| 正文 | system-ui, sans-serif | 14px / 1.5 | 400 |
| 辅助文字 | system-ui, sans-serif | 11–13px / 1.45 | 400 |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 12–48px | hero、grid gap |
| 控件圆角 | 6–8px | 按钮、卡片 |
| 容器圆角 | 4px | 头像 |
| 边框 / 阴影 | 1px `#2a2a2a` | 卡片边框 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 主操作 `#btnFollow` | padding 12×24px | 背景 `#ff4d6d` | 点击切换「关注/已关注」，样式 primary/secondary 互换；toast 反馈 |
| 次操作 `#btnContact` | 透明底 1px 边框 | 白字 | hover 浅底；toast「邮件已复制」 |
| 作品卡片 `.card` | thumb 140px + body 16px padding | `#1e1e1e` 底 | hover accent 边框 + translateY(-2px)；Enter 可触发 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 1280px | 3 列作品网格 | 不变 |
| ≤768px | 2 列网格，padding 缩至 24px | 按钮尺寸不变 |

## 内容与数据

- 名字「陆野」；身份句「独立视觉设计师 · 专注品牌识别与编辑设计，现居上海」
- 统计：47 作品、2.3k 关注者、186 正在关注

- 三条近期动态含时间与正文

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
