# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-coral-seed.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以「珊瑚种」成长记录产品为设定：暖珊瑚渐变、大圆角与柔和光斑营造友好 onboarding 感。实时 valid 反馈与协议 gating 让注册流程有节奏，区别于 001 的深色文献风。

## 适用场景与目标用户

面向习惯打卡、日记、习惯养成类应用的年轻桌面用户；期望注册过程轻量、无压迫感。

## 非目标

不做分步 wizard、不集成社交注册、不做复杂密码强度条；登录跳转仅为 toast 演示。

## 复刻提示词

暖珊瑚圆角注册卡：520px 居中，昵称+邮箱+密码，协议勾选解锁按钮，已有账号去登录，柔和 gradient 主按钮。
