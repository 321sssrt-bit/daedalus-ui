# 005 找回密码

## 意图元数据

- 意图版本：1
- 对应规范：`005-tide-mail.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

潮汐邮用海洋青与 wave SVG 传达「信件随波送达」；左右分栏在桌面给出品牌叙事，发送后等待态含 spinner 与重发冷却，完整覆盖找回密码心理路径。

## 适用场景与目标用户

企业邮箱、协作工具桌面端的密码重置；用户焦虑时需要有明确「已发送」确认与回登录退路。

## 非目标

不做 OTP 六位输入（留给 006）、不做多因素选择、不真发邮件。

## 复刻提示词

青蓝 split 找回密码：左 wave 品牌区，右邮箱输入+发送，发送后 spinner 等待态与 60s 重发，顶部返回登录。
