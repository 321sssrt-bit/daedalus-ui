# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-confirm-launch-check.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

深海军控台气质，琥珀强调色传递「即将点火」的紧张感。后果块左色条 + 勾选门禁让不可逆操作有仪式感和明确责任确认，适合 DevOps / CMS 发布场景。

## 适用场景与目标用户

面向已审核通过、即将推 prod 的运维或产品经理；在桌面宽屏控制台完成最后一道人工确认，强调环境名与构建号可核对。

## 非目标

不做多步骤向导、不回滚流程、不用红色删除式视觉；不模拟真实部署日志页。

## 复刻提示词

深夜 mission control 发布确认：navy `#0a1628`、amber accent、左色条后果说明、勾选后才亮的确认按钮、右下角返回与确认。
