# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-access-map.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

深紫管理后台风角色矩阵：侧栏角色像 ACL 条目，主区按模块分组权限，预览模式让管理员安全查看「他人所见」而不误改。

## 适用场景与目标用户

团队协作后台、CMS 多角色管理；管理员配置编辑者与查看者的能力边界。

## 非目标

不做自定义角色创建；不做权限继承树可视化；不审计日志。

## 复刻提示词

1280 角色权限页，240px 深紫角色侧栏三角色，右栏分组 checkbox 权限清单，预览只读模式，保存 toast，indigo accent。
