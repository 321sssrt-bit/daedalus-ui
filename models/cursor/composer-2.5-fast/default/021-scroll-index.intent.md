# 021 内容目录

## 意图元数据

- 意图版本：1
- 对应规范：`021-scroll-index.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以文学季刊的纸质感与宋体排版，让「目录—摘要」的阅读动线像翻索引卡：左侧编号目录建立秩序，右侧摘要区承担预览，适合长文聚合平台的首屏。

## 适用场景与目标用户

独立杂志、付费 newsletter、学术辑刊等需要一次展示多篇长文、且用户习惯按目录挑选阅读的场景；目标读者为深度阅读者。

## 非目标

不做无限滚动信息流；不模拟全文排版；不使用外网字体或图片占位。

## 复刻提示词

暖米色纸感季刊目录页，320px 左栏六条编号文章目录含作者，右栏选中摘要与标签，宋体标题 system 辅助字，赤陶色 accent，1280 桌面双栏。
