## 内容与数据

品牌「文献港 · 馆藏检索系统 LIBRARY OPAC」。初始检索词「量子引力导论」，结果 0 条：检索词仍以等宽字体保留在输入框与「检索词」chip 中，右侧红字「共 0 条馆藏记录」。空态主说明「馆藏目录中没有找到与『量子引力导论』相关的记录」，建议核对用字、缩短检索词，并给出 4 个可点的改搜词：引力波（2 条结果）、量子场论（3 条）、时间简史（1 条）、弦论（0 条，仍为空态）。有结果时显示目录卡：索书号（如 P145.8/12）、书名、著者与出版社、馆藏地（如「三层 · 自然科学阅览区」）、状态印章（在架 / 已借出 + 应还日期）。空态底部注明「可到一层总咨询台填写《读者荐购单》，采购周期约 3 周」。
