## 产品边界

单节课（水循环）的「读课文 → 三题练习 → 批改解析 → 错题订正 → 通关」学习闭环。作答数据仅存于页面会话，刷新即还原；不含题库浏览、计时、音视频课、多课解锁的真实内容、账号与排行。第二、三课恒为锁定演示，仅弹 Toast。

## 正常流程

1. 打开页面，停在 S0 课文：读三个知识点与水循环示意。
2. 点「学完啦，开始练习」→ S1，三道单选题出现，交卷按钮禁用并提示「还剩 3 题」。
3. 依次选择第 1 题 A、第 2 题 B、第 3 题 C（均为正确答案），交卷按钮逐个计数并解禁。
4. 点「交卷」→ S2：「答对 3 / 3 题」，三题全黄 ✓，主按钮变为「查看通关章」。
5. 点「查看通关章」→ S4：印章与「订正成功 · 本课通关」出现，顶栏三星 ★★★，侧栏第一课「已通关 · 3/3」。

## 异常触发与恢复

1. 触发：S1 中第 1 题故意选 B「小沙粒」（页面有显性小实验提示），第 2、3 题选对，点「交卷」。
2. 异常反馈：S2 成绩单「答对 2 / 3 题 · 有 1 题需要订正」；第 1 题粉色 ✕，标注「你的答案：B · 小沙粒」「正确答案：A · 水蒸气」，附粉笔解析与订正提示；第 2、3 题黄 ✓ 保留。
3. 数据保留：顶栏星星已点亮 ★★☆，侧栏显示「进行中 · 已答对 2/3」，已答对题的成绩不丢。
4. 恢复：点「返回错题订正（1 题）」→ S3 仅第 1 题重现，标注「上次选择了 B」；选 A 后「提交订正」解禁。
5. 重新成功：提交后 S2「答对 3 / 3 题」，点「查看通关章」进入 S4 通关。若订正时仍选错（如选 C），回到 S2 且解析保留、已答对题不受影响，可再次订正直至答对。

## 人工验收步骤

正常闭环：

1. 打开 `050-chalk50.html`，预期：木框黑板内左侧课程表三张卡，右侧课文含三知识点与水循环示意。
2. 点「学完啦，开始练习」，预期：3 题出现，交卷禁用显示「交卷（还剩 3 题）」。
3. 依次选 A、B、C，预期：每题选中项变黄，计数变「已作答 3 / 3」，交卷解禁。
4. 点「交卷」，预期：成绩单「答对 3 / 3 题」，三题黄 ✓，主按钮为「查看通关章」。
5. 点「查看通关章」，预期：印章页出现，顶栏 ★★★，侧栏第一课「已通关 · 3/3」。

异常恢复：

6. 点侧栏第一课回到课文，再进练习；第 1 题选 B、第 2 题选 B、第 3 题选 C，点「交卷」，预期：成绩单「答对 2 / 3 题」，第 1 题粉 ✕ 附解析，第 2、3 题黄 ✓。
7. 直接刷新前的状态确认：星星 ★★☆、侧栏「已答对 2/3」，说明答对题成绩保留。
8. 点「返回错题订正（1 题）」，预期：只有第 1 题，显示「上次选择了 B」，提交订正禁用。
9. 选 C 再提交，预期：回到成绩单仍是 2 / 3，第 1 题解析保留并标注上次选择 C（订正仍错不丢成绩）。
10. 再点「返回错题订正」，选 A 提交，预期：成绩单 3 / 3，点「查看通关章」看到印章与 ★★★，闭环成功。
11. 把窗口缩到 768px 宽，预期：课程表移到上方、卡片纵向排列，无横向滚动。
