## 内容与数据

- 店头:徽标「杂」、「转角小卖部」、「幸福里社区店 · 营业至 23:00」,右侧「购物车 N 件」。
- 小票抬头:店名、「幸福里小区 3 栋 101 室」、单号 № 20250612-0042、收银员阿芳。
- 商品四行(名称 / 单价 / 初始数量):光明优倍鲜奶 950ml ¥13.50 ×2;白象汤好喝豚骨面 5 连包 ¥15.80 ×1;卫龙大面筋 102g ¥4.50 ×3;本地小番茄 500g ¥9.90 ×1。
- 计费规则:小计 = Σ单价×数量;满 30 减 5(不满则为 ¥0.00);配送费 ¥3.00,折后满 ¥39 免(显示「已免」绿标);合计 = 小计 − 满减 + 配送费。初始:小计 ¥66.20、满减 −¥5.00、配送费 ¥0.00、合计 ¥61.20。
- 金额一律等宽字体、两位小数、¥ 前缀;红章初始「已核算」,下单后变「已收款」。
- 底部条码为纯 CSS 渐变,页脚「谢谢惠顾 · 小票即售后凭证,请妥善保留」。

## 动效与反馈
