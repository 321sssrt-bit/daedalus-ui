## 产品边界

- 单页创作工具：只含一件作品的编辑与导出，不含作品库、导入、撤销栈与账号体系。
- 预览为示意场景（SVG 山景剪影），参数以 CSS filter 模拟显影效果，不做真实像素处理。
- 导出结果为模拟产物（文件名 / 格式 / 尺寸 / 体积），不触发真实文件下载。
- 异常仅覆盖「导出条件不支持」一类：透明背景 × JPG；其余格式组合均视为合法。

## 正常流程

1. 打开页面，默认 PNG、1×，预览为月色山景。
2. 拖动曝光 / 反差 / 色温 / 颗粒滑杆，或切换图层显隐、勾选「透明背景」，中央预览实时更新。
3. 在格式卡中选择 PNG / WebP / TIFF 之一，按需切换输出倍率。
4. 点「开始导出」，弹出显影进度（药液浸润 → 影像浮现 → 水洗收尾）。
5. 进度 100% 后显示结果卡：文件名、格式、尺寸、体积、透明背景保留情况；点「继续编辑」回到主视图，底部状态变为「已导出 …」。

## 异常触发与恢复

- 触发入口（页面明示）：导出面板虚线提示框写明「勾选『透明背景』后选择 JPG，再点『开始导出』会触发格式冲突检查」；JPG 卡常驻红色「不支持透明」标签。
- 触发：勾选「透明背景」+ 选中 JPG + 点「开始导出」→ 导出被阻止，弹层列出两处冲突设置，图层行与 JPG 卡红色呼吸描边；参数、图层、倍率全部保留。
- 恢复路径 A（一键）：点「改用 PNG 重新导出」→ 格式自动切 PNG、描边消除、直接显影并成功出片。
- 恢复路径 B（手动）：「返回修改设置」→ 改选 WebP / TIFF 或取消「透明背景」勾选 → 再点「开始导出」→ 正常显影成功。

## 人工验收步骤

正常闭环：
1. 打开 `047-darkroom47.html`，确认三列工作台与红灯顶栏。
2. 把曝光拉到 +1.0 EV，确认预览变亮、读数显示「+1.0 EV」。
3. 确认格式为 PNG，点「开始导出」→ 看到进度条推进 → 结果卡显示「未定名作品-20261108.png / PNG · 支持透明 / 1280 × 800 px / 2.4 MB」。
4. 点「继续编辑」回主视图，底部状态显示「已导出 PNG · 1280×800」。

异常恢复：
1. 在图层「底片背景」勾选「透明背景」，预览出现棋盘格。
2. 选中 JPG 卡，点「开始导出」→ 确认弹层「导出被阻止」指出 JPG 与透明背景两处冲突，且 JPG 卡与图层行红色描边呼吸。
3. 点「返回修改设置」，确认滑杆数值与图层勾选原样保留。
4. 改选 WebP，再点「开始导出」→ 显影完成，结果卡显示 webp 文件与「已保留 Alpha 通道」。
5. 再次制造冲突后改用「改用 PNG 重新导出」一键路径，确认直接进入显影并成功。
