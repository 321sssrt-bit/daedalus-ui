## 内容与数据

- 品牌：顶条「电波 RADIO-43」+「UHF 446.2 · 加密信道」，等宽字体。
- 频道 3 个，顺序固定：LYNX-02 山猫哨所（未读 2）、ROCK-00 磐石指挥所（未读 0）、NITE-07 夜莺侦察组（未读 5）。

## 产品边界

一个军用对讲机风格的单频道即时通讯原型：支持频道列表、单会话收发、送达状态机（发送中 / 已送达 / 发送失败 / 重试）。不含：多人群聊管理、图片语音消息、消息撤回与编辑、账号体系、真实网络层（延迟为前端模拟）。

## 正常流程

1. 页面加载后停在频道列表，可见 3 个频道及未读数。
2. 点击「LYNX-02 山猫哨所」进入会话，未读徽标清零，历史电文按收发方向排列。
3. 在输入框输入「电波收到，继续观测。」，发送按钮由灰变琥珀可用态。
4. 点击「发送」，气泡出现并显示「发送中…」；约 800ms 后元信息变为「已送达 ✓」。
5. 返回频道列表，该频道预览更新为刚发出的电文与时间。

## 异常触发与恢复

1. 触发：在会话页打开右上角「模拟断网」开关，状态行变为「LINK LOST · 信号中断 · 消息将发送失败」，并弹出 toast 提示。
2. 输入任意电文并发送：气泡先「发送中…」，约 800ms 后变为失败态——气泡背景 #3D2F16、琥珀描边、元信息「发送失败」，气泡下方出现「↻ 重试发送」按钮，电文原文完整保留；频道列表预览显示「[发送失败]」前缀。
3. 保持断网点击重试：再次进入「发送中…」后仍失败，toast 提示「重试仍失败：信号中断中」。
4. 恢复：关闭「模拟断网」开关，状态行恢复「LINK OK」；点击失败消息的「↻ 重试发送」，约 800ms 后气泡恢复为正常样式并显示「已送达 ✓」，toast 提示「重发成功，电文已送达」。

## 数据变化

- `CHANNELS` 对象持有 3 个频道的 `msgs` 数组与 `unread` 计数；进入会话时 `unread` 置 0 并重绘列表徽标。
- 发送：向当前频道 `msgs` 追加 `{from:"me", text, time: 当前 HH:MM, status:"sending"}`，800ms 后按开关状态改写为 `done` 或 `fail`。
- 重试：仅当 `status === "fail"` 时生效，先将该条置回 `sending` 并刷新时间戳，再按开关状态落定。
- 列表预览始终取频道最后一条消息：失败时加 `[发送失败] ` 前缀，发送中加 `[发送中…] ` 前缀；时间与状态变化后列表与会话视图同步重绘。

## 人工验收步骤

正常闭环：

1. 打开页面，确认手机框内为频道列表，山猫哨所有 2 条未读。
2. 点击山猫哨所 → 进入会话，未读消失，顶部显示呼号 LYNX-02。
3. 输入「收到，保持静默。」→ 发送按钮亮起 → 点击发送。
4. 预期：气泡显示「发送中…」，随后变「已送达 ✓」；返回列表可见预览更新。

异常恢复：

1. 在会话页打开「模拟断网」开关 → 预期状态行变「LINK LOST」并弹 toast。
2. 输入「请求北向通道静默复核。」并发送 → 预期气泡最终变琥珀失败态，原文完整，出现「↻ 重试发送」。
3. 不关开关直接点重试 → 预期再次失败且文案仍在。
4. 关闭「模拟断网」→ 点「↻ 重试发送」→ 预期气泡恢复绿色描边并显示「已送达 ✓」，返回列表预览无前缀告警。
