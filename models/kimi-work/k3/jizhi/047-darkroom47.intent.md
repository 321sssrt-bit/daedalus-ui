# 047 暗房

## 意图元数据

- 意图版本：1
- 对应规范：`047-darkroom47.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把创作工具做成一间真正的暗房：近黑环境里只亮一盏红色安全灯，琥珀色承担所有「正在发生」的反馈（参数读数、选中态、进度）。导出冲突不做成冷冰冰的报错，而像师傅按住你的手：指出哪两个设置在打架，并递上「改用 PNG」这一步到位的修正。取舍是预览用 CSS 滤镜模拟显影而非真实图像管线，换来零依赖与即时响应。

## 适用场景与目标用户

摄影后期、胶片扫描件调校、播客封面与独立游戏贴图等轻量创作场景；用户是习惯夜间工作的独立创作者与摄影爱好者，熟悉图层与曝光语言，需要「所见即所得 + 导出前兜底校验」。

## 非目标

- 不做真实图像解码、RAW 处理与色彩管理，预览仅示意。
- 不做多作品管理、云同步、协作与版本历史。
- 不堆快捷键面板、曲线工具等专业重型控件，保持四参数 + 三图层的轻量台面。
- 不用常见的白底编辑器皮肤，也不做霓虹赛博风，坚持暗房红 + 琥珀双色纪律。

## 复刻提示词

「近黑红暗房安全灯氛围的摄影后期单页工具：左列图层（含透明背景开关），中央带胶片齿孔边框的实时预览（CSS filter 驱动），右列显影参数滑杆与导出格式卡；JPG 卡标红『不支持透明』，透明背景 + JPG 导出时被拦截并高亮两处冲突设置，可一键改 PNG 重新导出；琥珀色作强调，胶片颗粒与暗角效果层常驻。」
