## 复现验收清单

- [ ] 390px搜索表单和主按钮完整可见、无横向溢出。

- [ ] 选08A、核对、确认生成包含准确日期班次席位金额的票据。
- [ ] 选择09B并确认时售罄，原路线日期保留。
- [ ] 改08B后重新确认成功，原售罄座位已禁用。
- [ ] 同一行程已订座禁用，改日期、路线或班次后同座号可选；返回原行程仍禁用。

## 产品边界

实现路线搜索、固定演示班次、选座、库存检查、订单及票据；没有实时铁路数据、真实购票、支付或实名验证。票据明确不可用于乘车。

## 状态地图

search → results → seatView → reviewView → receipt；返回改班次/座位保留route对象。09B确认导致soldOut错误仍在reviewView；返回座位后该座禁用。

## 正常流程

确认搜索条件 → 选择G7301 → 选择08A → 核对06车厢/08A/156元 → 确认 → 票据显示相同信息及SX编号。

## 异常触发与恢复

搜索同路线 → 选择班次 → 选择09B售罄体验座 → 核对并确认 → 提示09B已售罄，未生成新票号 → 返回改08B → 重新核对确认 → 成功出票。

## 数据变化

route保存日期和站点，跨失败不清空。选座只改变seat；失败不增加tickets或booked。已订与已确认售罄记录均按出发站、到达站、日期、班次、座号隔离。成功booked加入本次行程席位，tickets加1，收据保存当次值；同一行程仍禁用已订座，其他日期、路线或班次不受影响。

## 人工验收步骤

正常：默认路线搜索 → 首班 → 08A → 核对 → 确认 → 票据G7301/06车厢08A/156元。
异常：再次搜索 → 首班 → 09B → 核对确认 → 售罄且日期不变 → 改08B → 核对确认 → 新票据08B，09B不可再选。
