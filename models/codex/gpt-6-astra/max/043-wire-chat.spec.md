## 内容与数据

三会话依次小芥、周行、修理小队。每组初始消息不同。消息最多800字，空白不可发送。页头在线为演示状态，聊天内明确离线体验，不会联系真人。

## 产品边界

实现会话切换、文字发送、模拟失败、原消息重试；不含真实网络、多人同步、附件或跨刷新持久化。发送是可观察的离线状态演示。

## 状态地图

list → 点击会话 → chat。聊天内消息分别为发送中、未送达、重试中、已送达；点击左上返回列表不丢失本页会话历史。

## 正常流程

进入小芥 → 输入“我带热茶” → 发送 → 输入框清空、出现发送中 → 650ms 后已送达 → 回会话列表可看到该预览。

## 异常触发与恢复

在会话点击“让下一条发送失败”再输入并发送。该消息650ms后变未送达，完整内容保留、出现重试发送。点击原消息的重试，450ms后同一气泡变已送达。失败开关只影响下一条并自动取消。

## 数据变化

每次发送只新建一个带自增id的消息，放入当前会话。重试只改变原对象status，不新建消息。失败内容仍可在离开并重新进入会话后找到。异步发送与重试完成只更新所属会话；切到另一会话后不得显示前一会话的成功或失败提示。

## 人工验收步骤

正常：小芥 → 输入“我带热茶” → 发送 → 等待已送达，核对文字。
异常：点异常开关 → 输入“九点见” → 发送 → 等待未送达 → 返回列表再进入 → 内容仍在 → 点重试 → 同一条显示已送达、总气泡数不变。
