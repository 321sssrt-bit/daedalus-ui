## 复现验收清单

- [ ] 390px首屏标题、动态、图片没有横向溢出。
- [ ] 写动态后字数等于输入长度。
- [ ] 选择仅自己，发布后卡片明确标注仅自己。
- [ ] 开启发布失败后，文字、换行、范围不丢失，列表不新增。
- [ ] 重试后列表只新增一条，作者为你，内容与范围完全相同。
- [ ] 我的筛选只显示自己发布的内容，减少动态无过渡。

## 产品边界

实现动态浏览、点赞、编辑、范围选择、失败保稿和重试；不含真实社交网络、图片上传或服务端权限。草稿与动态仅在当前页面会话中保留。

## 状态地图

community 动态流 → 加号 → composer。返回保留文本和范围。发布失败仍在 composer，出现错误和重试操作；成功新增动态并返回 community。街坊/我的切换过滤列表。

## 正常流程

浏览动态 → 加号 → 写“窗台的花开了” → 选择朋友可见 → 发布 → 首条卡片显示你、刚刚、朋友可见及原文。

## 异常触发与恢复

编辑含换行的草稿，选择仅自己；开启本次发布失败后发布。页面说明失败，原textarea和select均不变，动态列表不增。连接已恢复，点击重试发布，新动态只出现一次且范围仍为仅自己。

## 数据变化

失败只更新错误标志与按钮，posts数组不变。成功unshift一条内容/作者/范围完整的记录后才清空草稿、恢复计数和默认操作文案。

## 人工验收步骤

正常：加号 → 输入一段日常 → 朋友可见 → 发布 → 验证首条内容与朋友可见。
异常：加号 → 输入两行文字 → 仅自己 → 触发失败 → 发布 → 检查两行和仅自己仍在 → 重试发布 → 一条新动态、仅自己 → 切我的可见自己发布记录。
