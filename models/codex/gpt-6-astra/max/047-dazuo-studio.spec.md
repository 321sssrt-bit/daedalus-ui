## 内容与数据

标题把灵感放大、副题日常之外还有无限可能、初始色#e0ef55、角度-12°、深背景。SVG/PNG/JPEG均为600×760；JPEG禁止透明，标题不可纯空白。下载文件名dazuo-poster及相应扩展名。

## 产品边界

实现标题、副题、主题色、旋转、透明度、实时SVG预览以及SVG/PNG/JPEG实际导出。没有复杂图层管理、任意素材上传、服务器或项目持久化。

## 状态地图

编辑就绪 → 控件实时预览。点击导出进入生成中 → 成功出现格式尺寸和下载链接；不支持组合原位错误、没有新文件。修正设置后重新生成。

## 正常流程

改标题为“今天就出发” → 选择冰川蓝 → 调整旋转 → SVG格式 → 导出 → 看到尺寸和文件信息 → 下载并打开作品。

## 异常触发与恢复

点击体验透明背景+JPEG，再点导出。提示JPEG不支持透明且没有生成文件，文字/颜色/角度均保留。选择PNG或关透明，再导出，出现有效结果和下载链接。

## 数据变化

UI参数直接更新原SVG属性。导出克隆当前SVG，序列化成SVG Blob；PNG/JPEG把同一SVG绘制到600×760 canvas后编码。错误不替换上一次有效文件，既有下载链接代表之前导出快照。

## 人工验收步骤

正常：改标题今天就出发 → 冰川蓝 → SVG → 导出 → 下载，用SVG阅读器可见正确文本与几何。
异常：体验不支持组合 → 导出 → 明确错误且无新文件 → 改PNG → 导出 → 下载，PNG尺寸600×760且保留透明背景。
