## 复现验收清单

- [ ] 1280px课程目录与内容分栏，768px单列选项无溢出。

- [ ] 选B提交出现正确解释和练习完成，目录1/3。

## 产品边界

实现第一课入口、知识点、三选一练习、错误解释、重答与完成进度。后两课明确尚未开放；不含账号、服务器进度、自动评分排名或完整摄影课程。

## 状态地图

cover课程封面 → 进入 → quiz；选择后可提交。错误后quiz+feedback，选项冻结直到重答；retry清空本轮答案但保留曾错记录。正确→result，按曾错记录显示练习完成或订正成功。返回封面保留完成进度，再练开始新轮。

## 正常流程

进入课程 → 选择B侧光 → 提交 → 显示练习完成、原理解释，目录变已完成、课程1/3。

## 异常触发与恢复

新轮进入练习 → 选择A或C → 提交 → 错答卡标红，显示对应光线为何不合适和侧光原理，未完成本轮。点击重新作答 → 选择B → 提交 → 显示订正成功。

## 数据变化

答案选择只更新选中卡；错误设置hadMistake但不增加完成进度。正确将第一课标记完成，整体1/3；重复正确不叠加课数。每次再练重置本轮错答记录，完成历史仍保留。

## 人工验收步骤

正常：进入这一课 → B侧光 → 提交 → 完成说明及1/3。
异常：再练一次 → A正面光 → 提交 → 红色解释 → 理解了重新作答 → B侧光 → 提交 → 订正成功，仍1/3不重复计数。
