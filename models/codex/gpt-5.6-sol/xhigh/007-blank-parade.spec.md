# 007 空白游行

## 一句话气质

大胆、欢快，像一张等待开工的艺术节海报。

## 适合用在哪种产品

创作者收集图片、文字和零散灵感的视觉白板工具。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #F6F1E6 | 暖纸页面 |
| 表面 | #FFFDF7 | 导航与新建卡片 |
| 正文 | #151515 | 粗框线与标题 |
| 次要文字 | #68645E | 欢迎说明 |
| 强调 | #FF4F38 / #3765EB | 主行动与标题跳色 |
| 成功 / 危险 | #187C5A / #C82F3B | 创建结果与错误 |

## 字体和字号

使用 `Arial, Microsoft YaHei, system-ui`。显示字 65–138px/900，卡片标题 38px/900，正文 18px/400，辅助 12–13px/800，数字 12px/900。

## 间距、圆角、阴影

主内容水平内距 6vw，按钮间距 12px；仅插画和头像使用圆形，普通卡片保持直角；按钮用 `5px 5px 0 #151515`，弹层用 12px 硬阴影。

## 按钮 / 输入框 / 卡片

主按钮红底、次按钮纸白底，均为三像素黑框；创建结果卡像贴进画面的海报；点击后按钮下沉三像素形成实体感。

## 动效

按钮 150ms 下沉；创建卡即时出现，示例操作改变门的色彩。减少动态偏好时移除所有过渡。

## 不要做什么

不要使用温吞的空文件夹插画、灰色虚线框、居中小卡片或无意义庆祝动画。

## 复刻提示词

做一张构成主义艺术节海报式空态：超大黑体、粗黑分割、红蓝黄几何形和硬投影按钮；空白要像邀请开工，而不是错误或失落。
