# 049 脉搏花园

## 一句话气质

把健康数据养成一座克制、会生长的小花园。

## 适合用在哪种产品

运动记录、康复训练、日常健康习惯移动端。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #f8f4e9 | 自然纸面 |
| 表面 | #ffffff | 记录表单 |
| 正文 | #234032 | 数据与标题 |
| 次要文字 | #728475 | 周期说明 |
| 强调 | #4e8a63 / #aed067 | 保存 / 进度生长 |
| 成功 / 危险 | #357558 / #c55446 | 重算成功 / 无效数据 |

## 字体和字号

系统字体配 Georgia 数字；进度 45px，输入 22px，标签 11px。

## 间距、圆角、阴影

20px 页面边距；进度容器为 100px 胶囊，表单直角细线；不用浮卡阴影。

## 按钮 / 输入框 / 卡片

数字输入使用粗底线；绿色保存为唯一主按钮，红色测试入口保持次级。

## 动效

进度和柱高即时重算，不做庆祝粒子；减少动态时无过渡。

## 不要做什么

不要用医疗诊断措辞、恐吓红色或把无效数据计入目标。

## 复刻提示词

做一个纸面植物感健康记录页：大号生长环、七日嫩绿柱、两项清晰数字输入，保存后进度与趋势同时更新。

## 产品定位与目标用户

帮助普通用户记录一次活动并理解它对周目标和趋势的影响，不提供医学诊断。

## 核心任务

输入活动时长和平均心率，保存后看到总分钟、百分比和今日趋势改变。

## 页面或状态地图

目标/趋势总览 + 活动表单 → 保存成功；无效范围 → 字段规则错误 → 修正 → 重算成功。

## 正常流程

输入 30 分钟和 126，点保存，进度从 192 增至 222，百分比与今日柱更新。

## 异常触发与恢复

点测试入口填 980/360 并保存；错误定位两个合理范围并声明 64% 未变；点修正后自动重新保存并重算。

## 数据变化

有效记录增加总分钟并重算百分比/柱高；无效记录不改变 total 或图表。

## 主设备与响应式规则

390px 单列健康摘要与表单；宽屏仍维持手机式阅读尺度。

## 人工验收步骤

正常：记录 30/126 → 保存 → 核对 222/300 和趋势。异常：点测试 → 核对进度仍 64% → 点修正 → 看成功与新进度。
