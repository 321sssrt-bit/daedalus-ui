# 045 夜航电台

## 一句话气质

黑胶暗房里的一束酸绿色夜航信号。

## 适合用在哪种产品

长音频平台、独立播客馆、纪录片流媒体桌面端。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #08090b | 全局暗场 |
| 表面 | #15171d | 播放室 |
| 正文 | #f1f0e8 | 节目与按钮 |
| 次要文字 | #8f929a | 节目信息 |
| 强调 | #c9ff4f | 播放信号与进度 |
| 成功 / 危险 | #6ed3a4 / #ff665e | 恢复 / 网络中断 |

## 字体和字号

系统字体与等宽状态字；节目标题 34px，导航 13px，时间 12px。

## 间距、圆角、阴影

28px 主网格，26px 播放室内距；全部直角，唱片使用酸绿外发光。

## 按钮 / 输入框 / 卡片

内容发现是纵向唱片列表；播放器采用实体酸绿播放钮、原生进度条和可调整队列。

## 动效

不依赖旋转唱片；播放用文字状态表达，减少动态时关闭动画。

## 不要做什么

不要把播放器做成明亮音乐 App，不使用专辑封面外链或自动播放。

## 复刻提示词

做一座黑色夜航电台：暗房唱片视觉、酸绿信号、紫色队列选择、清楚的时间进度与网络恢复状态。

## 产品定位与目标用户

给深夜长音频听众提供安静的发现、播放、队列与断点保留体验。

## 核心任务

从左侧发现节目，开始播放，调整进度或队列，保存当前播放位置。

## 页面或状态地图

节目库 → 播放室（暂停/播放/进度/队列）→ 保存状态；中断 → 错误通知 → 重连 → 原位置继续。

## 正常流程

选节目，点开始播放，拖动进度，换队列项目，再点保存进度，页眉显示保存结果。

## 异常触发与恢复

点“模拟网络中断”，播放暂停并显示保留时间；点“重新连接并继续”，按钮恢复为播放中且进度值不回退。

## 数据变化

选择节目改变标题；进度与队列可变；保存写入页眉状态；异常只暂停并保留 lastProgress。

## 主设备与响应式规则

1280px 为发现栏加播放室；850px 以下隐藏发现栏并将主视觉和播放器上下排列。

## 人工验收步骤

正常：选凌晨建筑学 → 播放 → 拖进度 → 改队列 → 保存并看页眉。异常：播放中模拟中断 → 核对进度 → 重连 → 确认继续播放。
