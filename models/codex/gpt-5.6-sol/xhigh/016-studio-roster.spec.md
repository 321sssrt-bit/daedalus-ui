# 016 混合工作室名册

## 一句话气质

像一期色彩猛烈的独立创意人才年鉴。

## 适合用在哪种产品

跨城市创意工作室寻找成员、专长和协作对象的内部名册。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #EBFF52 | 标题与简介弹层的酸黄底 |
| 表面 | #F7F5EF | 成员网格外底 |
| 正文 | #171717 | 粗框、标题与选中筛选 |
| 次要文字 | #66645F | 职位与城市 |
| 强调 | #5D45D8 | 简介头像区和弹层阴影 |
| 成功 / 危险 | #26754F / #C43D3D | 联系结果与异常 |

## 字体和字号

使用 `Arial, Microsoft YaHei, sans-serif`，元数据用 `monospace`。显示字 46–92px/900，姓名 19px/800，弹层姓名 40px/900，正文 14–16px/400，辅助 9–12px/800。

## 间距、圆角、阴影

页面左右内距 36px，网格间距 18px，卡片内距 16px；除筛选胶囊和头像几何外均保持直角；卡片悬停用 7px 硬阴影，简介弹层用紫色 12px 硬阴影。

## 按钮 / 输入框 / 卡片

成员以多色肖像年鉴卡组成网格；筛选是黑框胶囊，搜索只有底线；点击卡片打开酸黄简介页，联系按钮为黑色实心。

## 动效

卡片悬停 160ms 上移，筛选和搜索即时重排，弹层即时出现；减少动态偏好关闭位移和过渡。

## 不要做什么

不要使用统一圆头像白卡、企业组织架构树、低对比灰蓝配色或只显示姓名而没有简介。

## 复刻提示词

制作一本独立创意年鉴式成员目录：酸黄巨型标题、多色几何肖像、两像素黑框卡片与硬阴影；筛选直接，个人简介像从卡片里抽出的一页强色海报。
