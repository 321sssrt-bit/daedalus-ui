# 034 余晖电台

## 一句话气质

夜航收音机、落日山脊和一盒仍在转动的旧磁带。

## 适合用在哪种产品

独立音乐播放器、深夜电台、播客频道和以完整聆听为中心的手机应用。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #15182A | 手机内夜色背景 |
| 表面 | #292C43 | 方形唱片封面与控制层 |
| 正文 | #FFF2D3 | 标题、控制按钮和磁带标签 |
| 次要文字 | #9296AD | 艺术家、时间和次级图标 |
| 强调 | #E75B78 | 播放进度、磁带字和收藏状态 |
| 成功 / 危险 | #5CC6C2 | 电台信号、焦点和播放反馈 |

## 字体和字号

使用 Avenir Next、Microsoft YaHei、Arial，电台频率和磁带标签使用 Consolas 等宽字体。歌曲标题 25px/700，播放按钮 25px，控制图标 29px，正文 12px，辅助 10–11px。

## 间距、圆角、阴影

手机宽 390px、外壳圆角 46px，屏幕内距 22–24px，封面圆角 28px，播放键 66px 正圆；封面使用 0 18px 32px 深黑柔影，播放键有 7px 暗色外环。

## 按钮 / 输入框 / 卡片

主视觉以 CSS 落日、山脊和磁带构成；进度轨可直接点击改变时间；中间是奶油色播放键，两侧切歌，下方收藏、队列、定时三个低权重控制。播放队列从底部出现。

## 动效

队列底页在 250ms 内进入；播放暂停、切歌、进度和收藏即时反馈，不让磁带或唱片持续旋转。减少动态偏好下取消底页过渡和磁带倾斜。

## 不要做什么

不要使用通用渐变唱片封面、毛玻璃控制条或夸张频谱动画；不要让装饰抢过歌曲名、进度与播放操作。

## 复刻提示词

在 390px 深夜手机框中制作收音机式播放器：方形主视觉由橙色落日、层叠山脊和奶油色磁带组成；下方显示歌曲与艺术家、粉色可点进度、奶油色圆形播放键、切歌和队列底页，用青色反馈保持夜航信号感。
