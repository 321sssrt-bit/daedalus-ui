# 001 夜航通行证

## 一句话气质

深夜宇航控制舱般克制、私密且可信。

## 适合用在哪种产品

面向创意团队的私密项目协作与资产管理平台。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #070914 | 全屏夜空底色 |
| 表面 | #11152A | 登录舱面板 |
| 正文 | #F7F4FF | 标题、输入文字 |
| 次要文字 | #9BA4C4 | 说明和状态 |
| 强调 | #9D7CFF | 行星标记、主按钮、焦点 |
| 成功 / 危险 | #57E3B4 / #FF6E8A | 节点在线与错误反馈 |

## 字体和字号

使用 `Inter, ui-sans-serif, system-ui, Microsoft YaHei, sans-serif`。显示字 54–112px/800，标题 32px/700，正文 16–18px/400，辅助 12–13px/500；数字继承系统无衬线并使用 700 字重。

## 间距、圆角、阴影

面板内距 32–68px，字段间距 18px；输入和按钮 14px 圆角，主面板 28px；面板使用 `0 30px 80px #0008`，按钮使用紫色柔光。

## 按钮 / 输入框 / 卡片

主按钮为满宽紫色实心；输入框使用深蓝黑表面、细描边和四像素焦点光圈；右侧显示密码按钮保持弱化，悬停才亮。

## 动效

按钮悬停 200ms 上移 2px；输入焦点 200ms 光圈过渡。减少动态模式下压缩至 0.01ms，仅保留状态文字反馈。

## 不要做什么

不要使用常见白底居中卡片、社交登录图标、霓虹过量描边或宇航照片。

## 复刻提示词

做一个深夜轨道控制舱式登录页：超大紧排标题占左侧，玻璃感登录舱占右侧，深蓝黑底配单一紫色与薄荷绿信号，信息少而精密。
