# 048 山线行程

## 一句话气质

一张松林与雪线之间的轻户外交通票。

## 适合用在哪种产品

山区巴士、景区接驳、城际小型交通预订移动端。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #f3f6f1 | 雪色页面 |
| 表面 | #ffffff | 搜索和班次 |
| 正文 | #17322e | 路线信息 |
| 次要文字 | #70847f | 余票与天气 |
| 强调 | #e67b3d | 选择与确认 |
| 成功 / 危险 | #2f8065 / #bb4d3f | 行程凭证 / 售罄 |

## 字体和字号

系统无衬线字体；主标题 29px，班次 14px 粗体，辅助 11–12px。

## 间距、圆角、阴影

16–22px 页面节奏；卡片全部直角，搜索卡用轻绿色投影，页头山线斜切。

## 按钮 / 输入框 / 卡片

路线输入为底线字段；班次整行可选，座位为小方块，橙色确认承担唯一提交。

## 动效

选择仅改变描边和颜色；减少动态时无过渡。

## 不要做什么

不要用地图外链、航空商务舱视觉或隐藏售罄触发方式。

## 复刻提示词

做一个松林绿与雪白的移动山线预订页：斜切山景头、悬浮路线搜索、纸质班次行、橙色选中与虚线行程凭证。

## 产品定位与目标用户

帮助城市旅客快速预订山区接驳，路线条件与余票异常都可恢复。

## 核心任务

搜索出发到目的地，选择可用班次和座位，确认后得到行程编号。

## 页面或状态地图

路线搜索 → 班次与座位 → 成功凭证；售罄班次 → 错误反馈 → 改选可用项 → 再确认。

## 正常流程

搜索路线，选青松号和 7B，点确认，看到 ML-814-7B 凭证。

## 异常触发与恢复

选标注“售罄检查”的晨雾号并确认；错误指出班次售罄且路线字段保留；点改选后再确认成功。

## 数据变化

搜索更新路线摘要；选择改变班次和座位；售罄不生成凭证；恢复设置为 09:10/7A。

## 主设备与响应式规则

390px 单列；宽屏保留手机框和完整山形页头。

## 人工验收步骤

正常：搜索 → 选 09:10/7B → 确认 → 核对凭证。异常：选 08:20 → 确认见售罄 → 确认路线仍在 → 改选 → 再确认成功。
