# 015 信号缎带

## 一句话气质

柔软的时间缎带串起一天内不同轻重的信号。

## 适合用在哪种产品

创意协作平台的项目、系统与安全通知中心。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #FFF3ED | 淡粉纸面外底 |
| 表面 | #FFFFFF | 每条通知卡 |
| 正文 | #402F34 | 标题和主操作 |
| 次要文字 | #907B80 | 时间与摘要 |
| 强调 | #D54F70 | 未读节点和左边线 |
| 成功 / 危险 | #3B8065 / #C94149 | 已读回执与安全通知 |

## 字体和字号

使用 `ui-sans-serif, system-ui, Microsoft YaHei`，页面标题使用 `Georgia, Songti SC, serif`。显示字 42–72px/500，通知标题 16px/700，正文 13px/400，辅助 10–11px/700，时间 11px/700。

## 间距、圆角、阴影

页面上下 42px，卡片内距 18×20px，条目间 14px；卡片 18px、类型图标 8px、按钮 8px 圆角；不用阴影，由时间轴和细边框组织。

## 按钮 / 输入框 / 卡片

通知卡沿竖直缎带排列，未读以粉色节点和左边线强调；点击卡片展开详情；全部已读为描边胶囊，筛选为紧凑圆角标签。

## 动效

详情在 160ms 内展开，已读节点即时变灰，筛选控制显隐；减少动态偏好关闭过渡但保留状态变化。

## 不要做什么

不要让所有通知同色同重，不要用弹窗打断浏览，也不要只有列表而没有展开与批量已读。

## 复刻提示词

把通知中心画成一条温柔时间缎带：浅粉背景、白色圆卡、粉色未读节点，协作、系统、安全分别用紫橙蓝红小图章；可展开细节并保留清晰时间层级。
