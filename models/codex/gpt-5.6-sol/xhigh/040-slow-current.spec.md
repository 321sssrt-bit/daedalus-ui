# 040 缓流队列

## 一句话气质

像雾中水流般安静，让等待不再显得焦躁。

## 适合用在哪种产品

创作导出、云端转码、批量素材处理的移动等待页。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #eceafa | 等候主背景 |
| 表面 | #faf9ff | 步骤卡片 |
| 正文 | #2d2b49 | 标题和已完成步骤 |
| 次要文字 | #817e9d | 说明和未到步骤 |
| 强调 | #7167a8 | 进度球与当前步骤 |
| 成功 / 危险 | #5f927f / #b76a77 | 完成反馈 / 取消 |

## 字体和字号

系统无衬线字体；进度 38px，标题 25px，步骤与说明 12–13px。

## 间距、圆角、阴影

24–30px 节奏；步骤卡 18px、按钮 12px；进度球用柔和紫色投影。

## 按钮 / 输入框 / 卡片

步骤卡清晰区分完成、当前和未来；“放到一边”中性，“取消任务”使用危险文字。

## 动效

不使用无限旋转；进度是稳定视觉状态，减少动态时关闭所有动画和过渡。

## 不要做什么

不要只放加载圈，也不要隐藏当前步骤、预计时间或取消后果。

## 复刻提示词

做一张雾紫色移动等待页：大颗渐变进度球、四步状态卡、明确预计时间，以及“放到一边”和谨慎取消两个出口。
