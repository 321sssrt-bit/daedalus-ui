# 050 定理研习室

## 一句话气质

古典研习室与深绿黑板共同承载一次真正的订正。

## 适合用在哪种产品

数学课程、知识训练、成人自学平台桌面端。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #f1ead7 | 课程目录纸面 |
| 表面 | #0e2d29 | 深绿黑板 |
| 正文 | #f4f0df | 黑板正文 |
| 次要文字 | #807d70 | 目录辅助 |
| 强调 | #efcf68 | 公式与提交 |
| 成功 / 危险 | #67ba8b / #e77b6e | 订正成功 / 错答解释 |

## 字体和字号

Georgia、宋体与系统中文字体；公式 54px，课题 32px，正文 15px。

## 间距、圆角、阴影

22–42px 桌面边距；全部直角；黑板使用内凹阴影和虚线公式框。

## 按钮 / 输入框 / 卡片

目录像课程页签；答案为整行黑板选项；黄色提交醒目，错答恢复按钮为暖红。

## 动效

阅读与练习直接切换，反馈在原题下出现；减少动态时无过渡。

## 不要做什么

不要只报对错、不解释；不要用游戏化金币或让重试重载整页。

## 复刻提示词

做一间纸质目录加深绿黑板的数学研习室：巨大黄色公式、宽松讲解、整行选择题，错答后给足以订正的解释并原地再答。

## 产品定位与目标用户

面向想理解而非背诵的成人学习者，把阅读、练习、解释和订正串成一个闭环。

## 核心任务

进入条件概率课程，完成阅读和练习，查看解释，并最终提交正确答案。

## 页面或状态地图

课程目录/概念讲解 → 单题练习 → 错误解释 → 再次作答 → 订正成功与进度更新。

## 正常流程

点进入练习，选择 B，提交，看到订正成功和课程进度 3/4。

## 异常触发与恢复

选择页面提供的 A 或 C 并提交；错误面板解释条件后样本空间为 3 枚蓝球；点再次作答，改选 B 并提交成功。

## 数据变化

选项只改变本次 answer；错误不更新课程进度；正确后进度从 2/4 更新到 3/4。

## 主设备与响应式规则

1280px 左课程目录、右研习黑板；800px 以下隐藏目录并将公式移到讲解下方。

## 人工验收步骤

正常：进入练习 → 选 B → 提交 → 见成功/3-4。异常：选 A → 提交 → 阅读解释 → 再次作答 → 选 B → 提交 → 见订正成功。
