# 042 青玉钱匣

## 一句话气质

传统钱匣的稳重秩序，配一枚现代电子回执。

## 适合用在哪种产品

个人钱包、家庭转账、社区金融服务移动端。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #eef3e6 | 钱包内容底 |
| 表面 | #ffffff | 金额与确认面板 |
| 正文 | #17312d | 主信息 |
| 次要文字 | #6e8078 | 标签 |
| 强调 | #d2a84a | 选择与确认 |
| 成功 / 危险 | #2f795e / #b54b43 | 转账印章 / 余额不足 |

## 字体和字号

系统中文字体配 Georgia 金额；余额 38px，金额输入 36px，正文 13–16px。

## 间距、圆角、阴影

20–30px 内容节奏；除头像外保持直角，宽屏手机框使用深绿投影。

## 按钮 / 输入框 / 卡片

收款人以圆印头像选择；金额为大号下划线输入；深绿主按钮、金色确认按钮。

## 动效

确认面板即时出现，无金额跳动；减少动态时关闭过渡。

## 不要做什么

不要使用赌场式金光、虚拟币行情或模糊付款来源。

## 复刻提示词

做一只青玉色移动钱匣：大号衬线余额、圆形收款人印章、直角确认单与绿色成功章，强调可信和可核对。

## 产品定位与目标用户

面向需要快速给熟人转账的普通用户，重点是来源、余额和凭证清楚。

## 核心任务

选择收款人，输入金额和资金来源，核对后确认，最终看到唯一凭证编号。

## 页面或状态地图

余额首页/转账表单 → 核对面板 → 成功凭证；超额时进入余额不足面板 → 换来源 → 回核对。

## 正常流程

选收款人，输入 128，点核对；确认姓名与金额后点确认，看到 QY-814-2036。

## 异常触发与恢复

点测试链接填入 1600，在钱包来源下核对会阻止转账并显示可用 1280；点“改用青禾储蓄卡”后重新核对并确认成功。

## 数据变化

失败时不生成凭证、不宣称扣款；切换来源仅改变可用上限；确认后生成固定格式凭证。

## 主设备与响应式规则

390px 移动端单列；宽屏显示在无圆角钱匣式手机框，操作顺序不变。

## 人工验收步骤

正常：选陈野 → 128 → 核对 → 确认 → 见成功凭证。异常：测试超额 → 核对见余额不足 → 换储蓄卡 → 再确认成功。
