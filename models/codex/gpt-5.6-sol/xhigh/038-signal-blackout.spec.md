# 038 信号断层

## 一句话气质

工业检修牌般直接、粗粝但不责怪用户。

## 适合用在哪种产品

交通服务、网络工具、工业设备控制端的移动故障页。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #131313 | 故障主背景 |
| 表面 | #202020 | 次按钮 |
| 正文 | #f4f1e8 | 标题与关键字 |
| 次要文字 | #99958c | 人话说明 |
| 强调 | #ff5a1f | 警示条与重试 |
| 成功 / 危险 | #91d18b / #ff5a1f | 状态反馈 / 故障 |

## 字体和字号

Impact、Arial 与系统中文字体；错误码 92px，标题 28px/粗体，工单 12px 等宽。

## 间距、圆角、阴影

26px 内容边距；全部直角无阴影；斜切色带制造物理检修感。

## 按钮 / 输入框 / 卡片

橙色实体重试为主动作，深灰描边回首页为安全出口；工单使用虚线框。

## 动效

重试仅有 700ms 文案状态变化；减少动态时不加入旋转或闪烁。

## 不要做什么

不要用可爱插画、模糊的“出错啦”或隐藏工单编号。

## 复刻提示词

用黑橙工业警示系统做移动故障页：超大描边错误码、斜切检修条、人话解释、真实工单和明确重试/回首页双出口。
