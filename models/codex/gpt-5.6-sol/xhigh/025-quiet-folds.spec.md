# 025 静页账户

## 一句话气质

安静折页、靛蓝封套与恰到好处的东方留白。

## 适合用在哪种产品

个人知识库、创作工具、文档协作与重视隐私的会员制服务账号设置。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #E8E5DC | 微暖灰设置背景 |
| 表面 | #F8F6EF | 设置纸页与头像 |
| 正文 | #252B2D | 标题与主要信息 |
| 次要文字 | #747B78 | 描述、路径和页脚 |
| 强调 | #334D5C | 身份封套、图标和标题 |
| 成功 / 危险 | #6A806A | 开启状态；陶红 #C76D52 用于提示与焦点 |

## 字体和字号

使用 Yu Gothic UI、Microsoft YaHei 系统字体；身份名 25px/700，设置标题 15px/700，正文 12–13px，辅助 11px，符号 20–26px。

## 间距、圆角、阴影

版心 1050px，页边距 28–48px，身份区内距 30×34px，设置行纵向 22px；圆形只用于身份和状态开关，其余零圆角；身份封套有 0 12px 30px 低对比阴影。

## 按钮 / 输入框 / 卡片

身份信息是一张靛蓝封套；设置行以细线分组，点击后像折页一样在下方露出灰纸详情；开关是唯一胶囊控件。侧栏只承担章节定位。

## 动效

详情折页即时出现，开关圆点即时换边，不使用连续展开动画；减少动态偏好下关闭全部过渡。

## 不要做什么

不要堆叠独立白卡、彩色图标宫格和密集表单；不要把“日式”误解成竹纹、书法或装饰性红印。

## 复刻提示词

制作一张微暖灰背景的安静账号设置页，上方以靛蓝横向封套展示身份，下方是一张奶油色折页，左侧目录、右侧三组细线设置；点击每行才露出灰纸详情，用陶红小提示和苔绿开关收束色彩。
