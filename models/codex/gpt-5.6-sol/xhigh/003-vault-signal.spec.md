# 003 信号库准入

## 一句话气质

冷峻工业档案，像一张受控区域通行单。

## 适合用在哪种产品

未公开研究项目与保密原型的成员协作空间。

## 色板

| 角色 | 色号 | 用法 |
| --- | --- | --- |
| 背景 | #E7E4DB | 工业灰纸外底 |
| 表面 | #F4F1E9 | 档案面板 |
| 正文 | #181B1D | 黑色边框与标题 |
| 次要文字 | #61666A | 操作说明 |
| 强调 | #FF5C35 | 邀请标签和悬停 |
| 成功 / 危险 | #167954 / #B5292F | 匹配与失败反馈 |

## 字体和字号

使用 `Arial Narrow, Microsoft YaHei, system-ui`，编号切 `monospace`。显示字 42–86px/800，标题 30px/700，正文 15px/400，辅助 10–13px/700，验证码 30px/800。

## 间距、圆角、阴影

主框距窗口 40px，内容内距 34–46px；全部保持直角，使用 2px 黑线；主框投下 `12px 12px 0 #B8B5AD` 的硬阴影。

## 按钮 / 输入框 / 卡片

主按钮是黑底等宽大写标签，悬停变橙；六个验证码格独立成框，焦点出现橙色硬投影；元数据使用黑色一像素网格。

## 动效

仅按钮颜色与验证码焦点在 120ms 内变化；验证结果即时出现。减少动态模式移除过渡。

## 不要做什么

不要圆润卡片、柔和渐变、人物头像或欢迎式营销文案。

## 复刻提示词

制作一张工业档案通行单：米灰纸、粗黑框、橙红审核章、窄体大标题和等宽编号；用硬阴影与表格线制造机械印刷感。
