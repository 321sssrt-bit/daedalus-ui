# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-airmail-stripe-inbox.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

小团队的邮件既有客户来信也有快递账单，用航空信条纹做品牌记忆点，界面本身保持安静的米白；未读只用一个红点和加粗表达，归档提供撤销，让处理邮件可以放心地快。

## 适用场景与目标用户

设计工作室、自由职业者处理客户往来邮件的桌面邮箱客户端。

## 非目标

不做聊天气泡式邮件；不包含写信编辑器、规则与标签管理。

## 复刻提示词

米白三栏邮箱，顶部 6px 红白蓝航空信斜纹，208px 文件夹栏配藏青写信按钮，400px 白色列表含红色未读圆点与全部/未读/星标胶囊，右侧大号主题阅读区，星标黄色态，归档后底部深色可撤销提示条。
