## 产品边界

实现：会话列表与未读、进入会话、多行输入与发送、发送中/已送达/已读状态、对方输入中与回复、模拟发送失败、失败保留与重试/删除、返回列表时摘要更新。不包含：新建会话、搜索、群聊管理、图片语音、通知推送。

## 状态地图

1. 会话列表（默认）
2. 当前会话：点任一会话进入；‹ 返回列表
3. 网络正常 / 模拟断网已开启：会话页网络条开关切换
4. 消息发送中 → 已送达 → 已读
5. 消息发送失败：断网开关开启时下一条消息进入此状态，开关自动复位
6. 重试中 → 已送达 / 已读；或删除失败消息
7. 列表摘要「❗ 有消息未发出」：会话中存在失败消息时

## 正常流程

1. 在会话列表点「小满」→ 进入会话，看到两条对方消息，列表未读清零
2. 在输入框输入「好呀，几点出发？」→ 发送按钮由灰变青柠
3. 点发送（或 Enter）→ 气泡出现在右侧，状态「发送中…」
4. 约 0.7 秒后变「已送达」，再约 0.9 秒变青柠色「已读」
5. 随后出现对方输入中三点，接着收到「好！那周六 8 点地铁站见 👟」

## 异常触发与恢复

触发：在会话页网络状态条打开右侧红色开关（文字变为「模拟断网已开启：下一条消息会发送失败」），然后发送下一条消息。
反馈：约 0.7 秒后该气泡变为红色虚线框，内容完整保留，下方显示「❗ 发送失败」与「重试」「删除」；开关自动复位为网络正常；返回列表时该会话摘要为红色「❗ 有消息未发出」。
恢复：在失败消息下点「重试」→ 状态变「发送中…」→「已送达」→（在线联系人）「已读」，气泡恢复青柠色；若重试时开关仍开着则再次失败，关掉开关后重试即可成功。

## 数据变化

- 初始：小满未读 2、设计组未读 5；小满会话 2 条消息。
- 正常发送后：小满会话 +1 条我方消息（已读）+1 条对方回复，未读 0。
- 失败时：消息数 +1，状态 fail，内容与时间保留，不计入已送达。
- 重试后：同一条消息状态 fail → sending → deliv → read，消息总数不变；删除则消息数 −1。

## 人工验收步骤

1. 正常：点小满 → 输入「好呀，几点出发？」→ 发送 → 依次看到发送中…、已送达、已读 → 看到对方回复
2. 异常：打开网络条开关 → 输入「我带三明治和热水」→ 发送 → 看到红虚线气泡与「❗ 发送失败」「重试」「删除」
3. 异常确认：点 ‹ 返回 → 小满一行显示「❗ 有消息未发出」→ 再点小满回到会话，失败消息仍在
4. 恢复：点「重试」→ 看到发送中… → 已送达 → 已读，气泡恢复青柠色
