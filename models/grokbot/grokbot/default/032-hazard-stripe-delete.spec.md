# 032 危险删除

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`032-hazard-stripe-delete.html`
- 复现范围：库房控制台永久删除生产数据库的危险确认卡：黄黑警示条、将失去的四类内容与数量、暂停替代方案、输入库名确认、显著的保留按钮与默认禁用的删除按钮，删除后显示进度与操作记录。

## 内容与数据

- 标题：永久删除数据库 qinghe-prod；说明：这是「青禾生鲜」的线上生产库，删除后所有数据、备份和连接都会一起消失，无法找回。
- 你将失去：全部 38 张数据表（6.3M 行）、过去 30 天每日自动备份（30 份）、正在使用此库的应用连接（3 个：青禾小程序、门店收银、财务报表）、成员访问权限与 API 密钥（11 人）。
- 替代：先暂停数据库，数据保留 90 天。
- 完成：qinghe-prod 已永久删除；操作记录 DEL-20261011-0093 已发送给 11 位成员。
