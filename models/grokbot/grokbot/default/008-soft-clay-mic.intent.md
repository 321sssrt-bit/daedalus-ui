# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-soft-clay-mic.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限请求要显得温和、可控，用黏土新拟物让按钮像实体开关；先说要什么、再说为什么、最后说怎么撤回，把「仅本次」放在与拒绝同级，减少用户被迫全允许的压力。

## 适用场景与目标用户

视频会议、在线课堂等需要麦克风的桌面或网页应用，在首次入会前询问。

## 非目标

不模拟浏览器原生弹窗；不包含摄像头和屏幕共享权限；不做强制允许才能继续的设计。

## 复刻提示词

黏土灰 #e7e3de 新拟物风格入会页，左侧内凹圆角会议预览与音量条，右侧 440px 外凸权限卡，橙色麦克风图标、三条橙点说明、整宽橙色允许按钮与并排的仅本次 / 暂不允许，选择后变内凹结果块。
