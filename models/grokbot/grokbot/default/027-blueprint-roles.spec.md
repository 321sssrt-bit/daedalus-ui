# 027 角色权限

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`027-blueprint-roles.html`
- 复现范围：图纸工坊角色权限页：蓝图网格背景、左侧 4 个角色、中间分组权限开关清单（未保存高亮、保存与撤销）、右侧以所选角色身份的界面预览。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 角色按钮 | 内边距 12px，1px 虚线框 | 名称 + 人数（琥珀色）+ 说明与已开权限数 | 悬停实线框；选中 1.5px #ffcf4d 框 + 浅黄底；切换后清单与预览同步 |
| 权限开关 | 44 × 22px 方形，滑块 13px | 关：白框灰块 | 开：#7cf0c5 底，滑块右移 21px；与已保存不同时外加 2px 琥珀描边；管理员角色全部禁用；关闭「查看图纸」会清空该角色全部权限 |
| 保存更改 | 高 40px，内边距 0 18px | #ffcf4d 底深蓝字 | 无改动时禁用；保存后状态文字变薄荷色「✓ 已保存」并清除高亮 |
| 撤销更改 | 高 40px，1px 白框 | 透明底 | 无改动时禁用；点击恢复到上次保存 |
| 界面预览 | 模拟导航三标签 + 四个操作 | 有权限为实线 | 无权限的标签删除线淡出、操作变虚线；无查看权限时提示「无权访问」 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| > 1100px（主视口 1280） | 三栏横排 | — |
| ≤ 1100px | 三栏纵向堆叠 | 内边距 20px |

## 内容与数据

- 页头：角色与权限；图纸工坊 · 建筑设计院协作空间 · 37 位成员；右侧图号 DWG-ROLE-REV.04。
- 角色：管理员 2 人（7/7，不可修改）、专业负责人 6 人（5/7）、设计师 21 人（3/7，默认选中）、甲方访客 8 人（1/7）。
- 权限 7 项：图纸（查看图纸、编辑与上传图纸、审核签发）/ 项目（导出 PDF / DWG、对外分享链接）/ 管理（邀请与移除成员、查看费用与发票）。
- 预览示例文件 A-101 首层平面图.dwg。

## 复现验收清单

- [ ] 1280 宽下三栏 240px / 剩余 / 320px，背景为蓝图双层网格
- [ ] 至少 3 个角色，默认「设计师」有琥珀色选中框
- [ ] 设计师清单中「审核签发」为关，打开后出现琥珀描边且保存按钮可用
- [ ] 右侧预览中「签发」按钮随开关从虚线变实线
- [ ] 点「保存更改」后状态显示「✓ 已保存」且按钮禁用
- [ ] 选中「管理员」后所有开关禁用
- [ ] 宽度 768px 时三栏纵向堆叠
