# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-retro-desk-upload.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

上传是最「工具」的动作，借 Windows 98 的立体灰面、方块进度条和状态栏，把队列、大小、状态都摊开在表格里，既有怀旧趣味又极其清楚；超限文件直接以错误状态入列而不是被悄悄丢掉。

## 适用场景与目标用户

设计印刷、资料归档类工具的批量上传窗口，用户在桌面上一次传多份大文件。

## 非目标

不做现代扁平拖放卡片；不包含云端文件浏览与权限分享。

## 复刻提示词

Windows 98 复古桌面上传窗口，#008080 青色桌面与桌面图标，#c0c0c0 立体灰窗口、深蓝渐变标题栏、菜单栏，白色凹陷虚线拖放区，表格队列带方块进度与绿色完成/红色错误状态，右侧处理选项分组框与立体按钮，底部三格状态栏。
