# 016 成员目录

- 意图版本：1

## 设计意图

研究院的人员目录像一本纪念册：竖版色块照片框、宋体姓名、酒红院徽色，营造学术机构的庄重又有人情味；每人一句自述引言，让「找人」不只是找邮箱。

## 适用场景与目标用户

科研院所、高校学院、中型企业的内部通讯录与人才名录。

## 非目标

不做组织架构树图；不包含权限管理与人员编辑。

## 复刻提示词

米白纪念册风成员目录，宋体大标题与酒红 #7a1f2b 圆形院徽，搜索框与部门胶囊，白卡片网格中竖版色块照片带内白框，右侧 360px 粘性简介面板含楷体引言、标签与酒红胶囊按钮。
