# 026 账单

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`026-ledger-green-billing.html`
- 复现范围：青柠云费用中心账单页：森林绿顶栏、左侧当前方案卡与支付方式卡（可更换）、右侧账簿纸风格账单记录表（年份切换、状态、金额、下载发票、年度合计）及更换支付方式弹窗。
