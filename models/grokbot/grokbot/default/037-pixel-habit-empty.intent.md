# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-pixel-habit-empty.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空列表最怕冷场，所以把它画成一座还什么都没长的像素小岛，木牌上写着 0，说明里只给一个很小的起点；主按钮做成红色像素实体键，点下去就能从模板一步种下第一个习惯，空态立刻变成列表。

## 适用场景与目标用户

习惯打卡、待办、收藏夹等列表型 App 第一次打开、还没有内容时。

## 非目标

不做习惯详情与统计；不包含注册登录。

## 复刻提示词

8-bit 像素风手机空态页，天蓝渐变天空，像素白云，阶梯形绿草棕土浮岛上木牌写 0 和小芽，等宽像素字体标题，红色像素描边主按钮带深红底边，下划线次链接，深靛色底栏金色当前项，奶油色像素描边模板面板。
