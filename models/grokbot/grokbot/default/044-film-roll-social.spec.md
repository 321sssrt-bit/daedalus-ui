# 044 社交社区产品

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`044-film-roll-social.html`
- 复现范围：胶片圈手机社交原型：动态流（好友冲洗条、拍立得式照片卡、可见范围标签、点赞）→ 全屏发布页（正文 300 字、四张底片选择、四档可见范围、模拟上传中断开关）→ 发布成功后动态顶部出现新帖；失败时保留草稿与可见范围并可重试。

## 产品边界

实现：浏览动态与点赞、打开发布页、编辑正文、选择底片、选择可见范围、发布并在动态顶部看到结果、模拟发布失败、保留草稿与范围、重试发布、取消时保留草稿。不包含：评论详情、关注与私信、真实图片上传与相册。

## 状态地图

1. 动态流（默认）
2. 发布页：点 ＋ 打开；「取消」关闭（有内容时动态流顶部提示草稿已保留）
3. 上传中：点发布后 900ms 遮罩
4. 发布失败：勾选模拟中断后发布，发布页顶部出现失败提示，发布按钮变「重试」
5. 发布成功：发布页关闭，动态流顶部新帖 + 绿色横幅

## 正常流程

1. 浏览动态流，可对任一帖点 ♥ 点赞
2. 点右下 ＋ → 发布页滑出，正文聚焦，发布按钮禁用
3. 输入正文 → 字数更新、发布可用；选择底片「海雾」；在可见范围里选「👥 仅关注我的人」
4. 点「发布」→ 显示「正在冲洗上传…」约 0.9 秒
5. 发布页关闭，动态流顶部出现「我 · 刚刚」的新帖，标签为所选范围，绿色横幅「✓ 已发布 · 可见范围：…」

## 异常触发与恢复

触发：在发布页底部勾选红色虚线框「模拟上传中断：让这次发布失败」，再点「发布」。
反馈：上传遮罩结束后，发布页顶部出现粉红提示「发布未完成」，说明动态没有发出去，并写明文字、照片和当前可见范围（如「🔒 仅自己」）都已保留；正文、底片选中、范围选中保持不变，动态流没有新增内容，顶栏按钮变「重试」。
恢复：点提示里的「重试发布」（或顶栏「重试」）→ 自动取消模拟中断并重新上传 → 发布页关闭，动态流顶部出现新帖，标签与草稿所选范围一致。

## 数据变化

- 初始动态 3 条。
- 失败时：动态仍 3 条；草稿 {正文、底片、范围} 完整保留。
- 成功后：动态 4 条，第 1 条为我的新帖（♥ 0），草稿重置为空、默认好友圈、取消模拟中断。
- 点赞：对应帖子数量 ±1。

## 人工验收步骤

1. 正常：点 ＋ → 输入「周末去了趟老城区，拍完一整卷。」→ 选海雾 → 选仅关注我的人 → 发布 → 顶部新帖标签「👥 仅关注我的人」

3. 恢复：点「重试发布」→ 回到动态流 → 顶部新帖标签「🔒 仅自己」，横幅显示已发布
