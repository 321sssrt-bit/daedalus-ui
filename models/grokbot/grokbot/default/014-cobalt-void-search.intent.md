# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-cobalt-void-search.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空结果最该做的是把人留住，所以大字承认「没找到」，紧接着给出已验证有结果的具体改法，并显示每条能得到多少；钴蓝与柠檬黄的高对比让页面像设计工具一样利落。

## 适用场景与目标用户

设计素材、图库、模板市场的搜索结果页，设计师在桌面上高频检索。

## 非目标

不用卡通哭脸插画；不推荐与查询无关的广告内容；不包含高级筛选面板。

## 复刻提示词

白底钴蓝 #2b3cff 设计素材站搜索无结果页，顶部 2px 墨边胶囊搜索框保留原词，已选筛选胶囊可移除，56px 粗体大标题带柠檬黄高亮，三条带结果数的圆角建议按钮，右侧浅灰插图卡与热门标签。
