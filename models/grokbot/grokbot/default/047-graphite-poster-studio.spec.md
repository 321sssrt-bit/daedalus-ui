## 异常触发与恢复

触发：格式选 JPG，并勾选「透明背景」（或格式选 SVG 且噪点图层可见、强度 > 0），点「导出海报」。
反馈：不生成文件，出现红色「无法导出」块：「JPG 格式不支持透明通道，但当前开启了「透明背景」。」，当前格式 JPG 与透明背景行红色描边；导出记录不变，作品参数全部保留。
恢复：点提示中的「改用 PNG」或「关闭透明背景」（SVG 冲突为「改用 PNG」或「隐藏噪点图层」）→ 设置随之改变、提示变绿「✓ 冲突已解决」→ 再点「导出海报」得到成功结果与下载链接。

## 数据变化

- 初始：导出记录为空。
- 参数修改：S 状态（标题、背景、图形、噪点、显隐）变化并即时重绘。
- 冲突：记录数不变，不产生文件 URL。
- 成功导出：记录 +1（文件名、约 KB），生成 blob 或 data URL 可下载；尺寸 = 1080 × 1440 × 倍率。
