# 045 音视频平台

## 意图元数据

- 意图版本：1
- 对应规范：`045-wild-field-docs.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

纪录片平台要让人安心看下去：用自然纪录的奶油纸面、墨线与铁锈色，画面里太阳随进度升起，让「播到哪了」本身成为画面；队列在右侧一直可调，进度随时保存。网络中断不清空也不跳回开头，遮罩里直接写出停在几分几秒，重连后原地续播。

## 适用场景与目标用户

视频、播客、课程平台的桌面观看页，用户连续看一个系列。

## 非目标

不做真实音视频解码、清晰度切换、弹幕与评论。

## 复刻提示词

自然纪录片在线观看桌面原型，奶油 #f5efe2 底与 1.5px 墨线边框，深色播放器里 CSS 绘制的天空、山丘与随进度升起的太阳，铁锈色进度条与播放键，琥珀虚线「模拟网络中断」按钮与深色中断遮罩带琥珀重新连接按钮，墨边硬阴影节目卡片，右侧奶白队列带上移下移移除。
