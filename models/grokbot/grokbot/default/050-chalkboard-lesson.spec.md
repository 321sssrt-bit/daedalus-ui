## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`050-chalkboard-lesson.html`
- 复现范围：「黑板课堂」桌面学习原型（木框绿黑板 + 粉笔字）：左侧课程列表与本课进度，讲解便签卡（独立事件与乘法规则），3 道练习（2 道选择、1 道填空），提交后显示对错与解释；答错给出针对所选错误的解释和订正提示，可再试一次，订正答对后盖「订正成功」章并记录；完成后显示结果统计并解锁下一课。

## 内容与数据

- 课程：第 1 课 什么是概率（已学完）、第 2 课 独立事件（进行中）、第 3 课 条件概率（学完第 2 课解锁）。
- 题 1：抛两次硬币两次都正面？ ½ / ¼（正确）/ ⅓ / ¾。
- 题 2：掷骰子偶数点概率，填分数（1/2、3/6、0.5 均正确）。
- 题 3：连续 5 次正面后第 6 次正面概率？ 小于 ½ / 等于 ½（正确）/ 大于 ½ / 无法确定。
- 每个错误选项都有专门解释（如赌徒谬误、热手谬误）。

- [ ] 1280 宽下木框黑板、左侧课程栏与讲解便签可见

## 产品边界

实现：课程入口与解锁状态、讲解、3 道练习（选择与填空）、提交判定、错因解释与订正提示、再次作答、订正成功反馈、进度、结果统计与重新练习。不包含：账号、错题本独立页、计时、多课程内容。

## 状态地图

1. 讲解
2. 作答中（未选 / 已选）
3. 答对
4. 答错（解释 + 提示）
5. 再次作答
6. 订正成功（盖章）
7. 本课完成（统计、解锁）

## 正常流程

1. 在课程栏确认「第 2 课 · 独立事件」，阅读讲解便签后点「开始练习 →」
2. 题 1 选 B ¼ → 提交答案 → 「✓ 回答正确」→ 下一题
3. 题 2 填 1/2 → 提交 → 正确 → 下一题；题 3 选 B 等于 ½ → 正确
4. 点「查看本课结果 →」→ 正确 3、作答 3 次，第 3 课解锁

## 异常触发与恢复

触发：在题 1 选择 A ½（或 C、D），或在题 2 填入 1/3 等错误分数，点「提交答案」。
反馈：所选选项变粉色删除线（填空框锁定），粉色虚线反馈块「✗ 答错了，再想想」，写出针对该错误的解释（如「½ 只是一次正面的概率……要相乘」）和蓝色订正提示（列出 4 种等可能结果）；进度不增加，出现「再试一次」。
恢复：点「再试一次」回到题目（原错选项虚线半透明，可重新选择或清空输入），选择正确答案 ¼（或填 1/2、3/6）提交 → 绿色「✓ 订正成功！」、订正章、第几次答对说明，进度 +1；结果页将该题标为「已订正」。

## 数据变化

- 初始：进度 0 / 3，第 3 课锁定。
- 答错：作答次数 +1，进度不变。
- 答对：记录该题 {是否订正, 作答次数}，进度 +1。
- 完成：统计一次答对数、订正后正确数、总作答次数；第 2 课标「已完成」，第 3 课解锁。重新练习清空本课记录。

## 人工验收步骤

1. 正常：点开始练习 → 题 1 选 B → 提交 → 下一题 → 题 2 填 1/2 → 提交 → 下一题 → 题 3 选 B → 提交 → 查看本课结果
2. 异常：题 1 选 A → 提交 → 看到答错解释与订正提示
3. 恢复：点再试一次 → 选 B → 提交 → 看到订正成功与盖章
4. 异常 2：题 2 填 1/3 → 提交 → 答错 → 再试一次 → 填 3/6 → 订正成功
5. 结果：查看本课结果，确认已订正标签与第 3 课解锁
