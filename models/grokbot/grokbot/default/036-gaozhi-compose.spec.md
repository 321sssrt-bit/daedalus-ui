## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 保存状态 | 8px 圆点 + 12px 文字 | 灰点「新草稿 · 未保存」 | 存草稿后绿点「草稿已保存 hh:mm · n 字」；之后再改动变黄点「有改动未保存」 |
| 存草稿 | 高 34px，1.5px 绿边 | 绿字 | 随时可用 |
| 发布 | 高 34px | #1f7a4d 底白字 | 标题为空、正文少于 20 字或超过 2000 字时禁用为 #b9c9bf；点击禁用的发布会在顶栏下给出原因；可用时打开成功弹窗 |
| 栏目标签 | 高 28px，圆角 14px | 随笔默认选中 | 单选，选中绿底白字 |
| 字数 | Courier New 14px 粗体 | n / 2000 字（不计空白） | 超出变 #c2410c 并提示超出多少 |

## 内容与数据

- 顶栏：✕、新草稿 · 未保存、存草稿、发布。
- 稿纸页眉：方格 · 随笔稿纸 / 第 1 页；页脚：15 × 20 = 300 / n / 2000 字。
- 标题占位：写个标题（必填）；栏目：随笔、城市、读书、吃喝。
- 正文初始：今天下班绕路走了一段老街，糖水铺的灯还亮着。（22 字）
- 成功：已发布 /《标题》已发布到「随笔」栏目，共 n 字。
