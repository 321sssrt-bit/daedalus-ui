# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-fluent-mica-account.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

设置页的核心是「找到一行、点开、改完」，借用 Fluent 云母材质让大量设置行显得轻；每行右侧直接展示当前值，不用点开就知道状态，详情内联展开避免跳页丢失上下文。

## 适用场景与目标用户

桌面协作软件或操作系统风格的账号设置，办公用户在 Windows 电脑上管理资料与安全。

## 非目标

不做多级跳转的设置子页；不包含账单与外观设置的具体内容。

## 复刻提示词

Windows 11 Fluent 风格账号设置，浅色云母渐变背景，280px 导航含渐变圆形头像与蓝色当前指示条，白色身份卡，分组的 64px 设置行带图标、当前值和 ⌄，点击内联展开浅灰详情块含蓝色开关与输入框。
