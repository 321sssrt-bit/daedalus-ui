## 产品边界

实现一次「选收款人 → 输金额 → 核对确认 → 拿凭证」的转账闭环，以及余额不足异常与恢复。不包含：扫码付款、账单筛选统计、银行卡绑定流程、指纹/密码校验。

## 状态地图

- `S0 钱包首页`：余额卡 + 资金账户 + 收款人 + 记录 + 底栏。
- `S1 金额输入`：收款人头像位 + 大金额 + 来源片 + 快捷金额 + 数字键盘 + CTA。
- `S2 核对确认`：金额/收款人摘要卡 + 资金来源单选 + 备注 + CTA。
- `S3 余额不足`：红徽 + 需付/可用对照 + 「改用储蓄卡」「返回修改金额」。
- `S4 转账凭证`：绿徽 + 金额 + 凭证号/时间/来源/备注卡 + 完成/再转一笔。

## 正常流程

1. 首页点任一收款人头像 → 进入 `S1`，顶部显示该收款人。
2. 数字键盘输入金额（或点快捷片），金额大字号实时上屏，CTA 由灰转绿可用。
3. 点「确认转账」→ 金额 ≤ 来源余额时进入 `S2` 核对页。
4. 核对收款人、金额、到账方式、手续费；可在单选行切换资金来源、填备注。
5. 再点「确认转账」→ 进入 `S4` 凭证页：对勾、金额、凭证号、时间、来源、备注。
6. 点「完成」或「再转一笔」回到 `S0`：余额已扣减、今日转出更新、记录顶部新增。

## 异常触发与恢复

- 触发：`S1` 中保持「现钞余额」来源（可用 ¥386.50 明示在来源片），输入超过该值的金额（最直接：点 `¥500` 快捷片）→ 点「确认转账」。
- 反馈：进入 `S3`：红徽、「余额不足，转账未发起」、对照卡显示本次需付与该来源可用余额、另一来源余额；转账不发起，不生成凭证。
- 恢复一（切换来源）：点「改用青柠储蓄卡支付」→ 自动切换到储蓄卡并进入 `S2` → 确认 → 成功凭证。
- 恢复二（降低金额）：点「返回修改金额」→ 回到 `S1` 原金额保留 → 用 `⌫` 或重输降至 ≤386.50 → 确认 → `S2` → 成功凭证。
- 保留数据：收款人、输入金额、备注在往返中均不丢失。

## 数据变化

- 成功转账：所选来源余额精确扣减（`386.50-500` 之类不会发生在余额来源，因其会被拦截）；首页余额、今日转出、`srcCashV/srcBankV` 同步刷新；记录列表 `unshift` 一条「转出 · 收款人」。
- 余额不足触发：不产生任何扣款与记录，凭证号不生成。
- 凭证号 `XJ20260923`+自增序号；时间为 HH:MM 格式。

## 人工验收步骤

正常闭环：

1. 打开页面：手机框居中，首页显示余额 `¥386.50`、两个资金账户、5 位收款人。
2. 点「老周」→ 进入金额页，顶部显示老周头像与名字。
3. 依次按 `2`、`0`、`0`（或点 `¥200` 片）→ 大金额显示 `¥200`，CTA 变绿。
4. 点「确认转账」→ 核对页显示老周、¥200.00、现钞余额；可改选储蓄卡单选行。
5. 点「确认转账」→ 凭证页：对勾、¥200.00、凭证号 `XJ20260923xxxx`、时间。
6. 点「完成」→ 首页余额变为 `¥186.50`，记录顶部出现「转出 · 老周」。

异常恢复：

1. 点「房东陈姐」→ 金额页点 `¥500` 快捷片 → 点「确认转账」。
2. 进入余额不足页：显示需付 `¥500.00`、现钞可用 `¥386.50`，未扣款。
3. 恢复路径 A：点「改用青柠储蓄卡支付」→ 确认页来源已是储蓄卡 → 确认 → 凭证页成功。
4. 恢复路径 B（再走一遍）：再次对任一收款人输 `¥500` 触发不足页 → 点「返回修改金额」→ 键盘 `⌫` 删成 `¥50` → 确认 → 核对 → 成功。
