## 产品边界

本原型实现：课程入口（课表）、单题练习、对错判定与讲解、订正重答、完成态回写。不包含：多题卷面、题库浏览、直播授课、账号与成绩单系统。

## 状态地图

- `v-index`（默认）：课表主页，含四讲状态、进入按钮、完成条（初始隐藏）。
- `v-intro`：第三讲讲次页，含要点列表与「开始随堂练习」。
- `v-quiz`：题目 + 2×2 选项 + 提交按钮；顶部元信息随作答次数更新。
- `v-result`：答错横幅（粉）或答对/订正成功横幅（黄）+ 选项回放 + 板书讲解 + 相应行动按钮。
- 右栏作答记录与状态徽章随每次提交实时变化。

## 正常流程

1. 在课表点「进入第三讲课堂」（或点第 3 讲行/卡）→ 进入 `v-intro`。
2. 点「开始随堂练习」→ `v-quiz`，元信息显示「第 1 次作答」。
3. 点选 B，按钮解禁 → 提交 → `v-result` 黄横幅「一次答对」+ 讲解。
4. 点「完成本课」→ 回 `v-index`：第 3 讲「已完成」、进度 3/4、完成条显示作答统计、Toast 提示。

## 异常触发与恢复

- 触发：在 `v-quiz` 点选 A/C/D 任一错误选项并点「提交答案」。
- 反馈：`v-result` 粉横幅「答错了，这一题还差一点」，选项回放中你的选择被粉红删除线标记，下方给出可订正的板书讲解；右栏新增「第 N 次 · 选 X · 答错」，状态变「订正中」。
- 恢复：点「回到题目再答一次」→ 回 `v-quiz`（选项清空、次数 +1），选 B 再提交 → 黄横幅「订正成功，这回对了」→ 「完成本课」收尾。

## 数据变化

- 每次提交：作答记录 +1（含所选字母与对错），状态徽章按最近一次结果更新，作答次数在题面元信息中递增。
- 答对并完成后：第 3 讲状态 本讲→已完成，单元进度 2/4→3/4，完成条出现；异常提交不改变课程完成状态，只记录一次「答错」。

## 人工验收步骤

- 正常闭环：① 主页点「进入第三讲课堂」→ ② 「开始随堂练习」→ ③ 选 B 提交 → 黄横幅「一次答对」→ ④ 「完成本课」→ 课表第 3 讲已完成、进度 75%。
- 异常恢复：① 同上进题，选 C 提交 → 粉横幅 + C 选项删除线 + 讲解框 + 记录「答错」→ ② 「回到题目再答一次」→ 元信息变「第 2 次作答」→ ③ 选 B 提交 → 「订正成功」→ ④ 「完成本课」→ 完成条显示「共作答 2 次 · 订正 1 次」。
