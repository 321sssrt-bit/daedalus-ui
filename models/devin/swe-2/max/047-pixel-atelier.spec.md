## 内容与数据

- 工具：画笔（B）、橡皮（E）、油漆桶（G）、取色器（I）、抓手；顶栏含快捷键提示「B 画笔 · E 橡皮 · G 填充 · I 取色」。

## 产品边界

实现：像素作品的图层（帧）编辑、笔刷/填充/取色、色板、画布尺寸与网格参数、三类实时预览（放大、平铺、逐帧播放）、四种格式导出与冲突校验、真实文件下载。

不包含：多画布/多文档管理、撤销重做栈、服务端存储、协作、图层混合模式与透明度、真正的像素动画时间轴（逐帧播放仅预览）。

## 正常流程

1. 在画布用画笔（可换色板色、1 px 或 2 px 笔刷）绘制或修改像素 → 画布与右侧预览同步刷新。
2. 在「图层 / 帧」新建或显隐帧 → 列表、缩略图、可见帧计数更新。
3. 点击「导出成品」→ 浮层中选择格式（如 PNG）与缩放 → 点击「生成文件」。
4. 绿色结果框出现：预览图 + 文件名 + 尺寸/帧数 + 「⬇ 下载文件」→ 点击下载得到真实 PNG/SVG/CSS/JSON 文件。

## 异常触发与恢复

- 主动触发 A：内容范围选「逐帧序列」，而可见图层 < 2 → 「生成文件」被拦截，红框列出「需要至少 2 个可见图层作为帧，当前仅 1 个可见图层」。
- 主动触发 B：格式选 JSON + 背景选「墨黑」→ 拦截并提示「只保存像素数据、不渲染背景」。
- 主动触发 C：格式选 CSS + 范围选「逐帧序列」→ 拦截并提示「只支持合成单帧导出」。
- 保留数据：冲突时画布、图层、已选选项全部保留，浮层不关闭。
- 恢复：A 可打开「帧02 · 平移变体」的可见性或「＋ 新建帧」，B 改回「透明」背景，C 改用「合成单帧」；再次点击「生成文件」即得到成功结果与可下载文件。

## 数据变化

- 绘制：当前激活图层 `pixels` 表增加/改写 `x,y → 色值`；橡皮与右键删除条目；油漆桶按连通区域改写。
- 图层：新建追加行并重命名「帧NN · 空白」；删除减少行且至少保留 1 行；显隐切换 `visible`，影响合成预览与逐帧序列帧数。
- 画布尺寸切换：重建 16/24/32 空数据并重排预置图样（原型范围内允许重置）。
- 导出冲突时不产生任何文件与结果；成功时生成对应格式产物，序列导出为横向精灵表。

## 人工验收步骤

正常闭环：

1. 打开页面 → 见到荧光怪客画布、右栏图层两行（帧02 隐藏）、放大预览同步。
2. 选品红色 + 画笔 → 在画布拖一笔 → 画布与预览同帧出现新像素。
3. 点「导出成品」→ 默认 PNG / 合成单帧 / 1× / 透明 → 点「生成文件」→ 见绿色结果框、文件名 `点彩工坊-合成-16x.png`、下载按钮可取到真实 PNG。
4. 改选缩放 8× 再导出 → 文件名与预览同，结果尺寸标注 128 × 128 px。

异常恢复：

1. 浮层中「内容范围」改「逐帧序列」→ 点「生成文件」→ 红框提示可见帧不足且无结果框。
2. 关闭浮层 → 在图层行点「帧02」的 ○ 使其变 ◉ → 重开导出并再次「生成文件」→ 出现精灵表结果，文件名 `点彩工坊-帧序列-16x.png`、元数据帧数 2。
