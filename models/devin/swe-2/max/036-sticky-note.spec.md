# 036 编辑发布

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px（移动端；桌面宽屏下包在居中的手机框内展示）
- 对应页面：`036-sticky-note.html`
- 复现范围：「碎念」便签发布页，含便签墙、胶带编辑器、字数计数、存草稿与发布上墙。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 正文框 | min-height 110px，横格底纹 | 虚线内文 | 输入实时更新 `0 / 140 字`，maxlength 140 |
| 发布钮 | flex 1.6，墨底黄字 | 「发布上墙」 | 内容非空才可发；点击生成新便签随机贴上墙 |
| 存草稿钮 | flex 1，虚线描边 | 「存草稿」 | 点击改状态为「草稿已存」+ 顶栏草稿标带时间 |
| 墙便签 | 150px 卡 + ⌀10px 红图钉 | ±3° 随机倾斜 | 发布时新增一张含标题与正文 |
| 状态字 | meta 行右侧 | 编辑中 ● | 草稿 ◌ / 已发布 ✓ |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390px | 机壳内全尺寸 | 单列移动布局 |
| 桌面宽屏 | 机壳居中于 `#3b3421` 深场 | 尺寸不变 |
| ≤430px | 机壳去圆角铺满视口 | 无框展示 |

## 内容与数据

- 顶栏「写一条碎念」；墙上预置 3 张便签（浇水提醒、书架灵感、周末海边）。
- 标题可空、正文 maxlength 140；状态字三态 编辑中/草稿已存/已发布。
- 发布把标题+正文生成为新便签（随机 left/top/rotation），并清空编辑器。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 按钮点按 | .12s | 缩至 .96 | 关闭过渡 |
| toast | .3s 淡入 1.6s 驻留 | 顶部纸条「已贴上墙」等 | 关闭过渡 |
| 发布 | 即时 | 新便签随机倾斜落位 | 即时 |

## 复现验收清单

- [ ] 明黄墙面上预置至少 3 张倾斜便签，各带红色图钉
- [ ] 编辑器卡片 -1.2° 倾斜，顶部有橙色胶带条
- [ ] 输入正文时字数计数实时更新，上限 140
- [ ] 点「存草稿」后状态变「草稿已存」且顶栏草稿标更新
- [ ] 点「发布上墙」生成新便签贴到墙上并清空编辑器
- [ ] 发布钮为深色大块，比存草稿钮更醒目
- [ ] CSS 含 `prefers-reduced-motion` 媒体查询并禁用过渡
