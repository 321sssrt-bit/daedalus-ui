# 020 定价 — grid-mono

## 意图元数据

- 意图版本：1
- 对应规范：`020-grid-mono.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用瑞士网格的绝对纪律表达 API 计费的绝对诚实：一张粗黑线大表对比四档，推荐档反白处理，把「选档」做成一次可核对的勾选而非营销诱导。

## 适用场景与目标用户

开发者工具、云 API、数据服务类产品的定价页；面向读表比参数的工程师与采购，强调条款透明、数字可对比。

## 非目标

- 不用彩色胶囊卡片、圆角阴影与插画，本页拒绝一切彩色。
- 不做 FAQ 手风琴、用量计算器、货币切换，聚焦档位对比与开通。
- 不用「最热」式营销话术，推荐档仅作事实标注。

## 复刻提示词

纯白瑞士版面：3px 黑线页眉挂黑方块字标「墨衡」，56px Helvetica 大标题接 2px 周期切换钮。核心是一张 table：170px 行标签列 + 4 档等宽列，表头 3px 黑线封顶，推荐档整列黑底反白带「推荐」白签；点击任意档整列套 3px 内描边，底部黑结算条升出显示所选与 CTA。等宽字体承载全部价格数字，全页零圆角零彩色。
