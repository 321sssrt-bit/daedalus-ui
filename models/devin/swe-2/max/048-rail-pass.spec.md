## 产品边界

实现：单条路线的班次查询、席位选择（二等/一等 + 座位图）、订单确认与提交、售罄异常反馈与改选恢复、电子行程凭证展示。

不包含：真实余票接口与支付、多乘客与证件编辑、往返/联程、改签退票流程、站外交通；「售罄校验」为演示用确定性触发，不代表真实库存。

## 正常流程

1. 搜索页确认出发/到达/日期（可交换站点、换日期）→ 点「查询班次」。
2. 班次列表选一班（非校验班次，如 G32）→ 进入选座页。
3. 选席别 tab 与座位（如 3车8C）→ 底部条显示已选与价格 → 点「确认选座」。
4. 订单页核对行程/乘车人/费用 → 点「提交订单」→ 900 ms 处理遮罩。
5. 进入行程凭证：打孔电子客票 + 「已出票」状态，订单号自动生成。

## 异常触发与恢复

- 主动触发 A（班次级）：班次列表点 G7618（带斜纹「售罄校验班次」标签）→ 其座位图整班斜纹 + 提示条 → 任选座位并确认、提交 → 失败屏。
- 主动触发 B（座位级）：普通班次选座页中点斜纹格 12F（图例标注「售罄校验位」）→ 订单页出现提示条 → 提交 → 失败屏。
- 失败屏内容：红框「席位已售罄」+ 具体席位（如「G32次 二等座 3车12F 已售罄，未扣款」）+ 保留卡显示原路线与日期。
- 恢复：「返回班次列表改选」回到同一查询结果的列表；「同班次重新选座」回到该班座位图；改选可售项后重新提交即进入行程凭证页。

## 数据变化

- 搜索：出发/到达/日期写入查询摘要并贯穿列表、订单、凭证与失败保留卡。
- 班次/座位：所选车次、席别、座位号写入订单与凭证；提交前价格随席别（二等/一等）切换。
- 售罄提交不产生订单；成功后生成 `YX260923-####` 订单号与「已出票」状态。
- 异常恢复后座位选择被清空、需重新选择；路线与日期条件不丢失。

正常闭环：

1. 打开页面 → 首页默认「杭州东 → 南京南 · 9-23」→ 点「查询班次」。
