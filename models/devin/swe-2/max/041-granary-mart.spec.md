## 内容与数据

- 品牌名「仓廪集市」，副标「有机粮仓 · 产地直发」；公告条写「今日粮仓直发 · 单笔满 ¥59 免运费 · 满 ¥100 自动抵谷香券 ¥8」。
- 8 个真实商品，各带中文产地（如「吉林·延边火山岩田」）与 2–3 个规格；价格格式 `¥`+两位小数。
- 明确的缺货入口：「有机红小豆」的 `2.5kg 囤粮装` 标注「· 售罄」；「秋田小町米 5kg 囤粮装」标注「本批仅剩 2 件」；「手工玉米糁 500g」标注「本批已售罄」。
- 结算规则：商品合计 + 运费（满 ¥59 免，否则 ¥6.00）− 谷香券（满 ¥100 减 ¥8）。
- 回执字段顺序：店名、「出 货 单 · ORDER RECEIPT」、单号 `GM20260923-xxxx`、下单时间、逐行商品明细、运费、抵扣、实付合计、收货仓点、支付方式。
- 异常保留数据：拦截后购物车条目、数量、选中规格全部保留；恢复只需减量或改选规格。

## 产品边界

实现单次「浏览 → 选规格数量 → 粮篓核对 → 提交订单 → 出货回执」闭环，以及缺货异常与恢复。不包含：登录、地址簿编辑、在线支付网关、物流跟踪、多门店比价。

## 状态地图

- `S0 市集浏览`：默认态，标签页 + 商品网格 + 空粮篓。
- `S1 已选规格/数量`：卡片上点规格片与步进器，价签实时改写。
- `S2 粮篓有货`：篓内列表、动态合计，可改数量、换规格、删行。
- `S3 售罄拦截（卡内）`：对售罄规格点加入 → 卡内错误条 + toast，篓不变。
- `S4 超量拦截（篓内）`：条目 qty>库存 → 行内提示；提交 → 拦截条 + 行高亮。
- `S5 回执浮层`：校验通过 → 全屏遮罩 + 出货单；关闭后回到 S0 且粮篓清空。

## 正常流程

1. 浏览商品，可按「全部/米粮/杂粮/豆类/磨粉」过滤网格。
2. 在卡片上点规格片、用 `−`/`+` 步进器定数量，价签价格随之更新。
3. 点「加入粮篓」：底部 toast 提示，右栏出现条目与合计。
4. 在粮篓内可再改规格片、加减数量、删行；商品合计、运费、谷香券、应付合计随每次操作实时重算。
5. 点「提交订单」→ 校验通过 → 弹出锯齿边出货单：单号、时间、明细、实付合计。
6. 点「返回集市」或「再下一单」：回执关闭、粮篓清空，回到市集继续选购。

## 异常触发与恢复

- 触发一（商品卡）：选择「有机红小豆 · 2.5kg 囤粮装」或「手工玉米糁 · 500g 纸袋」（片上有「售罄」标注），点「加入粮篓」→ 卡内陶红条提示「该规格本批已售罄，请改选有货规格」，底部 toast 同步提醒，粮篓不写入。
- 触发二（购物车）：把「秋田小町米 · 5kg 囤粮装」（仅剩 2 件）加进粮篓后在篓内按 `+` 到 3 件以上 → 行内出现「库存仅 2 件」提示；点「提交订单」被拦截：拦截条说明几项超库存，相关行带红晕高亮。
- 恢复：在篓内对该行点有货规格片（改选），或用 `−` 把数量减到库存内 → 拦截条消失 → 再点「提交订单」→ 正常弹出货回执。
- 拦截期间不提交订单、不生成单号、不清空粮篓。

## 数据变化

- 正常成功：生成单号 `GM20260923-` 自增序列与时间戳；回执明细 = 粮篓条目；关闭后粮篓清零、顶栏计数归 0。
- 卡内售罄触发：无任何数据写入，购物车计数与合计不变。
- 篓内超量：条目标记超库存，合计照常计算但不允许提交；恢复操作（改规格/减量）立即清除拦截标记并重算合计。
- 库存数据在单页生命周期内只读校验，不持久扣减（原型边界）。

## 人工验收步骤

正常闭环：

1. 打开页面，确认顶栏「仓廪集市」、公告条与 8 个商品卡可见，粮篓显示空态文案。
2. 在「高山燕麦片」卡选 `1kg 布袋`，步进器按到 2，点「加入粮篓」→ 出现 toast，右栏新增一行。
3. 再对「石磨全麦粉 2.5kg」加入 1 件 → 商品合计 ¥43.50 左右，运费 ¥6.00 或满额减免随金额变化。
4. 凑满 ¥100 观察「谷香券 −¥8.00」行出现。
5. 点「提交订单」→ 出货单弹出，单号形如 `GM20260923-1043`，明细与合计正确；点「返回集市」→ 粮篓清空。

异常恢复：

1. 在「有机红小豆」卡选 `2.5kg 囤粮装`（售罄片）→ 点「加入粮篓」→ 卡内出现售罄错误条、toast 提示，粮篓无变化。
2. 选 `1kg 布袋` 加入，再在「秋田小町米」卡选 `5kg 囤粮装`（仅剩 2 件）加入 1 件。
3. 在粮篓内把该行 `+` 到 3 → 行内提示「库存仅 2 件」；点「提交订单」→ 拦截条出现、行高亮、无回执。
4. 把该行规格改选为 `2.5kg 布袋`（有货）→ 提示消失；再点「提交订单」→ 出货单正常弹出。
