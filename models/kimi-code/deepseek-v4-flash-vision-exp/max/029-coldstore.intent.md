# 029 文件上传

## 意图元数据

- 意图版本：1

## 设计意图

上传页的体验核心是「宁可慢但要知道在干什么」。这里把单据上传放进「冷链库」场景：冷冻黑蓝底、冰蓝拖放框、库温实时显示——把「上传」理解成「入库」，文件入列后明确展示大小/类型/进度；失败文件不被踢出列表，而是留在原地给「重试」；「开始处理」只在全部就绪后激活，避免用户对着半截进度按按钮。进度为模拟但节奏真实（随机步进），便于展示全部状态。

## 适用场景与目标用户

适合单据扫描、证件、质检报告等必须留档的 B/S 工具；目标用户是库房/报关/质检操作员——他们要一次多选上传多个文件，且必须能看到「哪个文件失败、怎么重试」，因此失败态要持久保留而不是 toast 一闪。

## 非目标

- 不做图片预览缩略图（保留图标）、不做断点续传（重试全量重传）
- 不做多批次/文件夹目录；批次在顶部单行说明
- 不采用企业蓝白 SaaS 风；冷库冰蓝+薄荷绿是唯一语汇

## 复刻提示词

「冷链库 · 单据上传」页：深冷蓝黑背景、顶部「❄ 冷链库 · 单据上传 / 批次 BF-0904 · 收货单/检疫证/温控记录」与右侧「库温 -18.2°C · 链路正常」绿色脉搏胶囊；巨大冰蓝虚线拖放区（📄 把单据拖到这里…格式 PDF/JPG/PNG/XLSX）；下方文件列表行——文件图标、名称、大小/类型、进度条+百分比，完成行变薄荷绿「✓ 已就绪」并提供「移除」，失败行红框显示「✕ 上传失败 · 格式或网络」与「重试」；底部「已入列 N 份 · 可就绪 M 份」「清空列表」「开始处理全部」；像把单据送进冷库的入机台，每份单据都有明确去向。
