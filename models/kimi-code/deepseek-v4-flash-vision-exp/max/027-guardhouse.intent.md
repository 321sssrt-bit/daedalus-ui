# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-guardhouse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限配置最怕「看不懂谁有什么」。这里把角色做成「南岭巡防队哨兵团」：三个角色卡展示职责与人数，点击任意角色切换到「该角色视角」的权限矩阵；矩阵格用 ✓（允许）/◐（受限）/—（不允许）三态并可直接点击循环，把「切换预览-修改-保存」做成一条可摸的流程，配合「未保存计数」「放弃改动」避免误改。军绿+警戒黄的巡防气质让权限语义天然清晰（绿=放行，黄=需核准）。

## 适用场景与目标用户

适合团队协作工具、企业后台、社区型产品中需要「角色-权限矩阵」配置的场景；目标用户是管理员——他们需要先看角色定义再看能力矩阵，且修改时希望立刻知道有多少处未保存、能否一键放弃，而不是面对一张静态表格。

## 非目标

- 不做自定义角色创建、不做人员分配（人数为展示）
- 不做权限继承关系图；矩阵即全部
- 不采用蓝色企业风；军绿+卡其+警戒黄三色即全部语汇

## 复刻提示词

「南岭巡防队 · 哨兵团」角色权限页：军野绿米白底、顶部「哨长/巡哨/文书」三张浅卡（各含人数、职责、标签列表），点选后卡上有军绿勾边与「预览中」角标；下方为 5×3 权限矩阵——能力列「调度/巡查/放行/登记/存档」，行是三个角色；格子三态：军绿实底白✓、透明卡其空框、琥珀实底◐；说明行「点击空白格可切换 ✓ / ◐ / —」；底部保存栏显示「有 N 处未保存改动」与「放弃改动」「保存权限（军绿实底）」；整体像哨卡的值班簿，简洁、明确、可控。
