# 006 二次验证

## 意图元数据

- 意图版本：1
- 对应规范：`006-sentinel.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「二次验证」从安全流程变成「边境哨站对暗号」的场景：军绿、卡其、米白、红戳的行政档案气质，六位分格输入配合自动跳格与退格回退，让输入手感接近纸面填单；「证件之外还要对一句暗号」把验证的必要性解释成一则边境规矩，而不是冷冰冰的安全警告。失败计数、封锁与倒计时全部显性化，给人确定的可预期感。

## 适用场景与目标用户

适合档案、政务、银行后台、企业内网等略带严肃感的产品；目标用户是需要调动历史档案、且对成功/失败状态有强烈知情需求的操作者，他们对「为什么又要验证一次」持怀疑态度，因此需要一句合理的解释。

## 非目标

- 不做「记住这台设备」勾选、多因素切换（App/短信/邮件枚举）
- 不做令牌物理密钥、无感验证等现代金融风
- 不采用蓝色科技感或霓虹；全页仅军绿、卡其、红戳三色系

## 复刻提示词

一张「边境档案站」二次验证页：卡其底与细网格、墨绿顶栏写「界碑 · 边境档案站」、红戳底边；左侧说明区讲「证件之外还要对一句暗号」、手机 183 **** 0021、待办号 #A-4107；右侧米白验证卡上是六个 52×64 等宽数字格、状态行、120 秒倒计时的「重发暗号」、失败满 5 次的封锁提示与「改用备用号」；整体像 90 年代机关档案室，庄重但不吓人。
