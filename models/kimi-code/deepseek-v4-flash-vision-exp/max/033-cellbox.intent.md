# 033 钱包首页

## 设计意图

钱包首页的定时任务是把「我的钱」和「钱的最近去向」同时放好：深色渐变余额卡（¥268.40 唯一主视觉）+ 金币黄转出/玉绿收入语义 + 当日流水置顶；快捷操作「转出/收款/明细」是最常用三件套，转出用底部弹层带 100/200/全部快捷金额与「1 分钟内到账」承诺；底栏四 tab 保持钱包（on）为默认，不玩花活——这是一个要「随时看、随手转」的工具，干净、诚实、不炫技。

## 适用场景与目标用户

适合个人日常消费钱包/零钱类 App；目标用户是通勤族与年轻上班族——他们高频查看余额、给银行卡转账、记录小额消费，需要一屏内完成「看余额→看流水→转出」，并且转账确认成本低。

## 非目标

- 不做账单图表周报（流水即止）、不做零钱罐详细页（保留入口）
- 不做收款码生成、不做指纹支付（弹层按钮示意）
- 不采用大红大紫促销色；金币黄+玉绿+灰白三色语义即全部

## 复刻提示词

一部 390×844 手机里的「零钱匣」钱包首页：浅灰屏底、深色渐变余额卡「可用余额 ¥ 268.40 · 总资产 ¥ 1,286.00」与「零钱罐 2 个 / 本周支出 ¥182.00」；下方三枚快捷圆卡（转出金/收款玉绿/明细灰）；「全部/收入/支出/零钱罐」分段；六条流水卡（早餐 −12、红包 +66.66、地铁 −5、工资 +485…收入玉绿、支出深灰）；底部白底四 tab「钱包（绿）/账单/零钱罐/我的」；点「转出」弹出底部弹层——金额 30px 金色、¥100/¥200/全部转出三枚按钮、确认转出；整体像一只放在裤兜里的零钱匣，一眼看得清、一步转得出。
