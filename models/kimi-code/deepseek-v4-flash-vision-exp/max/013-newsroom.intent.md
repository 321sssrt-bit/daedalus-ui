# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-newsroom.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

收件箱常年被做成一排蓝色数据行；这里换成「晨间编辑部的来信台」：报纸米灰底、衬线报头、红笔圈点与主编批注，让「处理消息」回到「读稿—批注—签发」的编辑动作。列表保留未读红点、星标、急稿三套语义，读稿区以书信卡呈现，比「邮件三栏」多了审查氛围，但筛选/标记/已读的操作一个不少，先确保效率再谈气质。

## 适用场景与目标用户

适合内容编辑部、节目制作、媒体沟通类内部系统；目标用户是值夜/晨间编辑与审稿人——他们要在大量来稿中标记紧急项、快速批注、安排见报，需要「红笔批注」那种一览下的优先级感知，而非常规邮件客户端的整齐冷漠。

## 非目标

- 不做回复/撰写新邮件、不做草稿箱与已发送
- 不做全文搜索；只保留列表+读稿双栏
- 不采用蓝紫渐变或玻璃；报纸黑白灰+红笔三色即是全部

## 复刻提示词

一间报社晨间编辑部的收件台：米灰纸张背景，左侧「晨钟报。」衬线报头与四枚筛选胶囊（全部/未读/星标/急稿），列表是五封来信——未读带红点、星标用红星、急稿有急稿标；右侧是翻开在白桌上的稿件卡，衬线正文、红笔虚线批注框、底部归档编目行；顶部操作条有「全部标记已读」「星标」「已处理本文」；像值班编辑的案头，纸感与秩序并存。
