# 007 欢迎空态

## 意图元数据

- 意图版本：1
- 对应规范：`007-frontier.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态不应该是「抱歉，这里什么都没有」，而应该是一张等待落笔的白纸。我把欢迎空态做成一册「拓荒者手册」：木刻版画、牛皮纸、赭红硬边按钮，把「创建第一份内容」重新定义为「开垦第一块地」，用动作叙事代替功能说明；点击后的命名弹层让用户第一次动手就留下自己的名字，完成从「空白」到「有主」的转变。

## 适用场景与目标用户

适合日记、笔记、地图、路线标记等单人创作型工具；目标用户是刚注册、尚未产生任何内容的新用户——他们需要被给予「第一件事」的具体抓手，而不是看到一堆占位灰块。

## 非目标

- 不做引导多步教程（004 覆盖）、不做示例数据填充
- 不做「立即导入」等迁移入口；空态保持纯净
- 不采用炫彩渐变色；只用棕、沙、赭红、一点提示绿

## 复刻提示词

一册牛皮纸「拓荒者手册」的欢迎空态：左栏木刻版画（一间小屋、赭红落日与地平线），右栏是「这里还是一片荒地」的欢迎语、赭红硬边主按钮「开垦第一块地 →」与虚线次按钮「先看看别人的拓荒日记」；点击主按钮弹出纸卡「给第一块地命名」，确认后空态变为已开垦状态并出现绿色成功行；底色深棕、纸张米黄、赭红点缀，像一本旧旅行日志，诚恳而不煽情。
