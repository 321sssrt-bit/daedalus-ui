## 正常流程

1. 点《三个数的加法》；2. 第 1 题 9（正确答案）：选后提交 → 绿提示 + 解释；1.5s 后第 2 题；3. 依次完成 3 题 → 完成页（✓ 已完成 / 3 题全部作答完成 / 再学一遍）。

## 异常触发与恢复

- 触发：任选一题提交错误选项（如第 1 题选 8）→ 该选项红、正确选项绿、结果卡「× 答错了：正确答案是『9』」，给出订正解释（7+2=9…），并提供「返回题目再答一次」。
- 恢复：点「返回题目再答一次」→ 选项状态清空 → 选正确项提交 → 绿提示「✓ 答对了！」+ 解释 → 进入下一题；即「订正成功」。
- 数据：答错不影响课程计数；只有答对才进入下一题；最终完成页说明订正也算完成。

## 数据变化

- 答错：该题停留、状态 wrong/correct 标注；答对：qi+1；完成：finish 显示；无持久化。

## 人工验收步骤

1. 点课程卡进入第 1 题；2. 选「8」提交 → 红提示+正确答案 9+解释+「返回题目再答一次」；3. 点返回再答 → 选「9」提交 → 绿「✓ 答对了！」；4. 完成第 2、3 题 → 完成页出现；5. 点「再学一遍」→ 回课程入口。
