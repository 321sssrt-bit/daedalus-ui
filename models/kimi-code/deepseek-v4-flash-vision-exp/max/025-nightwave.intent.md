# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-nightwave.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

账号设置页的尊严在于「改得放心、看得清楚」。这里用「夜航电台调音台」的身份：深夜蓝黑 + 信号青，左侧是频率/连续播出天数，把账号放到「电台主人」语境中；设置分「个人资料/安全/通知与收听」三组，行内值一眼可见，点击行展开编辑而非另开页面，开关物理化（胶囊滑动）且默认值合理——开播提醒开、评论回复关。全部改动即时生效的说法楼下文案明确，保持坦诚。

## 适用场景与目标用户

适合内容创作者平台（播客、电台、直播间）的管理后台设置；目标用户是电台主播与运营——他们需要快速改「显示名/简介/音量/开播提醒」，并有「两步验证」「登录设备」这类安全控制，因此行内预览 + 展开编辑最符合其低打扰偏好。

## 非目标

- 不做多账号切换、不做主题定制（夜间即唯一主题）
- 不做真实保存反馈（按钮演示）、不做邮箱变更流程
- 不采用白色 SaaS 风；深蓝黑+信号青是唯一的电台视觉语言

## 复刻提示词

「夜航电台」账号设置页：深蓝黑背景、左侧电台侧栏（主台面/播客库存/账号设置…与「当前频率 FM 98.7」状态卡），主区顶部是「账号设置 / 资料与偏好」与身份行（渐变头像、航行家·阿绫、电波会员·3 级）；下方分「个人资料 / 安全 / 通知与收听」三组行式设置——显示名称、电台简介、登录密码、两步验证开关、登录设备、开播提醒开关、评论回复开关、默认音量 62%；点击行就地展开编辑输入框与信号青「保存修改」按钮，开关为物理胶囊；像夜间电台调音台一样专业、安静、一切可调。
