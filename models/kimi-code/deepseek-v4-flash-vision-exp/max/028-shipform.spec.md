## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 步骤条 st | flex 三项；padding 9px 6px；圆角 8px | 浅灰底弱化字 | `.done`：绿字+绿圆✓；`.on`：船体浅底深字+实心蓝圆 2；点击无跳转（仅视觉） |
| 字段 f | 两列网格（.full 跨列）；标签+控件+hint/err | 输入默认白底 1.5px 灰边 | 焦点海蓝边+光晕；校验失败 `.f.bad`：输入橙边橙底 + err 显示；输入时提示不变 |
| 必填标记 | label 后 `<em>*</em>` | 红色星 | 静态 |
| 节跳转 jump | 三枚胶囊按钮 | 白底海蓝字 | 悬停海蓝边；点击 `scrollIntoView({behavior:'smooth'})` 至对应节 |
| 保存草稿 | 透明细边 | 点击显示「✓ 草稿已保存到本机」2.2s | 悬停加深 |
| 提交申报 | 海蓝实底 | 点击校验：失败在 `.f.bad` 内聚焦首个错误并显示 err 文案 | 成功：按钮「已提交 ✓」1.8s + 「✓ 申报已受理…」2.6s |
| 必填/格式规则 | — | 船名非空；MMSI `/^\d{4}\s?\d{5}$/`；总吨位>0；船员 1–50 | — |
