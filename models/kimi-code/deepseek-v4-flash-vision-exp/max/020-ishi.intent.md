# 020 定价

## 设计意图

定价页不该是 SaaS 订阅表，也可以是「手工染坊的三档活」：靛蓝+亚麻+原木的尺度，把档位定义为「试染小样 / 成衣定染 / 整批定染」，每档用「适合谁」开头而非「包含什么」开头；权益清单用 ✓ 与「—」明确标出边界（这是手工作坊的诚实），推荐档用红旗与实底 CTA 引导但不压制选择；底部「联系染色师」保留人对人的入口，与促销横条共同构成「可谈」的温度。

## 适用场景与目标用户

适合手作定制、小型服务工作室、非标生产（打样/首件/批量）的定价页；目标用户是个人顾客与小 B 客户——他们需要先判断「我该选哪档」，再核对权益边界与交期，因此「适合谁」与「明确不含」比订阅制术语重要。

## 非目标

- 不做月费/年费切换、不做表单提交（联络为按钮）
- 不做对比表格多维度矩阵；三档权益按需展开
- 不采用深色科技风或绿色环保陈词；靛蓝染布与原木是全部气质

## 复刻提示词

一间蓝染工坊「ISHIGAMI」的定价页：浅靛蓝底、居中大字标题「一匹布的三种活法」，副题声明「明码标价不藏着掖着」；三列亚麻质卡片——试染小样 ¥39 起（第一次染布的人），成衣定染 ¥168 件起（最受欢迎，红底白字旗标、白底靛蓝细框、实底靛蓝按钮），整批定染 ¥2,880 批起（20 件起步、头样 2 件确认、可开专票）；每档权益清单用 ✓ 与 — 区分含与不含；底部原木色「联系染色师」按钮与「满 3 人同行立减 8%」促销条；整体像染布坊的报价单，诚实、干净、可商量。
