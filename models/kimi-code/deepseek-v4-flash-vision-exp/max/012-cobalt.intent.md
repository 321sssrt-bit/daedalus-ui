# 012 日历

## 意图元数据

- 意图版本：1
- 对应规范：`012-cobalt.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

日历不该永远是「效率工具的模样」。这里把排期做成「排窑历」：白瓷底、钴蓝勾线、铁锈印章与青瓷/铁锈分类色条，让烧窑、出窑、课程、交货在一个月格里呈现为窑坊的真实节奏。事件用「入窑/开窑/巡窑」等工序语言替代通用「会议/任务」，详情弹层保留了纸质历书的手写批注感，同时保持网格清晰、可导航、可点开。

## 适用场景与目标用户

适合工序密集、节奏多样的手工作坊、窑炉/烘焙/酿酒等生产型日历；目标用户是窑主与师傅——他们需要按天安排入窑、开窑、备料、交货，并一眼看出「哪天开窑哪天交货」，因此用类别色条区分事务性质而非装饰。

## 非目标

- 不做周视图/列表视图切换、不做事件创建表单
- 不做节假日/农历标注；庚子年仅为年代氛围
- 不采用扁平 SaaS 蓝紫或玻璃拟态；钴蓝+白瓷是唯一语言

## 复刻提示词

一张「青窑工坊」排窑月历：白瓷底色带细瓷纹、深钴蓝双线边框，顶部左侧是旋转的朱砂印章「窑」与「排窑历」标题，右侧是月份切换箭头；周头一行钴蓝浅底，正文为 7 列月格；事件以三种左色条卡显示——钴蓝=烧窑备料、青瓷=出窑/活动、铁锈=交货客单；点击事件弹出白瓷详情卡（分类/标题/时间/批注）与「知道了」「调整档期」按钮；整体像一本摊开的瓷坊账册，古典但可读。
