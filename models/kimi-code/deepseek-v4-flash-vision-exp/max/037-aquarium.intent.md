# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-aquarium.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态不是「什么都没有应付」，而是「第一件事怎么开始」的邀请函。这里把空态做成一只养好水、等待入鱼的空鱼缸：气泡、两条示意鱼、副标题「水已经养好了」把「没记录」转译为「万事俱备」；主按钮「+ 添加第一条鱼」是唯一强行动，「先随便看看别人的缸」提供零压力的退路；点主按钮后小规模展示「已养」状态（红绿灯鱼×6/水榕 1 盆），让操作有即时结果，而不是指望用户自己去脑补。

## 适用场景与目标用户

适合记录型/养成型 App（水族、植物、宠物、习惯）的空列表；目标用户是刚开缸的新手——他们不知道「第一条记录」从哪来，因此空态必须给出最小可行动作与「不动作也可自在」的退出，且文案要在「提示少了什么（水、缸、鱼）」与「一点不吓人」之间找到平衡。

## 非目标

- 不做新手问卷/引导三步（004 覆盖 onboarding）
- 不做教程弹窗；全部信息内联
- 不采用白色极简或过量插画；深水蓝+珊瑚鱼的自洽世界

## 复刻提示词

一部手机里的「我的鱼缸」空态页：深海水蓝底手机屏，顶部「‹ 我的鱼缸 / 今日 0 条记录」；中央水缸卡——半透明水蓝描边鱼缸，缸里画两条示意小鱼（珊瑚橙与水蓝）、三枚上升气泡、缸底沙线，上方小标「NO.001 空缸 · 待入鱼」；标题「缸还是空的——但水已经养好了」，说明「加入第一条之后，喂养提醒、水质变化和生长日记都会从这里开始」；主按钮「+ 添加第一条鱼（水蓝实底）」，次要「先随便看看别人的缸」；底栏「鱼缸/水质/图鉴/我的」；点击主按钮切换到「我的鱼缸 1 条 · 红绿灯鱼×6 · 水榕 1 盆」的小规模列表；像一只迎接第一尾鱼的空缸，安静而充满期待。
