# 010 看板

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`010-atelier.html`
- 复现范围：三列样衣看板整页；含卡片「移到下一列」推进、打样人筛选、新建样片弹层并落卡

## 内容与数据

- 品牌：样衣看板 · 秋冬企划；WORKROOM 2F · 裁剪台 · 第 21 周
- 列（3）：样布阶段（红棕点,#b0522d）/ 试身中（青绿点,#3e7d74）/ 已定版（草绿点,#a7c04b）
- 种子卡 7 条（含列、打样人、版型备注）：立领短款风衣/双面呢大衣切样/收腰连衣裙/廓形西装外套/直筒九分裤/针织开衫/衬衫式外套
- 筛选：全部打样人/阿黛/小舟/Mia/老莫
- 新建表单：样衣名称（maxlength 20）、面料 / 颜色（maxlength 20）、打样人下拉、放入列下拉；提交后新卡 meta「新钉卡片 · 待打样」、swatch #b9ad93、进入所选列并刷新
- 计数：每列列头显示当前条数（随移动/筛选/新建更新）
