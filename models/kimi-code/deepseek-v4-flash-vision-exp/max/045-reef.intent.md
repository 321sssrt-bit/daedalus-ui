# 045 音视频平台

## 设计意图

视频播放中断最伤人的不是「断」，而是「从头再来的恐惧」。这里把「深蓝视界」的断网做成可控演示：珊瑚色「模拟网络中断」按钮→立即暂停+「进度已保留」角标+遮罩「已离线 · 点击重连」，恢复后从冻结的秒数继续播放；同时进度调整（±10s、进度条）与「进度已保存」只作为常规状态展示。深海洋蓝+水蓝+珊瑚的纪录片语境让「深潜」成为隐喻——中断像深潜的潜点，记录从哪回来就回到哪。

## 适用场景与目标用户

适合长视频/纪录片/课程类平台；目标用户是夜听/晚间观影用户——他们最需要「断点续播」与「进度可见」，因此页面上进度、集数队列、保存状态三处都对进度显性化，断开时明确「保留」，恢复时自动续播而非询问。

## 非目标

- 不做缓冲动画/加载百分比（断网演示即可）
- 不做倍速/画质/字幕/弹幕
- 不做「观看历史」独立页（队列即历史地标）

## 复刻提示词

「深蓝视界」深海纪录播放器手机页：深海蓝渐变屏；发现页双列（鲸落之后/蓝鲸回声/冷泉绿洲，水蓝缩略）；进入播放器：190px 深海插画舞台（鲸尾、光斑、气泡）、右上时间 chip「02:25 / 26:40」、标题《鲸落之后·第一集》；进度条（水蓝填充）与 ±10s 按钮、大播放钮；「⚡ 模拟网络中断」珊瑚按钮；断网后——珊瑚角标「网络中断 · 进度已保留」、遮罩「▶ 已离线 · 点击重连」、时间冻结；点恢复后从原进度继续播放；队列区三集列表当前集高亮、「进度已保存 · mm:ss」；像一台深海潜航器的监视屏，中断是切换潜点，不是回到水面。
