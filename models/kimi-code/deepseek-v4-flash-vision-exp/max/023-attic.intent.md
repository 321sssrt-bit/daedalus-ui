# 023 收藏夹

## 意图元数据

- 意图版本：1
- 对应规范：`023-attic.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

收藏夹不该是「待看列表」的负数，而该是「我的旧物阁」。这里把收藏做成阁楼架子上的实体旧物：轮渡月票、粗陶盐罐、1963 版《农谚录》——每件都有来路、有价格故事；「去掉一条」被翻译成「搁到柜底」而非删除，灰化+虚线框保留了「还在阁楼里」的余地，也让误操作可逆。琥珀灯与深棕阁楼是唯一色系，物件插图用最简单的矢量写意，注意力留在「我攒过什么」。

## 适用场景与目标用户

适合收藏型产品与资料性工具（图鉴、书单、票据、标本、相册归档）；目标用户是收藏癖与念旧者——他们保留的不是价值，是来路；因此每个条目必须带来源与价格/来历叙事，且「移除」必须温和、可逆。

## 非目标

- 不做批量管理（多选删除）、不做搜索/排序
- 不做借阅/价值走势等附加功能
- 不采用扁平白底网格或电商红；琥珀+深棕+奶白是唯一温度

## 复刻提示词

一座「旧物阁」收藏夹：深棕阁楼墙面、顶部琥珀灯徽「旧物阁 · 我的收藏架」与计数胶囊「收藏 6 件 · 已搁下 0 件」；分类条「全部/老票据/手作/旧书/杂件」为琥珀描边胶囊；下方三列奶油旧纸卡，每张卡是旧物插画（轮渡月票、盐罐、旧书、钥匙牌、电影票根、笔筒）、名称、来路（「村口刘婆 2021 年赠」「旧书摊 8 元·字口完整」）、价格行与「搁到柜底」按钮；搁下后卡片灰化划线、虚线 rust 外框；集满搁下一个分类出现「这格架子空了」空态与「回到全部收藏」；像夜里提着灯看自己的旧物，温暖且取舍有据。
