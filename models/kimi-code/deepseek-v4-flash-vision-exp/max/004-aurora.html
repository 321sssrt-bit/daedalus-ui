STEP 1 / 3

欢迎来到极光哨站

这里是离光最近的一间小屋。接下来三步，帮你搭好观察坐标，然后就可以开始记录今晚的极光。

巡光员
每晚自动巡检，记录光带强度与风向，适合长期跟踪。
守夜人
只在预报强烈时提醒你，适合偶尔抬头看天的人。

STEP 2 / 3

给哨站起个名字

这个名字只会出现在你自己的观测日志里。取一个万一以后要讲到这里的名字。

▸ 之后随时可在「哨站档案」里改名，不影响任何已记录的观测。

STEP 3 / 3

最后确认一句话

极光哨站不会卖任何东西，只在你打开它时，替你多记一次光。

▸ 默认开启「低光通知」：夜里出现 Kp≥4 的绿色光带时，哨站灯会亮一下。
