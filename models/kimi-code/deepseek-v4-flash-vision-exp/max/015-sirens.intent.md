# 015 通知中心

## 意图元数据

- 意图版本：1
- 对应规范：`015-sirens.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

通知中心最容易变成「消息流水账」。这里把通知放进「红旗消防站告警总台」：nvy 顶带 + 消防红中线让「优先级」成为页面骨架——火警/出动/队务用红金青三色徽章及左边条分层，未读用红边强化，单条可展开联动详情，比普通「已读/未读」多了一层业务含义。浅钢灰白底色像值班室白板，保证长列表可读。

## 适用场景与目标用户

适合应急值守、运营监控、物业/警务/消防等需要「分类+优先级+处置细节」的通知中心；目标用户是值班主任与调度员——他们需要按类别快速扫视、识别未读火警、展开查看联动信息，而不是逐条点开链接。

## 非目标

- 不做通知偏好设置、不做推送渠道（弹窗/App 分流）
- 不做时间线图、不做批量删
- 不采用渐变小清新；红金青只对应三类语义，颜色不用于装饰

## 复刻提示词

一面「红旗消防站」告警总台：顶部深藏蓝横幅配消防红粗中线与「调度在线」绿色呼吸灯，中部是「全部通知/火警/出动/队务」页签与「未读 3 条」「全部标为已读」「只看未读」；下方白底列表七条通知——未读三条有红色左边条与红字「● 未读」，每个分类带红/金/青徽章，每条含图标、标题、描述、到场信息、时间，可展开联动细节（出动单号、巡检查项…）；整体像站房内的白板墙，秩序感强而不过度设计。
