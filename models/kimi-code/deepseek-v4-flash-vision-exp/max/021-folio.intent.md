# 021 内容目录

## 意图元数据

- 意图版本：1
- 对应规范：`021-folio.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

内容目录的质量决定「想不想点开」。这里把目录做成「独立刊物档案架」：纸白底、铅黑报头、橙红卷角旗标与手作封面，让每一本都是「从印刷机里长出来的纸」；分类筛选（文学/设计/摄影/生活）不破坏目录仪式感，点开弹出的是「摘要+编者+来源」而非跳转——保留纸刊摊开的体验，但把「读一段再决定」的信息量做足。

## 适用场景与目标用户

适合杂志、出版、小书店、独立刊物订阅平台的目录页；目标用户是纸质刊偏好者与内容编辑——他们需要按类别浏览、从封面气质判断、点开看摘要确认是否购买，因此封面、编者和摘要是目录的三个核心字段。

## 非目标

- 不做期刊详情全文页（摘要即终点）、不做收藏/购物车
- 不做搜索（分类足够）、不做滚动加载（6 条即示例）
- 不采用电商大图轮播；目录保持「书架」而非「瀑布流」

## 复刻提示词

一面「白页」独立刊物目录：纸白底上黑色超大报头「白页。」（句号为橙红），右侧竖排「VOL. 7 · 2026 秋 · 共收录 128 种」；过滤条为「全部/文学/设计/摄影/生活」黑色页签；下方三列刊物卡，每张封面是手绘风 SVG 小封面、左上旋转橙色卷号旗（NO.19…）、名称、一句推荐语、编者与产地（如「编·徐潮生 杨十七 / 上饶 / 季刊」）；点击卡片弹出纸白摘要卡，首字下沉橙红色，底部「买一本来读 / 合上目录」；整体像一家只卖纸刊的小书店，安静、讲究、有来路。
