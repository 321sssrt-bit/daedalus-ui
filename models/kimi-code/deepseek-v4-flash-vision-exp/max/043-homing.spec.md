## 产品边界

- 实现：会话选择/文字发送/送达状态/失败重发；不含：语音/图片、表情、群组、未读角标详情、已读回执（只有送达）。

## 状态地图

| 状态 | 触发 |
| --- | --- |
| 会话列表 | 初始/返回 |
| 当前会话（正常） | 点会话行 |
| 消息发送中→已发送 | 发送（正常） |
| 已送达 ✓ | 700ms 后自动 |
| 发送失败（err） | 点「📵 模拟断线」后发送 |
| 恢复送达 | 点该消息「重发」 |

## 正常流程

1. 会话列表默认「阿禾」选中；2. 点击进入会话；3. 输入文字；4. 点发送；5. 消息出现「已发送」，700ms 后转「已送达 ✓」。

## 异常触发与恢复

- 触发：输入条点「📵 模拟断线」→ 该按钮短暂变红提示；随后发送的下一条 out 消息 st=err：气泡旁红色「发送失败」+「重发」按钮，原文保留在会话流中。
- 恢复：点「重发」→ 该条 st 变 deliv（已送达 ✓），错误标记消失；此后发送恢复正常。
- 数据：失败消息不丢失、不视为已发送。

## 数据变化

- 发送前：消息数组+1（out/st）；失败：st=err 保留；重发：st=deliv；正常：sent→deliv。
- 送达状态只演示「已送达」，无「已读」。

## 人工验收步骤

1. 点「阿禾」进会话；2. 发「你好呀」→ 已发送→已送达 ✓；3. 点「📵 模拟断线」；4. 发「这条会失败」→ 红色「发送失败」+「重发」按钮；5. 点「重发」→ 变「已送达 ✓」；6. 再发一条 → 正常送达。
