# 022 个人主页

## 意图元数据

- 意图版本：1
- 对应规范：`022-guild.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

个人主页的输出是「这人是谁、我来干嘛」。这里把主页做成「长乐客栈庄主的手帖」：宣纸横纹、朱砂方印、楷体名号，画像用民间年画式线描；「留宿 · 关注」「递帖相谈」把社交动词换成客栈语言，一句身份里交代完「三代庄主、说书、立字据」——没有口号，只有行当；手记与客来简讯让主页有「活人信息」，而不仅是资料页。

## 适用场景与目标用户

适合传统文化、手艺人、乡贤、个人 IP 类的个人主页；目标用户是来「投宿/谈事/听段子」的访客——他们不关心粉丝数，关心这人能不能打交道、店里什么规矩，因此「在店夜/故人/定场段子」代替了关注数/粉丝数/获赞数。

## 非目标

- 不做动态流时间线（手记为静态四则）、不做私信功能（递帖为按钮）
- 不做封面头图大 banner；画卷本身即封面
- 不采用墨色极致黑白；宣纸+朱砂+玉青的暖旧色是全部

## 复刻提示词

一张「长乐客栈」庄主沈长乐的个人主页：宣纸底细横纹，外围双框描边如画卷；顶部细条「长乐客栈 / 长安西市 · 风字街 12 号」；门面左为年画风庄主画像（戴笠、红袍、方印「庄」旋转 6° 叠角），右侧大楷书姓名「沈长乐」、一句身份自述、账号 @changle_inn、三个数字（72 在店夜 / 1,208 故人 / 306 定场段子）、朱砂「留宿 · 关注」与细边「递帖相谈」；下方「庄主手记」四张卡（说书手记、封挂插图）与「客来简讯」三条留言，页脚「谢绝赊账」；像一家老客栈门前的告示牌，亲切而体面。
