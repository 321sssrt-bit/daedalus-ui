# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-setout.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

「发布」介于普通与删除之间：它不可撤回但也不是毁灭。这里做成「启航港公告发布」：海图纸蓝+深海洋蓝+米色卡，标题直接说「发布到船港公告栏」，后果清单用三条「会发生什么」讲清替代关系、推送范围与日志可追溯；勾选「已核对港调和潮汐表」是确认门槛而非形式，确认前按钮禁用，确认按钮永远比「返回编辑」更醒目——但返回还在，说明这不是单行道。

## 适用场景与目标用户

适合公告/发版/上线/排期类「不可轻按」的操作确认；目标用户是值班发布人——他们要的不是吓人的红字，而是「发布后谁会看到、能否追回」的明确答案，因此确认页必须给出「后果+影响面+可逆性说明」三件套。

## 非目标

- 不做预览弹窗（摘要已内嵌）、不做定时发布
- 不做红色警示大按钮（非删除语义）；navy 蓝+一点强调橙
- 不采用系统弹窗；独立确认卡片更可控

## 复刻提示词

「启航港 · 发布确认」卡片：海图浅蓝背景，深海蓝横幅「启航港 · 发布确认 / DEPT. OF SHIPPING · 航线公告」；罗盘图标旁大标题「把『C-417 航线』发布到船港公告栏？」与橙色强调「这一按，公告即刻生效——它不是删除」；下方「发布后会发生什么」清单（替代旧版、38 艘船推送、写入航政日志）；虚线航线摘要「东二码头 7 号泊位 → 南湾锚地 B 区」与开航窗口；一枚「我已核对港调和潮汐表」勾选框（勾选前「发布航线」置灰）；操作区「返回编辑」与深蓝实底「发布航线」，发布后显示绿色回执与 LOG-0927；像港务局值班室的起航单，郑重但可回车。
