## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 标题输入 | 透明；16px 800 | placeholder「给这封信起个头（30 字内）」 | 无边框无焦点态（随卡） |
| 正文 textarea | min-height 170px；13.5px | placeholder「写点今晚的事…」 | input 更新 counts |
| 字数行 | warn/okc | 正文 N / 500 字（默认 71） | ≥450 字变 rose `.warn`；>0 则 `.okc` 金色 |
| 附加 chip | padding 9px 14px；圆角 99px | 面板底灰字 | 点击 `.on`：紫边紫底紫字（匿名 chip 文案加 ✓）；可再点取消 |
| 存草稿 | flex:1；面板底 | 点击「已存 ✓」1.2s 复原 | hover 亮边 |
| 投入信箱 | flex:2；紫实底 | 点击：「已投入 ✓」金色底 + sentCard 显示 | hover #b090ff；正文空时提示「正文还空着哦（≥ 1 字）」 |
| 成功卡 sent-card | 面板-2 底金边 | 默认隐藏 | `.show` 显示「✓ 已投入电台信箱…明晚 22:00 播出」 |

## 内容与数据

- 页头：深夜来信 / 晚风电台 · 投稿
- 提示：◉ 今晚 22:00 前发出，可上「晚来风」栏目
- 默认标题：楼下的桂花开了；默认正文 71 字（桂花香/外公/拌糖/米糕…）
- 字数限制：标题 30、正文 500；计数文案「正文 N / 500 字」
- 附加：🧺 配一张图 / ✦ 匿名寄出（可切 ✓）/ # 桂花的季节
- 成功：✓ 已投入电台信箱；无需署名，明晚 22:00 在「晚来风」栏目播出；电台编辑组会先听一次。
