# 032 危险删除

## 意图元数据

- 意图版本：1
- 对应规范：`032-brewery.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

危险删除的合格标准是「吓人但不可怕、麻烦但可理解」。这里把删除做成「酿德坊整库注销」：深陶棕底+麦金横幅，损失清单用 × 列出三条，同时用 ✓ 明确「保留：成品记录与财务台账」——让删除边界先于按钮被看见；输入库名「酿德坊」才解锁删除（默认禁用），「不删了」与删除同尺寸并排，减压而不是吓退；删除后回执说明清空范围与「可重新建库」，删除不是终点。

## 适用场景与目标用户

适合数据量大的库级删除（酒样、库存、档案、项目）；目标用户是库管/管理员——他们怕误删，也怕流程蠢；因此「将失去/将保留」分列、精确输入校验、默认禁用的三重保险是标准配置，但文案要人话（「为什么这么麻烦：防止误删」）。

## 非目标

- 不做两步确认（输入即保险）、不做软删除开关
- 不做批量选择删除（库级删除单卡即可）
- 不采用大红恐惧色；陶棕+麦金+一点删除橙，保留酿坊的暖意

## 复刻提示词

「酿德坊 · 整库注销」删除卡：深陶棕背景、顶部麦金色横幅「产德坊 · 整库注销 / 305 个酒样」；卡片米黄色，标题「删除整个酒样库？」副文「这一步要认真」；「将失去」清单 3 条×号（历史记录/未导出酒单/库位化验预约）+ 1 条✓「保留：成品记录与财务台账」；输入框「输入『酿德坊』确认删除」——未输入时删除按钮置灰，输入正确后输入框绿边、按钮变为陶红实底「删除库『酿德坊』」；旁边是同样显著的「不删了（更醒目选项）」；点击后「正在倒空…」→「已删除 ✓」与绿色回执；整体像酒窖里贴的注销封条，郑重而讲理。
