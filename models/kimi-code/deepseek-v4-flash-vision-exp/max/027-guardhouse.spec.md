## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 角色卡 role | 3 列；padding 18px 18px 14px；圆角 14px | 白卡 1.5px solid #cfd1bd | 悬停边加深；`.on`：军绿边+3px 光晕+「预览中」右上角标；点击切换下方标题视角 |
| 权限格 chk | 18×18px；圆角 5px；居中 | `yes`：军绿实底白✓；`no`：透明+卡其边；`once`：琥珀底◐（受限） | 悬停可点格加深边；点击循环 no→once→yes→no；更新未保存计数 |
| 未保存计数 | `#dirty` 琥珀底徽章 | 初始 0 | 每次点击 +1；保存归零；放弃 `location.reload()` 还原 |
| 保存/放弃 | 保存：军绿实底；放弃：透明细边 | 悬停各自加深 | 保存后顶部「权限已保存 ✓」 |
| 顶部状态 | 快照胶囊 | 「权限快照已同步」 | 保存后文字变化 |

## 内容与数据

- 标题：哨兵团 · 角色权限；南岭巡防队 · 共 24 人 · 3 个角色；最近改动：昨天 21:14
- 三角色：哨长（2 人，调度/巡查安排/放行核准）；巡哨（14 人，分片巡检/异常上报/发起放行）；文书（8 人，登记/存档/打印）
- 权限矩阵能力列：调度/巡查/放行/登记/存档；初始：哨长全 yes；巡哨 调度 no、巡查 yes、放行 once、登记 yes、存档 no；文书仅登记/存档 yes
- 说明行：点击空白格可切换 ✓ / ◐ / —（保存后生效）
- 保存栏：有 N 处未保存改动；放弃改动/保存权限
