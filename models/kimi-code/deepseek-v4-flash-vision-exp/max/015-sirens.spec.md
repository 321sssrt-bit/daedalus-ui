## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 通知行 row | 网格 52px 1fr auto；padding 14px 16px；圆角 10px；左边条 4px | 默认左边条 teal #3f8d86；分类徽章 10.5px（火警红/出动金/队务青底） | 未读 `.unread`：左边条红 + 白底 + 未读标红字 700；悬停阴影；展开按钮 toggles `.is-open` 详情块（默认隐藏） |
| 分类标签页 tabs | 四枚；padding 8px 16px；圆角 8px | 边框 #d3dae2 灰字 | `.on`：navy 实底白字；点击过滤（all/fire/ops/hq） |
| 全部标为已读 | padding 8px 14px；圆角 8px | 边框 #d3dae2 灰字 | 悬停深化；点击全部 unread→false 并刷新计数 |
| 只看未读 | 同上（.wide 在 ≤900px 隐藏） | 默认只显示全部 | 点击切换 onlyUnread，文案「只看未读/显示全部」，并加 `.on` 样式 |
| 未读计数 | `#cnt` 11.5px 弱化字 | 未读 3 条 | 随已读操作更新 |
