# 024 结账

## 意图元数据

- 意图版本：1
- 对应规范：`024-ferry.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

结账页的最后一眼应该安心，而不是再被营销轰炸。这里做成「渡口粮行江轮结账台」：深舷蓝顶+水蓝账台，订单、地址、支付方式、应付账单四块信息按「核对→选择→付钱」排列；支付方式单选实时联动应付金额（钱包立减 2 元是唯一促销，且被计算进入按钮），点击确认立即给出黄色「凭证已生成」成功态；整体是「把货交到你手上之前的最后一关」，安静、清楚、有渡口的日常感。

## 适用场景与目标用户

适合社区团购、地方老字号、自提点模式的卖货结账；目标用户是阿婆式的高龄用户与信任型顾客——他们喜欢把地址、自提点、号码写清楚的大字清单，对「立减」敏感但反感复杂券逻辑，因此促销只有一条且直接算进应付。

## 非目标

- 不做优惠券选筐、不做多地址管理
- 不做物流跟踪（自提当天）、不做备注留言
- 不采用亮红大促风；水蓝+船舷蓝+少量日轮黄是全部

## 复刻提示词

「渡口粮行」的结账页：深蓝色船舷顶栏写着「渡口粮行 · 结账 / 共 3 步 · 当前第 3 步：核对与支付」，下方白卡双栏——左栏「1 验单」列出三件货（蜜枣×2 ¥35.6、桂圆干×1 ¥23.0、藕粉×1 ¥19.9）与收货地址「江畔新村 3 栋 502 / 沈阿婆」、自提点窗口与送达时间，「2 支付方式」三张可选卡（沿岸电子钱包、尾号 7731 银行卡、到店付现）单选并对勾；右栏「本次应付」账单：小计 ¥78.5、免运费、新客券 −¥5、应付 ¥73.5，绿色小卡提示钱包再减 ¥2，蓝色大按钮金额随支付方式变化（¥71.5/¥73.5）；点击后变日轮黄「✓ 支付完成 · 凭证已生成」；像登船前验票的柜台，安静而可靠。
