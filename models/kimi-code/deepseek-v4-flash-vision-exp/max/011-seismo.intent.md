# 011 数据看板

## 意图元数据

- 意图版本：1
- 对应规范：`011-seismo.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

数据看板的大忌是把「仪表」画成「装饰」。这里采用地震监测台的语汇：岩黑底 + 事件红橙/平静青的语义色对，波形主图是真实可切换的连续记录（当日/当周/当月三套数据），事件列表与台站健康度把「发生了什么」和「设备行不行」分成两个并列面板；数字卡顶部的 3px 色条延续信号语义，让颜色永远指向状态而非气氛。

## 适用场景与目标用户

适合地震监测、工业设备、电网巡检等「异常优先」类监控场景；目标用户是值班分析员与台网运维——他们需要先看有没有事件、再看设备健康度，因此信息顺序是「主图 → 关键数字 → 列表与健康度」，而不是营销式的居中美化。

## 非目标

- 不做地图震中分布、不做时间轴回放（两独立页能力）
- 不做深色之外的主题；色彩全部承载语义
- 不做 3D/渐增大图；只保留一条事件信号色

## 复刻提示词

一张华北地震台网的监测看板：深岩黑背景，左上绿色呼吸脉冲「震相台 · 华北台网监测」，右侧「运行状态：正常」胶囊；主卡是一段连续地震波形（青绿背景噪声、红橙事件峰），支持当日/当周/当月切换；下方四张关键数字卡（近 24 小时事件 7、在线率 98.2%、最大震级 M3.4、告警处理中 3），再下面是事件列表（含较强/中等/较弱三档徽章）与台站健康度进度条；颜色只有青（正常）与红橙（事件/预警），像值班室的监视屏而非报表。
