# 049 健康习惯产品

## 意图元数据

- 意图版本：1
- 对应规范：`049-mile.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

习惯记录的关键是「输错了别把账搞坏」。这里把晨跑日记的有效性校验做成「字段级定位 + 不落账」：距离或用时越界时（0.5–20 / 5–180），只把对应字段标红并写明范围，数据不写入、进度与趋势纹丝不动；修正后再保存才重算——让用户看到「改错不会产生半条记录」；目标卡与 7 日柱状趋势在同一屏，保存成功立刻看到进度变化，形成「记录→看见→继续」的短反馈环。

## 适用场景与目标用户

适合健康打卡、习惯追踪、饮食记账等「数值记录」工具；目标用户是刚开始晨跑的人——他们对「公里/分钟」的数字边界不敏感（可能输 25 km 或 3 分钟），因此校验提示必须给出明确范围并保持已有数据安全，而不是整单拒绝。

## 非目标

- 不做多活动类型切换（只跑步）、不做统计周报
- 不做目标设置（固定 5 次/18km 演示）
- 不做真实定位轨迹；数字输入即全部

## 复刻提示词

「晨跑日记」记录手机页：晨曦米金底、暖橙保存按钮；顶部深棕目标卡「本周目标：跑 5 次 · 已完成 2 次 / 9.2 / 18 km · 已完成里程」与橙黄渐变进度条；下方「记录一次晨跑」表单——本次距离（0.5–20.0 公里，超出会提示无效）、用时（5–180 分钟）、橙「保存这一次」；输入 25 保存时该字段红框+红字「× 无效：本次距离需在 0.5–20.0 公里之间」、底部红条「这次记录没保存：请修正标红的字段」、目标进度不变；改为 6.0/40 后保存——青绿提示「✓ 已保存：今日 6.0 km / 40 分钟，进度与趋势已更新」，目标卡跳 15.2、七日柱状图周五升高；像一本诚实的手账，写错只擦一行，不撕整页。
