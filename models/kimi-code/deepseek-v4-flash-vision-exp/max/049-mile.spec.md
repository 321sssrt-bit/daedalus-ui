## 正常流程

1. 输入 5.2 / 35；2. 点「保存这一次」；3. 目标卡里程从 9.2→14.4、进度条更新；4. 柱图周五高度更新；5. 显示成功提示；输入清空。

## 异常触发与恢复

- 触发：输入 25 km（>20）或 3 分钟（<5）→ 保存时字段红框 + hint 红字「× 无效：本次距离需在 0.5–20.0 公里之间 / 用时需在 5–180 分钟之间」+ 底部红条「这次记录没保存：请修正标红的字段」；进度/趋势保持原值。
- 恢复：修正（如 6.0 / 40）→ 再次保存 → 成功（进度/趋势重算更新）。
- 数据：无效时不写入周数据（week 数组不变）；成功覆盖当日值。

## 数据变化

- 成功：week[4] 更新为本次距离；total()/daysDone()/日均/进度条/柱图全部重算。
- 失败：无任何数据变化。

## 人工验收步骤

1. 输入距离 25 → 保存 → 字段红+「× 无效：…0.5–20.0 公里」、红条出现、目标仍 9.2；2. 改 6.0、用时 40 → 保存 → 青条「✓ 已保存：今日 6.0 km / 40 分钟…」、目标 15.2、柱图周五升高；3. 用时空 3 → 保存 → 用时字段红提示 5–180。
