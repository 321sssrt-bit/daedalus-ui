# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-nursery.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

注册页不该像考试报名，该像认领一块地：把「填表」包装成「种下账号」，用植物园的奶油绿与亮橙、圆角卡片和盆栽插画消除陌生感，同时把必填校验藏在温柔的小字里（"格式像是少了一片叶子"），让新人第一次就愿意认真填完。

## 适用场景与目标用户

适合面向个人用户的轻量生活服务（如植物养护、记事、习惯打卡、社交园艺类 App），目标用户是年轻、喜欢萌系与自然元素、对冷冰冰的 SaaS 表单有抵触的初次使用者。

## 非目标

- 不做手机号注册、第三方登录、验证码（留给后端流程）
- 不做玻璃拟态或深色主题；圆角卡片但拒绝霓虹渐变
- 不承诺注册后进入的完整向导（属于 004 题职责）

## 复刻提示词

奶油白底细点阵背景上的一张注册卡片：左侧浅绿渐变区画着一盆橙色花盆里探出新芽的插画、品牌「芽泥」与三步提示「起名/种下/等待开花」；右侧纯白表单圆角 24px，主按钮墨绿「种下账号」，必填星号与错误状态用亮橙与柔和红，成功提示是浅绿底小卡片；整体像一家植物园礼品店，温暖但不幼稚。
