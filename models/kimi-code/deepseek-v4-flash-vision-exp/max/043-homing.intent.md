# 043 即时通讯产品

## 意图元数据

- 意图版本：1
- 对应规范：`043-homing.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

消息功能最脆弱的是「发出去了到底送没送到」。这里用「咕咕通」信鸽隐喻包装——鸽灰蓝、会话栏深蓝、橙喙「模拟断线」按钮——把未读/已读的常规状态图简化为「已发送→已送达」两级，且刻意不做已读回执，避免干扰；失败消息不做「红色感叹号孤悬」的焦虑展示，而是保留气泡原样+「重发」小胶囊，让用户确认这是「这条消息没出去、可以再试一次」，而不是「聊天中断了」。模拟断线按钮自带 1.4s 态变红提示，故障可精确复现。

## 适用场景与目标用户

适合个人轻聊天/邻里互助/小团队 IM；目标用户是日常闲聊者——他们需要看到明确的送达状态，失败时能一键重发，且不希望被「对方已读」这类社交压力打扰。

## 非目标

- 不做朋友圈/群组/表情/语音消息
- 不做消息已读双勾（保持送达即止）
- 不做会话列表的未读徽章计数（显示最近一句即可）

## 复刻提示词

「咕咕通」消息手机页：鸽灰蓝屏；会话列表三行（阿禾/老白/修理铺小张，圆头像+最近一句+时间），选中项深蓝描边；进入与阿禾的会话——顶栏深蓝「‹ 阿禾 · 在线」；消息流：左侧白气泡（「来啦？我到了楼下便利店」），右侧深蓝气泡（「三分钟后到」带「已送达 ✓」绿色小字）；输入条为胶囊框+橙「📵 模拟断线」+深蓝发送圆钮；断线后发送的消息右侧显示红色「发送失败」与「重发」胶囊（原文保留），点击重发后变「已送达 ✓」；像两只鸽子在屋檐间来回，状态诚实、失败可重来。
