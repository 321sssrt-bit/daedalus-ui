# 001 登录

## 意图元数据

- 意图版本：1
- 对应规范：`001-telegraph.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「登录」从冷冰冰的门禁变成一场电报局入职仪式：米黄旧纸、电报键盘插画、红蓝信号灯和「拍发中」的等待文案，让输入密码这件事自带年代感与郑重感，同时主按钮与错误信号保持干净的可读性。

## 适用场景与目标用户

适合需要情怀与可靠性的老牌互联网服务（如历史档案馆、报业集团、慢递服务）或复古品牌站；目标用户是愿意为「仪式感」付费的文艺向用户，也尊重习惯快速进入的效率型用户——表单仍是标准三段式登录。

## 非目标

- 不做社交登录、二维码、多语言切换等扩展能力
- 不采用玻璃拟态、渐变霓虹等现代科技感套路
- 不做开放注册流程（已有账号的登录收回）

## 复刻提示词

一张 1912 年代电报局的登录卡片：米黄旧纸底、浅色细网格背景，左栏是老式发报机线描插画与品牌「远望电讯」，右栏是纸感表单；主按钮为深青色「发报 · 进入」，错误用朱红信号灯色，收报机区域用等宽字体显示状态；整体直角、虚线分隔、打字机时代的克制与幽默。
