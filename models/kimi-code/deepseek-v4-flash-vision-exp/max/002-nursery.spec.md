## 内容与数据

- 品牌：芽泥 Bai-ny；slogan：起个名字，种下第一株属于你的主页。泥里的事，交给芽泥帮你记、帮你长、帮你开花。
- 三步条：1 起名 / 2 种下 / 3 等待开花
- 字段（各带默认 hint）：园圃昵称*（maxlength 16，提示"最多 16 个字，之后随时可改"）；邮箱*（"用于找回密码，不会公开"）；密码*（"至少 8 位，含字母和数字"）
- 校验规则失效文案：昵称空→「请先给园圃起个名字。」；邮箱不符→「邮箱格式像是少了一片叶子，检查一下。」；密码不足→「密码至少 8 位，且同时包含字母和数字。」
- 协议：《园圃公约》《种子条款》，未勾选→「还需要勾选同意《园圃公约》才能种下账号。」
- 成功 toast：`✓ 账号已创建：欢迎来到芽泥，<昵称>，你的园圃从今天开始发芽。`
- 底部：已经是一盆老苗？去登录
