## 内容与数据

- 顶部：幕间剧场 · 今日夜场
- 剧目：`《雾中来客》`；演出 19:45 开演 · 第五幕；场地 幕间剧场 · 二层包厢；座位 D 排 07 号（凭邀请码入座）
- 说明：本场只对收到邀请函的人开放。请在票根正面输入函面上的六位核验码——验过之后，幕布才拉开。
- 输入提示：六位字符，字母不区分大小写；placeholder 如：MIST07
- 有效码（服务端等效）：`MIST07`、`CURTAIN`、`NIGHT05`、`VALT03`、`WIST15`（不区分大小写、忽略首尾空格）
- 错误文案：6 位以下→「需要六位核验码，您现在输入了 N 位。」；不匹配→「核验码 XX 不对应今晚的场次——请与发函人核对，或重看票根。」
- 成功：印章「已核验」+ 欢迎入场，D 排 07 号。幕布正在升起…
- 底部：没有邀请函？可以在售票处候补，或联系当晚持票人。
