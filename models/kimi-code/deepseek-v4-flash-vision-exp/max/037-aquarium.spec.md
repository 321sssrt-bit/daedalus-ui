## 内容与数据

- 页头：我的鱼缸 / 今日 0 条记录
- 空态：NO.001 空缸 · 待入鱼；「缸还是空的——但水已经养好了」；lead：你还没有记录任何一条鱼。加入第一条之后，喂养提醒、水质变化和生长日记都会从这里开始。
- 行动：+ 添加第一条鱼 / 先随便看看别人的缸
- 切换后：我的鱼缸 1 条；🐠 红绿灯鱼 × 6（入缸 · 今天 14:20）；🌿 水榕 1 盆（已定植 · 第 3 天）
