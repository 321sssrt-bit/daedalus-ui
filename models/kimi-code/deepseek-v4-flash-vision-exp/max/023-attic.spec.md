## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 收藏品卡 item | 3 列；padding 14px 14px 12px；圆角 6px | 奶油渐变底；物件图高 120px；下方名称/来路/脚注行 | 悬停：提升 -3px+阴影加深 |
| 搁下按钮 off | 24×24 圆；右上绝对定位 | 深棕底奶字 ✕ | 点击：item 加 `.gone`（opacity .45、虚线 rust 外框、图灰度、名划线） |
| 放回/搁下切换 take | padding 6px 12px；11px 700；圆角 6px | 透明底 rust 边框 rust 字 | 悬停 rust 实底；点击 toggle off；文案在「放回架上/搁到柜底」间切换 |
| 分类按钮 | padding 9px 18px；13px；圆角 8px | 边框 rgba(232,169,78,.3) 透明底米字 | 悬停琥珀边；`.on` 琥珀实底深字 800；点击过滤（all/老票据/手作/旧书/杂件） |
| 计数 | `.counts` 胶囊 | 收藏 N 件 · 已搁下 N 件 | 随状态实时更新 |
