# 044 社交社区产品

## 设计意图

社区产品的发布失败是最容易被用户当「白写了」的时刻。这里把「城墙根街坊广场」的发布失败包装成「喇叭卡壳了」——一条街坊能理解的错法：错误条明确说「草稿与可见范围都替你留着」，第二次点击即成功且内容置顶绿框标记；可见范围（全场/邻舍/自己留档）作为发布前的显式选择，让「这条给谁看」成为街坊社交的礼貌而非设置项；浏览流只保留最少的点赞/评论元信息，把注意力放在正文上。

## 适用场景与目标用户

适合邻里社区、兴趣小组、班级群等小型熟人社区的动态发布；目标用户是发「今天缺一头蒜」「楼下猫生了」这类小事的街坊——他们不追求传播量，追求「大家看得到+范围可控」；因此发布-反馈-置顶的闭环比点赞数更重要。

## 非目标

- 不做评论展开、点赞数字跳动（静态）
- 不做图片真实上传（占位框）、不做话题标签
- 不做关注关系（所有街坊即全部）

## 复刻提示词

「城墙根 · 街坊广场」社交社区手机页：牛皮米色屏、墙头砖红顶栏「城墙根 · 街坊广场」；动态流三条（枣红马/李婶/修门匠老韩——头像圆、正文、👍💬分享脚注）；点击「+ 说点什么」进入发布：草稿 280 字、「这条说给谁看」三选（全场街坊/左右邻舍/自己留档，默认全场）；第一次点「贴到公告栏」出现砖红错误「× 喇叭卡壳了：那阵风没把公告吹上去，草稿与可见范围都替你留着，再点一次就是」；第二次点击成功「✓ 已贴上公告栏（左右邻舍）」，900ms 后回流，新帖置顶并有草绿描边；像四合院墙根贴的条子，直白、邻里、失败可重贴。
