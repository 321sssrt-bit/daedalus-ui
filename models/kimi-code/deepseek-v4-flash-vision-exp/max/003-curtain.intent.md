# 003 邀请进入

## 意图元数据

- 意图版本：1
- 对应规范：`003-curtain.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「输入邀请码」变成一张真实票据的验票仪式：夜色剧场、金线招牌、带撕线与打孔的票根，让「没有邀请就进不去」的封闭感变成一种被期待的排他体验；错误提示用「不对应今晚的场次」而不是冰冷的「码无效」，保留戏剧性又可理解。

## 适用场景与目标用户

适合私密发布、内测、会员制活动、观影/观演预约等需要准入控制的场景；目标用户是持邀请函的参与者，他们需要清楚地知道「为什么进不去」以及「去哪核对自己手里的码」。

## 非目标

- 不做注册/登录流程（准入即进入，无账号体系）
- 不做自动发送邀请邮件、候补表单的真提交
- 不做二维码扫码验票；金线仅作装饰不承载信息

## 复刻提示词

深夜剧院的验票页面：底色近黑，中央是一张带打孔撕裂边的复古戏票，左半印着剧目《雾中来客》、时间座位与一句「凭邀请码入座」，右半是六位邀请码输入框与金色「验票入场」按钮；错误时票面抖动、红边提示；成功时盖上一枚旋转的绿色「已核验」印章。整体像 1950 年代戏院的票务柜台，排他而优雅。
