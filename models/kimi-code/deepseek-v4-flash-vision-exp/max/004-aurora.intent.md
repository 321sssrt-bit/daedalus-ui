# 004 新手引导

## 意图元数据

- 意图版本：1
- 对应规范：`004-aurora.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「欢迎页+三步引导」装进一座极光观测站的场景里：深蓝雪夜、发光小屋、青绿极光做主色，让第一次打开变成一次「点亮望远镜」的入站仪式。三步叙事不做成产品功能介绍，而是一起完成一件小事的节奏——选择身份、起名字、确认开头，每一步都在积累归属感。

## 适用场景与目标用户

适合个人向、重情绪价值的轻工具（极光预报、星象、天气、记账、日记类）；目标用户是愿意花 60 秒完成配置、喜爱夜空与自然意象的移动端青年用户，也适合作为高端极简产品的 onboarding 基调。

## 非目标

- 不做登录/授权（属于 001/008）、不做多语言、不做调查问卷式长引导
- 不采用霓虹紫蓝渐变或赛博科技感；青绿是唯一亮色
- 不做真实天气/极光数据接口，仅交互演示

## 复刻提示词

一张极光哨站的 onboarding 卡片：深蓝夜空渐变、雪峰与发光小屋的 SVG、青绿极光光带为唯一高亮；左侧垂直三步列表，右侧面板依次为「选择观察模式（巡光员/守夜人）」「给哨站起名」「确认一句话」，底部「上一步 / 下一步」，右上角「跳过引导」胶囊按钮；选中态用青绿描边与微光，完成时按钮文案渐变到「已进入 · 今晚见」；整体克制、安静、像仰望夜空。
