# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-scrap.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

检索页的分寸在于「条件可控、结果可读、回退容易」。这里把筛选做成「旧货行档案检索」：牛皮纸档案本 + 印章绿选中态，左栏货类/新旧/价格区间四组条件（两组单选、一组区间），右侧结果固定按价格升序并实时显示「找到 N 件」；每个筛选选项自带该类的条数徽章，让用户在做选择前就知道这条路的宽度；「清除全部」永远在可见位置，空态不甩锅而是提示放宽区间——把筛选从「惩罚性收窄」变成「安心逛」。

## 适用场景与目标用户

适合二手交易、档案查询、库存盘点类需要「多条件交叉检索」的产品；目标用户是淘货者与库管员——他们用「种类+新旧+价格」组合找目标，且常在不同条件间反复试，因此快速清空与实时计数比任何推荐都重要。

## 非目标

- 不做关键词搜索框（本题为筛选检索）、不做多选并存（单选互斥）
- 不做分页、不做排序切换（固定价格升序）
- 不做现代极简白；牛皮纸+印章绿+砖红是旧货行的全部语汇

## 复刻提示词

「旧货行 · 档案检索」页：牛皮纸底细斜纹，顶部印章「录」与「Y 市旧货市场 · 货品档案 2,108 条」；左栏「收窄你的货」贴纸风格筛选——货类（家具/家电/纸质/杂项，各带计数）、新旧程度（全新/九成新/八成新/品相好/需整修）、价格区间输入与「清除全部条件」；右栏结果区标题「找到 N 件 · 价格从低到高」，每张结果卡是缩略图 emoji、名称、店铺与年份元信息、标签胶囊、砖红价格与成色小字；如同在一家老货行的账房查档，筛选是向导而不是关卡。
