# 017 商店首页

## 意图元数据

- 意图版本：1
- 对应规范：`017-generalstore.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把商店首页从「电商大促」拉到「老街杂货铺」：木板顶棚、红漆招牌、奶油纸货架、手绘货品插画，让「逛店」回到「赶集」的生活感；栏目筛选（山货/日用/手工）与收藏/入袋交互保持电商底线能力，划线价与「掌柜自营·分类」小字保留了老店的诚实定价口吻——没有满天飘的促销，只有一块「今日特价」木牌。

## 适用场景与目标用户

适合地方特产、手作市集、农产品直营等「信任驱动」型电商；目标用户是中老年与城市返乡客——他们看重掌柜口碑、货源真实、价格实在，而不是算法推荐；页面以「铺规」「已营 27 年」等叙事建立信任。

## 非目标

- 不做搜索/排序（保留「从新到旧」提示）、不做移动端 TabBar
- 不做库存角标/评分星星；店铺信任靠文字叙事
- 不采用极简黑白或霓虹促销风；木、纸、红漆是唯一语言

## 复刻提示词

一座「镇口杂货铺」的集市首页：上方是深木板雨棚与红漆招牌「镇口杂货铺 · 山货日用手工老街放心价」，右侧「🛒 布口袋」按钮带件数角标；主区栏目条为「全部货品/山货/日用/手工」黑胶囊、「今日特价」红胶囊；货架四列奶油纸卡，每张卡是手绘 SVG 货品插画、名称、一句描述、红色现价（部分旧价划线）、「掌柜自营 · 分类」小字与叶绿「加入布袋」按钮，卡片右上角有可点收藏心；底部虚线「铺规：满 39 元包邮 · 山区 3 天发货」；像镇上只此一家的老铺，热闹而不廉价。
