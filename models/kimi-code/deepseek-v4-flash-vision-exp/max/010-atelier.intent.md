# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-atelier.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

看板不必是 SaaS 蓝紫模板。这里把「三列状态流转」做了场景化转译：一块时装工作室的样衣纸板，卡片是含布样色块的样片卡，「移到下一列」对应样布阶段→试身中→已定版的真实工序；米纸、石墨、红棕/青绿/草绿三色列头与硬阴影保留了实体看板「钉上去」的触感，同时新建弹层保持表单清晰，不让场景感牺牲可用性。

## 适用场景与目标用户

适合产品设计、服装/家具/材料工作室等以「实体转线上」为主要工作流的团队；目标用户是版师、打样员与项目经理——他们需要按工序推进卡片，且重视「谁在打样」的归属感，因此卡片带打样人头像与筛选。

## 非目标

- 不做拖拽交互（以按钮推进保证全键盘可达）、不做子任务/附件/评论
- 不做卡片泳道（时间维度）或 WIP 限额等精益板约束
- 不采用渐变或玻璃拟态；色彩只用布样语义三色

## 复刻提示词

一间时装工作室的三列看板：米纸底带细网格，板头是「样衣看板 · 秋冬企划」与石墨色「+ 新建样片」按钮、打样人筛选；三列分别为样布阶段（红棕）、试身中（青绿）、已定版（草绿），每张卡片是一块带布样色块的样片卡——名称、面料、打样人圆头像、「移到下一列 →」按钮；底部弹层可填写名称/面料/打样人/放入列；像一块手工钉满布料的软木板，工序感大于数据感。
