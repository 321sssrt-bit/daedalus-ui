## 内容与数据

- 品牌：雾灯 Foglight；顶部说明：灯光在雾里指路，密码在忘了的时候也一样。雾灯局全年 3,500 次帮人点回门前的灯。
- 标题：找回密码；副文：输入注册时留的联系方式，我们寄去一盏新的引路灯。
- 字段 placeholder：you@example.com 或 138 0000 0000
- 校验：空 → alert「请先填写注册邮箱或手机号。」；非邮箱且非 11 位手机（1[3-9] 开头，忽略空格/连字符）→ alert「这个联系方式看起来不像邮箱或手机号，请检查。」
- 等待文案：✉ 引路灯已寄出；30 秒后可重新点亮；30 分钟内没收到？先翻翻垃圾邮件柜。；重发一次
- 已到达文案：✓ 邮件已重新到达；打开邮件里的「重新点亮」，就能设置新密码。
- 返回：想起来了？返回登录
- 倒计时：30s 起，每秒-1，等宽字体显示
