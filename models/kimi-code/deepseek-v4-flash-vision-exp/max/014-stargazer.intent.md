# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-stargazer.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

「搜索无结果」最常见的失败是道歉式空态——「很抱歉没找到」。这里把找不到处理成「望远镜对准了错误编号」：观星台的星表检索采用官方名称+编号编目，一次「改名」就能找到，所以解决方案不是一句抱歉，而是四个「换个叫法」的等价条目（星座名、编号、分类、旧编目），把「失败」变成「改名再试一次」的引导。深紫夜空让空态有情绪但不沮丧。

## 适用场景与目标用户

适合目录型、数据库型产品的检索空态（天文、词书、图鉴、档案）；目标用户是研究者或考据型用户——他们输入的名称与编目系统不对应但目标明确，最需要的不是推荐刷屏，而是指出「编目语言」的差异并给等价词。

## 非目标

- 不做「清空搜索/回到首页」常规按钮（保留品牌自然的 ⌘K 提示）
- 不做相关推荐瀑布流；建议严格对应「等价叫法」
- 不采用纯黑或纯白；夜空紫是唯一底色，星光黄仅作点缀

## 复刻提示词

一张观星台检索空态页：深紫夜空渐变背景中的半透明卡片，顶部紫色辉光球体「观星台 · 星表检索」，搜索框内保留「仙女座星云」，下方一行「星表 4120 条 · 0 条匹配」；空态中心是一支对准空无一星夜空的望远镜插画，标题「望远镜里，什么都没有」，解释里点明该星表按「官方名称+编号+发现者」编目；再下方是四张「换个叫法」建议卡（仙女座 / M31·NGC 224 / 梅西耶天体 / 梅西耶 31），点击即替换检索词；整体如天文台夜晚的值班室，安静、专业、给出路。
