# 023 收藏夹

## 意图元数据

- 意图版本：1
- 对应规范：`023-drawer.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

收藏夹做成中药铺的百宝柜：每件藏品住一屉，纸标签手写名、黄铜拉手，移出像拉开抽屉取走。附「放回去」撤回，删除就不该一惊一乍。取舍是放弃列表效率，换把收藏当物件对待的仪式感。

## 适用场景与目标用户

标本、旧物、模型等实体收藏爱好者的藏品管理页，或阅读/影视收藏夹的拟物化皮肤，用户视藏品为物件而非数据。

## 非目标

- 不做批量管理与多选
- 不用标准网格图片流
- 不提供分享与公开展厅功能

## 复刻提示词

深木百宝柜收藏夹：3 列拟物抽屉卡（标本 SVG + 纸标签 + 年份 + 黄铜拉手），黄铜分类签过滤，悬停显出 ✕ 移出钮，移出弹米纸提示条带「放回去」撤回，头部屉数实时联动。
