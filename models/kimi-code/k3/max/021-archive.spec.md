# 021 内容目录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`021-archive.html`
- 复现范围：独立杂志《档案》内容目录的编辑排版、刊头、篇目列表与点开摘要。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 视口 1280 × 800 px，padding 36px 24px 64px | 报纸最大宽 860px 居中 | 背景 `--news` 报纸米 |
| 刊头 | padding-bottom 18px，margin-bottom 6px | 左右基线对齐：40px 刊名 / 期号注记 | 底部 3px 双线 `--ink` |
| 栏目标尺 | padding 10px 2px | 左右两端小字 | 底部 1px 实线 |
| 篇目列表 | 通宽 | 每篇一条横向 row：栏目 64px / 主栏弹性 / 时长 / 箭头 | 行间 1px `--line`，无卡片 |
| 摘要区 | 默认隐藏，padding 2px 86px 20px | 左侧 3px `--red` 引用条 | 展开时撑起所在条目 |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--news` | `#f4efe2` | 报纸米背景 |
| `--card` | `#faf6ea` | 行悬停底 |
| `--ink` | `#1c1a17` | 墨黑标题、刊头线 |
| `--red` | `#c03a2b` | 编辑红：栏目、摘要引用条 |
| `--muted` | `#7d7466` | 辅助文字 |
| `--line` | `#d9d0ba` | 行间线 |
| `#4a4438` | `#4a4438` | 摘要正文 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 刊名 | `"Songti SC","STSong","SimSun",serif` | 40px / 1 | 900 / .24em |
| 篇名 | 同上 | 18px / 1.5 | 700 / 默认 |
| 正文 | `"PingFang SC","Microsoft YaHei",system-ui,sans-serif` | 15px / 1.75 | 400 / 默认 |
| 辅助文字 | 等宽 + 同正文 | 11–12px / 1.75 | 400 / .14–.2em |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 8px | 行内距 16px、栏距 16px 为其倍数 |
| 控件圆角 | 4px | 仅焦点框，整体保持纸面直角 |
| 容器圆角 | 0 | 编辑排版不用圆角卡 |
| 边框 / 阴影 | 3px `double var(--ink)` 刊头线；无投影 | 纸面感 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 篇目行 | 全宽按钮，padding 16px 6px | 透明底 | 悬停米底；点击展开摘要且箭头转 90° 变红，同时收起其他篇目 |
| 栏目标签 | 固定 64px 宽 | 红色 11px 加粗大写感 | 六种栏目：田野/人物/考据/声音/清单/来信 |
| 摘要块 | 左侧 3px 红条引用 | 默认隐藏 | 展开显示摘要与「进入正文」 |
| 进入正文 | 文字 + 红色下划线 | 红色 12.5px | 悬停转墨黑；点击后变为上架说明 |
| 阅读时长 | 等宽 12px | 右侧灰字 | 不适用 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 860px 报栏居中，摘要缩进 86px | 全部组件如上 |
| ≤ 680px | 刊名缩为 30px，时长列隐藏 | 摘要改为全宽 |

## 内容与数据

- 刊头：《档案》第 47 期 · 处暑号，标注「独立杂志 · 每月一期 · 本期 6 篇」
- 六篇目录，每篇含栏目、宋体篇名、作者（文/摄/采写分工）与阅读时长
- 点开任一篇展开红色引用条摘要与「进入正文」，同一时间只展开一篇
- 页脚固定编辑部地址与纸刊信息

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 行悬停 | .13s ease | 米底淡入 | 即时切换 |
| 摘要展开 | .2s ease（箭头） | 箭头旋转 90° 变红、摘要出现 | 箭头即时定位 |
| 篇目互斥 | 即时 | 展开新篇时收起旧篇 | 不适用 |
