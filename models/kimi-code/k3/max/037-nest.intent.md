# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-nest.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

家庭账本空着不该像出错：巢里一枚蛋，配一句「柴米贵知道，日子才不慌」。主按钮只要求记一笔早饭钱，门槛压到最低；纸质账用户给了拍照导入的退路。取舍是不做空态功能导览，先让第一笔记上。

## 适用场景与目标用户

家庭共享记账、日常开支记录类产品，用户是掌管家用的人，可能从纸质账本迁移而来。

## 非目标

- 不做预算仪表盘与图表教学
- 不用红色赤字焦虑风格
- 不在空态放会员推荐

## 复刻提示词

蛋壳白暖棕的家庭记账空态（390px 手机框）：巢与蛋 SVG 插画 + 「账本还是空的」主说明 + 「记第一笔」胶囊主按钮 + 「拍照导入」虚线次行动，点主按钮弹半层（五类分类胶囊 + 金额输入），记账后空态转列表，底栏四枚。
