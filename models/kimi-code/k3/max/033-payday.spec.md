# 033 钱包首页

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`033-payday.html`
- 复现范围：蓝领钱包「发薪日」首页的余额区、流水列表、转入转出半层、底部导航与宽屏手机框呈现。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 | 全屏应用布局 | 全部组件如上 |
| 宽于 520px（宽屏） | 应用装入居中手机框，带舞台标签 | 框高 `min(844px, 视口高 − 90px)` |
| ≤ 520px | 手机框消失，应用铺满视口 | 圆角与边框取消 |
