# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-study.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

学术笔记的设置页像书房里的皮面账册：深棕侧栏是书脊，设置行像抽屉拉手，点开展详情，开关是黄铜拨杆。身份行用「名章」代替头像。取舍是把设置收敛为三组，学者不需要一面墙的选项。

## 适用场景与目标用户

学术笔记、文献管理、研究工具类产品的账号设置，用户是高校与研究机构的人文学者，偏好安静、可预期、不催促的界面。

## 非目标

- 不做主题换肤与实验室功能开关
- 不用彩色插画与吉祥物
- 不做账号注销的强引导

## 复刻提示词

皮革书房风设置页：224px 深棕左侧栏（4 分组），主区身份行（宋体名章 + 姓名单位 + 更换按钮），三个设置组各含可展开行（表单/设备清单/黄铜开关），保存弹提示条，米纸底、1px 米线。
