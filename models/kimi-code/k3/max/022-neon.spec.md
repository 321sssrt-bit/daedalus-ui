# 022 个人主页

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`022-neon.html`
- 复现范围：音乐人「宋霓」个人主页的霓虹头图区、作品网格、曲目展开与关注/邀约动作。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 视口 1280 × 800 px，`min-height:100vh` | 头图区 + 内容最大宽 1020px 居中 | 背景 `--bg` 暗紫黑 |
| 头图区 | padding 64px 32px 40px | 头像 / 身份 / 操作三段横向 flex，间距 30px | 两团粉紫径向光晕，`overflow:hidden` |
| 作品网格 | 3 列 grid，间距 16px | 卡片含 120px 渐变封面 + 文字区 | `--panel` 底、1px `--line`、圆角 16px |
| 曲目条 | 默认隐藏，margin-top 18px | 标题 + TRACKLIST 注记 + 曲目行 | 粉紫描边卡 |
| 动态区 | margin-top 34px | 圆点时间线纵向列表 | 行间 1px 虚线 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 关注按钮 | 胶囊 padding 12px 34px | 粉紫渐变底 + 光晕 | 点击变描边「已关注」，听众数 86,214→86,215 |
| 演出邀约 | 描边胶囊 padding 10px 34px | 透明底 | 悬停粉边粉字；点击变为经纪邮箱说明 |
| 作品卡 | 120px 渐变封面 + 文字区 | 六张各异色渐变 | 悬停上浮 3px；选中粉边光晕并展开曲目条，再点收起 |
| 曲目条 | 全宽卡，padding 18px 22px | 粉紫描边 | 显示所选唱片曲目与时长 |
| 头像 | 124px 圆环 | 粉紫渐变环 + 宋体「霓」 | 不适用 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 头图三段横排，作品 3 列 | 全部组件如上 |
| ≤ 860px / ≤ 560px | 头图转纵向居中，按钮横排 | 作品 2 列 / 1 列 |

## 内容与数据

- 头图：名字「宋霓 NEON SONG」、身份句「在城市的电流里写歌的人」、三项统计（24 作品 / 131 演出 / 86,214 听众）
- 作品六张：雨站、夜班机、霓虹河口、冷敷、橙线、低频信箱，各带类型年份曲目数
- 点作品展开对应曲目表（曲序、曲名、时长），再点收起
- 动态三条：开票、黑胶、录音进度
- 关注切换计数；演出邀约点击后显示经纪邮箱

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 卡片悬停 | .15s ease | 上浮 3px、粉边 | 即时切换 |
| 关注切换 | .18s ease | 渐变底与描边互换、计数变化 | 即时切换 |
| 曲目展开 | 即时 | 曲目条显隐 | 不适用 |
