## 产品边界

本原型实现：亲友选择、金额与祝福、资金来源选择、核对确认、转账凭证、余额不足拦截与恢复。不包含：实名认证、银行卡管理、红封领取方视角、拆分拼手气玩法。

## 状态地图

- 选人视图（初始）：亲友网格 + 最近往来
- 金额视图：头卡带入收款人；金额 / 祝福 / 来源可改；底部「写好，去核对」
- 核对视图：金额与明细确认；「包出去」触发校验
- 余额不足态（核对视图内警示条）：指明来源可用余额与差额，凭证未生成
- 凭证视图：红封凭证；「再包一个」回选人视图
- 返回：金额/核对视图可经 ← 回上一视图，已填内容保留

## 正常流程

1. 选人视图点「老妈」→ 金额视图，头卡显示收款人
2. 输入 ¥520，祝福选「生日快乐」，来源保持零钱
3. 点「写好，去核对」→ 核对视图显示 ¥520.00、老妈、生日快乐、零钱
4. 点「核对无误，包出去」→ 凭证视图：红封编号、金额、来源与送达时间
5. 点「再包一个」回到选人视图

## 异常触发与恢复

- 触发（可见操作）：来源选「零钱」（可用 ¥2,000），金额输入 3000，走到核对视图点「核对无误，包出去」
- 反馈：转账被阻止，不出凭证；红警示条显示零钱可用 ¥2,000.00 与差额 ¥1,000.00，并给出两条出路（改小金额 / 换储蓄卡）
- 恢复 A：点 ← 回金额视图把金额改为 2000 以下再核对确认 → 成功
- 恢复 B：回金额视图把来源改为「工商银行储蓄卡（尾号 3355）」，再次确认 → 成功生成凭证

## 数据变化

- 选人：收款人写入头卡与核对明细
- 金额 / 祝福 / 来源的每次改动同步到核对视图
- 余额不足拦截时：不生成编号、不扣款、不丢已填内容（金额、祝福、来源原样保留）
- 成功转账：生成红封编号与凭证快照；「再包一个」清空金额、隐藏警示

## 人工验收步骤

正常闭环：
1. 点「外婆」→ 输入 200 → 祝福选「身体健康」→ 来源零钱
2. 「写好，去核对」→ 核对显示 ¥200.00 / 外婆 / 身体健康 / 零钱
3. 「包出去」→ 凭证视图出现红封编号与「外婆 已收下 ¥200.00」

异常恢复：
1. 选「表弟」→ 金额输 3000 → 来源保持零钱
2. 去核对并「包出去」→ 出现余额不足警示（可用 ¥2,000，差 ¥1,000），无凭证
3. 点 ← 返回，把来源改选为储蓄卡 → 再确认 → 成功生成凭证
