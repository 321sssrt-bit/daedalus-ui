# 004 新手引导

## 意图元数据

- 意图版本：1
- 对应规范：`004-atlas.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把三步引导画成一段旅程：进度条是地图上的虚线小路，站点是营地，最后一步的按钮直接叫「开始规划」。地图米与青绿维持手绘舆图纸感。取舍是每步只讲一个动作，宁可少讲也不多字。

## 适用场景与目标用户

旅行规划、行程协作类产品的首次启动引导，用户是有明确出行计划的个人或小团体，需要在 30 秒内理解产品的三个核心动作。

## 非目标

- 不做自动轮播，节奏交给用户
- 不用视频或 Lottie 重型动画，静态 SVG 插画足矣
- 不收集偏好问卷，引导只讲不問

## 复刻提示词

手绘地图风的三步新手引导卡：米色等高线背景上 640px 卡片，顶部虚线路径进度（3 个站点），每步左侧 SVG 插画右侧文案，底部「上一步 / 下一步」胶囊按钮，最后一步变「开始规划」，右上角可跳过，完成态为「行囊已备好」。
