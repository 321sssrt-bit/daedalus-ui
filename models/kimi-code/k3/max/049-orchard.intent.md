# 049 健康习惯产品

## 意图元数据

- 意图版本：1
- 对应规范：`049-orchard.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

健康数据的核心是「算得准、不冤枉人」：合理范围直接印在字段标签上，超范围就标红那一个字段，并且明说「原有进度一步都没动」。苹果绿圆环与「摘苹果」文案给坚持一点甜味。取舍是只做补记链路，不展示传感器的自动记步。

## 适用场景与目标用户

步行、运动、喝水等习惯记录产品的记一笔原型，用户偶尔漏记需要手动补登，最怕补错把数据弄乱。

## 非目标

- 不做心率睡眠等多指标
- 不做社交 PK 与奖章墙
- 不用深色运动风

## 复刻提示词

苹果绿步行健康原型（390px 手机框）：128px SVG 目标圆环（54%）+ 步数信息，7 日趋势柱（今日绿色），补记卡双字段（标签标注合理范围 1–50,000 / 1–600），超范围保存字段标红且进度不动，合法保存后圆环/步数/剩余/今日柱四处重算并给绿提示。
