# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-embassy.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

领事系统的权限页要「庄重可问责」：藏青与金、盾牌、角色编号，每个角色一句话说清责任边界。矩阵逐项可拨，未保存有明确警示。取舍是用角色预设而不是自由组合，权限首先讲制度。

## 适用场景与目标用户

政务、签证、审批类后台的角色权限配置页，使用者为系统管理员，操作低频但高风险，需要清楚的预览与确认。

## 非目标

- 不做按人分配、按组织继承的复杂模型
- 不用多色标签墙表达权限
- 不做权限变更的审批流展示

## 复刻提示词

藏青金色的权限矩阵页：顶栏盾牌品牌 + 金底线，左侧四张角色卡（编号 + 职责说明，选中金左条），右侧三组九项权限行（藏青金珠开关），底部脏状态注记 + 保存按钮（禁用→解禁→下发提示）。
