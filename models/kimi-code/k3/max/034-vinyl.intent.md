# 034 正在播放

## 意图元数据

- 意图版本：1
- 对应规范：`034-vinyl.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

播放页的核心情绪是「针落在胶上」：整屏只有一张转动的唱片，琥珀标签随曲而换，进度条压到最细。暂停即停针。取舍是砍掉歌词与封面卡片轮播，让这一屏只属于这一首歌。

## 适用场景与目标用户

黑胶气质的独立音乐 App、播客单集播放页，用户是愿意为一张专辑坐下来的人。

## 非目标

- 不做歌词滚动与评论流
- 不用流媒体常见的白底卡片风
- 不做均衡器与音效面板

## 复刻提示词

深棕黑胶播放页（390px 手机框）：272px 同心纹唱片（琥珀标签、播放时 6s/圈旋转、减少动态时停转），宋体曲名，细琥珀进度条可点跳，三圆钮（上下曲奶油描边、播放键琥珀实心），三曲轮换重置进度。
