# 026 账单

## 意图元数据

- 意图版本：1
- 对应规范：`026-meter.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

水电账单要让人安心而不是惊喜：工业灰压住版面，警示黄只给关键线，「本期应付、余额、代扣状态」放在最上面一排。取舍是把营销位全部删掉，账单页只回答三个问题：多少钱、什么时候扣、从哪扣。

## 适用场景与目标用户

电力、水务、燃气等公共事业的自助账单页，用户是按月核账的家庭户主，也常需要为报销下载发票。

## 非目标

- 不做用量分析图表与节能建议
- 不用圆角大卡糖果色
- 不在账单页放理财产品导流

## 复刻提示词

工业灰公共事业账单：钢灰顶栏（警示斜纹块 + 户号），四张摘要卡（黄顶线、等宽数字），左侧六期明细表（待缴黄/已缴绿状态、行内发票下载），右侧代扣方式卡（可展开更换三种方式并即时更新），底部提示条反馈。
