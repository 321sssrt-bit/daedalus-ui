## 内容与数据

- 三课：执笔与中锋（已结业）、永字八法（学习中）、间架结构（未开课）
- 讲义：永字八法名实一段，范字「永」楷体大图
- 小试一题：「侧」法指哪一笔；A 横 / B 点（正确）/ C 竖 / D 捺
- 答错：所选项朱底、正确项绿底，朱批给出可订正解释（点与横的辨析 + 指引重读讲义句）
- 订正答对：绿色「订正成功」框，进度 0/1 → 1/1 且进度条走满

## 产品边界

本原型实现：课程目录、讲义阅读、单题作答、结果解释（朱批）、答错订正与通过反馈。不包含：多课题库、书写轨迹识别、作业互评与证书。

## 状态地图

- 讲义作答态（初始）：讲义 + 选项可选，交卷钮待解禁
- 答错批语态：对错着色 + 朱批解释 + 「再答一次」入口，进度不变
- 再答态：选项复位，批语收起
- 订正通过态：绿色订正框，进度 1/1 走满

## 正常流程

1. 读讲义（永字八法名实）
2. 选 B「点画（侧）」→ 交卷
3. 绿色订正框出现，进度走满，第二课通过

## 异常触发与恢复

- 触发（可见操作）：选错误项 A「横画（勒）」点交卷
- 反馈：A 项朱底、正确项 B 绿底；朱批框指出答错并给出可订正的解释（引讲义原文辨析点与横，提示重读「起笔一点定全字精神」）；进度保持 0/1
- 恢复：点「返回题目，再答一次」→ 选项复位 → 改选 B 交卷 → 绿色「订正成功」框，进度 1/1 走满

## 数据变化

- 选择：仅记录当前选中项，交卷钮解禁
- 答错：选项禁用、对错着色、批语出现；进度数据不变
- 再答：全部作答状态复位（选中/着色/批语清空）
- 答对：进度 0/1 → 1/1、进度条 33% → 100%，交卷钮退场

## 人工验收步骤

正常闭环：
1. 选 B → 交卷 → 绿色订正框 + 进度走满

异常恢复：
1. 刷新页面 → 选 A → 交卷 → A 朱底 B 绿底、朱批解释出现、进度仍 0/1
2. 点「返回题目，再答一次」→ 选项复位
3. 选 B → 交卷 → 「订正成功」、进度 1/1、进度条走满
