## 组件规格与状态

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 | 全屏详情布局 | 全部组件如上 |
| 宽于 520px（宽屏） | 应用装入居中手机框 | 框高 `min(844px, 视口高 − 90px)` |
| ≤ 520px | 手机框消失铺满视口 | 布局不变 |

## 内容与数据

- 标题「徽杭古道 · 反穿线」，副题临安 → 绩溪 · 中级难度
- 三项数据：18.5 公里 / 累计爬升 860m / 参考用时（随节奏联动）
- 可调节项：节奏三档（休闲走 9h / 标准走 7.5h / 强驴走 5.5h），各带不同的入山时间与装备建议
- 主体内容：路线说明一段 + 五个途经点及里程
- 收藏 ♡/♥ 切换并弹提示；开始徒步弹起点提示
