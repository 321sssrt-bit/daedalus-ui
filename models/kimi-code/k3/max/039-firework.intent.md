# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-firework.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

抢到票的瞬间值一场小烟花：夜蓝底金粉、宋体「抢 到 了」、副题给一个骄傲的理由。回执信息全部卡片化可核对，取票细节收进展开层不抢戏。取舍是庆祝但不喧宾夺主——编号与席位永远比彩带大。

## 适用场景与目标用户

演出、赛事、火车票等抢购场景的成功回执页，用户刚刚经历高并发抢购，需要立刻确认「抢到了、是哪张、怎么取」。

## 非目标

- 不做分享炫耀海报生成
- 不用白底绿勾的通用成功页
- 不在回执页做搭售与推荐

## 复刻提示词

夜蓝金粉的抢票成功回执（390px 手机框）：金粉闪点 + 金圈对勾 + 宋体「抢到了」，回执卡（金色等宽订单编号横带 + 演出/时间/席位/实付四行），可展开取票详情（取票码示意图 + 须知），吸底金色「完成」按钮点击变「已收入票夹」。
