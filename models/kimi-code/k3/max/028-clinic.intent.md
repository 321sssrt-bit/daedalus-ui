# 028 长表单

## 意图元数据

- 意图版本：1
- 对应规范：`028-clinic.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

带宠物看病的人多有心焦：薄荷绿压住情绪，长表单拆成四节配锚点，随时知道自己在哪。必填星号与行内红提示让返工最少。取舍是草稿只存本机、文案明说，不给隐私添悬念。

## 适用场景与目标用户

宠物医院、社区诊所、体检机构的初诊登记页，用户是抱着宠物单手操作的家长，需要大点击区与清晰进度感。

## 非目标

- 不做医生排班选择器
- 不用冷蓝医院系统风
- 不要求注册账号才能挂号

## 复刻提示词

薄荷绿医护长表单：吸顶栏 + 左侧 188px 分节锚点（滚动监听高亮），右侧四节卡片（就诊信息/宠物档案/主诉病史/联系方式），必填红星、提交校验标红并滚动定位，吸底操作条「保存草稿 / 提交挂号」。
