# 020 定价

## 意图元数据

- 意图版本：1
- 对应规范：`020-greenhouse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

植物监测的定价页也要「有氧气」：浅绿底加三团光斑像温室里的散射光，玻璃卡是温室的玻璃墙。推荐档唯一实心，一眼锁定。取舍是用年付即时折扣替代复杂优惠计算器，一页说清。

## 适用场景与目标用户

物联网种植监测、智慧农业 SaaS 的订阅定价页，用户从阳台花友到庄园主跨度大，需要按规模快速分档。

## 非目标

- 不做用量计算器与功能对比大表
- 不用深色科技风或紫色渐变 SaaS 模板
- 不在页内塞客户案例与媒体报道

## 复刻提示词

浅绿玻璃拟态定价页：三团模糊光斑背景，三档等宽玻璃卡（花房免费 / 温室专业推荐档带绿徽章绿边 / 庄园联系顾问），每档 38px 等宽价格 + ✓/— 权益列表，顶部月/年付胶囊切换即时改价改注记，点击按钮弹对应提示。
