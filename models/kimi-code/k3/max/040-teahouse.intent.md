# 040 等候

## 意图元数据

- 意图版本：1
- 对应规范：`040-teahouse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

排队页就是那张捏在手里的取号票：竹青票头、锯齿撕边、大号码，当前步用琥珀轻轻跳。等待的核心信息只有三个——叫到几号、前面几桌、还要多久。「先逛逛」给等待一个出口。取舍是取消做得轻量但明确，茶肆不强留客。

## 适用场景与目标用户

餐饮、茶饮、热门门店的排队等位页，用户在店附近徘徊，需要 3 秒内读懂还要等多久。

## 非目标

- 不做预点单与会员插队
- 不用进度条百分比（等位不可精确）
- 不做广告位打发时间

## 复刻提示词

竹青米白的等位票页（390px 手机框）：取号票（竹青票头 A42 + 锯齿撕边）+ 当前叫号/前桌数/预计分钟大字，四步步骤条（当前步琥珀脉冲），刷新按钮逐桌推进直到「到你了」横幅，「先逛逛到号叫我」可开关提醒，「过号不等了」取消降透明。
