# 037 列表空态

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`037-nest.html`
- 复现范围：家庭记账「巢」列表空态的插画主说明、去创建主按钮、快捷记账半层与底栏。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 空态插画 | 130 × 110 px 巢与蛋 SVG | 静态 | 首次记账后整区隐藏 |
| 主按钮「记第一笔」 | 胶囊 padding 14px 42px | 暖棕底带光晕 | 点击弹起记账半层 |
| 次行动「拍照导入」 | 文字 + 虚线下划线 | 辅助色 | 点击同样打开记账半层 |
| 分类胶囊 | 五枚横排换行 | 描边 | 选中暖棕底白字 |
| 金额输入 | 等宽 28px | 底部分隔线 | 金额 > 0 时「记到账上」解禁 |
| 账目行 | 全宽白卡 | 图标 + 类别 + 时间 + 金额 | 记账后插入列表顶部 |
| 底栏 | 四等分 | 灰字 | 选中暖棕加粗 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 | 全屏布局 | 全部组件如上 |
| 宽于 520px（宽屏） | 应用装入居中手机框 | 框高 `min(844px, 视口高 − 90px)` |
| ≤ 520px | 手机框消失铺满视口 | 布局不变 |

## 内容与数据

- 空态主说明「账本还是空的」+ 一段日子观文案 + 巢与蛋插画
- 主按钮「记第一笔」，次行动「上个月是纸质账？拍照导入」
- 记账半层：五类分类（默认早饭）+ 金额输入，确认后插入账目行并离开空态
- 底栏：账本 / 盘算 / 家务 / 我的
- 顶行月份「8 月」

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 半层弹起 | .3s ease | 自底部滑入 + 遮罩 | 直接到位 |
| 记账成功 | 即时 | 空态隐藏、账目行出现 | 不适用 |
| 按钮悬停 | .13–.15s ease | 变色 | 即时切换 |
