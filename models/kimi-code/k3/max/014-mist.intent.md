# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-mist.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

「没有结果」被说成「山里雾大」，与产品名空山呼应；原词必须留下，让人确认自己没输错。改搜建议给三条性格不同的路：放宽、换说法、放弃搜索直接逛。取舍是把空态当作导航页来做，而不是一句抱歉。

## 适用场景与目标用户

数字图书馆、档案库、知识管理产品的搜索场景，用户是有明确目标但词不一定准的研究者与读者。

## 非目标

- 不做热门搜索榜与搜索历史
- 不用红色错误样式对待「无结果」
- 不提供站外搜索跳转

## 复刻提示词

冷灰紫雾感搜索空态：居中 560px 舞台，胶囊搜索条里保留原搜索词，宋体标题「山里雾大，没有找到『词』」，三条改搜建议胶囊（放宽词 / 换词 / 看全部），点建议即时切换空态或结果卡，背景两团模糊雾斑缓慢漂移。
