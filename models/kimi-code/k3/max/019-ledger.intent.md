# 019 购物车

## 意图元数据

- 意图版本：1
- 对应规范：`019-ledger.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

文具铺的购物车就是账房先生的一页流水账：牛皮纸桌面、朱砂栏线、宋体抬头，删除叫「划去」，合计用朱砂大字。取舍是把数量、小计、合计做成唯一主角，不做推荐搭售，忠于账本的克制。

## 适用场景与目标用户

文具、茶礼、手作等带熟人客情的小店电商购物车，用户是回头熟客，买得少而精，看重账目清楚。

## 非目标

- 不做优惠券、满减凑单与推荐位
- 不用标准电商的白底蓝按钮风格
- 不提供移入收藏夹，划去就是划去

## 复刻提示词

牛皮纸账本购物车：居中 780px 账册卡（左侧双朱砂栏线、右上旋转印章），五列表格（品名含产地/单价/数量步进/小计/划去），等宽数字，加减即时重算小计与 30px 朱砂合计，划去整行划线并从合计剔除，朱砂「去结算」按钮弹提示条。
