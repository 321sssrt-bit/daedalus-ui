# 003 邀请进入

## 意图元数据

- 意图版本：1
- 对应规范：`003-obsidian.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

邀请制产品的门槛本身就是卖点：深黑、琥珀金与宝石线稿把「核对邀请码」做成开锁仪式。失败反馈明确报剩余次数，制造稀缺而非挫败。取舍是用较高的视觉浓度换神秘感，信息只做一件事。

## 适用场景与目标用户

端到端加密协作、私密社群、内测产品等邀请制场景，用户是持有邀请码的特定访客，单页只服务「核验」这一个动作。

## 非目标

- 不提供注册或登录入口，邀请制之外的用户只能申请
- 不用亮紫渐变、霓虹等常见「科技感」皮肤
- 不做二维码扫码进入

## 复刻提示词

深黑琥珀金的邀请核验窄卡：居中 384px 卡片浮在光晕圆环上，宝石线稿图标，等宽字体邀请码输入自动加短横，琥珀主按钮核验，失败红边抖动并报剩余次数，成功切换绿色开门视图。
