# 030 筛选检索

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`030-library.html`
- 复现范围：古籍「藏书楼」检索页的顶栏检索、四组侧栏筛选、结果计数联动与清除。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 视口 1280 × 800 px，`min-height:100vh` | 顶栏 + 左筛选 + 右结果 | 背景 `--silk` 绢色 |
| 顶栏 | padding 16px 28px | 宋体馆名 + 最大宽 520px 检索条 | `--pine` 深青底 |
| 筛选侧栏 | 固定宽 236px | 四组筛选卡 + 清除按钮 | `--card` 底、1px 边、圆角 10px |
| 结果区 | 弹性占宽 | 计数行 + 书目卡纵向（间距 10px） | 书目卡左 4px 深青边条 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 筛选组 | 标题栏 + 复选行（行高 38px） | 米卡白底 | 行悬停变浅；勾选即过滤并解禁清除钮 |
| 清除按钮 | 全宽描边 padding 10px 0 | 深青字 | 无筛选时禁用；点击复位全部条件 |
| 书目卡 | 通宽，padding 14px 18px | 左深青边条 | 悬停右移 3px 加阴影 |
| 状态标签 | 胶囊 padding 3px 10px | 三色：可借阅绿 / 仅存目红 / 修复中黄 | 随书目数据定色 |
| 结果计数 | 朱砂等宽数字 | 「命中 7 种」 | 筛选或检索即时重算；零结果显示空态提示 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 236px 侧栏 + 弹性结果 | 全部组件如上 |
| ≤ 880px | 筛选转顶部通栏 | 书目卡标签换行 |

## 内容与数据

- 七册书目：宋 2、明 2、清 2、民国 1；版本含刻本/抄本/稿本/石印；藏区江浙/两淮/闽中；状态可借阅 3 / 仅存目 2 / 修复中 2
- 筛选规则：组内或、组间与；检索框按书名包含匹配
- 计数「命中 N 种」随条件即时变化；无结果显示空态并提示放宽条件
- 清除按钮一键复位所有勾选与检索词

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 筛选/检索 | 即时 | 结果列表显隐、计数变化 | 不适用 |
| 书目悬停 | .13s ease | 右移 3px、阴影 | 即时切换 |
| 清除 | 即时 | 条件复位、列表还原 | 不适用 |
