# 036 编辑发布

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`036-postcard.html`
- 复现范围：「明信片」书写页的邮票卡面、标题正文、字数与状态联动、寄出与存草稿。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 称呼输入 | 下划线式，楷体 17px | 无框底线 | 焦点底线变邮戳红 |
| 正文输入 | 横线格 textarea，楷体 16px/2.1 | 米底横线 | 输入实时更新字数与状态 |
| 字数 | 等宽 11.5px | 辅助色 | ≥480 字转邮戳红；上限 500 |
| 状态签 | 描边胶囊 | 「还空着」红字 | 书写中 → 可寄出 → 已收寄 |
| 寄出按钮 | 1.3 份宽 × 48px | 邮戳红底 | 称呼空或正文 <10 字禁用；成功后变「已在路上」并盖邮戳 |
| 存草稿 | 1 份宽 × 48px | 墨边透明底 | 点击弹抽屉提示 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 | 全屏书写布局 | 全部组件如上 |
| 宽于 520px（宽屏） | 应用装入居中手机框 | 框高 `min(844px, 视口高 − 90px)` |
| ≤ 520px | 手机框消失铺满视口 | 布局不变 |

## 内容与数据

- 顶行「写一张 · 寄往成都」+ 状态签
- 称呼占位「致：阿灿」，正文占位两行，落款「—— 清言 于拱宸桥」
- 字数 `N / 500` 实时更新；状态逻辑：空 →「还空着」，有字未达标 →「书写中」，称呼非空且正文 ≥10 字 →「可寄出」
- 寄出后盖圆形收寄邮戳（含日期）、状态变「已收寄」并弹五天到达提示
- 存草稿弹「已夹进抽屉第三格」

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 盖邮戳 | .3s ease | 从 1.4 倍钤下，透明度至 .8 | 直接显示 |
| 输入联动 | 即时 | 字数、状态签、按钮可用性 | 不适用 |
| 提示条 | .28s ease，2.2s 驻留 | 底部上浮 | 直接显示 |

## 复现验收清单

- [ ] 宽屏下应用位于 390px 手机框内，卡面带虚线邮票边与右上蓝色邮票
- [ ] 正文为楷体横线格，输入时字数 `N / 500` 实时更新
- [ ] 状态签随输入在「还空着 / 书写中 / 可寄出」间变化
- [ ] 称呼为空或正文不足 10 字时寄出按钮禁用
- [ ] 点寄出后出现圆形收寄邮戳，按钮变「已在路上」
- [ ] 点「夹进抽屉」弹存草稿提示
- [ ] 系统开启减少动态后邮戳直接显示
