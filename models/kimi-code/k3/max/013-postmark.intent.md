# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-postmark.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把收信这件事还给邮局：奶油纸面、靛蓝栏架、邮戳红点点在未读旁边，阅读区盖一枚旋转的验收章。归档叫「放进木抽屉」。取舍是用三栏经典骨架承载复古皮肤，效率与情绪各半。

## 适用场景与目标用户

书信式慢邮件、编辑部稿约信箱、个人写作社区的信件功能，用户是重视文字往来质感的写作者与编辑。

## 非目标

- 不做会话串、快捷回复与富文本撰写
- 不用 Gmail 式冷灰蓝企业皮肤
- 不做垃圾邮件拦截等运营功能展示

## 复刻提示词

复古邮局三栏收件箱：靛蓝顶栏带邮戳圆章，左侧分类栏（收件箱/星标/已归档含计数），中间列表（未读红点加粗、过滤胶囊、☆/★ 切换），右侧阅读区有旋转邮戳章 + 宋体标题 + 「归档这封信」，奶油纸色、栏间 1px 米线。
