# 001 登录

## 意图元数据

- 意图版本：1
- 对应规范：`001-inkwell.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把登录做成「回书房」而不是「过闸机」：左侧深墨蓝书房区用印章和竖排诗句建立写作者的身份认同，右侧暖纸表单只留最少字段。取舍是牺牲品牌区在窄屏的曝光，换桌面端的仪式感。

## 适用场景与目标用户

中文长文写作、笔记或文学社区类产品，用户以已有账号的回归作者为主，登录频率低但停留时间长，适合带情绪价值的入场页。

## 非目标

- 不做第三方社交登录与扫码登录，保持书房独处的安静感
- 不用玻璃拟态、渐变紫蓝等 SaaS 常见皮肤
- 窄屏直接隐藏品牌区，不做缩略版插画

## 复刻提示词

文人书房气质的登录页：左 44% 深墨蓝品牌区（朱砂印章 + 竖排诗句 + 金色点缀），右侧暖纸色登录卡（宋体标题、密码/验证码双标签、朱砂主按钮、错误抖动提示），系统字体单文件实现。
