# 017 商店首页

## 意图元数据

- 意图版本：1
- 对应规范：`017-market.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

生鲜电商的信任来自「市集感」：奶白底像摊位上的牛皮纸，每件货写明谁家种的、几点摘的，价格是暖橙色粉笔字的感觉。取舍是首页不放搜索和广告轮播，先让人逛起来。

## 适用场景与目标用户

社区生鲜、农夫市集、同城当日达类产品，用户是每天买菜的街坊，决策快、认摊位、看重产地与新鲜度。

## 非目标

- 不做轮播广告位与秒杀倒计时
- 不用冷蓝科技风或黑底轻奢风
- 不展示跨城物流商品，只做本地当日

## 复刻提示词

暖橙奶白的市集商店首页：吸顶栏含店名「早市」+ 六个栏目胶囊 + 菜篮子角标，橙黄渐变特惠横幅，4 列货品卡（SVG 食材图 + 产地 + 橙色价格 + 加购按钮，加购变绿「已加 ✓」并弹提示），栏目点击过滤网格。
