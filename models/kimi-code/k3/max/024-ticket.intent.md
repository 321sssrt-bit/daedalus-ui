# 024 结账

## 意图元数据

- 意图版本：1
- 对应规范：`024-ticket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

付款页做成一张真票：砖红头带、撕线副券、半圆缺口，付完当场盖「已出票」章——钱花出去的瞬间就拿到了东西。取舍是把订单摘要完全票券化，少一张冰冷的明细表。

## 适用场景与目标用户

演出、电影、展览等票务产品的结账页，用户购票决策已做完，需要的是确定性：座位、时间、金额一眼可核对。

## 非目标

- 不做优惠码、发票信息等多步骤表单
- 不用标准电商结算的灰蓝风格
- 不支持票面定制与选座图

## 复刻提示词

撕线票券结账页：左栏米白票券（砖红头带演出名、三行明细、砖红 34px 合计、虚线撕线 + 半圆缺口副券含票号场次），右栏 340px 支付面板（三种支付方式卡可选中、26px 应付、砖红确认按钮），支付成功票面盖绿色旋转「已出票」章，头部有保留倒计时。
