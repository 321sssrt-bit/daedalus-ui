# 042 钱包支付产品

## 意图元数据

- 意图版本：1
- 对应规范：`042-redpacket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

亲友转账做成包红封：宫墙红要克制，只在头卡、主按钮和凭证上用足；金额大、祝福可选、来源可换。余额不足不甩错误码，直接说还差多少、怎么补救。取舍是把「喜庆」装进凭证一刻，过程保持清爽。

## 适用场景与目标用户

亲友间转账、节日红封场景的原型，用户覆盖长辈，需要大字、明确的来源选择与可理解的异常说明。

## 非目标

- 不做拼手气与群红封
- 不用紫色金融科技风
- 不做账单统计与社交排行

## 复刻提示词

宫墙红金的红封转账原型（390px 手机框）：选人网格 → 金额视图（红头卡、38px 金额、祝福胶囊、零钱/储蓄卡来源行带余额）→ 核对卡 → 确认校验（超额出红警示条显示可用余额与差额，可改金额或换来源）→ 金框红凭证（福字 + 编号）。
