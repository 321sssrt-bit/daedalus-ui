# 038 故障

## 意图元数据

- 意图版本：1
- 对应规范：`038-roadwork.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

导航报错就该长成一块施工牌：黄黑斜纹夹住屏幕，第一句先说人话、先免责（不是你的问题），再给工单号与绕行希望。取舍是重试一次就能绕开，不把用户困在故障里反复戳。

## 适用场景与目标用户

导航、配送、出行类产品的路况异常页，用户在车里或路边，单手操作、情绪急，需要大字与确定答复。

## 非目标

- 不做技术错误码堆叠（404/500 式）
- 不用红色错误弹窗
- 不提供在线客服长流程

## 复刻提示词

黄黑施工牌风导航故障页（390px 手机框）：上下警示斜纹条，三角黄底施工牌 SVG，人话说明（路段 + 不是你的问题 + 已接单），工单号卡可复制，黑底黄字「重新算一条路」重试后出现绿色绕行结果卡，描边「回首页」。
