## 内容与数据

- 预览图「巷口修表铺 · 黄昏」，文件名注记随色彩模式变化
- 参数：曝光 ±1.0、对比 0.80–1.40、暖调 0–40；图层：胶片颗粒、暗角
- 导出格式：JPEG / TIFF / 银盐相纸（实体）；尺寸：6 寸 / A4 / 方 8 寸
- 冲突规则：银盐相纸仅支持黑白影像；彩色 + 银盐 → 拦截
- 结果卡：文件名（暗房-编号.后缀）、规格（格式 · 尺寸 · 色彩）、体积（按格式区分）

## 产品边界

本原型实现：参数与图层编辑、实时预览、导出格式与尺寸选择、导出结果回执、冲突组合拦截与恢复。不包含：真实图像文件处理、多图批处理、历史版本与预设保存。

## 状态地图

- 编辑态（初始）：预览 + 参数可调，全部改动实时可见
- 导出选择态：格式与尺寸下拉
- 冲突拦截态：红色冲突条（指出银盐 × 彩色），不产生结果
- 冲洗中态：按钮禁用约 1.2s
- 完成态：绿色结果卡（文件名 / 规格 / 体积），可改参数再导

## 正常流程

1. 拖曝光到 +0.6、对比到 1.20，预览实时变亮变硬
2. 关掉「胶片颗粒」图层芯片，颗粒消失
3. 格式选 JPEG、尺寸 A4
4. 点「开始导出」→ 冲洗中 1.2s → 绿色结果卡：暗房-巷口修表铺-0XXX.jpeg · A4 · 彩色 · 8.2 MB

## 异常触发与恢复

- 触发（可见操作）：保持彩色模式，把格式选为「银盐相纸（实体）」，点「开始导出」
- 反馈：导出被阻止，不出现结果卡；红色冲突条写明「银盐相纸只承接黑白影像」，并给出两条路（切黑白 / 改用数字格式）
- 恢复 A：把「影像色彩」切到黑白，再导出 → 成功（规格显示黑白）
- 恢复 B：把格式改回 JPEG 或 TIFF，再导出 → 成功（规格显示彩色）

## 数据变化

- 参数/图层/色彩：实时作用于预览滤镜与叠加层，文件名注记同步
- 冲突拦截：不产生文件、不显示结果卡，全部编辑状态保留
- 成功导出：生成结果快照（文件名/规格/体积），编辑状态可继续调整再次导出
- 切换格式或色彩时冲突条自动收起

## 人工验收步骤

正常闭环：
1. 调暖调到 +30 → 预览转暖
2. 格式 TIFF、尺寸 6 寸 → 导出 → 结果卡显示 TIFF · 6 寸 · 彩色 · 48.6 MB

异常恢复：
1. 色彩保持彩色，格式选银盐相纸 → 导出 → 红色冲突条出现，无结果
2. 点「黑白」→ 再导出 → 结果卡显示 银盐相纸 · 黑白
