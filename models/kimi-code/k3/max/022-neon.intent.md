# 022 个人主页

## 意图元数据

- 意图版本：1
- 对应规范：`022-neon.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

音乐人主页就是一张演出海报：暗场、粉紫追光、渐变圆环头像，作品封面敢用撞色。点唱片出曲目像翻开内页。取舍是把社交功能压到只剩关注与邀约，主页首先是海报，其次才是入口。

## 适用场景与目标用户

独立音乐人、乐队、脱口秀演员等表演者的对外主页，访客是乐迷与演出主办方，需要快速判断风格与档期状态。

## 非目标

- 不做播放器与在线试听进度条
- 不用白底简约设计师作品集风
- 不放电商周边售卖模块

## 复刻提示词

暗底粉紫霓虹的音乐人主页：头图区光晕 + 渐变圆环头像 + 名字/身份句/三项统计 + 渐变关注按钮（可切换已关注并改计数），3 列渐变封面作品网格，点卡展开曲目条，下方圆点时间线动态三条。
