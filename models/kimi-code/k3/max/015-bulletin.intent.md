# 015 通知中心

## 意图元数据

- 意图版本：1
- 对应规范：`015-bulletin.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

通知中心做成教学楼里那块真布告栏：软木底、黄便签、红图钉，未读的就是「新钉上去的」。点开便签即展开全文，动作与真实看栏一致。取舍是放弃严肃的通知列表表格，用拼贴换校园感与扫读趣味。

## 适用场景与目标用户

学校、园区、社区公告场景，用户是学生与教职工，每天路过式地扫一眼，需要快速分辨「哪张是新钉的」。

## 非目标

- 不做通知发布后台与审批流
- 不用企业 IM 的会话式通知样式
- 不做已读回执与@提及

## 复刻提示词

软木布告栏通知中心：棕色颗粒板背景上 2 列黄色便签微旋转拼贴，红图钉 + 四色类型标签 + NEW 角标表未读，点开便签展开全文转已读，右侧米纸面板含类型筛选（带计数）、34px 未读大数字、「全部标为已读」胶囊按钮。
