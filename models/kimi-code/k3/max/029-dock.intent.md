# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-dock.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

码头单证是重活：钢青是龙门吊的颜色，安全橙只给「开始处理」和进度。队列把每份单证的状态说清楚——待处理、解析中、已归档，处理中不许误删。取舍是放弃花哨的拖拽动效，换状态机的确定感。

## 适用场景与目标用户

港口、货代、报关行的单证批量上传页，用户是单证员，一次传一摞，最怕传完没下文或传错撤不回。

## 非目标

- 不做断点续传与秒传的技术展示
- 不用云盘的轻快蓝白风
- 不做在线预览单证内容

## 复刻提示词

钢青安全橙的单证上传：虚线拖放区（悬停变橙），下方待处理队列行（图标 + 名称 + 等宽大小 + 状态 + 进度条 + 删除钮），安全橙「开始处理」逐份推进状态（待处理/解析中/已归档），头部计数联动，底部提示条。
