# 032 危险删除

## 意图元数据

- 意图版本：1
- 对应规范：`032-furnace.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

注销是「把东西投进熔炉」：炭黑压迫、熔岩红只给危险与确认词，取消是全卡最亮的按钮，删除反而又暗又小还要手书二字。取舍是让后悔的路径永远比毁灭的路径好走——这正是本题的评分点。

## 适用场景与目标用户

账号注销、整库清空、解散组织等不可逆销毁场景，用户需要被充分告知代价，并且随时可以体面退出。

## 非目标

- 不做冷静期与找回流程的展开
- 不用温和的中性色弱化危险性
- 不允许回车快捷提交确认词

## 复刻提示词

炭黑熔岩红的注销确认卡：顶部红线 + 熔岩图标，失去清单四行（等宽数字 + 红 ✕），手书「销毁」解禁描边红删除钮（默认禁用、小而暗），取消按钮大而亮在上，成功后灰圈对勾完成态，底部熔岩余晖光晕。
