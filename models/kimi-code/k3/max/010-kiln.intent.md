# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-kiln.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把看板从软件园拉回工坊：列名是真实工序，列头写着窑温与湿度，卡片像用胶带钉在木板上的工单。移动就是「送往下一道工序」。取舍是放弃拖拽的精确手势，用明确的工序按钮换取触达稳定。

## 适用场景与目标用户

手作工坊、小型制造、课程工作室的生产流转看板，用户是工坊主与驻场作者，每天围绕几件实体作品推进工序。

## 非目标

- 不做多人头像、评论、附件等协作套件
- 不用 SaaS 常见的灰蓝冷色看板皮肤
- 不引入拖拽排序，列内顺序按进入先后

## 复刻提示词

陶艺工坊三列看板：米白底，三列「拉坯 / 修坯上釉 / 入窑烧制」各带窑房环境注记与计数，作品卡有胶带条、釉色标签和「上一 / 下一工序」移动按钮，陶土赤「新建一件坯」在首列开虚线表单，卡片可选中。
