## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 唱片 | 272px 圆，同心纹 | 静态 | 播放时 6s/圈旋转；暂停即停 |
| 播放键 | 68px 圆 | 琥珀底深棕图标 | 点击切播放/暂停图标并控唱片转停 |
| 上/下曲 | 52px 圆 | 奶油描边图标 | 点击换曲：曲名、标签、时长、进度全部重置 |
| 进度条 | 全宽 × 5px | 深棕槽琥珀条 | 每秒推进；点击跳转到对应位置 |
| 时间 | 等宽 11px 两端 | 当前 / 总长 | 随进度推进 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 390 × 844 | 全屏播放布局 | 全部组件如上 |
| 宽于 520px（宽屏） | 应用装入居中手机框 | 框高 `min(844px, 视口高 − 90px)` |
| ≤ 520px | 手机框消失铺满视口 | 唱片区弹性居中 |

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |

## 复现验收清单

- [ ] 宽屏下应用位于 390px 手机框内，深棕底中央 272px 黑胶唱片
- [ ] 初始唱片匀速旋转，进度从 1:21 每秒推进
- [ ] 点播放键：唱片停转、图标变播放三角；再点恢复
- [ ] 点下一首：曲名变「末班环线」、唱片标签与时长同步、进度归零
- [ ] 点进度条中部，时间跳到约半程
- [ ] 窗口缩到 520px 以下手机框消失
- [ ] 系统开启减少动态后唱片不转但播放计时仍走
