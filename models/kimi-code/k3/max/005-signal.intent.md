# 005 找回密码

## 意图元数据

- 意图版本：1
- 对应规范：`005-signal.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

找回密码在运维产品里是一次「值班事故处理」：等宽字体标签、工单号、雷达与倒计时把流程仪表化，橙色只给关键动作。取舍是牺牲亲和力，换专业场景下的确定性与可核对感。

## 适用场景与目标用户

运维监控、告警值班、工程控制台类产品，用户是轮班工程师，常在高压、低耐心状态下使用，需要每一步都有明确编号与状态反馈。

## 非目标

- 不做安全问题、人工客服等冗长核验分支
- 不用圆角大卡与插画等 C 端亲和元素
- 不提供第三方账号找回

## 复刻提示词

工程仪表风的找回密码页：深灰蓝底 + 顶部状态栏（品牌与绿色探针），中央 404px 卡片带等宽字体工单头，单个联系方式输入 + 信号橙主按钮，提交后切等待态——雷达图、40px 倒计时大数字、脱敏联系方式、60 秒后可重发，两个视图均有返回登录。
