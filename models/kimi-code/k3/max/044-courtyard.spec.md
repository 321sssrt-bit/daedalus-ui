## 内容与数据

- 预置四条邻里动态（带范围签：全院子 / 仅本楼），各有头像、楼栋、时间与点赞评论数
- 编辑器：正文（≥2 字可发）+ 可见范围三选（全院子 / 仅本楼 / 仅邻居组）
- 发布成功后新动态插入流顶（标识「刚刚」与所选范围）
- 演练开关打开时发布必失败：草稿条出现在流顶，内容与范围完整保留

## 产品边界

本原型实现：动态浏览、文字动态编辑、可见范围选择、发布入流、发布失败草稿保留与重发。不包含：图片/视频发布、评论楼中楼、私信与推荐算法流。

## 状态地图

- 动态流（初始）：四条动态 + 悬浮「写一条」
- 编辑半层：正文 + 范围 + 演练开关 + 发布钮
- 失败草稿态：流顶草稿条（预览 + 范围 + 两个出口），原动态流不变
- 恢复态：重发成功，新卡入流顶，草稿条消失

## 正常流程

1. 点「写一条」弹起半层
2. 输入「今晚七点院里有露天电影，自带小马扎」
3. 范围选「全院子」（或仅本楼 / 仅邻居组）
4. 点「发到院子里」→ 半层收起，新动态出现在流顶，标识「刚刚」与范围签
5. 底部提示「已发到院子里（全院子）」

## 异常触发与恢复

- 触发（可见操作）：在半层打开「发布演练」开关（红色），再点发布
- 反馈：半层内出现失败说明；半层收起后流顶出现草稿条，完整保留正文与所选范围，并说明「没发出去」
- 恢复 A：点草稿条「再发一次」→ 演练自动解除，动态入流顶
- 恢复 B：点「接着改」→ 半层重开，正文与范围原样，可修改后正常发布

## 数据变化

- 发布成功：新动态插入流顶，点赞评论从 0 起计；输入框清空
- 发布失败：不产生动态卡；正文与范围写入草稿条，原流不动
- 重发/续编：草稿数据原样回灌；成功入流后草稿清空
- 点赞：仅本地数字 ±1

## 人工验收步骤

正常闭环：
1. 「写一条」→ 输入「桂花开了，晨练走东线」→ 范围选「仅本楼」
2. 发布 → 流顶出现该条，范围签「仅本楼」

异常恢复：
1. 「写一条」→ 输入任意正文 → 范围选「仅邻居组」→ 打开「发布演练」→ 发布
2. 看到流顶草稿条：内容预览 + 「仅邻居组 · 未发出」
3. 点「接着改」确认正文与范围原样保留 → 收起
4. 点「再发一次」→ 动态入流顶、草稿条消失
