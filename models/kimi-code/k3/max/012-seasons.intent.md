# 012 日历

## 意图元数据

- 意图版本：1
- 对应规范：`012-seasons.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

茶园的时间不是日程表，是节候：宣纸底、黛绿字、节气用朱砂标出，事件条像插在格子里的小旗。详情栏叫「茶园记事」，没有安排的日子写「茶树照常生长」。取舍是牺牲时间轴精度，换农时的一目了然。

## 适用场景与目标用户

茶庄园、农场、民宿等跟随节气运转的经营主体，用户是园主与管家，关心的是这个月地里要做什么、哪天有客人来。

## 非目标

- 不做周视图、日视图与拖拽改期
- 不用互联网日历的冷蓝商务风
- 不接入外部日历订阅

## 复刻提示词

宣纸黛绿的农历茶园日历：7 列月格每格含公历数字 + 农历小字（节气朱砂加粗），事件以茶绿/朱砂小条嵌在格内，右侧 292px「茶园记事」详情卡联动，宋体月份标题 + 上下月切换，今天用朱砂内描边标出。
