# 045 音视频平台

## 意图元数据

- 意图版本：1
- 对应规范：`045-cinema.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把流媒体做成老放映厅：影院黑、票根黄、片名字卡加胶片颗粒，断网不叫「加载失败」而叫「放映暂停，胶片没丢」。进度保留是放映员的承诺。取舍是用字卡代替视频画面，把注意力集中在播放状态机本身。

## 适用场景与目标用户

怀旧影视频道、资料馆点播、慢直播间的播放原型，用户愿意一晚看一部老片子。

## 非目标

- 不做弹幕、打赏与连麦
- 不用短视频的上下滑信息流
- 不做倍速与清晰度矩阵

## 复刻提示词

影院黑票根黄的放映厅原型：左 2 列渐变海报片单，右 16:8 银幕（片名字卡 + 颗粒纹），控制行（黄色播放圆钮 + 可点进度条 + 时间码 + 网络开关），状态行实时报片名进度，断网浮层保进度、重连后续播，队列行可换片。
