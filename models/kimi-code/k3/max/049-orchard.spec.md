## 内容与数据

- 初始：今日已走 4,320 步 / 目标 8,000（54%），剩余 3,680 步
- 趋势：近 7 天柱条，今日柱为当前达成率
- 补记字段：步数（合理范围 1–50,000）、时长（1–600 分钟），范围直接标在字段标签上
- 无效保存：定位标红错误字段 + 红提示「原有进度一步都没动」；合法保存：绿提示 + 圆环/步数/剩余/今日柱重算

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 进度重算 | .3s ease（柱高） | 圆环弧长、百分比、今日柱联动 | 即时到位 |
| 校验失败 | 即时 | 字段红边 + 行内提示 + 红提示条 | 不适用 |
| 按钮悬停 | .14s ease | 变深绿 | 即时切换 |

## 产品边界

本原型实现：活动数据补记、合理范围校验、目标进度与趋势重算、无效数据拦截与恢复。不包含：传感器自动记步、睡眠/心率模块、社交排行与奖章系统。

## 状态地图

- 今日总览态（初始）：圆环 + 趋势 + 补记卡
- 校验失败态：错误字段标红 + 红提示条，进度数据不变
- 保存成功态：绿提示条，圆环/步数/剩余/今日柱四处重算
- 达成态：步数 ≥ 目标时圆环中心显示「达成」

## 正常流程

1. 在补记卡输入步数 2400、时长 35
2. 点「存进今天」
3. 绿提示「已补记 2,400 步 / 35 分钟」
4. 圆环从 54% 升到 84%，今日已走变 6,720，剩余变 1,280，今日趋势柱升高

## 异常触发与恢复

- 触发（可见操作）：步数字段（标签明确标注 1–50,000）输入 99999，点「存进今天」
- 反馈：步数字段红边 + 行内提示「先不改你的进度」，红提示条说明进度未动；圆环、步数、趋势全部保持原值
- 恢复：把步数改回范围内（如 2400）再保存 → 字段恢复、绿提示出现、进度与趋势重算

## 数据变化

- 合法保存：steps += 输入值；圆环 dashoffset、百分比、今日步数、剩余步数、今日柱高同步重算；输入框清空
- 非法保存：steps 与全部视图数据不变；仅字段与提示条进入错误态
- 修正再存：错误态清除，正常写入

## 人工验收步骤

正常闭环：
1. 输入 2400 / 35 → 存进今天 → 看到 54% → 84% 的重算与绿提示

异常恢复：
1. 输入 99999 / 35 → 保存 → 步数字段红边、红提示条，圆环仍 54%
2. 改输 2400 → 保存 → 红态清除，圆环升至 84%
