# 011 数据看板

## 意图元数据

- 意图版本：1
- 对应规范：`011-pulse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

运动数据要看「势」不看「美」：深空灰压住屏幕，荧光绿只给当前值与选中态，像夜跑时手表上唯一亮着的东西。周/月切换回答不同问题——周看执行，月看趋势。取舍是放弃渐变面积图，用可点柱子换一个明确的读数动作。

## 适用场景与目标用户

跑步、骑行、铁三等耐力运动训练产品，用户是有训练计划的严肃爱好者，每周复盘负荷与心率分布。

## 非目标

- 不做社交动态、排行榜等社区模块
- 不用白底糖果色健身 App 风
- 不堆心率变异性等进阶指标，保持一屏一主题

## 复刻提示词

深色运动仪表盘：顶栏带荧光绿脉搏点，四个等宽大数字统计卡，8 列训练负荷柱状图（周/月分段切换、柱子可点击出读数），4 列侧栏为五色心率区间条与最近训练列表，全程等宽数字字体。
