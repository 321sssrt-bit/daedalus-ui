# 006 二次验证

## 意图元数据

- 意图版本：1
- 对应规范：`006-vault.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

大额交易的二次验证要让人感到「厚重」而不是「麻烦」：深绿绒面、黄铜厚边框与宋体大字距模拟金库门的分量；逐格码输入给明确的物理反馈。取舍是强化庄重感，弱化跳转出口——安全场景不该轻易离开。

## 适用场景与目标用户

银行、证券、企业财务等资金类产品的关键操作核验，用户是进行大额转账或高危变更的账户持有人，需要明确的尝试次数与锁定后果。

## 非目标

- 不提供人脸、指纹等生物核验分支的展示
- 不用轻快浅色与圆角亲和风格
- 锁定后不提供自助解锁，只给人工专线

## 复刻提示词

金库风二次验证：深绿绒面背景上 420px 厚黄铜边框卡片，宋体「金库复核」标题，6 格等宽字体复核码（自动前进、可粘贴），黄铜「开库」主按钮未满禁用，45 秒重发倒计时，三次失败切红色锁定视图。
