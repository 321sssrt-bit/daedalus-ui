# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-lantern.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限请求最怕被当成打扰，所以让「允许」立刻有回报：按钮一按，夜市的灯当场亮起来。底部浮层用对话口吻先讲收益再讲边界。取舍是给婉拒也设计了体面的退路（手动搜索），换长期信任。

## 适用场景与目标用户

本地生活、导览、出行类需要系统权限的产品，首次关键功能前的授权询问；用户对隐私敏感，需要知道给了什么、换来什么。

## 非目标

- 不做系统级权限弹窗的像素复刻，这是产品内的前置说明层
- 不强制授权才能使用，保留无权限路径
- 不用全屏盖脸式打断

## 复刻提示词

夜市氛围的权限请求：夜蓝 SVG 场景（灯笼串 + 建筑剪影）上方叠 560px 暖纸底部浮层，图标 + 「要位置权限、为什么」对话式说明，三个选择（红色主按钮允许 / 描边仅这一次 / 文字婉拒），允许后场景摊位灯光渐亮并显示「三条夜市已点亮」，婉拒给手动搜索退路，结果可重新选择。
