# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-sprout.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

注册被包装成「播种」：按钮叫「浇水，发芽」，提交成功叫「发芽成功」。圆润卡片、嫩绿与三段强度计都服务于轻快、低门槛的气质。取舍是把条款与安全说明压到最轻，换首次转化的顺畅。

## 适用场景与目标用户

面向个人用户的生活记录类产品（植物养护、习惯养成、手账），新用户以移动端年龄偏轻的群体为主，注册动机弱、需要即时反馈鼓励。

## 非目标

- 不做分步注册向导，一屏完成
- 不用深色或高对比商务配色
- 不展示第三方登录按钮与图形验证码

## 复刻提示词

嫩绿圆润的注册单卡：白卡 24px 圆角浮在淡绿光斑背景上，顶部嫩芽 SVG 徽章，三个字段 + 三段密码强度计 + 协议勾选，胶囊主按钮条件不满足时禁用，提交后整卡切换为「发芽成功」。
