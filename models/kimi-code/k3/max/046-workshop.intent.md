- 意图版本：1

## 设计意图

车间协作的信任来自「记清楚」：机油蓝灰是工装色，安全黄只给当前动作；顶栏先把你的身份与权限边界写明。受限工单不是死胡同——拒绝区说清缺什么、保证没写入，再给申请与返回两条正路。取舍是把权限模型简化成「本班可动 / 设备科受限」一眼可见。

## 适用场景与目标用户

制造车间、设备运维、工程班组的工单协作原型，用户是班组长，混用触屏与键鼠，需要明确的状态机与可追溯记录。

## 非目标

- 不做甘特图与排产
- 不用互联网项目的紫色协作风
- 不做跨部门权限的完整配置后台

## 复刻提示词

机油蓝灰安全黄的工单协作原型：三列（工单列表带受限徽章 / 详情含四态步进器 + 分派下拉 + 推进钮 / 活动记录倒序），新建内嵌表单，受限工单点推进展开红色拒绝区（缺权限说明 + 不写入 + 申请权限/返回出口），正常动作全部实时写记录。
