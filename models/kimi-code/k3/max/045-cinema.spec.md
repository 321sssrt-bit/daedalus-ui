# 045 音视频平台

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`045-cinema.html`

## 内容与数据

- 片单六部老电影（年代 + 时长），放映队列四部
- 银幕片名字卡 + 胶片颗粒纹；控制行：播放/暂停、进度、时间码、网络开关
- 状态行实时显示「正在放映 / 暂停 / 网络中断 ·《片名》停在 mm:ss」
- 中断浮层写明保留的进度值，重连后从该进度继续走秒

## 复现验收清单

## 产品边界

本原型实现：片单发现、模拟播放（进度走秒）、进度跳转、队列换片、播放状态展示、网络中断保进度与恢复续播。不包含：真实视频流、弹幕、清晰度切换与下载。

## 状态地图

- 浏览态（初始）：左片单右银幕，首部载入、暂停在 00:00
- 放映态：进度走秒，状态行实时更新
- 队列换片态：片名/时长/选中联动，进度归零
- 断网态：银幕浮层 + 保留进度，播放定格（可重连）
- 恢复态：浮层收起，从保留进度继续放映

## 正常流程

1. 初始载入《城南旧事》，点播放键开始放映
2. 进度条与时间码每秒推进，状态行同步「正在放映」
3. 点进度条跳到约 45:30；状态行同步
4. 点队列「庐山恋」换片：片名字卡更换、进度归零
5. 全程状态行显示当前片名与进度

## 异常触发与恢复

- 触发（可见操作）：放映中点控制行右侧「网络」开关（绿转灰）
- 反馈：播放立刻定格，银幕覆盖深色浮层「网络中断，放映暂停」，等宽字体显示保留进度（如 00:47），状态行转「网络中断」
- 恢复：点浮层「重新连接」（或再拨网络开关）→ 浮层收起，从保留的 00:47 继续走秒，不丢进度、不回零

## 数据变化

- 播放：pos 每秒 +1，进度条与时间码同步；到片尾自动载入队列下一部
- 跳转：pos 按点击比例改写
- 断网：pos 冻结并写入浮层「kept」；期间播放键无效
- 恢复：pos 从冻结值继续，状态行恢复「正在放映」

## 人工验收步骤

正常闭环：
1. 点播放 → 看到进度推进、状态行「正在放映《城南旧事》」
2. 点进度条约 2/3 处 → 进度跳转
3. 点片单「小花」→ 银幕与队列联动换片

异常恢复：
1. 放映中记下当前进度（如 00:32）
2. 点「网络」开关 → 浮层显示「进度已为你保留在 00:32」
3. 点「重新连接」→ 浮层消失，进度从 00:32 继续走秒
