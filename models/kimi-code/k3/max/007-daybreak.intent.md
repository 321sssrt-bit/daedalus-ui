# 007 欢迎空态

## 意图元数据

- 意图版本：1
- 对应规范：`007-daybreak.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态就是产品的第一口气：暖橙渐变当日出，一句「还是空白」把空说成邀请而不是缺失。主次行动分明——写自己的，或先看别人的。取舍是不放任何导航与功能入口，让第一次打开只有一件事可做。

## 适用场景与目标用户

晨间日记、冥想记录、轻量手账类产品，用户是刚开始建立记录习惯的个人，首次启动时需要情绪上的安静引导而非功能导览。

## 非目标

- 不做功能列表式的新手介绍
- 不用插画库常见的扁平小人
- 不在空态放广告、会员引导或红点

## 复刻提示词

日出氛围的欢迎空态：暖橙垂直渐变满屏，居中日出 SVG + 宋体标题「今天的第一页，还是空白」，橙色胶囊主按钮展开行内书写卡（200 字计数），虚线次按钮展开一条他人示例日记，保存后底部弹提示条。
