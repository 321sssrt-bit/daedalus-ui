- 意图版本：1

## 设计意图

徒步详情最有用的「可调节项」是节奏：同一条线，休闲走和强驴走是两个世界——用时、入山时间、水和装备全跟着变。松绿石灰配等高线，像翻开一页路书。取舍是把评论与打卡榜砍掉，详情页只服务走前决策。

## 适用场景与目标用户

徒步、登山、越野跑路线产品的详情页，用户是有经验的户外人，关心强度匹配与装备清单。

## 非目标

- 不做实时轨迹记录与定位
- 不用卫星图风格的深色地图
- 不做约伴与领队报名

## 复刻提示词

松绿石灰色徒步详情（390px 手机框）：顶部等高线图区（虚线路径 + 起终点 + 海拔签），标题 + 收藏心，三数据卡，节奏分段器（休闲/标准/强驴）联动用时与装备建议文案，路线说明 + 五途经点，吸底「开始徒步」按钮。
