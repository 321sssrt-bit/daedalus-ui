# 033 钱包首页

## 意图元数据

- 意图版本：1
- 对应规范：`033-payday.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

蓝领钱包的关键词是「工钱到手」的踏实：藏蓝像工装，明黄只给余额与转出。流水写人话——转给家里、高温补贴、AA 聚餐。取舍是放弃理财导流位，首页只看钱进钱出。

## 适用场景与目标用户

面向蓝领与灵活就业群体的钱包发薪页，用户年龄跨度大、机型杂，需要大数字、大按钮和一眼能懂的流水。

## 非目标

- 不做理财、借贷导流卡片
- 不用毛玻璃与紫粉渐变
- 不在首页推保险与广告

## 复刻提示词

手机框内的蓝领钱包首页：藏青渐变头部（38px 明黄等宽余额 + 眼睛掩码 + 转出/收款双按钮），五条白卡流水（入绿出橙），底部四枚导航，转出弹底部半层金额输入并即时扣减余额，宽屏套 390px 手机框。
