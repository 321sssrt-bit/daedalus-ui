# 016 成员目录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`016-constellation.html`
- 复现范围：天文社群「星图」成员目录的星空网格、组别筛选与成员简介弹层。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 视口 1280 × 800 px，`min-height:100vh` | 内容最大宽 1080px 居中，padding 30px 26px 50px | 背景 `--space`，70 颗星点 fixed 铺底闪烁，z-index 0 |
| 头部 | 通宽，margin-bottom 24px | 左右两端：标题 / 组别筛选胶囊 | 标题 24px 大字距 |
| 成员网格 | 4 列 grid，间距 16px | 卡片 padding 20px 16px 16px 居中 | `--space-2` 底、1px `--line` 边、圆角 14px |
| 简介弹层 | fixed 全屏遮罩 `rgba(8,12,24,.7)` | 居中 420px 卡片，padding 28px 26px | z-index 10，金边 + `0 24px 70px rgba(0,0,0,.6)` |

## 设计令牌

### 色彩

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--space` | `#0f1626` | 页面深夜蓝背景 |
| `--space-2` | `#16203a` | 卡片底 |
| `--star` | `#f4d47c` | 星光金：角色、选中、弹层描边 |
| `--ink` | `#e6e9f2` | 正文标题、星点 |
| `--muted` | `#8d97ad` | 辅助文字 |
| `--line` | `#263252` | 边框分隔 |
| `--accent` | `#7b93f2` | 星座连线、悬停 |

### 字体

| 角色 | 字体栈 | 字号 / 行高 | 字重 / 字距 |
| --- | --- | --- | --- |
| 显示字 | `"PingFang SC","Microsoft YaHei",system-ui,sans-serif` | 24px / 1.6 | 700 / .16em |
| 标题 | 同上 | 15–19px / 1.6 | 700 / .06em |
| 正文 | 同上 | 14.5px / 1.6 | 400 / 默认 |
| 辅助文字 | 同上 | 11.5–12.5px / 1.6 | 400 / .1–.12em |

### 间距、圆角与层级

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| 基础间距 | 8px | 网格间距 16px、卡内间距为其倍数 |
| 控件圆角 | 999px | 筛选胶囊 |
| 容器圆角 | 14px | 成员卡与弹层 |
| 边框 / 阴影 | 1px `solid var(--line)`；弹层 1px `--star` 边 + 大投影 | 夜空层次 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 成员卡 | 网格等宽，圆形 72px 星座头像 | 深蓝底 1px 边 | 悬停上浮 3px、边框转金色；点击打开简介弹层 |
| 组别筛选胶囊 | padding 7px 16px | 深底灰字描边 | 悬停亮边；选中金底深字加粗并过滤网格 |
| 星座头像 | 52px SVG：连线 + 大小星点 | 蓝线、金白双色星 | 每位成员按种子数错排，互不重复 |
| 简介弹层 | 420px 卡 + 全屏遮罩 | 金边大投影 | 点遮罩、✕ 或 Esc 关闭 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 × 800 | 4 列网格 | 全部组件如上 |
| ≤ 960px / ≤ 520px | 网格转 2 列 / 1 列 | 卡片全宽自适应 |

## 内容与数据

- 在册 8 位成员，三组：目视派 3、深空摄影 3、科普讲解 2
- 卡片含星座头像、花名、组别与常驻据点；头部注明「在册 8 位 · 下次集体观测：八月廿九晚」
- 点卡片打开简介：常驻、设备、入会时间、代表作与一段自述
- 筛选胶囊：全部 / 目视派 / 深空摄影 / 科普讲解

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 星点闪烁 | 3s 循环错峰 | 星点明灭 | 停止闪烁 |
| 卡片悬停 | .15s ease | 上浮 3px、金边 | 即时切换 |
| 弹层开合 | 即时 | 遮罩与卡片显隐 | 不适用 |

## 复现验收清单

- [ ] 1280 × 800 下深夜蓝底有 70 颗错峰闪烁的星点，4 列成员网格
- [ ] 每张卡片是圆形星座 SVG 头像（连线 + 大小星点），8 张互不重复
- [ ] 点「深空摄影」网格只剩 3 位对应成员，胶囊选中变金色
- [ ] 点成员卡打开 420px 金边弹层，含设备、入会、代表作与自述
- [ ] 弹层可经 ✕、遮罩或 Esc 关闭
- [ ] 窗口缩到 960px / 520px 时网格转 2 列 / 1 列
- [ ] 系统开启减少动态后星点停止闪烁
