## 设计意图

邻里社交的气质是院子和布告栏：青砖色顶、暖阳色「写一条」，范围签像贴在布告角上的「给哪栋看」。发布失败不吞稿——草稿条钉在流顶，内容与范围一字不少。取舍是把可见范围做成发布主角之一，邻里产品里它比文案还重要。

## 适用场景与目标用户

小区邻里、园区、村落共同体的小型动态产品，用户彼此面熟，发言在意「给谁看」。

## 非目标

- 不做图片九宫格与视频
- 不用大厂的无限推荐流
- 不做陌生人可见的公开广场

## 复刻提示词

青砖暖阳邻里动态原型（390px 手机框）：吸顶院名栏 + 四条带范围签的动态卡 + 暖阳悬浮「写一条」，编辑半层（正文 + 可见范围三选 + 红色发布演练开关），失败时流顶草稿条保留内容与范围（再发一次 / 接着改），成功入流顶。
