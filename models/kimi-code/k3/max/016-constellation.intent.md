# 016 成员目录

## 意图元数据

- 意图版本：1
- 对应规范：`016-constellation.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

成员目录做成一片星空：每个人都是一小座星座，头像由星点连线生成，人人不同。深夜蓝与星光金让「同好会」三个字有了暗夜温度。取舍是放弃真实人像，用生成式星座头像换隐私与浪漫。

## 适用场景与目标用户

兴趣社群、俱乐部、社团的成员名录页，用户彼此以花名相称，看重个性与归属，不需要实名与职务层级。

## 非目标

- 不做组织架构图与职务排序
- 不用默认几何头像（首字母圆块）
- 不加关注、私信等社交动作

## 复刻提示词

星空成员目录：深夜蓝底 70 颗闪烁星点，4 列网格卡片（圆形生成式星座头像 + 花名 + 组别 + 据点），组别筛选胶囊选中变金色，点卡开 420px 金边弹层显示设备、入会时间、代表作与自述。
