# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-library.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

古籍检索的气质是「书库深青 + 绢面米黄」：筛选组像函套上的题签，书目卡左侧一条深青像书脊。计数用朱砂数字，呼应批校。取舍是不做搜索结果高亮闪烁，书库的东西应当安静地在那里。

## 适用场景与目标用户

图书馆古籍部、档案馆、方志库的检索页，用户是研究者与地方志工作者，习惯按朝代、版本、藏区收敛范围。

## 非目标

- 不做全文检索与 OCR 在线阅读
- 不用现代电商筛选器的活泼样式
- 不做借阅车与预约流程

## 复刻提示词

深青绢色古籍检索：顶栏宋体馆名 + 绢色检索条，左侧四组 facet（朝代/版本/藏区/状态各带计数），右侧书目卡（左深青边条 + 宋体书名 + 四个标签，状态三色），朱砂计数随筛选即时变化，清除按钮复位，零结果有绢面空态。
