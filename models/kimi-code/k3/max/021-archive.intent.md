# 021 内容目录

## 意图元数据

- 意图版本：1
- 对应规范：`021-archive.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

杂志目录就是报纸的版面：刊头双线、红色栏目、宋体篇名，摘要用引条而不是弹窗，一切都在版内完成。取舍是放弃封面图与缩略图，相信文字本身的排列力量。

## 适用场景与目标用户

独立杂志、深度报道专栏、文学期刊的期目录页，用户是愿意读长文的订阅者，先扫栏目与篇名再决定读哪篇。

## 非目标

- 不做无限滚动与推荐阅读流
- 不用卡片大图流排版
- 不放点赞、转发等社交指标

## 复刻提示词

报纸编辑排版的内容目录：860px 居中，刊头 40px 宋体刊名 + 3px 双线 + 期号，六篇列表（红色栏目 + 宋体篇名 + 作者 + 等宽时长），点开行内展开红条摘要与「进入正文」，篇目互斥展开，页脚编辑部地址。
