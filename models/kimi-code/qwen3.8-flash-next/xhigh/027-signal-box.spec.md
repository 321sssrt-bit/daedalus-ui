# 027 角色权限 roles

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`027-signal-box.html`
- 复现范围：铁路信号房式权限台——左列角色手柄、右侧四大类 11 项权限开关矩阵、按角色的未保存改动跟踪、保存/放弃与顶部信号 lamp 回显。

## 内容与数据

站名「滨江车辆段 · 调度权限台 · 联锁模式 C」。5 个角色：值班站长 R-01（6 人）、行车调度员 R-02（9 人）、维修工程师 R-03（14 人）、票务员 R-04（22 人）、见习观察员 R-05（5 人）。四大类 11 项：行车 SIG-01 进路排列 / SIG-02 道岔加锁 / SIG-03 调车作业计划；客运 PSG-01 站内广播 / PSG-02 闸机应急释放 / PSG-03 停运公告发布；设备 DEP-01 屏蔽门就地锁 / DEP-02 电梯检修模式；台账 REC-01 日报导出 / REC-02 录像回放 / REC-03 事故报告签发。每角色有独立基线开关组合（如维修工程师放行 道岔加锁/屏蔽门/电梯/录像 4 项），概览条实时显示「放行 N 项 · 禁用 M 项」。初始消息「基线已同步 · 上次保存 09:26 · 值班站长」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 切换角色 | 即时渲染 | 黑底反白跟手、开关矩阵整体刷新、概览计数更新 | 同样即时（本就以状态切换为主） |
| 拨动开关 | 旋钮位移 0.18s cubic-bezier(.3,.8,.3,1) | 绿芯辉光出现/熄灭；改动行左缘黄标条亮起 | 无过渡直接跳位，颜色与标条保留 |
| 保存 | 无动画 | 底栏消息落款时间、黄灯熄灭、绿灯点亮、该角色黄点消失 | 反馈文案完整保留 |
| 悬停角色 | transform 0.15s ease | 右移 3px | 关闭位移 |

## 复现验收清单

- [ ] 1280 宽：外框 3px 黑线、左列 276px、底栏黑底；权限矩阵共 4 类 11 行，每行右侧有 52×26 开关。
- [ ] 点「维修工程师」：概览变 R-03、放行计数 4；其开关组合与值班站长不同——验证角色切换预览生效。
- [ ] 拨动任一开关：该行左缘出现 5px 黄条，顶部琥珀灯点亮，「保存权限」由禁用变可点，角色列表该项出现黄点。
- [ ] 带着改动切到别的角色再切回：改动仍保留（黄条还在），未保存角色名旁有黄点。
- [ ] 点「保存权限」：底栏出现「已保存 HH:MM · 角色 · 变更已下发联锁台」，黄条与黄点消失，琥珀灯灭。
- [ ] 再拨一格后点「放弃改动」：恢复保存前状态，计数回退。
- [ ] 窗口收到 768px：单列布局、角色两列网格、权限行编号列隐藏，不破版。
- [ ] 开启「减少动态效果」：开关跳变无滑动，但灯色、黄条、消息全部保留。
