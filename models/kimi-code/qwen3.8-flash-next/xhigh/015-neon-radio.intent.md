# 015 通知中心 alerts

## 意图元数据

- 意图版本：1
- 对应规范：`015-neon-radio.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

通知中心本质是一盏盏等人在亮的灯，于是把「未读」做成会呼吸的霓虹：紫夜底上浮着电台辉光，未读卡片自带灯罩描边，读完灯就灭。品红与紫罗兰按业务色分工而非装饰，胶囊圆角呼应调台按钮，让刷屏变成拨频道的动作。

## 适用场景与目标用户

语音电台、直播陪玩、夜店活动等夜间娱乐产品的站内通知中心；用户是深夜挂在直播间、需要一眼分辨「开播/互动/账单/安全」的活跃听众。

## 非目标

不做白底黑字的企业风通知列表与蓝色超链接；不做红点角标堆叠与强制弹窗；不做通知分组时间轴、置顶与稍后提醒等高级收件能力。

## 复刻提示词

赛博夜店通知中心：午夜紫 #12101f 底叠紫罗兰 #8b5cf6 与品红 #ff4d8d 两团辉光渐变；深紫面板卡 18 px 圆角，未读卡紫描边 + 脉动品红呼吸点，读完灯灭转灰；左侧一列调台式圆角胶囊过滤器，辉光圆点图标按业务配色，一切按钮皆 999 px 胶囊。
