# 019 购物车 cart

## 意图元数据

- 意图版本：1
- 对应规范：`019-thermal-receipt.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

购物车的本质就是一张待付的单据，索性让它成为一张真小票：等宽字、虚线分隔、条码与红字合计，结账的动作和撕票同构。取舍是牺牲宽屏陈列效率，用 520px 单栏的仪式感换取「金额即小票」的确定感与可信度。

## 适用场景与目标用户

便利店 / 即时零售的在线购物车与订单确认前页；用户是下单快、核对金额快的附近居民与上班族。

## 非目标

不做商品大图陈列、不做营销弹窗与优惠券堆叠、不做深色科技感；不含支付、地址与售后流程。

## 复刻提示词

热敏纸 `#f4f2ee` 压在灰台面渐变上，全页等宽字体，一切分隔用虚线/点线/双线，红色 `#c62828` 只给合计与结算，条码与锯齿撕边收尾，数字全部右对齐两位小数。
