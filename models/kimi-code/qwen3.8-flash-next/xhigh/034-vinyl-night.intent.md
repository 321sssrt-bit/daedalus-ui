# 034 正在播放（vinyl-night 黑胶唱片行）

## 意图元数据

- 意图版本：1
- 对应规范：`034-vinyl-night.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

播放器的核心快感是"这件东西在转"，所以让圆盘+唱臂承担全部主视觉：暂停时预旋 -24° 表示"上着弦"，播放时唱臂落针、8 秒一圈匀速转，把最抽象的播放状态变成最直白的机械动作。暖紫与电子管橙来自夜间灯下听碟的色温，黑紫底压低亮度护眼。

## 适用场景与目标用户

怀旧向音乐 App、黑胶/爵士/低保真电台类产品、播客「正在播放」页；用户是夜里戴耳机听整张专辑的人，重氛围甚于重功能密度。

## 非目标

不做流媒体式的瀑布推荐与评论弹幕；不做亮色通用播放器皮肤；进度条不做手势微动画堆料；不引入任何真实封面图。

## 复刻提示词

夜场黑胶播放器移动页：黑紫底 #251e35→#121019、304px 纹路圆盘 + 换曲变色的中心标签、右上金属唱臂随播放落针、电子管橙 #e08e45 大圆播放键、紫橙渐变进度条可点跳、三行歌单当前曲带跳动均衡器；气质像凌晨唱片行柜台后的试听机。
