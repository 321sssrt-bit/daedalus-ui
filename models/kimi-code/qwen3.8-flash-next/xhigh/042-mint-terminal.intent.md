# 042 钱包支付产品

## 意图元数据

- 意图版本：1
- 对应规范：`042-mint-terminal.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把手机里的转账当成一台随身行情终端上的下单：墨绿黑屏幕、等宽数字、滚动行情与硬边栅格先建立「钱在实时流动」的语境，再用整屏直角与细网格线压住一切轻浮感。余额、缺口、预计结余全部用可对比的等宽数字说话，让「够不够」在按确认前就已看得见；余额不足做成交易系统的拒单回执而非道歉弹窗，跌色低饱和、全程冷绿，钱的事冷静办。

## 适用场景与目标用户

面向高频小额资金往来的个体经营者、小商户主与盯行情的人：在通勤、看盘间隙用一台「像终端的钱包」给固定商户付款、结货款。产品品类是随身转账/商户钱包，情境是单手、碎片时间、需要快速核对金额与来源，而不是一次性消费结账。

## 非目标

不做圆润亲和的 C 端钱包脸（无大圆角、无插画、无渐变糖果色）；不做红色警告弹窗与拟物钞票元素；不实现真实支付、风控、扫码与收款人管理；余额不足不用全屏报错打断——拒单是面板级的回执，恢复操作就在眼前；行情带仅作氛围，不假装可交易。

## 复刻提示词

随身金融终端风转账原型：墨绿黑 #0e1713 底 + 石墨绿 #1f2d27 直角面板，1 px #2b3d34 细网格线贯穿；薄荷绿 #3ddc97 只给余额、涨、成功与主按钮，跌与余额不足用低饱和 #cf7d6b；全等宽 tabular 数字（余额 30 px、输入金额 40 px 带闪烁方块光标），顶部 28 px 滚动行情带 + 页脚状态灯（IDLE/ARMED/BLOCKED/EXEC/SETTLED）；流程五屏互斥：行情首页选来源与收款人 → 3×4 硬边键盘输金额（含警示色「超限」芯片）→ 指令核对单 → 三步琥珀执行 → 倾斜「已清算」印章凭证；拒单是 1 px 警示描边的拦截回执板，AMEND 或就地换来源即刻可重试。
