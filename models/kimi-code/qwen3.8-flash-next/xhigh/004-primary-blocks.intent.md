# 004 新手引导 onboarding

## 意图元数据

- 意图版本：1
- 对应规范：`004-primary-blocks.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

引导本身就演示产品主张：方块、黑线、三原色。让引导页长成产品的第一张网格，用户还没上手就先「住进」这套秩序；步骤用整块纯色而非进度条小圆点，把枯燥的 onboarding 变成一幅蒙德里安。取舍是放弃一切柔和过渡与插画陪伴，接受略强的视觉硬度和一点陌生感。

## 适用场景与目标用户

强调秩序与边界的团队协作/看板类产品（任务网格、排期系统、设计交付管理）的首次启动引导；用户是被混乱文档折磨过、欣赏理性审美的设计师与工程师小团队。

## 非目标

不做渐变、圆角、投影弥散、吉祥物插画与庆祝彩带动效；不做进度圆点或百分比条（步进即色块）；不做多语言切换与头像上传等注册旁支。

## 复刻提示词

纯白画布上一只 6px 纯黑粗线画出的 1080px 大格框：左侧 224px 竖轨依次是钴蓝大矩形、贴左下的小红方块、柠檬黄底块；主格内每步左侧立一块 184px 纯色板（红→蓝→黄，印 78px 黑色/白色序号），右侧无衬线粗黑标题与短句；选项是 3px 黑边矩形，选中整块变钴蓝；底栏黑粗线以上放三枚步进方格，右下大号黑底按钮 hover 变红。全程无圆角、无阴影渐变，硬切切换，1920s 风格派构图制度。
