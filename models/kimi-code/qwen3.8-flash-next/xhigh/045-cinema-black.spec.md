## 内容与数据

- 片单 6 部（片名/时长秒）：霓虹巷 1440（24:00）、潮汐记录 1110（18:30）、无声广播 1875（31:15）、盐与尘 728（12:08）、夜航台 1664（27:44）、玻璃苔 1012（16:52）；时码一律 `mm:ss` 等宽字体。

- localStorage 键 `midnight-resume`，值 `{"fi":片索引,"pos":整秒}`；刷新后暂停态恢复，overlay 提示「上次放映到 mm:ss · 点播放续播」。

## 产品边界

实现一台本地「午夜场」放映台：内容发现（6 部片单场刊）、开始/暂停播放、进度 seek、队列增删与顺播、模拟断网与重连续播、播放状态持久化。不含真实视频解码（海报图代替影片画面）、账号体系、搜索筛选、音量与字幕、服务端同步。

## 状态地图

| 状态 | 触发 | 可见特征 |
| --- | --- | --- |
| 待机 | 初始且无存档 | overlay「从场刊选一部影片，开演」，时码 00:00/00:00，LED 灰 |
| 就位暂停 | 点「立即放映」 | 海报入幕，overlay 盖「已就位 · 点播放开演」 |
| 播放中 | 点播放键 | overlay 隐藏，徽标闪烁，LED 金，走秒+保存注 |
| 暂停 | 播放中再点播放键 | overlay 现「已暂停 · 点播放继续」 |
| 断网 | 播放中点「模拟信号中断」 | 深红横幅+「暂停在 mm:ss，进度已保留」，LED 红，播放键变重连语义 |
| 片尾接映 | 走秒到时长上限 | 自动播队列下一部，否则按片单循环；toast 报接映片名 |

## 正常流程

1. 点场刊「立即放映」→ 影片入幕并直接开播，徽标出现，时码走秒，右下保存行「已保存 · 片名 mm:ss」。
2. 拖进度条 → 时码与滑块即时到位，保存行「手动调整进度 · mm:ss」，存档同步写入。
3. 点其他影片「加入队列」×2 → 队列侧栏出现 01/02 项，脚注「队列 2 部 · 共 mm:ss」。
4. 点队列项 → 立即改映该片，该项金色高亮；点 ✕ → 移除且脚注重算。
5. 当前片播完 → 自动接映队列下一部（无队列则片单循环），toast 说明接映来源。

## 异常触发与恢复

- 触发：播放中点控制条「模拟信号中断」（仅播放中启用，即题定「播放器中的可见操作」）。
- 失败表现：立即暂停并停秒；深红横幅常驻：「信号中断：《片名》暂停在 mm:ss，进度已保留，未丢失。」；状态条同步说明；保存行定格「进度保留于 mm:ss」；断点 `cutPos` 保留，不受暂停期间拖动影响（拖动会同步更新断点）。
- 恢复：点横幅「重新连接」（或断网中直接点播放键，等效重连）→ 横幅撤下，从 `cutPos` 自动续播，toast「信号恢复 · 从 mm:ss 继续放映」，走秒与存档继续。

## 数据变化

- 播放期间每秒写一次 `midnight-resume={fi,pos}`；暂停、seek、断网、重连均即时写入。
- 断网期间：进度冻结在断点，不丢存档；重连后时码从断点继续，无回零。
- 队列：加入 +1 并重算脚注总时长；移除 −1，若删的是当前播放位则解除高亮（`qi=-1`），删前面的项则高亮位左移。
- 刷新页面：队列清空（不持久化），当前片与进度从存档恢复。

## 人工验收步骤

正常闭环：①打开页面见待机 overlay → ②点《霓虹巷》「立即放映」见开播+徽标+走秒 → ③拖进度条见时码跳变 → ④加两部进队列点第一队列项见金色高亮改映 → ⑤等片尾见 toast 接映下一部。
异常恢复：①播放中点「模拟信号中断」→ ②见深红横幅含断点 mm:ss、画面停秒、LED 变红 → ③点「重新连接」→ ④见横幅消失、从断点续播、toast 报「从 mm:ss 继续放映」→ ⑤播放中刷新页面 → ⑥见 overlay「上次放映到 mm:ss」，点播放从该点续播。
