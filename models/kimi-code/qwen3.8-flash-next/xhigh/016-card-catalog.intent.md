# 016 成员目录 directory

## 意图元数据

- 意图版本：1
- 对应规范：`016-card-catalog.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「找一个人」还原成去档案柜抽一张索引卡：卡其柜面、白卡、maroon 边框与印章让目录有实体秩序感，打字机等宽字暗示铅字打印的档案制度。筛选叫「拉抽屉」、看简介叫「抽屉细看」，交互动词全部沿用柜体隐喻，减少一次界面翻译。

## 适用场景与目标用户

档案室、博物馆、图书馆、律所等以「编制内成员 + 部门」为组织方式的内部名录页；用户是要快速确认某人是谁、在哪个工位、现在在不在的同事或来访登记者。

## 非目标

不做头像瀑布流与渐变色个人主页等社交名片语言；不做在线状态、私信与排班日历等协作能力；不做搜索联想与排序权重，过滤只做字面命中。

## 复刻提示词

档案馆成员目录：柜体卡其 #d9c9a3 竖纹底，白色索引卡 #faf6ec 带顶部打孔圆、maroon #6e3b2f 直角边框与硬平移阴影；打字机等宽字大字距，首字圆印章旋转 -9°，状态用旋转小章（在职/出差/休假）；筛选条是带把手的抽屉行，点开人从右侧滑出档案抽屉，隐喻贯穿到按钮文案。
