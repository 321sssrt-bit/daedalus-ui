# 021 内容目录 index

## 设计意图

目录的职责是「快速定位、可信出处」。借用古籍馆卡片目录的纸墨制度——竖排题签、朱丝栏、书号机打行——让每条书目天然携带作者、版本、书格等来源信息，展开题要如同抽出一张目录卡。取舍是牺牲现代列表的紧凑度，换取检索文献的仪式感与可信度。

## 适用场景与目标用户

古籍数据库、档案馆、出版社书目、博物馆藏品索引等「条目少而信息重」的检索页；用户是研究者、藏书人或需要核对出处的编辑。

## 非目标

不做无限滚动瀑布流、不做缩略图网格、不做圆角卡片与投影的现代 SaaS 列表；不实现真实馆藏检索接口与预约下单流程。

## 复刻提示词

旧纸 #efe6d0 上铺红色双线框的书志卡，左侧一条藏青竖榜写馆名并钤朱印，横向五列著录行如目录卡片，点击一行下滑抽出题要与书格机打小字，宋体、直角、零圆角。
