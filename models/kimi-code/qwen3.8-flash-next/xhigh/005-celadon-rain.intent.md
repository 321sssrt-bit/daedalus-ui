# 005 找回密码 reset

## 意图元数据

- 意图版本：1
- 对应规范：`005-celadon-rain.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

找回密码是用户最焦躁的时刻，所以刻意做「减法」：一列 460px 细流、极疏的字距、会呼吸的青瓷圆球，把「等待一封邮件」这件枯燥事渲染成檐下等雨。取舍是牺牲信息密度与营销位，换取单一动线的确定感。

## 适用场景与目标用户

面向偏内容/社区气质的中文 C 端产品（阅读应用、播客、生活记录类账号中心）的用户自助找回页；用户多为移动端过来或在电脑前第一次忘记密码的普通用户，情绪上需要安抚而非技术流程展示。

## 非目标

不做多步向导（邮箱→图形码→短信码分页）、不做账号安全广告位、不做深色模式、不加插画与阴影卡片；不用通用 SaaS 居中大卡片 + 蓝色主按钮那一套。

## 复刻提示词

淡青瓷底色的单列找回密码页，宋代瓷器式的静气：极淡 #eef4f1 底、深一档墨青字、一颗缓慢呼吸的青瓷圆球表示「正在投递」；所有按钮扁平方圆 2px、宽字距、无阴影；文案写成散文短句（「像一场小雨，安静地落过去」），拒绝流程感词汇。
