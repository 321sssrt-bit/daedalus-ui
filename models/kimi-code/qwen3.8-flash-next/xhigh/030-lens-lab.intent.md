# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-lens-lab.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

检索台像一台精密光学仪器：低温冰蓝底 + 纯白面板让数据自己发声，钴蓝是唯一的"通电"信号，只落在选中与命中上；1 px 发丝线代替阴影分层，轻密度排版把注意力留给计数与条目。取舍是放弃卡片投影和彩色徽章的热闹，换仪表般的秩序与可信。

## 适用场景与目标用户

检测实验室、医疗影像、EDA/天文数据管理等多条件检索后台；用户是每天带着明确目标来查记录的工程师或研究员，条件经常组合使用，需要即时知道"还剩多少"。

## 非目标

不做消费级内容流（大图卡片、瀑布流）；不做深色主题与高饱和渐变；不做分页/无限滚动的真实大数据机制（9 条演示数据全量渲染）；不加拖拽滑块等花哨控件。

## 复刻提示词

光学仪器面板风检索页：冰蓝 #e9f3f7 页面、纯白直角卡、钴蓝 #2b6cb0 仅用于选中态与焦点环，全页只有 1 px #c9dcea 发丝线分层、零阴影；左侧 320 px sticky 筛选轨（关键词/两组多选胶囊/分段控件/2×2 时间窗/排序），右侧 34 px 等宽大计数 + 命中占比 + 细条目记录卡；术语仪器化（光路、标定、谱线数、时间窗）。
