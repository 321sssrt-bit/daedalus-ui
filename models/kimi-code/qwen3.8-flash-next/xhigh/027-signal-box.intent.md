# 027 角色权限 roles

## 意图元数据

- 意图版本：1
- 对应规范：`027-signal-box.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限是"谁能扳动什么"的问题，于是把整页做成一间联锁信号房：白面板配纯黑粗框，权限只有放行/禁止两态，正好对应信号灯的绿与灭；未保存改动用琥珀灯与黄标条三级回显，让"动过哪里"一目了然。取舍是放弃柔和的中性灰阶层次，换取零灰影的高对比与工业直角色彩语言。

## 适用场景与目标用户

面向强安全语义的管理后台：轨交/电力/工厂 SCADA、医疗设备权限台、金融双人复核配置。用户是拥有授权责任的管理员，操作低频但后果重，需要明确的"改动—待保存—已下发"链路而非一键云端同步的轻率感。

## 非目标

不做搜索式权限中台与批量模板；不做三态（继承/覆盖）复杂模型；不用圆角卡片与蓝色链接的通用后台皮肤；不做真实下发接口。

## 复刻提示词

铁路信号房权限矩阵：浅灰墙面上一块 3px 纯黑粗框的白色信号柜；左列是带扳杆图标的角色按钮（选中黑底反白），右侧四大类 11 行权限表，每行「编号-名称-开关」，开关是黑槽绿芯的信号灯（放行亮绿带辉光，禁止灰芯居左）；类目题签是黑底白字小块；底部黑条控制台放保存/放弃与消息；改动行左缘黄标条、角色旁黄点、顶部琥珀灯三级提示未保存。
