# 008 权限请求 permission

## 意图元数据

- 意图版本：1
- 对应规范：`008-hazard-tape.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限即危险作业：借工业安全标的语言（斜纹带、黑体重号字、单据编号、留痕脚注）把「要什么权限、为什么」抬到必须逐项过目的份量。三种批复并列同权，不诱导点批准；驳回文案明说后果与替代路径，尊重用户说不的权利。

## 适用场景与目标用户

偏工具/生产力的桌面 Web 应用首次执行敏感任务时的授权页：本地文件处理、硬件调用、局域网设备协作类（如车间管理、图纸导出、图像批处理）；用户是有安全戒心、需要看清用途才肯放行的专业使用者。

## 非目标

不做系统级原生弹窗仿制（刻意用应用内单据）；不用柔和渐变与圆角卡片稀释严肃感；不折叠权限细节、不用默认勾选；不实现真实权限 API 与审计后端，仅演示批复状态机。

## 复刻提示词

沥青黑底上的工业权限申请单：单据上下各一条黄黑斜纹警示带，抬头用三角惊叹黄底标牌加 800 字重的「权限申请单」，权限逐条列（黄框线描图标 + 用途短句 + 黄色 chip 标注限制范围），批复区三个直角按钮——黄底黑字「批准」、黄描边「仅此一次」、红描边「驳回」，批复后原地弹出带时间戳的黑底结论牌。
