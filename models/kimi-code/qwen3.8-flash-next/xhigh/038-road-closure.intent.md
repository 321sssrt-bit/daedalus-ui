# 038 故障

## 意图元数据

- 意图版本：1
- 对应规范：`038-road-closure.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「系统坏了」翻译成用户熟悉的市政语言：围挡、封条、工单号。故障不再是一句冷淡的报错，而是一场看得见的施工——有编号可查、有师傅在修、有预计放行时间，焦虑被转译成等待的确定性。黑体重字与斜纹给了错误页罕见的力量感。

## 适用场景与目标用户

物流柜、停车、缴费等高即时性工具的故障/降级页；面向在路边赶时间、需要「到底几点能好」而不是「请稍后再试」的普通市民用户。

## 非目标

不用悲伤插画或哭泣表情安抚情绪；不用柔和渐变的「友好错误页」套路；不承诺做不到的自动恢复；不引入成功绿——放行也用围挡橙，保持材料一致。

## 复刻提示词

市政施工围挡风错误页：水泥灰 #d9d9d6 + 围挡橙 #f2711c + 沥青黑 #1f1f1e 斜纹横条压顶，旋转封条盖工单号，黑体 900 大字标题，直角粗边框按钮；重试时有橙白斜纹进度条，恢复后发「通行卡」。
