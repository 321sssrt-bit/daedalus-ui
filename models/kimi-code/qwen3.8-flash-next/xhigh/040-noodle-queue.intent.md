# 040 等候

## 意图元数据

- 意图版本：1
- 对应规范：`040-noodle-queue.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

等位的焦虑要用烟火气来熬：暖纸底、竹木招牌、红印章号码牌，把排队做成一张捏在手里的号票。手写小票替用户记住点单，步骤条和倒计时把「还要等多久」讲诚实，「放到一边」承认人会临时走开——市井馆子的分寸感就在这几处。

## 适用场景与目标用户

餐饮排队取号小程序的等位中页面；面向晚市饭点拖家带口、会在商场里边走边等叫号的大众食客。

## 非目标

不做会员积分、加群领券等运营组件；不做真实定位到店判断（入座是手动确认）；不用冷色 SaaS 进度环——进度必须是红白斜纹的「面馆感」；倒计时为演示节奏加速，不承诺真实厨房用时。

## 复刻提示词

市井面馆等位：暖纸 #f6e7c9 底 + 印章红 #c0392b 号码大字与圆章 + 竹木 #a8703d 店招，楷体写号码和小票，步骤条红点光晕推进，挂起横幅与「到你了」盖章动画；界面装在深色手机壳里，宽屏居中。
