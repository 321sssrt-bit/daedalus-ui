# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-boarding-pass.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

出票成功的仪式感来自实体票的记忆：齿孔、撕线、剪刀口、条码，一张票票面把「钱已付、位已留」说得可触摸。票纸米配孔雀绿是机场柜台的安静版本，等宽编号负责可信，大字距负责体面——成功页不需要撒花，一张好票本身就是庆祝。

## 适用场景与目标用户

火车票、演出票、酒店确认等「凭码通行」交易的成功回执；面向习惯电子客票、仍会在检票口截图放大票面的出行用户。

## 非目标

不做彩带、礼花、满屏对勾的庆典风；不做社交分享裂变按钮；不假装能真的撕票——撕裂线只是视觉与条码的分区，不设计撕开交互；详情不做二级页面跳转。

## 复刻提示词

登机牌回执：票纸米 #fdf6e9 两段式卡片 + 齿孔撕裂线 + 孔雀绿 #177e6c 按钮与圆点，等宽字体排车次与订单号，条码 SVG 收尾；整页浮在深孔雀绿柜台背景上，装在深色手机壳里。
