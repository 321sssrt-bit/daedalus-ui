# 009 工作台总览 overview

## 意图元数据

- 意图版本：1
- 对应规范：`009-night-cockpit.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把运维值班当作夜航飞行：值班者需要在一眼扫过的范围内确认「飞得稳不稳、还剩多少油、哪里有告警」。所以采用驾驶舱制度——中央是读数，左右是仪表与队列，尾栏是系统状态行；深色底让彩色灯位成为唯一注意力信号，等宽数字保证数值跳动不抖行。取舍是牺牲舒适留白换取单屏信息密度。

## 适用场景与目标用户

SaaS 平台的运维/值班工作台，用户是轮班盯盘的 SRE 或平台工程师，情境是排班期内的持续监看与异常处置，交班前须把告警清零。

## 非目标

不做浅色主题、不做营销式大屏、不做圆角卡片与投影层级；不覆盖移动端深度使用（768 只求不碎）；不做图表缩放拖拽等 BI 级交互。

## 复刻提示词

深空蓝黑驾驶舱、青绿航电主色加琥珀告警、方角面板与 1px 细线、等宽读数、270° 指针仪表、四列仪表甲板、左导航选中带侧光条、全站呼吸灯位。
