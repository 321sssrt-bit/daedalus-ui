# 026 账单 billing

## 意图元数据

- 意图版本：1
- 对应规范：`026-bank-vault.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

账单是最需要"可信"二字的页面，所以借老银行票据的制度：雕纹纸卡、双圈红线章、衬线等宽数字、直角与双细线框，钱像被库房认真保管着。取舍是放弃深色仪表盘式的现代账单，接受信息密度偏纸质、装饰线偏多，换来"每笔都可对账"的庄重感。

## 适用场景与目标用户

面向对公/高单价订阅的结算中心：私有化软件年费、金融数据订阅、贵金属与保险类服务。用户是财务与采购，拿这张页面对票、报销、审计，需要票据感与可核对性而非营销感。

## 非目标

不做信用卡营销卡片流；不做渐变彩色统计图；不用圆角大阴影的"钱包 App"审美；不在原型里做真实文件下载或跳转外部支付网关。

## 复刻提示词

老银行金库账单页：深金库绿底叠横向细纹，抬头 3px double 黄铜线；内容区是米色雕纹纸卡（2px 黄铜边框 + 4px 外 offset 细线），左"当前方案"证券配 -14° 红双圈「已生效」圆章，右"在用票据"绿色卡面 + 黄铜芯片 + 可展开的候选票据夹；下方通栏结算账簿：大写宽字距表头、衬线 tabular 金额右对齐、✓绿/⊘红状态词、直角小描边按钮。全直角、少阴影、多细线。
