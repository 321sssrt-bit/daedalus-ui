# 017 商店首页 store

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`017-market-pop.html`
- 复现范围：农夫市集首页单页——招牌区、栏目筛选、8 个货品卡片网格、竹篮计数、收藏开关与页脚信息，不含结算流程。

## 画布与区域布局

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |

| 页脚 | border-top 3px 实线；padding 26px 0 34px；`.fgrid` flex、gap 56px、可换行 | 三栏信息并排，窄屏自动换行 | 纸面色 `#fffaef` 背景块 |

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 加入竹篮按钮 | 胶囊，padding 8px 15px，14px/800 | 叶绿 `#2e7d4f` 底、纸面字、3px 墨边 | 悬停底色加深 `#205c3a`；按下 scale(.95)；点击后文字变「已入篮」、底色 `#e4572e`，900ms 后还原；顶部竹篮计数 +1 |
| 收藏按钮 | 38px 圆形、3px 墨边、内嵌 20px 心形 SVG | 心形描边不填充，aria-pressed=false | 点击后心形填充 `#e4572e`、aria-pressed=true，可反复切换；悬停 scale(1.08) |
| 栏目筛选按钮 | 胶囊 padding 8px 20px，15px/800 | 纸面底墨字 | 选中 `.is-on` 底色番茄红白字；点击后按 data-cat 过滤卡片 display |
| 货品卡片 | 3px 边、20px 圆角、图片衬底高 126px、SVG 96×96 | 硬阴影 6px 6px 0 | 悬停 translate(-2px,-3px) 且阴影加深；禁用状态：不适用 |
| 价格 | `¥` 14px + 数字 30px/900 + 单位 12px | 番茄红数字、muted 单位 | 错误 / 禁用状态：不适用 |

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 | 4 列网格，招牌与竹篮同一行 | 全尺寸展示 |
| ≤ 1024px | 网格降为 3 列 | 店名 54px → 44px |
| ≤ 768px | 网格降为 2 列；容器 padding 30px → 18px | 店名 38px、字距 6px；竹篮徽章换到下一行（margin-left:0）；不出现横向滚动 |
| prefers-reduced-motion: reduce | 无布局变化 | 全部 transition/animation 置 none，悬停位移取消，点击仍改色与计数 |

## 内容与数据

店名「果市集」，副标「城市农夫市集 · 每周三 / 周六开市 · 本季第 21 集」。通告：「今日 06:40 晨采到货 · 三里屯 / 望京双自提点 · 满 49 元免运费，竹篮满 5 件优先排单」。8 个货品按「名称 / 产地·规格 / 价格 / 按钮」顺序：沙瓤番茄 ¥8.8/份、水果胡萝卜 ¥6.5/份、阳山水蜜桃 ¥39.9/盒、赣南脐橙 ¥26.9/箱、乡村酸面包 ¥28/个、全麦核桃包 ¥22/个、农场鲜牛乳 ¥18.5/瓶、洋甘菊一束 ¥19.9/束。栏目为 全部/时蔬/果物/烘焙/酪乳/花植，每卡带同色栏目标签。竹篮初始 0 件。页脚三栏：开市时间 / 自提与配送 / 摊主入驻。数据可替换，但「标签-图-名-规格-价-按钮」层级不得变。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 卡片 / 按钮悬停 | .18s / .15s ease | 位移 2–3px、硬阴影加深 | 取消位移与过渡，样式保持 |
| 点击加入竹篮 | 即时 + 900ms 定时回弹 | 按钮变红显「已入篮」，竹篮计数递增 | 无过渡但文字与计数照常变化 |
| 切换栏目 | 即时 | 选中胶囊变红，网格仅显示对应 data-cat 卡片 | 行为一致，无额外动效 |
