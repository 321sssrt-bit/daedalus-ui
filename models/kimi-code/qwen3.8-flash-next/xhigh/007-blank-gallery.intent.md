# 007 欢迎空态 welcome-empty

## 意图元数据

- 意图版本：1
- 对应规范：`007-blank-gallery.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态不是缺内容，而是一次开馆仪式。用白盒展馆的规矩对待留白：96px 巨字宣言占住版面，留白本身成为主角；朱红全页只出现几处，反而让「开始」显得郑重。产品隐喻（展馆/东墙/展位/藏品）把冷冰冰的 empty state 翻译成可继续生长的空间。

## 适用场景与目标用户

创作与收藏类产品的首次登录页：个人作品集、线上展馆、笔记库、照片归档等；用户是刚注册、还没有任何数据的内容创作者，需要被邀请产出第一件东西，而不是被功能清单轰炸。

## 非目标

不做功能导览轮播（tour）、不做九宫格模板大卖场、不用渐变和圆角卡片、不放 3D 插画；不使用除黑、白、灰阶与单一朱红之外的任何色相。

## 复刻提示词

当代美术馆白盒式空态页：全白画布上放一组 96px 级黑色巨字（「这里 / 空无一物。」，第二行褪成浅灰），正文只用一小段灰字，全页唯一彩色是一点朱红 #e23e2c；一切元素直角、发丝线边框；右侧一条「东墙」展位栏承接第一次操作的成果，页脚用「藏品 N 件」记录进度。
