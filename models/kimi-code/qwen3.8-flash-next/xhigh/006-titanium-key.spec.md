## 内容与数据

设备信息四格固定示例值：请求设备「ThinkPad X1 · 窗口 11」、来源地点「上海 · 徐汇（新 IP 段）」、请求时间「2026-09-07 09:41:16」、核对通道「手机 App「钛匙」推送」。标题「新设备登录请求」，说明「护卫单元不认识这台设备。向你的可信手机核对一枚六位数密钥码。」。行为数据规则：仅数字可入格（非数字即时剥除）；输满 6 位自动提交；退格在空格上回退左格；粘贴自动分发至多 6 格；错误码扣尝试（初始 3），减到 0 触发冻结 180 秒；正确码固定 482913（演示提示行公开写出）。重发倒计时固定 30 秒。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面载入 | 无入场动画 | LED 1.6s steps(1) 青色闪烁标示在线 | LED animation:none，改为常亮 |
| 单元格聚焦 | 120ms ease | 边框转 #3fd8cf + 青色外发光 | transition 关闭，态即时切换 |
| 验证码错误 | shake 320ms ease | 六格整组左右位移 ±6px、边框转红、状态行红字「剩余 N 次尝试」 | animation 关闭，仅保留红边+红字静态反馈 |
| 第 3 次失败 | 即时 | 冻结牌弹出、格子全禁用、LED 转红停闪、180 逐秒倒数 | 倒数与状态全部保留（必要反馈） |
| 验证通过 | 即时 | 放行牌出现、LED 文案「已放行」、按钮组禁用 | 全部保留 |

## 复现验收清单

- [ ] 1280 × 800 下控制台实测宽 520px 且页面正中，背景可见 48px 间距的十字网格线
- [ ] 六格 OTP 单格高 64px、内部数字为等宽字体；键入字母被剥除不入格
- [ ] 输满 6 位错误数字（如 123456）：格子抖动后红边，状态行显示「密钥码不匹配 · 剩余 2 次尝试。」
- [ ] 连续 3 次错误后：冻结牌出现且格子不可输入，「180」每秒减 1；期间重发/核对按钮均禁用
- [ ] 输入 482913：绿色放行牌出现、LED 文案变「已放行」、三键全部禁用
- [ ] 载入后「重发（30s）」逐秒递减，到 0 变为「重发密钥码」且可点击，点击后再次进入 30s
- [ ] 768px 宽下操作行变纵排、三键等宽 100%，无横向溢出
- [ ] 开启减弱动态后：LED 不闪、错误不抖动，但红边、冻结倒数等反馈仍完整
