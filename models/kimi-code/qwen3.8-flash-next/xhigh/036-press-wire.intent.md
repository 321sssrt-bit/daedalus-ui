# 036 编辑发布（press-wire 记者电讯）

## 意图元数据

- 意图版本：1
- 对应规范：`036-press-wire.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把"发稿"还原成拍电报的仪式：纸面打孔、等宽铅字体、截稿红 live 点倒数，让字数上限和截稿压力成为界面里的角色而非提示文案。存稿与发布各盖一枚斜印章（蓝=存档、红=签发），状态一眼可辨且不可回退，呼应"以回执为准"的职业规则。

## 适用场景与目标用户

新闻编辑台 App、内部通报/值机/调度类"发布即生效"工具；用户是赶截稿线的编辑或值班员，需要极低的输入摩擦和明确的"发没发出去"回执。

## 非目标

不做富文本与配图编辑器；不做社交式表情、话题、预览卡片流；不做圆角胶囊全套的柔和 SaaS 皮肤；回执不做可撤销的假交互开关。
