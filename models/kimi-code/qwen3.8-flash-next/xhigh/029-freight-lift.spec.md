## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 ≥ 1280 px | 两列 `400px + 1fr`，容器居中 | 全部 5 列队列网格、钢梁三段横排 |
| ≤ 768 px | 主区改单列纵排，内边距收至 16 px；顶梁换行 | 队列网格收为 3 列（面单/品名/重量），隐藏状态胶囊与卸载列；称重读数移到第二行 |

## 内容与数据

- 顶梁文案：品牌「钢运 GANGYUN」；「月台 B-07 · 班次 早班 06:00–14:00 · 值守 周建军」；右端两个称重单元「队列件数」「总重」，实时等于队列实际值。
- 初始队列 3 件：`GY-0417 高炉温度监测点位表.csv 86.5 MB 已入库`、`GY-0418 质检照片_3号平台.zip 1.24 GB 待装运`、`GY-0419 排产计划_9月第2周.xlsx 4.7 MB 待装运`。
- 重量格式：≥ 1.00 GB 显示两位小数 GB，≥ 1 MB 显示一位小数 MB，其余取整 KB；面单号 `GY-` + 3 位递增序号。
- 拖放区文案：「将货件拖入月台」「支持多件同时入列，单件上限 2.0 GB」；月台注记与操作条提示随操作更新（新到件数、卸载、入库完成「本班次 N 件已全部入库」）。
- 队列清空时显示空态「月台空闲。当前没有排队货件，拖入或开单后在此过磅。」

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 传送带处理中 | 每 160 ms 推进 3–10%，条纹位移动画 0.8 s 线性循环 | 进度带橙纹条变长、状态胶囊「传送中」橙色、按钮锁为「传 送 中」 | 关闭条纹位移与颜色过渡，仅保留宽度步进与文字反馈 |
| 拖拽悬停 / 悬停控件 | 过渡 0.15 s | 拖放区变热橙色 `#e2a267`；按钮底色翻转 | 过渡置 0，状态仍以颜色即时呈现 |
| 卸载 / 入库完成 | 即时 | 行移除、计数与总重即时重算；完成后提示「本班次 N 件已全部入库」 | 不适用（无动画依赖） |

## 复现验收清单

- [ ] 1280 宽下顶梁 + 14 px 危险条纹带 + 左 400 px 月台 / 右队列两列，与「画布与区域布局」表尺寸一致。
- [ ] `:root` 的 11 个令牌色值（`#c9ccce`…`#3d7a3f`）逐字出现在 CSS 中，页面无外网资源。
- [ ] 初始队列为上述 3 件，重量、状态胶囊三种状态至少同屏可见「待装运」「已入库」。
- [ ] 拖入文件或点「开单选货」选择文件后，新行出现且顶梁「队列件数/总重」即时更新；「卸载」删除对应行（仅「待装运」行可点）。
- [ ] 点「开始处理」后逐件推进 8 px 高进度带直至全部「已入库」，期间按钮禁用、传送中行不可卸载。
- [ ] 队列清空后显示「月台空闲…」空态文案。
- [ ] 浏览器缩到 768 px：变单列且不出现横向滚动条；开启系统「减弱动态效果」后条纹不再循环位移。
