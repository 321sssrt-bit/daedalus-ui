# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-sterile-theater.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

不可回退的发布像一台手术：把页面清成无菌场地，只留一张单卡、一句后果、一次操作。冰蓝大留白压低心率，警示红仅圈住"无法回退"四个字，勾勾选加抄复核码的仪式借自医疗无菌核查——用流程摩擦换深思，用「启封/回执」的隐喻让责任落地留痕。

## 适用场景与目标用户

医院 HIS、金融清算、生产配置下发这类"一按生效、无法回退"的发布确认页；用户是手里握着全院/全厂生效权限的发布负责人，操作时往往已被日常流程磨掉警觉，需要被强制停一下。

## 非目标

不做多步骤向导或进度条；不做二次弹窗套娃（本页就是那"一次确认"）；不提供撤销、回滚能力（回执是记录，不是回退入口）；不用拟物医疗器械插画。

## 复刻提示词

医疗无菌风发布确认页：冰蓝 #dcecef 大留白场地中央一张 620 px 白单卡，卡顶一条斜纹「无菌封条」并明文印复核码；警示红 #bc3a2b 只用于一句不可回退后果与错误态；手术绿 #4a917c 给确认钮、勾选与成功印章；解锁条件=勾选复核声明+抄写封条复核码；确认后整卡换成居中印章回执。
