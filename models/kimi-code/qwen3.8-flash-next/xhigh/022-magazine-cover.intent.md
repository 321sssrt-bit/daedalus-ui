# 022 个人主页 profile

## 设计意图

个人主页的本质是「被记住的一个人」。把它做成一期杂志封面：人像影像打底、红色刊头压顶、大字主张横在画面正中，作品与动态顺势变成「本期目录」。取舍是牺牲信息密度与首屏可达性，换取第一眼的人格冲击；档案区再把信息密度找回来。

## 适用场景与目标用户

摄影师、设计师、写作者等创作者的个人站/作品集首页；访客是编辑、甲方与同行，来了只需要记住名字、一句话身份和一个入口。

## 非目标

不做博客流、无限信息流或后台管理界面；不用圆角卡片、渐变彩斑等通用 SaaS 视觉；不接真实社交平台的关注 API，关注只是本地状态。

## 复刻提示词

满版黑白城市影像上压一期个人杂志封面：刊头红 #d32f2f 的超粗无衬线大字名、右下角一枚旋转红圆章、左下白色大字主张、右侧竖排三条错落引题；下方米白页接档案条、四格作品与三条动态，全直角硬边印刷感。
