## 产品边界

单文件模拟一个桌面绘画工具的"调参—预览—导出"闭环：只做导出条件校验与结果回执的拟真，不做真实像素编码与文件落盘；画面是固定 SVG 场景 + 参数化滤镜，不做自由绘画。数据全部驻留页面内存，刷新即回种子状态。

## 状态地图

| 状态 | 进入方式 | 界面表现 |
| --- | --- | --- |
| 默认编辑态 | 打开页面 | 厚涂/颗粒开/透明关/PNG；预警条与结果卡隐藏；日志含 3 条种子 |
| 实时预览态 | 改动任何左栏参数 | 画框、回显、预警条同帧更新 |
| 冲突预警态 | 选 SVG+颗粒 或 JPG+透明 | `#fmtWarn` 红虚线条说明将被阻止的原因 |
| 导出进行态 | 无冲突时点导出 | 按钮禁用 0.7s，进度条铺满 |
| 导出成功态 | 进行态结束 | 绿结果卡（文件/尺寸/大小/状态）+ 绿 toast + ✓ 日志 |
| 导出被阻态 | 冲突时点导出 | 红卡 + shake + 修复按钮×2 + ✕ 日志 + 红 toast |
| 修复后待导态 | 点任一修复按钮 | 结果卡清空、设置已改、预警熄灭，可再次导出 |

## 正常流程

1. 打开页面 → 左栏默认参数下画框即时呈现《向海坡地》厚涂预览。
2. 调尺寸/色相/厚度/颗粒/透明/图层 → 中栏画框与底部回显实时反映改动。
3. 右栏确认 PNG → 点「导出作品」→ 进度条 0.7s → 绿结果卡显示 `向海坡地-v7_海报.png`、1200×1600、模拟大小、已写入本地；导出记录顶部新增 ✓ 行，toast 确认。

## 异常触发与恢复

- 触发：格式选 SVG，保持「画布颗粒」开启（或选 JPG 并开启「透明底」），点「导出作品」。
- 失败表现：红色冲突卡逐字指出冲突（矢量无法封装位图颗粒 / JPG 不支持透明通道），声明未生成任何文件且画面数据未被改动；导出记录 ✕ 置顶；红 toast；预警条此前已实时预告。
- 恢复：点红卡内「改用 PNG 导出」或「关闭画布颗粒」（JPG 场景为「改用 PNG 导出」/「关闭透明底」）→ 设置被一键改好、预警条熄灭 → 再点导出 → 走通成功闭环。

## 数据变化

- 每次成功/被阻导出各追加一条带时间戳的日志（✓ 或 ✕，✕ 注明未生成文件）。
- 修复按钮直接改写对应 state 并同步原生控件勾选态。
- 成功卡内大小随尺寸/格式/厚度/图层组合实时重算；页面刷新所有数据回退到种子 3 条日志。

## 人工验收步骤

正常闭环：① 默认参数点导出 → 进度条后出绿卡与 ✓ 日志；② 改横幅+impasto 再导出 → 卡内尺寸与大小变化；③ 开透明底选 PNG 导出 → 棋盘格预览下仍成功。
异常恢复：① 选 SVG（颗粒开）→ 预警条出现，点导出被阻（红卡+✕日志）；② 点「关闭画布颗粒」→ 预警熄灭；③ 再点导出 → 成功绿卡，闭环恢复。
