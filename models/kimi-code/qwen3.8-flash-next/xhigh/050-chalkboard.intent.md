# 050 在线课程练习 · chalkboard

## 意图元数据

- 意图版本：1
- 对应规范：`050-chalkboard.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把练习场景立在一块教室黑板上：墨绿板面、木框、粉笔字，让"做题"回到最朴素的课堂经验。核心取舍是让"错误"成为板书的一部分——答错的题像写错的粉笔字一样可以被擦掉重写，订正用另一支彩色粉笔标出，而不是刺眼的红叉判罪。这让"错了再答"成为流程内的正常动作，而非惩罚页。

## 适用场景与目标用户

面向 K12 与自学人群的课程配套练习页：用户在课时结束后就地做几道选择/填空题，答错后需要理解错在哪并重交。主要用户是学生（低压力、可反复）与授课教师（看订正轨迹）。不适合考试认证类场景——那里的视觉语言应该是严肃判卷，而不是可擦写的黑板。

## 非目标

- 不做游戏化积分、勋章、连击等激励皮肤。
- 不做真实账号、服务端判题与题库管理，题目与对错全部内嵌单文件。
- 不采用常见的"白卡片 + 蓝色按钮"在线课程模板，也不用红色大叉渲染失败。
- 不使用外网字体模拟手写体，中文一律走系统字体。

## 复刻提示词

一块教室黑板作为整页画布：墙面深橄榄 `#232a22`，黑板墨绿 `#2e4a3e` 带木质边框 `#8a6a42` 与 chalk 托盘；标题与正文用粉笔白 `#f2efe2`，轻微不均的透明度模拟粉笔颗粒。强调色是三支彩色粉笔：黄 `#f2d97a`（题号与当前步）、粉 `#f0a3b8`（错误与擦除提示）、浅蓝 `#a9c9e8`（讲解与链接）；订正后答案用浅绿 `#b6dc9c` 覆写，保留"先错过、后订正"的痕迹。答错不弹红屏，而是粉笔淡出加"擦掉重写"按钮，重交成功后整题转绿。中文文案、系统字体、内嵌 CSS/SVG，离线单文件运行。
