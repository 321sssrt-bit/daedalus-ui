# 025 账号设置 account

## 意图元数据

- 意图版本：1
- 对应规范：`025-dial-mech.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「账号设置」当作一枚精密机芯后盖来排布：枪灰金属壳压住整页，黄铜只给边框、当前值和可操作件，让视线沿刻度圈落进设置行。取舍是牺牲通用性换秩序感——行按钮直角、表冠带滚花，宁可"不像现代 SaaS"，也不滑回白卡列表。

## 适用场景与目标用户

面向高客单价、强"器具感"产品的账户中心：高端设备云、精密仪器订阅、会员制俱乐部后台。用户是长期持有者，设置低频但每条都重，值得一次有仪式感的展开与拨动。

## 非目标

不做扁平蓝紫 SaaS 皮肤；不做无限下拉的巨型设置搜索流；不引入外置字体与图标库；不用真实旋钮拖拽手势（步进钮已够验收）。

## 复刻提示词

精密钟表后盖式账号页：枪灰拉丝金属底、黄铜细边框、米白表盘圆点头像、刻度圈装饰；设置项是左侧带黄铜粗边的直角金属行，点开滑出详情——内含 SVG 旋钮（红线指针）、滚花表冠开关与表盘色盘；右侧独立 300px「状态柱」回显动力储备与偏差仪表。
