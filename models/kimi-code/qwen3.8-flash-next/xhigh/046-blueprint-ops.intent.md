# 046 设计意图 · blueprint-ops

## 意图元数据

- 意图版本：1
- 对应规范：`046-blueprint-ops.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

借"晒图纸"的蓝底白线美学做工程协同出图台：把抽象的权限体系翻译成有实体感的东西——每张任务卡盖一枚状态图签章，受限图签贴红斜纹与 RESTRICTED 戳。被拒绝不是弹窗报错，而是一件"手续没办齐、章盖不下去"的工程事件。

## 适用场景与目标用户

面向需要区分公开区与专业专有区的轻协同工具：设计院出图、工程变更单、法务/财务分组审批。用户是有明确角色边界的多角色团队——外来审图人能看到受限任务的存在，但动不了，且每次越界都被明说"为什么、缺什么、怎么办"。

## 非目标

不做真实 RBAC 后台、多人实时协作与冲突合并；不表现审批工作流的全套（多级会签、驳回、委托）；不追求移动端适配——蓝图网格与标题栏本来就是大图纸的隐喻，桌面才成立。

## 复刻提示词

晒图蓝 #0b2c4d 底上铺 96px+24px 双层白色细网格，全部圆角压到 3px，边框用蓝图白 #7fb4e0 的细线，图号与时间戳一律等宽字体。任务卡右上角盖 rotate(-6deg) 的等宽状态章（DRAFT/IN PROGRESS/IN REVIEW/ARCHIVED 各配蓝/黄/红/绿），受限卡另盖 rotate(6deg) 红色 RESTRICTED 斜章并铺 -45° 红斜纹底。权限拒绝时用整幅红边横幅说明缺哪项权限且未写入任何数据，恢复路径是"申请→批准→角色章转绿→斜纹消失"，让权限变化在页面上全程肉眼可见。
