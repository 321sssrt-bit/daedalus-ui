# 033 钱包首页（jade-tally 玉牌钱庄）

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`033-jade-tally.html`
- 复现范围：云岭钱庄钱包首页一个屏幕，含余额令牌卡、转出/收款入口、最近流水与底部四 tab 真切换；不含真实转账链路。
