# 013 收件箱 inbox

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`013-airmail-sort.html`
- 复现范围：航空邮件主题的桌面收件箱单页，含信札列表、格目过滤、读信区、星标与归档操作。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 px | 双栏 grid：428 px 列表 + 剩余宽度读信区，gap 22 px，容器 max-width 1216 px | 信封卡整宽堆叠；信笺内边距 30/36 px |
| 窄于 1024 px（含 768 px） | grid 收为单列，读信区移到列表下方 | 列表变自身滚动区 max-height 340 px；信笺内边距降为 24/22 px；顶栏自然换行不碎裂 |
| 宽于 1216 px | 容器锁 1216 px 居中，两侧留桌面底色 | 无组件变化 |

## 内容与数据

- 顶栏：品牌「鸿雁信箱」+ 副行「POSTE AÉRIENNE · 示例巷 * 号 · 第 3 分拣格」；右侧「9 月 7 日 · 午后班」与朱框「待拆 4 封」（数字红字、随操作实时减）。
- 初始 7 封信：4 封未读（01 沈昭底片、02 青芷印刷所二校样、04 许砚北船政笔记、06 灯塔书讯），2 封在架已读（03 停电通知、05 调阅回执），1 封初始已归档（07 装订完工）。字段顺序固定：未拆章 → 星标 → 寄达行 → 主题 → 寄件人 · 发信地 · 到信时间。
- 信笺 meta 行顺序：寄件人 → 发信地 → 到信时间；正文段落行高 2、两端对齐；停电通知含 3 条「◆」清单行。
- 数据可替换，但「待拆计数在打开信后必须减 1」这一行为必须保留。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 无入场动画 | 静态呈现桌面 + 航空条 | 不适用 |
| 悬停信封 / 星标 | 0.16–0.15 s ease | 信封上浮 2 px；星标放大 1.15 | 全部 transition 置为 none，悬停位移消失，状态仍由颜色区分 |
| 点选信封开拆 | 即时 | 红「未拆」章消失、待拆数减 1、toast「已拆封 1 封 · 待拆数已更新」 | toast 的 rise 动画取消，文字照常出现，2.2 s 后隐藏 |
| 星标 / 归档 | 即时 | toast 提示「已星标 / 已取消星标 / 已归档 / 已退回架上」；信笺右上归档章出现或消失 | 动画取消，提示与状态变化保留 |

## 复现验收清单

- [ ] 1280 px 下顶栏下方存在连续的红蓝 45° 斜条（红 #c0392b 与蓝 #2c5aa0 各 12 px 交替），左列表列宽为 428 px。
- [ ] 信封卡外圈为红蓝斜条、内圈为 #cbb18f 牛皮面；未读信带旋转 -4° 的红色「未拆」小框，初始待拆计数为 4。
- [ ] 点击任一未读信封：右栏读出主题、寄件人、发信地、到信时间与正文，该信未拆章消失，顶栏待拆数减 1。
- [ ] 点击信封右上角星标可在 ☆ 与 ★ 间切换，且「星标」格目签只显示已星标信；取消全部星标后该格目显示虚线空框文案。
- [ ] 点「归档此函」后信从「在架」消失、toast 出现，「已归档」签内可见该信且信笺右上有旋转 8° 的 #2c5aa0 蓝框章；点「退回架上」可还原。
- [ ] 格目 4 个签逐一点击均能过滤列表，选中签为 #cbb18f 实底。
- [ ] 窗口缩到 768 px 宽：双栏变单列，列表区内滚不撑破页面，无横向滚动条。
- [ ] 开启系统「减少动态效果」后悬停无位移、toast 无位移动画，但所有文字反馈仍可见。
