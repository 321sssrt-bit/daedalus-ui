# 031 发布确认

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`031-sterile-theater.html`
- 复现范围：桌面端「发布确认」单页——无菌封条单卡内呈现不可回退后果，勾选复核声明 + 输入封条复核码 4821 双条件解锁「确认发布」，成功后卡片切换为已发布回执态；「返回修改」退回草稿。

## 内容与数据

- 关键文案逐字保留：标题「将《临床操作手册》v3.2 发布至全院」；一句后果「发布后，v3.2 将立即推送给全院 1,240 名医护人员，现行 v3.1 同时下线且无法回退。」；警示行「此操作完成后不可撤回，旧版本立即停止分发…」；声明「我已逐项复核目录、剂量表与附录 B 的修订差异，确认可以对外生效。」
- 封条带三段：「无菌封条 STERILE SEAL」「批次 V3.2-0907」「复核码 4821」（复核码同时是解锁口令，明文印在封条上）。
- 事实三行顺序固定：更新摘要 / 生效范围 / 预计推送。
- 解锁条件：勾选声明 且 输入去空格后恰为 `4821`；回执文案「回执号 REL-20260907-0114 · 操作人 李某 · 2026-09-07 09:44」。
- 计数提示随缺项变化：「还差 2 项…」「还差 1 项…」「已解锁…」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面载入 | 无入场动画 | 静态呈现，封条斜纹常驻 | 不适用（本就没有入场动效） |
| 输入复核码 | 边框/光环过渡 0.15 s | 不符即红环红提示，相符即绿环绿提示，锁钮仍禁用直到勾选 | 过渡置 0，颜色即时切换 |
| 确认发布 / 返回修改 | 悬停过渡 0.15 s；确认后内容瞬时替换 | 卡片整体换为印章回执态；返回则清空表单并变「已退回草稿」 | 悬停颜色即时切换，状态替换不受影响 |

## 复现验收清单

- [ ] 1280 宽下 620 px 单卡水平居中、上方留白约 72 px，页面除状态条与单卡外无其他模块（极疏制度）。
- [ ] `:root` 十一个色值（`#dcecef`…`#d5e6e1`）逐字出现在 CSS；封条带可见斜纹且无外部图片。
- [ ] 初始「确认发布」为禁用灰态；只勾选或只输对复核码时仍禁用，且下方提示分别显示「还差 1/2 项」。
- [ ] 输入 `482` 之类的错码出现红环与「复核码与封条不符」；补全 `4821` 且勾选后按钮转绿可点。
- [ ] 点「确认发布」后卡片替换为居中印章、标题「v3.2 已发布，封条已启封」与回执号，状态胶囊变「已发布」。
- [ ] 点「返回修改」后勾选与输入被清空、按钮回到禁用、胶囊变「已退回草稿」。
- [ ] 768 px 下单卡不破版、主按钮变全宽；开启减弱动态效果后所有过渡立即切换无补间。
