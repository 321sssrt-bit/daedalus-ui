# 045 本地片库放映台

## 意图元数据

- 意图版本：1
- 对应规范：`045-cinema-black.spec.md`

## 设计意图

本地放映场景的第一诉求是"沉浸"：环境越暗，片库越像片场而非文件管理器。近黑底配丝绒红、古金把注意力压回影幕本身，金色只留给时码、进度与选中态这类关键信息，红色只做场次与直播等状态标记，避免彩色噪声。影院仪式感（场刊式列表、灯箱海报、放映指示灯）用极克制的装饰量换回情绪价值，代价是浅色环境与高密度表单场景不适用。

## 适用场景与目标用户

面向 NAS / 本地硬盘片库的桌面端放映台、媒体库首页或家庭影院中控页：用户是拥有本地片源、在大屏或暗光环境下选片观看的个人玩家与家庭共用场景。片单策展、午夜连映、观影聚会排片这类"有情绪诉求"的品类最贴合；办公媒资审核、白天明亮车间的终端不适合本方案。

## 非目标

- 刻意不用玻璃拟态、彩色渐变、插画人物与圆角大留白的"清爽 SaaS"套路——它们会破坏暗场沉浸。
- 不做真实视频解码、文件读取、网络流媒体与字幕引擎；片源、时码、播放进度全部为页面内置模拟数据。
- 不做账号体系、多用户权限与跨设备同步；队列与片单只在单页会话内生效。
- 不提供窄屏移动端布局，原型按桌面放映台单一尺寸设计。

## 复刻提示词

"做一个午夜影院气质的本地片库放映台：近黑背景（#101010 系）、丝绒红（#7a1f2b）做状态强调、古金（#cfa952）只用于时码/进度/选中态；左侧场刊式片单三列网格配灯箱海报，中央 16:9 影幕配放映指示红灯，右侧 300px 队列面板；系统字体、内嵌 CSS/SVG、无外链；连映队列可点播、可显示售罄外的全部正常/异常/恢复状态。"
