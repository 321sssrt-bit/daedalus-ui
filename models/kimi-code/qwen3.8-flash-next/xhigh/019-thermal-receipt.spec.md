# 019 购物车 cart

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`019-thermal-receipt.html`
- 复现范围：便利店在线购物车单页——整页是一张从出纸口吐出的热敏小票：条目行内加减数量、删除、空车态、小计/95折/应付合计实时重算、条码与去结算，不含支付页。

## 内容与数据

店头三行：「邻 家 便 利」/「NEIGHBOR MART · STORE #0117 · 示例市示例区演示路 ** 号 · 021-****-****」；机单信息：终端 03 · 店员 0826 · 会员 ****6521，开单 2026-09-06 19:42，在线小票 0117-260906-0431。初始 5 条（品名/单价/数量）：芝士饭团 金枪鱼蛋黄酱 110g ¥3.50×2、白桃气泡水 480ml ¥5.50×1、原味酸奶 205g×3 连杯 ¥12.90×1、佳农香蕉（按把）¥2.80×3、巴氏鲜牛乳 900ml ¥18.50×1。汇总公式：件数=Σ数量；小计=Σ单价×数量；应付=round(小计×0.95,2)，折扣=小计−应付；初始 8 件 / ¥52.30 / −¥2.62 / **¥49.68**，金额一律两位小数。页脚：谢谢惠顾 + 15 分钟退换与发票政策。

## 动效与反馈

## 复现验收清单

- [ ] 1280 宽下小票为 520px 居中窄长条，台面无横向滚动，小票底缘呈 18px 周期锯齿撕裂
- [ ] CSS 中出现 `#f4f2ee`、`#17181a`、`#c62828`、`#c9c5bc`、`#6b6862`、`#9b978e`、`#edeae2` 且各司其职
- [ ] 初始汇总为 8 件 / ¥52.30 / −¥2.62 / ¥49.68（红色 30px 大字）
- [ ] 把白桃气泡水从 1 加到 2：行小计 5.50→11.00、件数 9、小计 ¥57.80、折扣 −¥2.89、应付 ¥54.91 同帧变化
- [ ] 数量=1 的行「−」钮变灰不可点；点「✕ 删除」该行消失且汇总重算
- [ ] 删空后出现「小票已撕空」与补回钮，点补回恢复 5 条且金额回到初始值；空车时结算钮禁用
- [ ] 点击「去结算 ▸」后文案变「已锁单 · 请到 3 号窗口报取票号」并不可再点
