实现：会话列表与未读、进入群聊、输入（含快捷表情）、发送、送达/已读回执、已发消息编辑、失败消息保留+重试+改后重发、拼团卡片一次性登记、弱网故障注入开关、群友自动回复。不包含：真实网络与账号、图片/语音/红包消息、撤回与删除、群管理、搜索、通知角标持久化（刷新即重置为初始演示数据）。

## 正常流程

1. 选择会话：列表点「阳光花园 · 水果拼团 3 群」→ 切聊天屏，未读徽标清零，消息流滚到最新（张姐「接龙+1 ✅」）。
2. 输入消息：点输入框敲字或点快捷表情追加；输入非空时发送钮从灰禁用转珊瑚橙可用。
3. 发送消息：点「发送」/Enter → 消息立即以珊瑚橙气泡+「发送中」转圈上屏，输入框清空。
4. 看到送达状态：约 0.9 s 后转「已送达」+灰双勾；约 1.7 s 后转「已读 · 团长张姐」蓝字；随后群友先弹「正在输入」三跳点，再自动回一条并按轮换下一条回复。
5. 附加闭环：点自己已读气泡→「编辑这条」→输入框回填、钮变「保存」→ 保存后原气泡替换并标「已编辑」，toast 确认。

## 异常触发与恢复

- 触发：点聊天顶栏右侧「网络流畅」蓝胶囊 → 变红「弱网中」并弹提示条「下一条消息会发送失败（用于演示）」；此时发送的下一条消息在发送中约 0.9 s 后落为失败态。
- 失败保留：气泡转红虚线描边浅红底，文字一字不差保留，状态行「⚠ 发送失败 · 内容已保留」，旁挂「重试发送」红胶囊与「改一改」灰胶囊；toast 同步说明内容已保留。该消息不进入送达链，也不会被后续发送顶掉。
- 拦截：弱网未关直接点「重试发送」→ 不发请求，toast 提示先关开关，弱网胶囊左右抖 0.4 s 指出入口。
- 恢复：再点红胶囊回「网络流畅」→ 点该气泡旁「重试发送」→ 同一气泡回「发送中」→ 约 0.9 s「已送达」→「已读」，红虚线样式移除；或点「改一改」回填原文编辑，保存即按新文本重发并走通同一成功链（气泡标「已编辑」）。

## 数据变化

- 打开会话：该群 unread 4/2/0 → 0；返回列表预览行改为最后一条消息摘要（「我：…」/「群名：…」）、时间同步。
- 发送：该群 msgs +1（status sending→delivered→read）、群 time 更新；自动回复再 +1，replyIdx 按群 0→1→2… 对回复池取模。
- 编辑保存：原消息就地改 text 且 edited=true，不新增记录；失败消息编辑保存时 status 重置为 sending 重走链路。
- 失败时：消息文本、id、时间一律保留，仅 status=failed；重试/改发均在原对象上进行，不复制、不丢失、不重复上屏。
- 拼团登记：每群 joined 一次性置真，进度 93.75%→100%，计数 15/16→16/16，二次点击无效。

## 人工验收步骤

正常闭环：
1. 打开页面 → 见 3 个会话、置顶签与未读 4。
2. 点「阳光花园 · 水果拼团 3 群」→ 进群，消息滚底，徽标清零。
3. 输入「帮我留一组，微信支付 ✅」（或点 🍑 表情追加）→ 发送钮转橙。
4. 点「发送」→ 珊瑚橙气泡「发送中」转圈 → 0.9 s「已送达」→ 1.7 s「已读 · 团长张姐」。
5. 等约 2.5 s → 「团长张姐 正在输入」三跳点 → 自动回复「收到！给你留一组 🍑」。
6. 点自己那条已读气泡 → 「编辑这条」→ 改文本 → 「保存」→ 原气泡更新并带「已编辑」。
7. 点卡片「我要补位」→ 进度满格转绿「16/16 已成团 🎉」、按钮「已登记 ✓」。
8. 点返回 → 列表预览变「我：帮我留一组…」且未读消失；换点「城东冷库 · 售后群」→ 渲染冻虾售后记录。

异常恢复：
1. 点右上「网络流畅」→ 变红「弱网中」+红虚线提示条。
2. 发送「再帮我带一组青菜」→ 发送中后转红虚线「发送失败 · 内容已保留」，内容仍在。
3. 直接点「重试发送」→ toast 拦截、胶囊抖动，消息仍保留。
4. 点红胶囊关弱网 → 再点「重试发送」→ 同一条气泡发送中→已送达→已读，虚线红框消失。
5. （分支）再犯一次弱网失败后点「改一改」→ 回填编辑 → 「保存」→ 新文本重发成功并标「已编辑」。
