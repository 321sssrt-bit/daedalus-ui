## 内容与数据

单据抬头：三角惊叹牌黄底黑图 + 「权限申请单」，右侧单据号「PERMIT-0922」、签发「铆钉工场安管科」。申请条：「铆钉工场」网页版申请执行「排产图纸导出」，需 3 项权限，提示可撤回。三项权限固定字段顺序与要点：摄像头（chip「仅拍照」，单次抓拍、不录视频、画面不出本机）；选定文件夹的读写（chip「范围受限」，仅用户亲手指定的「图纸导出」文件夹，写 PDF 与 DXF）；局域网设备发现（chip「出厂 Needed」，只读设备名与型号，找到 3 号激光切割打印机）。脚注「安管科留痕」：批复写入审计流水、可撤销。批复文案各含本机时间戳（HH:MM:SS）；驳回态必须写明「不批准也能用：网页端仍可查看图纸，只是无法导出」。
