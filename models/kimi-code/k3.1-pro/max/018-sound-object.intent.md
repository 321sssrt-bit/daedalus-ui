# 018 商品详情

## 意图元数据

- 意图版本：1
- 对应规范：`018-sound-object.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用石墨哑光背景承托巨大产品结构，以酸性黄只标记选择和行动。技术参数紧贴购买决策，金属与织物选择直接改变图形，让高端感来自工艺细节而非装饰。

## 适用场景与目标用户

适合旗舰头戴耳机、高保真音响和精密消费电子的官方商品页。面向已了解基础参数、正在比较饰面与佩戴材质，并希望确认试听、保修和交付条件的购买者。

## 非目标

不做潮玩式炫光、持续旋转的伪 3D 或夸张促销；不堆砌无关配件推荐，不隐藏价格条件，也不把商品详情扩展成完整支付与物流结算页。

## 复刻提示词

设计石墨哑光与酸性黄的高端耳机详情页，左侧占满视野的精细 SVG 头戴耳机带金属渐变和声学网孔，右侧紧凑排列型号、价格、饰面和耳罩选择，选项真实改变产品，主按钮醒目，工业排版克制精准。
