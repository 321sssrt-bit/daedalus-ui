# 040 等候

## 意图元数据

- 意图版本：1
- 对应规范：`040-bakery-wait.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用奶油纸色、焦橙和深棕烤炉，把等待转成面包正在变香的现场感。拱形炉窗与四步进度回答“做到哪了”，预计时间与放到一边则减少反复刷新的焦虑。

## 适用场景与目标用户

适合现烤烘焙、咖啡轻食和到店自取消遣订单；目标用户是下单后暂时离开店铺、需要知道取餐时间并能随时回看进度的顾客。

## 非目标

不采用物流地图、骑手轨迹或冷色加载转圈；不实现真实计时同步、支付退款、商品选购与门店定位，时间和订单均为固定示例，取消结果用于演示页面状态。

## 复刻提示词

设计一款中文手作烘焙店手机订单等候页，奶油纸底、焦橙操作、深棕拱形烤炉，炉窗里有金黄面包和细微热浪；宋体标题搭配大号预计时间，四步进度清晰，底部可放到一边或取消，取消先弹出退款确认。
