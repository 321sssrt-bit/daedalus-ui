# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-drop-lab.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把上传从普通文件框变成实验进样：浅灰网格台面、青色扫描线和石墨协议面板明确区分样本与参数，让校验、处理和结果像一条可追踪的实验流程。

## 适用场景与目标用户

适用于光谱分析、环境检测和科研数据处理软件的批次导入台，主要服务需要连续提交多份样本并核对协议与处理状态的实验员和研究助理。

## 非目标

不做云盘、相册或消费电子风上传卡片；不包含真实光谱算法、后台任务持久化、多人协作和原始文件上传，处理仅用于展示可操作的批次状态。

## 复刻提示词

设计中文科研文件上传台：浅灰工作面、青色扫描托盘 SVG、石墨协议面板、Consolas 实验编号。上方三步流程，中间密集文件队列和运行日志，右侧协议开关与青色开始按钮。文件有大小、校验、逐行进度和删除，完成后给出可下载摘要。
