# 003 邀请进入

## 意图元数据

- 意图版本：1
- 对应规范：`003-orbit-pass.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用径向轨道把“核对邀请”变成对接程序，中央舱只保留一个关键任务；电光绿表达许可，失败则转为清晰的红色诊断，让稀缺感不牺牲可修正性。

## 适用场景与目标用户

适合邀请制科研协作空间、封闭测试社区或会员制线上观测站的首访入口，面向已经收到成员邀请、需要快速确认席位与访问范围的桌面用户，也兼顾窄屏核对。

## 非目标

不采用星球照片、蓝紫霓虹玻璃拟态或游戏化技能面板；不提供公开注册、邀请码购买、真实权限鉴权和多人聊天，遥测数据仅用于建立本站情境。

## 复刻提示词

制作炭黑太空舱与电光绿的邀请进入页：中心为多层旋转轨道和方正邀请码核对舱，左侧简短准入说明，右侧细密遥测；等宽大码输入、明显红色失败反馈、绿色许可成功与对接完成，克制而精密。
