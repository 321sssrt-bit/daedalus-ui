# 011 数据看板

## 意图元数据

- 意图版本：1
- 对应规范：`011-tide-analytics.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以深海观测仪器取代通用 BI 卡片，让磷光曲线成为视觉中心；数字、警戒线和站点剖面围绕同一读数任务组织，兼顾值守扫读与精确核查。

## 适用场景与目标用户

用于海岸环境监测平台、港口潮位值守屏和科研浮标数据后台。主要用户是需要快速判断潮位变化、核对传感器状态并导出观测序列的海洋观测员与港务调度员。

## 非目标

不采用明亮通用仪表盘、彩色装饰饼图或营销式大数字；不做多站点地图、告警规则配置、用户管理和复杂报表设计器，也不把实时状态伪装成可编辑数据。

## 复刻提示词

设计一套深海暗底的中文潮位观测台：左侧窄仪器导航，上方四枚单色关键数字，中央一张带科学网格、虚线比较序列与橙色警戒线的青色磷光 SVG 趋势图，右侧放仪表和潮次；使用等宽数字、细微边线、低亮深青材质，可切换日／周／月并检查数据点。
