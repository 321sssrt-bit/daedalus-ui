# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-seed-list.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把空清单处理成一张等待播种的园艺手帖，用暖沙、陶土和不对称叶片曲线消除“没有数据”的失落感。插画传达可能性，主按钮直接给出低门槛的第一步。

## 适用场景与目标用户

适合家庭园艺、阳台种植和植物养护记录应用；目标用户是第一次建立种植计划、需要选种建议与轻量提醒的城市新手园丁。

## 非目标

不采用工业仪表盘、冷色数据空态或通用纸箱插图；不包含电商购买、植物识别、复杂日历和真实定位天气，时令内容仅作固定的播种建议示例。

## 复刻提示词

设计一款中文家庭园艺 App 的种植清单空态，暖沙纸面、深叶片绿、陶土色点缀，中央是手绘种子袋、陶盆与幼苗组成的有机 SVG；圆润但不对称的按钮与卡片，底部三栏导航，空态文案温和具体，点击可真实添加第一株植物。
