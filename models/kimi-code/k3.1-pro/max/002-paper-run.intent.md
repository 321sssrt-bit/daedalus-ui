# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-paper-run.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把注册处理成寄往编辑部的一张登记纸：大号期号、红色批注与竖向流程强调出版秩序，双列底线表单减少填写压力，让“被编辑认真阅读”成为核心承诺。

## 适用场景与目标用户

适合独立杂志、地方文化刊物和非虚构内容平台招募通讯员或撰稿人；主要服务第一次建立供稿关系、需要明确资料用途和人工核对周期的城市观察者与乡土记录者。

## 非目标

不使用插画头像墙、渐变科技背景或社交账号一键注册；不延伸至投稿编辑器、稿费结算、真实邮件发送与账号鉴权，也不在首屏加入长篇平台介绍。

## 复刻提示词

做一张暖白纸张与珊瑚红批注构成的中文杂志通讯员注册页：左侧巨大 047 期号、折叠报纸线稿和三步编辑流程，右侧直角登记纸内是双列底线表单、选题标签与印刷式提交按钮，带真实收讫回执。
