# 005 找回密码

## 意图元数据

- 意图版本：1
- 对应规范：`005-signal-post.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把找回密码设计成一封可追踪的邮政专递，用票据、邮票和投递路线缓解账号受阻时的焦虑。等待时间与下一步始终可见，兼顾复古个性和安全流程的确定感。

## 适用场景与目标用户

适合文化阅读、独立邮箱或会员制内容产品的桌面账号恢复入口，面向已经注册但暂时无法登录、希望明确知道邮件去向与等待时间的用户。

## 非目标

不模拟真实邮件或短信服务，不要求用户填写原密码；不采用通用居中浅色卡片、科技渐变或玻璃拟态，也不把密码重置、新账号注册和完整账户中心塞进本页。

## 复刻提示词

设计一页中文“信号邮局”密码寻回界面：浅邮蓝网格背景、暖白直角票据、朱红邮票与硬边投影，三栏分别为信鸽路线插画、密码寻回表单、投递步骤；实现邮箱／手机切换、内联错误、60 秒等待与重发、更换地址及返回登录，保持印刷品质和清晰状态反馈。
