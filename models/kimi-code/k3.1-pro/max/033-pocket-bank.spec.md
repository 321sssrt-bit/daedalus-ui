# 033 钱包首页

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px

## 内容与数据

- 首页品牌为“青桔零钱”，初始可用余额 `¥2,846.30`，昨日收益 `+0.14 元`；快捷入口顺序为“转出”“收款”。
- 初始流水依次为晨光咖啡 `−18.00`、林小满转入 `+120.00`、城市地铁 `−4.00`、笔笔攒 `−6.00`、联华超市 `−86.50`、周野的红包 `+66.00`；首页只显示前四笔。
- 账单初始支出合计 `114.50`、收入合计 `186.00`；全部/支出/收入筛选会改变可见列表，合计保留全月口径。
- 转出默认选择林小满，也可选择周野或妈妈；金额必须大于 0 且不超过余额，按分四舍五入。成功后余额扣减，新的“转给××”记录以“刚刚”插入首位，支出合计同步增加。
- 超余额错误必须显示“余额不足，最多可转出 ¥…”，非正数显示“请输入大于 0 元的转出金额”；不使用 alert。
- 收款 sheet 包含许青禾的收款码图案和账号 `QJ 2025 0826`；复制成功或不可用时都在产品内反馈，后者显示可手动记录的账号。
- 底部导航为“零钱 / 账单 / 权益 / 我的”。权益含笔笔攒累计 `128.60` 与自动存 3 元开关；个人页含许青禾、余额显示开关、收款账号与安全限额。

## 复现验收清单

- [ ] 390 × 844 px 下为暖黄余额区、墨色硬边、最近流水与四栏底导航；宽屏时应用置于 `404px` 宽手机框内。
- [ ] 首页初始余额为 `¥2,846.30`，至少显示四笔具体流水，转出与收款入口均位于余额下方。
- [ ] 点击小眼睛会隐藏金额，个人页“首页显示余额”开关同步；再次操作可恢复。
- [ ] 点击流水可展开账户、分类和流水号；底部“账单”可用全部/支出/收入筛选并显示正确初始合计。
- [ ] 输入超过余额的金额会出现具体错误；改为合法金额后转出成功，余额、首页流水和账单支出同步更新。
- [ ] 收款入口打开包含收款码和 `QJ 2025 0826` 的 sheet；四栏导航均切换真实内容而非空占位。
- [ ] 768px 宽时隐藏桌面便签并居中手机框，没有横向滚动；390px 时外框消失。
- [ ] 开启减少动态后 sheet 和开关不播放过渡，金额校验、转账、筛选与文字反馈仍有效。
