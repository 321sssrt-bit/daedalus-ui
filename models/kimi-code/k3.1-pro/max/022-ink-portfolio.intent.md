# 022 个人主页

## 意图元数据

- 意图版本：1
- 对应规范：`022-ink-portfolio.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把主页做成可徐徐展开的手卷，用大号姓名、原画式 SVG 与朱砂印章建立作者辨识度；作品优先于社交数据，关注与约稿保持克制。

## 适用场景与目标用户

适用于独立插画师、水墨艺术家和视觉创作者的个人官网，方便出版编辑、文化机构与品牌美术指导集中查看风格、近作和约稿信息，也让普通访客能直接关注作者。

## 非目标

不做图片瀑布流、电商店铺、在线画板或完整社交动态；不采用霓虹渐变、玻璃拟态、头像矩阵和通用作品卡片。长卷展示五件代表作品，不声称具备作品购买或真实邮件发送能力。

## 复刻提示词

设计宣纸白底的中文独立插画师主页：水墨黑大姓名与朱砂印章，克制的创作档案，五幅精致原创 SVG 山水、白鹤、市集、松月和花枝组成横向手卷，配墨色关注按钮与约稿弹层。
