# 036 编辑发布

## 规范元数据

- 规范版本：2
- 主视口：390 × 844 px
- 对应页面：`036-street-zine.html`
- 复现范围：复现宽屏手机框内的街头小报编辑器，以及实时计数、栏目选择、存草稿、校验、发布回执和再写一篇。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 | 390 × 844 px 时手机为 390 × 844 px 全屏，画布内边距归 0 | 编辑区独立纵向滚动，刊头与发布栏固定可见；无横向页面滚动 |
| 宽屏展示 | 1280 × 800 px 时手机为 390 × 760 px，20px 画布内边距；左右装饰文案可见 | 编辑区独立纵向滚动，刊头与发布栏固定可见；无横向页面滚动 |
| 宽屏断点 | 视口宽度不足 900px 时隐藏两侧装饰，仅保留居中手机 | 不改动编辑器字段顺序和操作 |
| 窄屏断点 | 宽度不超过 430px 时画布内边距归 0，手机为 100% × 100dvh | 去除 3px 外框、28px 圆角和硬阴影，变为全屏移动布局 |
| 低高度断点 | 宽于 430px 且高度不超过 680px 时画布内边距 12px，手机高度为 `100dvh - 24px` | 编辑区继续内部滚动，底栏不挤压主按钮 |

## 内容与数据

- 固定品牌顺序为“巷口 / 街头小报 / STREET ZINE”；刊期为“VOL.08 / 城市观察”。
- 初始标题为“天台上种花的人，把风留住了”，署名“文 / 阿黎　摄 / 北野”，默认栏目“人物”；标题最多 32 字，正文最多 600 字。
- 正文以两段真实街访文字开场，保留“老城的天台总比地图多一层”这一首句；插图说明为“图 01 / 城市上空，另有一种生活”。
- 标题计数采用 `已输入字符数 / 32`，正文采用 `已输入字符数 / 600`；底部总字数排除空白字符，输入时同步更新。
- 初始状态为“未保存”和“有修改，尚未存草稿”；存草稿后显示当前 `HH:mm`，发布成功后显示“已发布”。发布稿号固定为 `AL-008-026`。
- 标题为空、正文为空或两者皆空时分别给出具体错误并聚焦缺失字段；草稿允许只含标题或正文，两者都空时不可保存。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 发布回执进入 | 280ms，`cubic-bezier(.2,.8,.2,1)` | 弹层由屏幕底部移入；遮罩直接出现，焦点移至“返回编辑” | 动画时长压至 0.01ms，直接呈现最终位置 |
| 存草稿 | 状态即时更新；提示 2600ms 后隐藏 | 显示“草稿已存好，灵感不会丢。”，刊头标记与保存时间同步改变 | 不依赖动画；保留文字反馈与计时隐藏 |
| 栏目与发布 | 点击反馈即时；送印等待 650ms | 栏目切换黑底选中态；发布时主按钮禁用，成功后显示含真实标题的回执 | 保留状态切换，取消非必要过渡 |

## 复现验收清单

- [ ] 在 1280 × 800 px 下测得手机外框为 390 × 760 px，且页面没有横向滚动。
- [ ] 刊头、编辑区、发布底栏的纵向关系正确，滚动正文时刊头与发布按钮不离开手机框。
- [ ] 修改标题或正文后，三处字数显示即时更新，并出现未保存状态。
- [ ] 选择“街头 / 人物 / 散步”之一会出现黑底红影选中态，且可用键盘操作。
- [ ] 清空标题后点击发布，不打开成功弹层，而是显示红边字段与具体错误。
- [ ] 点击“存草稿”后出现保存时间与成功提示；点击发布后 650ms 出现带真实标题和稿号的回执。
- [ ] 在发布回执选择“再写一篇”，两个字段清空、栏目回到人物、焦点进入标题。
- [ ] 在 390 × 844 px 下外框变为全屏，在 768px 宽下无装饰重叠或布局破裂。
- [ ] 开启减少动态后，发布弹层不做可见位移动画，但全部操作与文字反馈仍可用。
