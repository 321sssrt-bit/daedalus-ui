## 内容与数据

- 品牌为“芽动”，主标题“把每一次活动，养成一片绿。”，核心区域依次为今日进度、记一次活动、七日生长趋势、最近记录。
- 初始目标 60 分钟；今日 28 分钟、3.2 公里、3 条记录，完成 47%，还差 32 分钟；距离以十分之一公里的整数保存，分钟使用整数。
- 初始七天分钟依次为 `32、45、20、55、38、50、28`，日均 38.3；最后一天与今日分钟共享状态。
- 初始三条记录依次为今天 12:10 步行 16 分钟 / 2.2 公里、今天 07:40 步行 12 分钟 / 1.0 公里、昨天 18:20 跑步 45 分钟 / 5.6 公里。
- 活动类型为步行、跑步、骑行；默认步行。时长只接受 1–240 的整数分钟；距离只接受 0.1–50.0 且最多一位小数。输入旁常驻合理范围。
- “填入 300 分钟与 0 公里”只改变输入值；用户再点击“保存活动并重算”才执行校验。无效时定位到具体字段，保存按钮不会假装成功。
- 有效保存后新增记录 ID 为 `activity-N`，显示当前本地 `HH:mm`；今日分钟与距离累加，第七根趋势柱同步，历史顶部出现新记录，日均按七天总和 / 7 重新计算。
- 数据仅存于本页会话，刷新恢复初始值，不声称云端或刷新后持久保存。

## 产品边界

实现单页健康活动记录：查看今日分钟目标与距离、选择活动类型、输入时长与距离、校验、保存、更新目标进度、七日柱状趋势、日均和最近活动历史；提供明确的超范围数据演练和修正恢复。

不包含真实传感器、GPS、心率、卡路里、账号、云同步、刷新后持久化、社交竞赛、饮食睡眠、医疗建议或跨日目标编辑。所有数据为可操作的本地演示。

## 正常流程

1. 在初始页确认今日 28 分钟和 3 条记录，点击“记活动”或直接滚动到表单。
2. 选择步行、跑步或骑行，保持默认时长 18 分钟、距离 1.6 公里，或输入其他合法值。
3. 点击“保存活动并重算”；校验通过后新增一条当前时间记录。
4. 今日分钟变为 46，距离变为 4.8 公里，记录数变为 4，圆环显示 77%，剩余 14 分钟。
5. 第七根柱由 28 变为 46，周均从 38.3 变为 40.9；历史顶部显示刚保存的类型、18 分钟和 1.6 公里。
6. 可再次输入合法活动并保存，所有数字继续累加，证明流程可重复。

## 异常触发与恢复

1. 点击“填入 300 分钟与 0 公里”，输入值改变但今日数据尚未变化。
2. 点击“保存活动并重算”；时长报“当前为 300 分钟，合理范围是 1–240 分钟”，距离报合理范围为 0.1–50.0 公里。
3. 错误汇总明确原进度仍为 28 分钟、3.2 公里，3 条记录与七日趋势未改；没有新增记录或成功提示。
4. 将时长改为 12、距离改为 0.8，再次保存；字段错误清除。
5. 成功后今日为 40 分钟、4.0 公里、4 条记录，完成 67%，第七柱为 40，周均为 40.0；历史顶部出现 12 分钟 / 0.8 公里新记录。
6. 若从正常流程后继续异常，则失败保留当时的 46 分钟、4.8 公里和 4 条记录，恢复成功在其基础上继续累加，不恢复出厂值。

## 数据变化

| 操作 | 今日与趋势 | 记录与反馈 | 不变量 |
| --- | --- | --- | --- |
| 编辑 / 填入无效示例 | 不变 | 仅输入值与选中态改变 | 不提前保存或重算 |
| 无效保存 | 今日分钟、距离、七柱、周均全部不变 | 不新增记录，不增加序号；显示错误 | 失败不得覆盖已有成功数据，不得重置表单以外的状态 |
| 合法保存 | 分钟与距离累加，第七柱同步，周均重算 | 记录顶部新增唯一 ID，序号 +1，显示成功 | 记录内容、图表和进度来自同一次提交 |
| 连续保存 | 在前次结果上继续累加 | 每次新增一条，可超过 60 分钟目标 | 不重复复用 ID，不把超目标百分比截断显示 |
| 刷新 | 恢复演示初始数据 | 清空本页新增记录 | 不属于持久保存承诺 |

## 人工验收步骤

### A. 正常记录与重算

1. 打开页面，核对初始 28 分钟、3.2 公里、3 条记录、47% 和日均 38.3。
2. 选择“步行”，保持 18 分钟与 1.6 公里，点击“保存活动并重算”。
3. 确认出现成功面板，今日变为 46 分钟、4.8 公里、4 条记录、77%，剩余 14 分钟。
4. 滚动到趋势，确认今天柱为 46、周均为 40.9；历史顶部为步行 18 分钟、1.6 公里及当前时间。
5. 再保存一次合法活动，确认记录数与进度继续增加而非覆盖前一条。

### B. 无效数据拦截与修正恢复

1. 重新打开页面恢复初始值，点击“填入 300 分钟与 0 公里”，再点击保存。
2. 确认两个字段均有具体错误，错误汇总明确 28 分钟、3.2 公里、3 条记录和趋势未变；页面没有成功记录。
3. 核对七柱最后值仍为 28、周均仍为 38.3，今日圆环仍为 47%。
4. 将时长改为 12、距离改为 0.8，再次保存。
5. 确认今日变为 40 分钟、4.0 公里、4 条记录、67%，今天柱为 40、周均为 40.0，历史出现 12 分钟 / 0.8 公里。
6. 点击底部“今日”“趋势”导航，确认只定位到同一 HTML 的相应区域，失败与成功状态没有依赖外部页面。
