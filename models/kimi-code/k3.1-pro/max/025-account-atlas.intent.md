# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-account-atlas.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把账号页做成出发前的装备清单，用森林绿侧栏、浅地形线和清晰的当前值建立可靠感；详情集中到右侧抽屉，避免长设置页反复跳转。

## 适用场景与目标用户

适用于徒步、露营、越野跑和路线记录产品的桌面账号中心，服务需要维护公开资料、管理位置共享与离线地图，并在出行前检查天气及邮件提醒的户外用户。

## 非目标

不做路线规划、活动报名、密码修改全流程或真实云同步；不采用通用蓝色 SaaS 仪表盘、过度玻璃拟态和层层嵌套开关。设置仅保留页面内状态，不包含账号注销或设备远程控制。

## 复刻提示词

设计森林绿与浅地形线的中文户外账号设置页：深色窄侧栏带下次徒步行程，右侧身份行与三组六项清晰设置，点击任意行打开右侧图纸感详情抽屉，使用鼠尾草绿选中态、金黄色焦点和保存反馈。
