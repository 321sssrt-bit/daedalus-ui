# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-launch-seal.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以档案颁布仪式替代常见警告弹窗，让羊皮纸、皇家蓝流程与封蜡印共同传达正式感；把不可逆后果和核对声明放在同一视线内，庄重但不制造删除恐慌。

## 适用场景与目标用户

适用于企业知识库、制度手册或产品文档的正式版本发布。主要使用者是需要对可见范围和发布记录负责的内容主理人、文档管理员与团队负责人，通常发生在多人会签完成后的最后颁布环节。

## 非目标

不做通用删除确认、不采用居中白色小模态框，也不提供版本撤回、定时发布、成员权限编辑或完整文档阅读器。仪式感应服务于核对，不扩展为复杂审批流。

## 复刻提示词

设计一张中文企业知识库“正式颁布”桌面页：皇家蓝侧栏记录三步流程，羊皮纸主区是一纸版本发布文书，右侧有精细封蜡 SVG 印鉴；一句明确后果、必须勾选才能用印，返回保留草稿，成功后生成带红印的正式回执，整体像当代数字档案署。
