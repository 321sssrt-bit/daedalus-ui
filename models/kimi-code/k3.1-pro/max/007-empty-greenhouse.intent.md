# 007 欢迎空态

## 意图元数据

- 意图版本：1
- 对应规范：`007-empty-greenhouse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把空态画成晨光中的真实温室，而不是缺数据的报错。宋体大标题与细线苗床让人放慢节奏，主次行动分别照顾立即播种和先学习的人。

## 适用场景与目标用户

适合家庭园艺记录、阳台种植管理或小型温室照料产品的首次使用。主要用户是刚开始种叶菜、香草的城市种植者，他们可能还没有种子，也不熟悉苗床、发芽周期和间苗等概念。

## 非目标

不做电商导购、社区内容流或复杂物联网监控；不用夸张插画、奖杯和空泛“暂无数据”代替可执行的起步路径，也不把首屏塞满种植课程。

## 复刻提示词

设计一款象牙白与植物绿的中文温室欢迎空态：宋体大标题居左，晨光玻璃温室和三张透视空苗床 SVG 居右，细线、土壤棕、少量嫩绿，主次双按钮清楚，底部三步引导像园艺手册般安静自然。
