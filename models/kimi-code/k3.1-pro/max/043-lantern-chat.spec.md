## 产品边界

本原型实现会话列表、进入与返回、未读清零、按会话保存草稿、文本消息发送、本地时间同步、发送／送达回执，以及当前会话的可重复网络失败演练和人工恢复重试。数据仅存在于本页运行期间。

不包含真实账号、服务器或网络请求、通知推送、消息持久化、联系人管理、群成员管理、图片与附件、语音视频、消息删除／撤回、搜索和已读回执同步；不模拟修改其他会话的网络或历史消息。

## 状态地图

- **会话列表**：初始页；点击任一会话进入聊天，未读数即时清零。
- **聊天－连接正常**：显示双方历史、编辑器和“让下一条发送失败”；可返回列表。
- **聊天－演练待命**：点击演练按钮进入，显示“等待发送”和“已待命”；可点击“取消本次演练”返回正常。
- **聊天－发送中**：有效输入点击“寄出”或按 Enter 后，追加唯一 ID 的自己气泡；正常消息走向已送达，已待命消息走向失败。
- **聊天－失败且断线**：待发消息结算后进入；原文与 ID 不变，显示“发送失败”和禁用重试，演练区提供“恢复网络”。
- **聊天－已恢复待重试**：点击“恢复网络”进入；失败消息仍保留且重试可用，不清空、不自动重发。
- **聊天－重试发送中**：点击该气泡的“重试”进入；仅原消息状态改变，随后在同一气泡显示已送达。
- **提示反馈**：发送、失败、恢复、重试和送达均更新页面内文字，并由 `role="status"`／`aria-live="polite"` 提示；没有浏览器 alert 或独立弹窗页面。

## 正常流程

1. 在列表点击“沈青梧”：切换到同一会话页，显示原有五条消息，沈青梧未读从 `2` 变为 `0`，顶部总数从 `6` 变为 `4`。
2. 在“消息内容”输入“南窗见，我会带上那册书。”：寄出由禁用变启用，字数同步；点击“寄出”。
3. 当前会话末尾新增一条右側靛蓝气泡，内容完全一致，先显示“发送中…”；编辑器清空，列表时间更新为当前 `HH:mm`，最近消息显示“发送中 · 南窗见，我会带上那册书。”。
4. 约 `720ms` 后，同一气泡显示“已送达”，不新增第二条；返回列表可见“我：南窗见，我会带上那册书。”及相同时间。
5. 再次进入沈青梧可看到刚才的消息；输入“茶汤正好，路上见。”并发送，可重复看到发送中与已送达。

## 异常触发与恢复

1. 在任一聊天页点击“让下一条发送失败”：状态变为“等待发送”，说明变为“已待命：当前会话下一条发送将失败”。
2. 输入一段可辨识原文并点击“寄出”：只消耗一次待命，仍先追加原气泡并显示发送中；不会改动既有消息。
3. 约 `720ms` 后，该气泡在原位置显示“发送失败”，正文逐字保留，不能出现已送达；演练区显示断线，重试暂时禁用。
4. 点击“恢复网络”：仅清除当前会话断线状态，失败原文、ID、时间和气泡数量不变，重试变为可用。
5. 点击失败消息旁的“重试”：同一 ID 从失败变为发送中，约 `720ms` 后变为已送达；不得调用新增消息逻辑。
6. 再输入一条新消息并寄出，正常送达，证明恢复完成。之后可再次点击演练按钮，重复完整异常闭环。

## 数据变化

- 正常发送：目标会话 `messages.length + 1`，新增一个 `out-N`；状态路径仅为 `sending → delivered`。结算只修改该 ID 的 `status`，不再次追加。
- 失败发送：同样只在提交时追加一次，状态路径为 `sending → failed`；`text` 原字符串不变，`offline` 仅设为当前会话的 `true`。其他会话的 `messages`、未读数、草稿和演练字段不得改变。
- 恢复网络：只把当前会话 `offline` 改为 `false`、待命标记保持清除；失败消息仍为 `failed`，消息总数不变。
- 重试：目标消息必须仍为失败且属于当前会话；仅执行 `status = "sending"`、`attempts + 1`，随后原对象改为 `delivered`。消息 ID、正文、原始时间、数组位置和总数均不变，任何重试都不得生成新的 `out-N`。
- 重复点击或过期计时器不得重复结算：只有状态仍为 `sending` 的匹配 ID 才接受状态变化；非失败消息不能进入重试。
- 会话切换：发送函数捕获会话 ID 与消息 ID，计时器按两者查找目标；切换视图不改变这条归属。进入会话只把该会话未读清零，返回不重排消息。

## 人工验收步骤

### 正常发送闭环

1. 打开页面，确认列表有沈青梧、阿棠、南窗茶事、周聿怀四行；记下沈青梧的未读 `2` 和顶部未读 `6`。
2. 点击沈青梧，确认双方历史气泡、编辑器和网络演练均可见；点击返回，确认沈青梧变为已读、顶部变为 `4`。
3. 再点击沈青梧，在编辑器输入“南窗见，我会带上那册书。”，确认纯空白时寄出禁用、输入后启用。
4. 点击“寄出”，立即核对末尾只有一个新气泡、原文一致、状态为“发送中…”；确认编辑器已清空。
5. 等待约一秒，核对原气泡改显示“已送达”而非新增气泡；返回列表，核对最近消息和 `HH:mm` 时间已同步。
6. 再进入该会话，发送“茶汤正好，路上见。”，确认第二次正常闭环仍能完成。

### 失败、恢复与原消息重试

1. 在沈青梧聊天页点击“让下一条发送失败”，确认看到“等待发送 / 已待命”；如需验证取消，可再点“取消本次演练”，然后重新待命。
2. 输入“失败演练：银杏叶仍夹在原页。”并点击“寄出”，记下新气泡及正文；先看到发送中，随后看到发送失败。
3. 核对正文逐字保留、原气泡位置不变、没有已送达、没有第二个同文气泡；确认“重试”禁用且演练区出现“恢复网络”。
4. 返回列表再进入沈青梧，确认失败消息仍在；再打开阿棠，确认其五条历史、未读和消息内容未受失败影响，然后返回沈青梧。
5. 点击“恢复网络”，确认失败消息仍未消失、重试已启用；点击这条消息旁的“重试”。
6. 核对原气泡显示发送中后已送达，全文与 ID 不变、消息总数不变，不存在重复气泡或第二条重试副本。
7. 再发送“网络已恢复，稍后南窗见。”，确认正常送达；再执行一次“让下一条发送失败”，确认异常流程可重复触发。
