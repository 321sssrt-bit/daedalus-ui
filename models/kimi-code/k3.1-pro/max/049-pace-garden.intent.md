# 049 健康习惯产品

## 意图元数据

- 意图版本：1
- 对应规范：`049-pace-garden.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把健康记录做成一座会慢慢生长的花园，用桃色记录纸、深绿目标环和每日柱形刻度减轻打卡压力。异常不惩罚用户，清楚保留原进度，让修正和继续记录都更安心。

## 适用场景与目标用户

适合步行、跑步和骑行等轻量健康习惯产品，面向希望在通勤后快速记一次活动、查看今日目标与最近一周变化的移动端用户，尤其适合不喜欢复杂训练指标的人。

## 非目标

不提供医疗诊断、专业训练计划、卡路里或传感器采集；不采用红黑竞技仪表盘、排行榜焦虑、霓虹健身风，也不承诺云同步、刷新后保存或跨设备共享。

## 复刻提示词

设计“芽动”中文移动健康原型：奶油纸面、桃色表单、深绿目标环、嫩绿幼苗与珊瑚今日柱，配七日生长趋势和有机圆角；实现步行/跑步/骑行记录、分钟与距离合理范围校验，无效保存绝不改变旧进度，修正后同步重算目标、趋势、周均和历史。
