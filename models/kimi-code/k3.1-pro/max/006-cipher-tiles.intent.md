# 006 二次验证

## 意图元数据

- 意图版本：1
- 对应规范：`006-cipher-tiles.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用黑白硬边和钴蓝焦点传达安全核验的确定感；六格像机械密码锁，错误与锁定直接可见，避免安全页常见的柔弱卡片感。

## 适用场景与目标用户

适合设计资产库、企业网盘或开发者控制台在密码登录后进行二次确认。主要用户是已在工作设备上登录、需要快速读取短信并继续进入项目的团队成员，也照顾粘贴验证码和键盘输入习惯。

## 非目标

不采用圆润玻璃拟态、插画营销页或多余安全广告；不实现真实短信发送、生物识别、账号找回全流程和服务端风险策略，备用邮箱只呈现本地切换反馈。

## 复刻提示词

制作一张黑白粗野主义二次验证页：纸灰细网格背景，巨大中文短句与几何密码矩阵在左，钴蓝焦点和粗黑硬阴影验证面板在右，六个直角大输入格，等宽数字，倒计时、错误和锁定状态清晰，整体像精密机械票据。
