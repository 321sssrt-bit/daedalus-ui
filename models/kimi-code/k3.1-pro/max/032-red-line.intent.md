# 032 危险删除

## 意图元数据

- 意图版本：1
- 对应规范：`032-red-line.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用瑞士警示海报式的黑白硬边与唯一危险红，把删除整库从普通设置中隔离；先量化永久损失，再要求逐字确认，并让实心黑色取消始终压过红色删除。

## 适用场景与目标用户

适用于云平台、数据基础设施或企业内部运维控制台的生产数据库删除。面向具备高危权限的站点可靠性工程师、数据库管理员和技术负责人，使用情境是已停止写入后执行不可逆资源销毁。

## 非目标

不采用柔和圆角卡片、插画化空态或模糊的“确定吗”弹窗，不提供回收站、删除后恢复、备份下载和权限转移能力，也不把红色大按钮用作诱导性主操作。

## 复刻提示词

制作中文生产数据库危险删除页：极白方格画布、纯黑海报左栏、危险红斜线划去数据库 SVG，右侧逐项列出永久损失；直角硬阴影、等宽编号、逐字输入确认词才解锁，黑色取消大而醒目，红色删除克制且需最终模态再确认。
