# 045 音视频平台

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`045-frame-cinema.html`

## 产品边界

本原型实现六部本地模拟内容的发现与载入、播放／暂停、逐秒进度、拖动或键盘 seek、下一部、队列增删与排序、页内播放状态保存、主动网络中断及断点续播。它模拟音视频平台的状态与界面，不包含真实视频解码、声音、流媒体缓冲、账号、付费、搜索、评论、弹幕、下载、跨设备同步或刷新后恢复。

## 状态地图

| 状态 | 进入操作 | 关键可见状态与可离开操作 |
| --- | --- | --- |
| 初始暂停 | 打开页面 | 夜航西飞、00:00、3 部待播、网络正常；可播放、seek、切片或调队列 |
| 正常播放 | 点击“播放”或“开始放映” | 每秒加 1 秒，主按钮变“暂停”；可暂停、seek、下一部或模拟断网 |
| 暂停待命 | 点击“暂停”，或载入新片 | 计时器停止，当前位置不变；新片位置为 00:00；可继续播放 |
| 进度调整 | 拖动／键盘操作进度条 | 当前位置变为滑轨值并保存；若播放中且未到片尾则继续计时，拖到片尾会停止 |
| 队列变更／切换 | 上移、下移、移除、加入队列或点击“下一部” | 队列数量与顺序同步；下一部位置归 00:00，并保留切换前的播放／暂停模式 |
| 网络中断 | 点击“模拟网络中断” | 当前片名、精确断点与队列快照保留，播放暂停，相关操作禁用；仅能恢复或浏览页面 |
| 恢复续播 | 点击“重新连接并续播” | 恢复快照片名、位置和队列；若未到片尾则立即从断点继续计时，可再次调整与播放 |
| 片尾 | 位置达到当前片长 | 自动暂停并显示“重播／重新放映”；重播从 00:00 开始，下一部仍可用 |

以上均为同一 HTML 内的状态；断网层是唯一覆盖银幕的状态层，不跳转到其他页面。

## 正常流程

1. 在发现轨点击“城市呼吸”：停止旧计时器，当前片切换为“城市呼吸”，位置归 00:00，保持暂停；保存文案显示该片与 00:00。
2. 点击“播放”：状态变“正在放映”，只启动一个每秒计时器；例如 5 秒后显示 00:05，进度按 `5 / 442` 填充，保存文案记录开始播放时的片名与 00:00。
3. 点击“暂停”：停止计时器，保存当前位置；例如断点显示 00:05，再等待 3 秒仍为 00:05，保存文案显示“已暂停”。
4. 将进度调至 02:10（130 秒）：位置立即变为 130 秒，保存文案显示“《城市呼吸》 · 02:10 · 进度已调整，已暂停”。再次点击播放后，从 02:10 继续而不是归零。
5. 点击另一片目的“＋ 队列”，或在待播队列点击上移／下移／移除：队列立即更新，当前片与位置不被重置，保存文案记录队列动作和当前位置。
6. 点击“下一部”：队首成为当前片并移出队列，位置归 00:00；若切换前为播放中则自动继续，否则暂停待命。随后仍可播放、暂停和 seek，形成可反复操作的正常闭环。

## 异常触发与恢复

1. 正常播放时，例如“夜航西飞”位于 00:36，点击播放器内“模拟网络中断”。中断处理先记录当前片 id、整数秒位置和有序队列副本，再暂停并清除唯一计时器；保存文案显示该片、00:36 和“网络中断，已保留断点”。
2. 断网层显示“放映暂时中断”和人话说明，页头显示“网络已中断”；播放、进度、下一部、切片和队列调整禁用。等待任意时长，位置不得变化，当前内容不得切换，队列不得丢失或重排。
3. 点击“重新连接并续播”：从断网快照恢复同一部片、同一位置和同一队列；若断点小于片长，立即从该位置启动一个计时器。断点 00:36 恢复后的首帧仍为 00:36，约 3 秒后应为 00:39，不得从 00:00 开始。
4. 恢复后页头显示“已恢复 · 00:36 续播”，保存文案显示“网络已恢复，从断点续播”。用户可再次 seek、暂停、调队列或下一部，也可再次发起网络演练。

## 数据变化

| 操作 | 当前片与位置 | 播放／连接 | 队列 | 保存记录 |
| --- | --- | --- | --- | --- |
| 播放 | 片名与位置不变 | `playing: true`，启动一个计时器 | 不变 | 写入片名、当前位置、播放状态与“开始／继续播放” |
| 暂停 | 片名与位置不变 | `playing: false`，清除计时器 | 不变 | 写入暂停时的精确秒数 |
| 用户 seek | 位置设为滑轨整数秒，例如 130 秒 | 未到片尾则保留原播放模式；到片尾则暂停 | 不变 | 写入新位置和“进度已调整” |
| 载入新片 | 切换片名，位置归 0 | 暂停且清除旧计时器 | 移除队列中同名新片，其余顺序保留 | 写入新片、00:00 和“已载入” |
| 下一部 | 队首成为当前片，位置归 0 | 保留切换前播放模式，重建至多一个计时器 | 队首移除 | 写入新片与 00:00 |
| 断网 | 当前片、位置和队列先写入快照，随后不得隐式改变 | `online: false`、`playing: false`，清除计时器 | 断网期间锁定且完整保留 | 写入断点与“网络中断” |
| 恢复 | 从快照还原同片、同位置、同队列 | `online: true`；未到片尾则 `playing: true` | 与断网前逐项一致 | 写入断点与“从断点续播” |

核心不变量：任一时刻至多一个播放计时器；暂停或断网时位置不增长；断网快照的 `filmId`、`position` 和有序队列不丢失；恢复不得把非片尾断点重置为 0；片名、位置、队列、保存文案始终相互对应。

## 人工验收步骤

### 正常闭环：播放 → 调整 → 保存

1. 打开页面，确认当前为“夜航西飞”、00:00、已暂停，队列为 3 部；点击“播放”。
2. 等待约 5 秒，确认当前时间从 00:00 增长到例如 00:05；点击“暂停”，把实际暂停位置记为 T，再等待 3 秒，确认仍为 T。
3. 拖动进度条至 02:10（130 秒），确认时间码与填充同步，且可见“播放状态已保存 · 《夜航西飞》 · 02:10 · 进度已调整，已暂停”。

### 异常闭环：断网保留 → 恢复 → 再次操作

1. 回到“夜航西飞”，将进度设为 00:30，点击“播放”；等待约 6 秒，在例如 00:36 时点击“模拟网络中断”，以实际显示值为断点 T。
2. 确认出现“放映暂时中断”和“重新连接并续播”，保存文案含“《夜航西飞》 · 00:36 · 网络中断，已保留断点”（若实际断点不同则以 T 为准），队列仍为原数量。
3. 等待 4 秒，确认时间一直为 T；确认播放、进度、下一部、片目和队列按钮均禁用，不能偷偷前进或重置。
4. 点击“重新连接并续播”，确认断网层消失，首帧仍为 T，页头显示“已恢复 · T 续播”；等待 3 秒，确认时间约为 T + 3 秒而不是 00:03。
5. 点击“暂停”并确认保存；将进度调至 02:00，确认显示 02:00 与对应保存文案。再调整一次队列顺序，确认断点恢复后队列仍可用。
6. 再次点击“播放”并等待 2 秒，确认从 02:00 到约 02:02；再次执行断网与恢复，确认仍可重复保留和续播。
