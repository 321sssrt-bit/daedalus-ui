# 001 登录

## 意图元数据

- 意图版本：1
- 对应规范：`001-harbor-key.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以夜航海图和黄铜航标建立私人俱乐部的仪式感，把登录做成归港核验；大面积海图承载品牌想象，紧凑纸卡则让输入与错误反馈保持直接。

## 适用场景与目标用户

面向游艇会、滨水俱乐部或私人泊位的会员门户，适合已有账号的船主与会员在到港前查看泊位、确认预约并进入专属服务，尤其契合桌面端值守终端与家庭电脑。

## 非目标

不采用通用 SaaS 插画、明亮蓝紫渐变或大面积圆角玻璃卡；不实现真实鉴权、会员付费、船只登记和泊位修改，成功票据仅用于呈现本次入口流程的终点。

## 复刻提示词

设计深海军蓝与旧黄铜配色的私人港湾登录页：左侧为精细夜航海图、虚线航线和中文衬线大标题，右侧为紧凑米色会员核验卡；方正边角、细密坐标、真实错误与通行成功状态，整体安静、私密、像一本航海俱乐部手册。
