# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-mod-board.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把任务流动变成一张包豪斯工作桌：黄、蓝、红列头先传达状态，黑白卡片承载细节，几何图形帮助扫读而不替代文字，新建入口像明确的排版色块。

## 适用场景与目标用户

适合品牌设计、广告创意和独立出版团队管理短周期项目。主要用户是需要在印刷、影像、文案和采购任务之间频繁交接的设计师与项目统筹，使用情境是晨会调整和日常工作流推进。

## 非目标

不采用柔和 SaaS 蓝色卡片、渐变玻璃或大量图表；不做复杂甘特图、工时计费、依赖关系和多人实时协作，也不用仅靠颜色表达优先级或完成状态。

## 复刻提示词

制作一套包豪斯中文项目看板：暖白纸面，红黄蓝大色块与黑白硬边，四列几何列头，任务卡带圆方三角标记、清晰排版和偏移黑影，醒目蓝色新建按钮，支持拖放与详情编辑，像现代主义海报变成可用工具。
