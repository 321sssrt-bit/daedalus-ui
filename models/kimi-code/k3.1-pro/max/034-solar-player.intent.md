# 034 正在播放

## 意图元数据

- 意图版本：1
- 对应规范：`034-solar-player.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以深梅紫夜色托住日落橙，把唱片作为唯一视觉中心；标题、进度和控制沿拇指路径向下收束，营造回家路上戴耳机听独立音乐的私密沉浸感。

## 适用场景与目标用户

适用于华语独立音乐、氛围电台或编辑精选歌单的移动端正在播放页。主要用户是通勤、散步和夜间放松时希望快速暂停、拖动或切歌，又重视专辑氛围与曲目情绪的听众。

## 非目标

不做通用白色音乐卡片、视频播放器、歌词逐字滚动、评论社区或真实音频流媒体服务，不引入外部专辑图片；随机、循环与播放列表只服务于当前四首的轻量播放体验。

## 复刻提示词

制作深梅紫与日落橙的中文沉浸式手机播放器：大标题下是一张精细 SVG 黑胶，同心纹包裹日落群山标签，橙色圆播放键和细进度线，五键控制与底部下一首；带真实计时、切歌和队列，像一张为黄昏 pressed 的独立唱片。
