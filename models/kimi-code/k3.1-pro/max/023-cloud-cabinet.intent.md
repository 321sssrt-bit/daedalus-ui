# 023 收藏夹

## 意图元数据

- 意图版本：1
- 对应规范：`023-cloud-cabinet.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把收藏夹想象成一只轻松的云端文具柜，用粉蓝空间、柠檬黄纸带和高低不一的便签区分内容类型，让整理操作保持可逆而不打断浏览。

## 适用场景与目标用户

适用于设计工作者、学生和研究者保存文章、图集、声音与工具网页的个人资料库。适合午后整理灵感、写作前找回参考，以及按内容类型快速缩小浏览范围的情境。

## 非目标

不做企业网盘、文件同步状态、在线音视频播放或社交推荐；不采用深色科技仪表盘、整齐等高的缩略图墙和复杂多选批量管理。收藏数据只保存在当前页面，撤销仅限最近一次移出。

## 复刻提示词

设计粉蓝与柠檬黄的中文云端收藏柜：圆润云朵标志、便签式不对称卡片、八条真实文章/图集/声音/工具内容，三列错落排布，配胶囊分类计数、书签移出按钮和底部撤销提示。
