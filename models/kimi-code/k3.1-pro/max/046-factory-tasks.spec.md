## 正常流程

1. **创建**：点击“新建任务”，输入“减速器油封压装复检”，选择林岚与 OP-50 压装，再点击“创建并分派”。T-107 以待处理、林岚出现在看板；总任务和待处理各 `+1`，活动顶部新增陈昊的“未创建 → 待处理”。
2. **分派 / 改派**：在 T-107 的负责人选择中由林岚改为周齐。当前卡片立即显示周齐，活动顶部新增“林岚 → 周齐”；状态统计不因改派改变。
3. **推进**：点击 T-107 的“开始任务”。任务移至进行中列，待处理 `-1`、进行中 `+1`，活动新增“待处理 → 进行中”。再点击“标记完成”，任务移至已完成列，进行中 `-1`、已完成 `+1`，活动新增“进行中 → 已完成”，推进按钮禁用。
4. **查看记录**：在现场活动顶部看到每次成功操作的操作者、实际时间、T-107 和前后值；点击任一 T-107 活动对象，详情 sheet 显示同一任务当前状态、负责人以及按时间倒序的本任务活动。

## 异常触发与恢复

1. 记录 T-103 的当前值：进行中、周齐，本任务活动 `1` 条；另记全部活动数为 `N`。
2. 点击页面顶部或侧栏的“权限演练”，实际尝试把 T-103 从进行中推进为已完成。权限校验返回拒绝，显示缺少“编辑受限任务 / `edit_restricted`”。T-103 仍为进行中、周齐，本任务活动仍为 `1`，全部活动仍为 `N`，统计不变。
3. 也可在 T-103 卡片选择另一负责人或点击“标记完成”触发同类拒绝；选择控件会重绘回原负责人，失败尝试不写入活动。
4. 点击“申请访问权限”。只生成 T-103 的 `pending` 申请及提交时间，按钮显示待审批；不改 `restricted`、状态、负责人、统计或活动。再次尝试受限变更仍被拒绝。
5. 点击“安全返回可操作区域”。关闭权限框并聚焦首个有权限且未完成任务，默认初始流程为 T-101；返回本身不新增活动、不推进任务。
6. 手动点击 T-101“开始任务”或选择新负责人。该普通任务变更成功，活动从 `N` 增至 `N+1`，顶部出现陈昊的新记录；推进时相关统计同步 `±1`。T-103 保持进行中、周齐和原活动数量，证明恢复发生在有权限任务上。

**失败不变量**：任何 `reason: permission` 的改派 / 推进、空标题创建、相同负责人选择、已完成任务推进均不得追加活动。权限失败时 T-103 的 `restricted=true`、`status=doing`、`assignee=周齐`、任务活动数和全部活动数保持不变；申请与安全返回同样不得修改这些任务字段或写入活动。

## 人工验收步骤

### 正常闭环：创建 → 分派 → 推进 → 活动记录

1. 打开页面，确认六项初始任务、四名成员与 `6 / 2 / 2 / 2` 统计。
2. 点击“新建任务”，先空标题提交；看到“请输入任务标题后再创建”，任务和活动数不变。
3. 输入“减速器油封压装复检”，分派林岚，工作中心选 OP-50 压装，点击“创建并分派”。
4. 确认 T-107 出现在待处理列，统计为 `7 / 3 / 2 / 2`，活动为 `7` 条且顶部是陈昊的创建记录。
5. 在 T-107 负责人选择中改选周齐；确认卡片变为周齐，统计仍为 `7 / 3 / 2 / 2`，活动为 `8` 条且显示“林岚 → 周齐”。
6. 点击 T-107“开始任务”；确认卡片进入进行中列，统计为 `7 / 2 / 3 / 2`，活动为 `9` 条且显示“待处理 → 进行中”。
7. 点击“标记完成”；确认卡片进入已完成列，统计为 `7 / 2 / 2 / 3`，活动为 `10` 条且推进按钮禁用。
8. 点击活动中的“T-107 减速器油封压装复检”；确认详情显示已完成、周齐和本任务全部已提交记录。

### 异常恢复：权限拒绝 → 申请 / 返回 → 有权限变更成功

1. 在初始页面记下 T-103 的进行中、周齐、本任务 `1` 条活动及全部 `6` 条活动。
2. 点击“权限演练”；确认出现“这项变更未执行”和 `edit_restricted`，T-103 与统计、活动均未变化。
3. 点击“申请访问权限”；确认出现待审批申请且按钮禁用，活动仍为 `6`，T-103 仍为进行中、周齐，没有自动获得编辑权限。
4. 点击“安全返回可操作区域”；确认对话框关闭，T-101 高亮且“开始任务”获得焦点，活动仍为 `6`，没有替你自动提交恢复变更。
5. 手动点击 T-101“开始任务”；确认它从待处理进入进行中，统计由 `6 / 2 / 2 / 2` 变为 `6 / 1 / 3 / 2`，活动增至 `7`。
6. 查看活动顶部，确认新记录为陈昊操作 T-101、实际时间和“待处理 → 进行中”；再打开 T-103，确认它仍是进行中、周齐、仅查看，申请没有修改其任务数据。
