# 047 创作工具产品

## 意图元数据

- 意图版本：1
- 对应规范：`047-poster-lab.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以骨白工作纸承托电紫操作与荧光绿反馈，把参数、图层和导出收进清晰创作链；海报保持大胆几何，界面克制紧凑，让冲突修正也留在同一工作台。

## 适用场景与目标用户

面向需要快速制作活动海报、社交媒体封面的平面设计师与内容运营：在桌面端调整文案、几何图形和配色，立即交付矢量或位图文件，也适合需要透明素材的排版实验。

## 非目标

- 不采用黑底赛博霓虹、玻璃拟态或堆叠渐变光球，避免掩盖作品本身。
- 不做自由绘路径、图片上传、多页排版、撤销历史或模板商城。
- 不加入账号、云保存、多人协作和发布流程，不暗示刷新后仍可恢复作品。
- 不把导出做成只有成功提示的演示，也不让错误覆盖已有成果。

## 复刻提示词

设计一个骨白、电紫、荧光绿的桌面海报实验室：左侧参数与图层，中间大胆几何中文 SVG 海报，右侧真实导出台；像成熟创作工具一样紧凑、直接、可恢复，所有反馈留在同一工作台。
