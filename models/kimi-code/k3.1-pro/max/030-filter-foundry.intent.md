# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-filter-foundry.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以工业筛选机和仓储档案为参照：安全橙只指向条件与关键动作，密集参数按件号排列，让采购人员在多条件收窄时仍能迅速核对库存、库位和价格。

## 适用场景与目标用户

适用于制造企业的 MRO 备件采购与维修仓储系统，主要服务需要根据设备件号、材质和现货情况快速锁定替代件的维修工程师与采购专员。

## 非目标

不做电商大图画廊、鲜艳促销标签或柔和消费品卡片；不包含在线支付、供应商比价、审批流和真实库存锁定，询价单仅记录当前页选择。

## 复刻提示词

设计中文工业备件检索页：浅灰金属工作面、石墨顶栏、安全橙警示条与大型匹配计数。左侧五组密集筛选，右侧件号档案列表，含库存库位、协议价、参数展开和加入询价；用一台内嵌 SVG 筛选机作为页头主视觉，保持硬边与工程刻度感。
