# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-role-switchboard.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把角色授权转译成电话交换台的接线操作：珊瑚线路指示当前角色，拨杆对应权限，实机监视器即时揭示后果，让高风险设置既可比较又不轻率。

## 适用场景与目标用户

适用于文档协作、内容出版和项目空间的权限设置，主要服务需要为管理员、编辑和外部审阅者划分能力边界的团队负责人或 IT 管理员。

## 非目标

不采用常见浅色 SaaS 三卡片或科幻霓虹效果；不包含单成员自定义权限、审批流、权限审计历史和真实身份模拟，预览只验证界面可用性。

## 复刻提示词

制作中文角色权限页面，视觉像一台维护良好的老式电话交换台：炭灰机架、珊瑚接线、黄铜接点、米灰权限纸面。左侧三角色插孔，中间八项拨杆，右侧可切换桌面和窄屏的实机预览；未保存圆点、逐项撤销和按角色保存都要清楚。
