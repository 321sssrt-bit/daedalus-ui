# 038 故障

## 意图元数据

- 意图版本：1
- 对应规范：`038-repair-ticket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用公共事业蓝、工程网格和警示黄建立可靠的服务语感，故障说明先区分网络问题与燃气事故，再突出已保留的工单。重试与回首页同级可见，减少中断时的不安。

## 适用场景与目标用户

适合燃气、水务、电力等城市公共事业的移动报修服务；目标用户是在家中设备故障后急着提交工单、又担心信息丢失或重复申报的居民。

## 非目标

不采用夸张红色报错、幽默插画或技术堆栈说明；不包含实时地图派单、在线聊天、缴费和真实电话呼叫，安全指引与工单进度使用固定示例数据。

## 复刻提示词

设计一款中文城市燃气 App 的报修提交故障页，深海军蓝与公共事业蓝为主、警示黄状态带，背景像工程蓝图，断开管线 SVG 和带切角的正式工单；文案明确网络失败且内容已保留，底部有蓝色重试和描边回首页，重试后能生成受理工单。
