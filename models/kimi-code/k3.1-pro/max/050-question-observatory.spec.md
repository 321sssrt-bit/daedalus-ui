## 内容与数据

- 品牌为“星题观测室”，课程为“抬头可见的宇宙”，当前第 03 课“月相是怎样形成的”。初始单元进度为 2 / 5，本节未完成。
- 课程入口必须显示学习目标和“开始本节练习”；点击后进入同一 HTML 内的月相单选题。
- 题干为“从地球看，月亮被照亮的部分为什么会周期性变化？”，四个选项顺序固定：
  1. A：月亮自己发光并主动改变强度，错误。
  2. B：月球绕地球公转，太阳照亮半个月球，地球所见亮面比例改变，正确。
  3. C：地球大气按月遮住月亮，错误。
  4. D：月亮每月远离太阳并失去光亮，错误。
- 未选择时提交禁用；选择只记录 A/B/C/D，不改变课程完成度。提交后作答次数 +1。
- 错误提交会显示所选答案的专属原因及“公转 + 观察亮面比例”的订正线索；错误次数 +1，本节完成状态与 2 / 5 进度不变。
- 返回再次作答清空已选但保留作答和错误次数；仍选错误项可再次得到相应解释。
- 正确提交后本节掌握为 100%、单元进度为 3 / 5，展示完整正确解释。若此前错误次数大于 0，标题为“订正成功”；一次答对则显示“回答正确”。
- “重新演示本题”会重置本节作答次数、错误、完成与单元进度到初始 2 / 5；普通返回课程保留本页完成。刷新恢复初始数据。

## 产品边界

实现一个天文短课的入口、课次与单元进度、月相单项选择、提交结果、针对错误选项的解释、返回同题再次作答、正确完成与订正成功，以及重新演示。

不包含真实账号、班级、长期学习档案、多题库、AI 生成讲解、音视频课、讨论区、考试计时、证书或云同步。课程插画和进度均为本页可操作的演示数据。

## 正常流程

1. 打开课程，核对月相第 03 课、单元 2 / 5 和学习目标，点击“开始本节练习”。
2. 阅读题干和轨道图，选择 B；选项出现浅黄底和选中圆点，提交按钮启用。
3. 点击“提交观测结论”；作答次数记为 1，B 为正确答案。
4. 成功页显示“回答正确”、正确结论、本节掌握 100%、作答 1 次和单元 3 / 5。
5. 点击“返回课程”，当前课次显示“已完成 · 可复习”，顶部进度为 3 / 5。
6. 可再次开始复习，或在成功页选择“重新演示本题”恢复本题初始。

## 异常触发与恢复

1. 进入练习后选择 A（也可选 C 或 D），点击提交。
2. A 显示“月亮本身不发光”的针对性错误原因，并给出“月球公转 + 地球所见亮面比例”的订正线索。
3. 作答为 1 次、错误为 1 次，本节未完成，单元仍为 2 / 5；错误 A 保留为砖红 ×，其他选项锁定，不出现成功页。
4. 点击“返回题目再次作答”；同一道题仍在，选项解锁、已选清空，次数保留。
5. 选择 B 并再次提交；作答为 2 次，正确后显示“订正成功”。
6. 成功页显示掌握 100%、作答 2 次、单元 3 / 5，解释与正常正确路径一致，证明已经恢复并成功。

## 人工验收步骤

### A. 正常学习闭环

1. 打开页面，确认单元 2 / 5、月相第 03 课和“开始本节练习”。
2. 进入练习，确认提交禁用；选择 B 后确认选中态与提交启用。
3. 提交后确认“回答正确”、正确结论、掌握 100%、作答 1 次、单元 3 / 5。
4. 返回课程，确认第 03 课和顶部进度已完成更新。
5. 可再次进入课程复习，不需要刷新页面。

### B. 错误答案、解释与订正成功

1. 重新打开页面并进入练习，选择 A 后提交。
2. 确认错误 A 有 ×，解释指出月亮不发光，通用线索包含公转与亮面比例；作答 1 次、错误 1 次、进度仍为 2 / 5。
3. 点击“返回题目再次作答”，确认仍是最初的题干，选项可重新选择，次数没有清零。
4. 选择 B 并提交，确认标题为“订正成功”，作答为 2 次、掌握 100%、进度为 3 / 5。
5. 点击“重新演示本题”，确认进度回到本题初始 2 / 5；可再次执行错误与正确路径。
