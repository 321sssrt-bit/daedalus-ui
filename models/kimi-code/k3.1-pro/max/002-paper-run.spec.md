## 内容与数据

必须保留“纸上行”“把你的现场，写进下一期。”“通讯员登记”和“已有账号？去登录”。字段顺序为姓名、联系邮箱、手机号码、常驻城市、关注方向、选填报道意向、资料使用约定。前四项与约定初始为空或未勾选；关注方向有城市、乡土、手艺、环境、人物五项，其中“城市”默认选中。手机号按去除空格后的 `^1\d{10}$` 校验；邮箱使用原生邮箱格式校验；至少选择一个方向。合法提交等待 750 ms 后显示“你的资料已抵达编辑部”和编号 `PR–047–0186`，回执写入姓名与城市、邮箱、已选方向。再登记会清空资料、恢复城市选项并回到第一步。登录视图要求有效邮箱与至少 6 位密码，成功后显示“签到成功，信箱已打开”。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 无自动连续动画 | 首屏直接呈现期号、步骤和完整登记纸 | 不适用 |
| 用户操作 | 输入与标签过渡 `.16s–.18s ease`；步骤圆号过渡 `.2s ease`；注册等待 `750ms`；登录等待 `650ms` | 标签选中换色；主按钮有按压位移；提交文案变为“正在装订资料…”；成功后出现收讫章与回执 | 所有过渡缩短为 `.01ms`，异步状态、焦点移动与回执保留 |
| 校验失败 | 无位移动画 | 汇总提示出现，错误字段加红色底线并聚焦首个错误项 | 行为不变 |

## 复现验收清单

- [ ] 1280 × 800 px 下左侧大号 047、报纸线稿和三步轨与右侧双列登记纸同时可见。
- [ ] 页面采用暖白纸纹、珊瑚红和直角硬阴影，不是通用圆角卡片皮肤。
- [ ] 四个必填项、至少一个方向及资料约定均会校验，错误定位到具体字段。
- [ ] 方向标签可用鼠标和键盘切换，默认“城市”选中，选中态清晰。
- [ ] 合法提交后出现真实填入值的回执，步骤 01 变完成、步骤 02 变当前，再登记可恢复。
- [ ] “已有账号？去登录”可切换到登录表单，登录成功可见，并能返回原注册状态。
- [ ] 860 px 与 560 px 断点下布局按规则重排，768 px 宽无意外横向滚动。
- [ ] 减少动态模式下没有持续动画，提交、错误和成功反馈不受影响。
