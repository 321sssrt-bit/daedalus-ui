## 内容与数据

- 产品名为“云格 / CLOUD CABINET”，页面标题为“把喜欢的东西，收进云里。”，初始共八件收藏。
- 分类及初始数量为：全部 8、视觉 3、阅读 2、声音 2、工具 1；分类计数始终表示当前仍保留的总数，而非仅可见数。
- 八条内容依次为“黄与蓝的十二种比例”“城市步行的 42 个观察角度”“雨落便利店｜环境声 28 分钟”“把表格做得更易读的 7 个细节”“独立杂志《附近》第 07 期”“陶器表面的冰裂纹理”“清晨七点半的轻爵士”“地铁站字体采集：七月”。
- 每条至少包含分类、标题、具体来源和类型/数量；描述使用真实中文内容，不出现空占位项。
- 默认选中“全部”；筛选只改变可见项，不移除数据。移出一条后总件数及对应分类数减一，撤销后恢复；某分类为零时显示空状态与“查看全部收藏”。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 无自动连续动画 | 初始直接展示全部八件收藏 | 无额外变化 |
| 用户操作 | 筛选与移出悬停 150–160ms `ease`；卡片 180ms `ease`；撤销提示 7000ms，普通提示 2600ms | 筛选即时更新可见卡片、计数和空状态；移出后显示内容名与撤销按钮；恢复后给出成功提示 | 所有过渡缩至 0.01ms；重排、数量与状态反馈仍立即可见 |

## 复现验收清单

- [ ] 1280 × 800 px 下页面宽 1160px，三列卡片具有不同高度、106px/132px 图像与不对称圆角。
- [ ] 粉蓝 `#EAF4FC`、柠檬黄 `#F5EB72` 和深色 `#26374A` 与 HTML 一致，首屏实际有八条具体收藏。

- [ ] 移出某分类最后一条后出现空状态，“查看全部收藏”可返回完整列表。
