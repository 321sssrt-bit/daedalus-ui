# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-night-window.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用深靛蓝夜色和一盏琥珀窗灯承载安静的结束提醒，让权限请求成为夜间仪式的一部分；理由与边界紧邻按钮，降低被催促授权的压力。

## 适用场景与目标用户

适合睡眠辅助、屏幕使用管理、阅读或专注计时产品在首次开启结束提醒前请求系统通知。主要用户是在深夜工作、希望保留安静环境又担心忘记休息的自由职业者和知识工作者。

## 非目标

不使用通用白色系统弹窗、恐吓式权限文案或营销通知；不请求通讯录、定位等无关能力，也不在此页实现完整专注计时器、真实系统授权和睡眠分析。

## 复刻提示词

制作深靛蓝夜景中的中文通知权限页：巨大拱形窗内嵌 SVG 月亮、城市剪影和琥珀台灯，右侧半透明深蓝权限卡，清楚写出通知用途和隐私边界，琥珀允许按钮搭配单次与拒绝选项，安静、克制、有夜晚仪式感。
