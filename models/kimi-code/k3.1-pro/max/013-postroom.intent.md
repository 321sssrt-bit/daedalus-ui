# 013 收件箱

## 意图元数据

- 意图版本：1
- 对应规范：`013-postroom.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把收件箱理解为一张真实分拣台：牛皮纸文件夹负责归置，中间邮签帮助扫读，右侧保留信纸、邮票与寄件信息。邮政藏蓝集中承担操作，红色只标记未读与星标。

## 适用场景与目标用户

用于港口、档案馆、设计园区等内部行政收发系统，也适合重视信件阅读体验的团队邮箱。主要用户是行政值班员、档案管理员和需要集中处理外部来信的运营人员。

## 非目标

不采用冷蓝企业邮箱、无边框白色长列表或过度圆润的社交消息卡；不做即时聊天、写信编辑器、真实附件上传下载和账户权限配置，也不以虚假加载代替邮件处理。

## 复刻提示词

设计一套中文邮政收发室三窗格邮箱：藏蓝顶栏、牛皮纸文件夹、米白邮件列表和信纸阅读区，配邮票齿孔、邮路编号与细分拣线；未读红点、红色星标、藏蓝归档按钮，支持搜索、未读过滤、阅读、归档和撤销，气质像有序的现代邮政工作台。
