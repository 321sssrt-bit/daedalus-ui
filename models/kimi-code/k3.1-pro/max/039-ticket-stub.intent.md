# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-ticket-stub.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把成功反馈做成一张值得保存的电影票根，薄荷绿传达出票完成的轻快感，深海军蓝稳住场次与编号。撕裂线、缺口和取票码优先于普通订单列表，强化凭证感。

## 适用场景与目标用户

适合影展、电影院、演出与展览的移动购票成功页；目标用户是刚完成支付、需要迅速核对场次座位并在入场时再次找到电子凭证的观众。

## 非目标

不采用通用绿色对勾加白卡的电商订单样式；不提供座位修改、在线退票、分享海报和真实扫码验证，二维码为固定视觉示例，金额与场次均为示例数据。

## 复刻提示词

设计一张中文独立影展手机成功票根，薄荷绿成功区叠着白色电影票，深海军蓝文字与海上海报，真实撕裂虚线、两侧半圆缺口、细密取票二维码和等宽数字；下方可展开购票细节，深色完成按钮进入同风格票夹。
