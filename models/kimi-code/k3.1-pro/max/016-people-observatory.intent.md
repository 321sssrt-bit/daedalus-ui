# 016 成员目录

## 意图元数据

- 意图版本：1
- 对应规范：`016-people-observatory.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

用银灰档案台与紫外光标记塑造理性而有人味的研究机构。人物首字母头像保留个体差异，密集索引与舒展简介分开，让查找和认识一个人都不受打扰。

## 适用场景与目标用户

面向跨学科研究院、实验室与设计研究团队的内部成员目录。适合新成员寻找合作者、项目负责人按研究方向组队，以及行政人员确认成员当日在所状态。

## 非目标

不做企业即时通讯、组织结构汇报线或公开社交主页；不使用千篇一律的真人照片墙、荧光霓虹赛博背景，也不把成员信息压缩成只有姓名和部门的表格。

## 复刻提示词

设计一座银灰与紫外光色的研究所成员观测台：左侧精密档案导航，右侧可搜索筛选的人物索引，圆形 SVG 首字母头像带轨道线，卡片可切网格和列表，点击展开深色身份带简介；克制、科学、可键盘操作。
