## 内容与数据

- 品牌固定为“岛映 / ISLAND CINEMA”；初始标签“电子票根”，成功标题“订票成功，好戏即将开场。”，副文案“电影票已收进你的票夹”。
- 片名为“海边来信”，格式“中文 / 2D / 112 分钟”，影院“岛映影城 · 滨江店”，地址“滨江西路 26 号”。
- 场次顺序为“6 月 21 日 周日 / 19:30 / A 厅 / 7 排 12 座”；取票码 `836 291`，订单编号 `IDF-260621-0836`。
- 购票细节默认收起，字段顺序为“购票人 / 票品 / 票价 / 服务费 / 实付 / 支付方式 / 下单时间”；金额 `¥86.00 + ¥3.00 = ¥89.00`。
- 初始完成按钮下方说明“入场时请出示此票根 · 无需打印”；点击后隐藏成功页与底栏，显示“你的票夹”和 1 张待观影卡片。
- 票夹保留相同场次和取票码；“查看电子票根”返回原票根，不能生成重复票或改变订单数据。
