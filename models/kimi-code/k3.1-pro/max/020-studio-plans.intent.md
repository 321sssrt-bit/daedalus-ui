# 020 定价

## 意图元数据

- 意图版本：1
- 对应规范：`020-studio-plans.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

借瑞士网格、粗黑框与热粉标记，把复杂权益变成可直接比较的版面。推荐档用黑白反转而非浮夸徽章，价格切换同时交代年结总额，让创作团队快速做决定。

## 适用场景与目标用户

适合视频审片、设计协作、素材版本管理等创作 SaaS 的公开定价页。面向自由创作者、2–5 人项目小组，以及需要权限分组、采购咨询和企业发票的中小型工作室。

## 非目标

不做电商促销式倒计时、飘动渐变和层层折扣套路；不使用圆角玻璃卡片，不隐藏年付实付金额，也不在定价页内伪造完整支付或复杂团队管理后台。

## 复刻提示词

设计瑞士排版风格的创作协作定价页，黑白纸面、热粉矩形标记、巨大粗体中文标题，三档直角方案共用硬边网格，中间推荐档黑底反转；月付年付真实联动，权益清楚，购买与咨询表单完整可操作。
