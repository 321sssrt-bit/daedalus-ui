# 048 出行服务产品

## 意图元数据

- 意图版本：1
- 对应规范：`048-railway-post.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以铁路邮政存根取代旅游卡片，用青绿轨道、奶油纸面与信号红校验串联班次、席位和凭证；信息按车票阅读顺序排列，让售罄改选也不丢失行程上下文。

## 适用场景与目标用户

面向城际铁路移动端的单人二等座购票流程，适合通勤或周末短途旅客在出门前快速比较直达班次、选定座位并核对凭证。尤其适合需要清楚看见票价、余票和失败原因，再沿原路线改选的用户；本原型也用于演示班次与单座两类售罄恢复。

## 非目标

- 不采用目的地摄影、景点推荐、酒店捆绑或通用旅游卡片瀑布流。
- 不做实时铁路票源、真实支付、登录验身、多人购票、退改签或真实扫码验票。
- 不用弹窗打断失败流程，不把售罄演练藏在控制台，也不以禁用全部操作代替可恢复的异常。
- 不为宽屏另做桌面多列布局，不通过外部字体、图片或脚本改变离线纸票质感。

## 复刻提示词

设计“青驿铁路”移动购票连续原型：铁路青绿、奶油纸面、少量信号红，结合轨道刻度、邮政印记、打孔存根与车厢座位图；按车票层级排路线、班次、席位、金额和验票凭证，售罄反馈明确且改选不丢失行程。
