# 046 团队协作产品

## 意图元数据

- 意图版本：1
- 对应规范：`046-factory-tasks.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以铝灰设备面板承托钴蓝操作路径，把工单、工位与审计活动放进同一班次视野；优先让每次变更有据、权限受阻可恢复，舍去消费级协作工具的轻盈装饰。

## 适用场景与目标用户

面向电驱、减速器等离散装配线的班组协作控制台。生产班组长在交班或巡线时创建并分派工序任务，工艺、质量与设备工程师在工位间推进检查和复测；生产主管可用受限任务演练权限拦截，确认失败不留假记录，再引导成员返回普通任务恢复工作。

## 非目标

- 不做通用聊天、文档协作或消费级待办产品的视觉换皮。
- 不采用霓虹深色赛博风、彩色玻璃拟态、插画卡片墙或无功能装饰图表。
- 不实现真实登录、后端持久化、多人实时同步、审批后台或自动授权。
- 不加入拖拽跨状态、撤销回退、附件、评论、任务删除与设备控制，避免模糊本题核心闭环。

## 复刻提示词

设计一套中文离散制造班组协作控制台：铝灰设备表面配钴蓝关键动作，深色窄侧栏，真实工单与工位编号，三列任务看板紧邻现场审计时间线；紧凑但可键盘操作，用同一设计系统呈现任务详情、权限拒绝、待审批申请和安全恢复，突出“失败不变更、成功必留痕”。
