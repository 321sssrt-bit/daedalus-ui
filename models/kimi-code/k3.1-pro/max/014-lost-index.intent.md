# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-lost-index.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

将搜索失败写成一张图书馆检索回执，而不是一句报错。原查询像题名一样被郑重保留，目录员式改搜建议落在三张索引卡上，让空态自然通向下一轮查找。

## 适用场景与目标用户

用于公共图书馆、高校特藏库、档案馆和地方文献联合目录。适合研究者、学生与古籍阅览者在题名不确定时，通过主题、机构和责任者继续定位资料。

## 非目标

不采用搜索引擎的大空白插画、机器人道歉或电商推荐卡；不做自然语言问答、虚假智能纠错、在线购书和真实馆际互借，也不把无结果弱化成普通加载状态。

## 复刻提示词

设计中文图书馆卡片目录搜索空态：米色桌面、酒红馆名与检索框，一张带索引签和底部打孔的奶白回执卡，原搜索词用宋体大号引文保留；下方三张略旋转的横线索引卡给出具体改搜建议，点击可命中并展开带索书号的馆藏卡片。
