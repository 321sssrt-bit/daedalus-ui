# 043 即时通讯产品

- 意图版本：1

## 设计意图

以宣纸留白、靛蓝字句和灯笼红回执营造灯下书信感；列表先呈现远近往来，聊天页把演练与重试织入同一阅读节奏，让故障反馈清楚却不破坏纸张温度。

## 适用场景与目标用户

适用于读书会、茶室、独立文化空间或熟人社区的中文移动通讯产品。用户在通勤、到店途中或晚间闲暇时查看熟人近况、发送短句，并希望在网络波动时确认原文没有丢失；主要用户是重视文字质感、需要明确回执而非高密度办公协作的人群。

## 非目标

- 不采用霓虹渐变、玻璃拟态、通用蓝色聊天模板或密集企业工作台导航。
- 不用过度古风装饰牺牲消息辨识度，也不把演练做成开发者控制台。
- 不扩展真实联网、账号体系、云同步、附件、语音视频、群管理、撤回删除等相邻能力。
- 不让失败自动重发，不用浏览器 alert，不把恢复网络等同于已重试成功。

## 复刻提示词

设计一只宣纸质感的中文手机通讯产品“灯笺”：以宋体标题、细纸边、折角气泡和印章般未读数形成克制书信感，靛蓝代表自己，灯笼红只强调寄出与异常；列表像四封近讯，聊天页把网络演练、失败原文保留、恢复与原位重试自然串起，拒绝通用霓虹聊天皮肤。
