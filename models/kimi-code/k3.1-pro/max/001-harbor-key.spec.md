# 001 登录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`001-harbor-key.html`
- 复现范围：复现私人港湾会员登录首屏，以及密码显隐、登录校验、通行成功和页面内找回密码流程。

## 内容与数据

必须保留品牌“泊钥 / HARBOR KEY”、主标题“归来，自有灯火。”，以及“会员编号或绑定邮箱”“通行密码”“核验并进入港湾”“找不到密码？”的顺序。账号初始为空，密码初始为空且掩码，“在这台设备上记住我”默认勾选。空账号、空密码、少于 6 位密码分别在原字段下方显示错误；合法非空输入提交 700 ms 后显示“你的港湾已就绪”、大写会员标识、北堤 A–17 和“可自由进出”。找回视图要求有效邮箱，成功文案为“重置指引已寄出”，邮箱本地部分仅保留前两位并以 `***` 遮蔽；返回登录不清空原账号。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 航线虚线 `18s linear infinite`；灯塔扩散环 `3.2s ease-out infinite`，第二环延迟 `1.6s` | 航线缓慢流动，入口灯塔出现两轮扩散 | 动画缩短为 `.01ms` 且仅一次，保留静态航线和灯塔 |
| 用户操作 | 控件过渡 `.18s ease`；登录等待 `700ms`；找回等待 `650ms` | hover 变色、按钮上移；提交中显示“正在核验身份…”或“正在寄出…”；随后切换成功内容 | 过渡缩短为 `.01ms`；异步状态与文字反馈仍保留 |
| 校验失败 | 无位移动画 | 字段下方出现具体错误，汇总提示可见，焦点移至首个错误字段 | 行为不变 |

## 复现验收清单

- [ ] 1280 × 800 px 下左侧海图与右侧登录分屏完整，无横向滚动，卡片宽约 410 px。
- [ ] 海图包含网格、等深线、黄铜虚线航线、罗盘、船标与北堤 A–17 到达信息。
- [ ] 空表单、短密码均出现对应字段错误；密码显隐按钮可切换 `type` 与 `aria-pressed`。
- [ ] 合法账号和至少 6 位密码提交后出现通行成功票据，点击“切换会员账号”可返回。
- [ ] “找不到密码？”可进入找回视图，有效邮箱提交后出现脱敏地址，并可返回登录。
- [ ] 820 px 与 480 px 断点分别触发单列和紧凑间距，768 px 宽没有内容溢出。
- [ ] 开启减少动态后，航线与扩散环不再持续运动，登录和找回反馈仍可使用。
