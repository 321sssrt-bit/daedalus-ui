# 045 音视频平台

## 意图元数据

- 意图版本：1
- 对应规范：`045-frame-cinema.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把发现轨、银幕与待播队列放进同一间数字放映室，以炭黑收拢干扰、橘色标示播放动作。断网反馈守住断点而非抛出技术告警，让恢复续播清晰可信。

## 适用场景与目标用户

适合桌面端策展型影视、纪录短片或独立音视频平台的夜间观影场景：用户用笔记本浏览少量编辑精选，先安排今晚的观看顺序，再在播放器中连续欣赏。主要用户是重视内容氛围、需要清楚掌握播放位置，也希望网络波动后能无缝接着看的观众。

## 非目标

- 不采用霓虹多色渐变、玻璃拟态或密集海报墙，不做无限下拉的信息流推荐。
- 不加入弹幕、评论、社交关系、账号付费、广告投放等相邻能力。
- 不伪装真实视频解码、声音或远端缓冲；本页只模拟本地播放状态，也不承诺刷新恢复。

## 复刻提示词

设计一间炭黑与放映橘构成的中文桌面放映室：宽银幕居中，右侧是紧凑待播队列，下方为横向策展片目轨；海报全部用几何 SVG。播放控件清楚、断点保存可感知，网络中断直接覆盖银幕并提供醒目的“重新连接并续播”，整体克制、温暖、可离线运行。
