## 产品边界

实现六件商品的浏览与选择、规格和数量、单会话库存、购物袋增删改、动态合计、演示收货信息核对、提交校验、成功回执、新订单，以及主动缺货 / 库存不足演练和恢复。库存按“商品 + 规格”独立计算，同规格购物行合并，改选到已存在的规格时也合并并校验合计数量。

不包含真实支付、真实仓库或后端持久化、账户登录、优惠券、运费计算、订单历史、物流跟踪、退换货操作、搜索筛选和跨页面跳转。页面刷新会恢复初始演示数据；库存演练是明确标注的评测操作，不是仓库接口。

## 正常流程

1. 点击任一商品卡：该卡显示“正在挑选”，右侧展示对应 SVG、商品名、价格、材质、尺寸与两个规格。
2. 点击规格并用 `+`、`−` 或数量输入设定整数数量：库存文字和按钮禁用状态同步变化。
3. 点击“加入购物袋”：商品按“商品 + 规格”进入或合并到购物袋，购物袋自动打开；行小计、总件数和应付总额可见。
4. 在行内点击加减、修改规格或移除：仅改变对应数据并重算合计；点击“继续挑选”可加购其他商品。
5. 点击“核对收货信息”：进入同一对话框的核对状态，检查或修改收件人、手机、省市、详细地址，并复核每条商品规格与金额。
6. 点击“提交订单”：全部校验通过后扣减已购库存、生成顺序订单号、清空购物袋并显示回执。
7. 点击“继续购物，开始新订单”：关闭回执，回到浏览状态；购物袋为空，剩余库存保留，可再次走通流程。

## 异常触发与恢复

### 主动触发

1. 先把商品某规格加入购物袋，再点击购物袋内“库存演练 / 选择商品”或页头“库存演练”。
2. 对目标购物行点击“模拟此规格缺货（0 件）”；若该行数量大于 1，也可点击“模拟此规格仅剩 1 件”。按钮明确标注“演示”。
3. 返回购物袋后，原商品、规格、数量与合计仍保留；点击“核对收货信息”再点击“提交订单”。
4. 校验失败时显示“商品名 · 规格”，以及“需要 X 件，当前可售 Y 件”；没有成功回执和新订单编号。

### 改选有货规格恢复

1. 对可售 0 件的错误行点击“改选「另一规格」”；也可返回购物袋用规格下拉自行改选。
2. 新规格必须能容纳改选后的合并数量，否则保持原规格并提示可售量。
3. 成功后错误清除、规格更新，商品单价与总件数不变；再次点击“提交订单”生成成功回执。

### 减少到可售数量恢复

1. 当错误规格可售量大于 0 且小于需求量时，点击“减至 Y 件”；也可返回购物袋用减号调整。
2. 数量变为可售量，行小计、商品小计、总件数与应付总额同步减少；错误清除。
3. 再次点击“提交订单”，库存按恢复后的数量扣减并生成成功回执。

## 数据变化

| 操作 | 会变化的数据 | 不得变化 / 约束 |
| --- | --- | --- |
| 浏览与详情选规格 | 当前商品、当前规格、详情数量重置为 1 | 购物袋、库存、订单序号不变 |
| 加入购物袋 | 新增或合并购物行，数量增加；合计与件数重算 | 不扣库存；同规格加入后的总数量不能超过当前可售量 |
| 加减 / 删除 / 改选 | 对应行数量、规格或行是否存在；合计与件数重算 | 不允许数量低于 1 或高于库存；改选合并后也不能超库存；未成功提交前不扣库存 |
| 库存演练 | 仅目标“商品 + 规格”的 `stock` 被设为 0 或 1 | 购物行、数量、金额、其他规格库存、订单序号均不变 |
| 失败提交 | 仅增加可见校验问题与焦点 / 通知状态 | `state.cart` 的商品、规格和数量，行小计、总件数、总金额，所有规格库存，`state.orderSequence`、`state.lastOrder` 均不得变化；不得出现新成功订单号 |
| 恢复修改 | 改规格或减少数量，清除当前校验问题并重算合计 | 不自动提交；必须再次点击提交；不能借机增加超过新规格库存的数量 |
| 成功提交 | 按购物行扣减对应规格库存；订单序号 +1；保存回执快照；购物袋清空 | 回执商品、规格、数量、小计、总件数和总额必须等于通过校验的提交快照 |
| 开始新订单 | 关闭回执并清除 `lastOrder`，步骤回到购物袋 / 浏览 | 已扣库存不回滚，订单序号不重置，可再次加购 |

## 人工验收步骤

以下步骤按顺序从首次打开开始，覆盖正常闭环、减量恢复、改规格恢复；订单号日期取当天，这里只核对会话内顺序后缀。

### A. 正常闭环与购物袋增删改

1. 点击“野枝粗陶花器”，选择“苔绿”，点击一次 `+` 使数量为 2，再点击“加入购物袋”。应看到该行小计 ¥536、总件数 2、应付总额 ¥536。
2. 点击“继续挑选”，选择“暮色手作马克杯”，保留“燕麦白”和数量 1，点击“加入购物袋”。应有两行，花器小计 ¥536、马克杯小计 ¥128，总件数 3、商品小计与应付总额均为 ¥664。
3. 在马克杯行点击 `+`：该行变 2 件 / 小计 ¥256，总件数 4 / 总额 ¥792；再点击 `−`：恢复 1 件 / 总件数 3 / 总额 ¥664。
4. 点击马克杯行“移除”：只剩花器，总件数 2 / 总额 ¥536。点击“继续挑选”并重新加入燕麦白 1 件，应恢复两行与 ¥664；此过程不应扣减库存。
5. 点击“核对收货信息”，核对默认收件人林小满、手机 13800138000、浙江省杭州市及详细地址；核对花器苔绿 2 件、马克杯燕麦白 1 件与总额 ¥664。
6. 点击“提交订单”。应看到订单已收到、当天日期且后缀为 `001` 的订单号、两项商品及规格、总件数 3、订单总额 ¥664；苔绿库存 8→6，燕麦白库存 10→9。
7. 点击“继续购物，开始新订单”，再打开购物袋。应显示空状态和总件数 0；关闭购物袋准备异常验收。

### B. 库存不足后减量恢复

1. 选择花器苔绿，数量设为 2 并加入购物袋；总额应为 ¥536。
2. 在购物袋点击库存演练的“选择商品”，对“野枝粗陶花器 · 苔绿”点击“模拟此规格仅剩 1 件”。返回后应看到当前可售 1 件，但购物袋仍为 2 件、总额仍为 ¥536。
3. 点击“核对收货信息”并直接点击“提交订单”。应看到“野枝粗陶花器 · 苔绿，需要 2 件，当前可售 1 件”；合计仍为 2 件 / ¥536，没有成功回执或后缀 `002` 的订单，苔绿库存仍为 1。
4. 点击错误区的“减至 1 件”。应保留核对页，错误清除，数量与总额变为 1 件 / ¥268；点击“提交订单”。
5. 应出现后缀 `002` 的成功回执，商品为苔绿 1 件、总额 ¥268；苔绿库存 1→0。点击“继续购物，开始新订单”。

### C. 缺货后改选有货规格恢复

1. 选择马克杯燕麦白，数量设为 2 并加入购物袋；总额应为 ¥256。
2. 打开库存演练，对“暮色手作马克杯 · 燕麦白”点击“模拟此规格缺货（0 件）”。返回后购物袋仍为燕麦白 2 件 / ¥256。
3. 进入核对并提交。错误应明确指出该商品与燕麦白规格、需求 2 件、可售 0 件；合计不变，无新订单号，燕麦白库存保持 0，窑变棕库存保持 6。
4. 点击“改选「窑变棕」”。应保留 2 件与 ¥256，规格变为窑变棕，错误清除；再次点击“提交订单”。
5. 应出现后缀 `003` 的回执，商品为窑变棕 2 件、总额 ¥256；窑变棕库存 6→4，燕麦白仍为 0。继续购物后购物袋清空，可再次开始新订单。
