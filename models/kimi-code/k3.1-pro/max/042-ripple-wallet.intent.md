# 042 钱包支付产品

## 意图元数据

- 意图版本：1
- 对应规范：`042-ripple-wallet.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

以深海蓝承托转账的谨慎感，用水波青标记行动路径；同心波纹串联余额、确认与凭证，让资金变化清晰可见，优先保证金额核对与异常恢复。

## 适用场景与目标用户

面向个人移动钱包中的熟人小额转账演示：用户已登录，在通勤或居家场景中给常用联系人付款，需要在确认前快速比较零钱与演示卡余额。也适合产品评审时反复演练超额拦截、修改金额和更换来源，而不触碰真实资金。

## 非目标

- 不采用普通银行蓝白卡片、密集理财货架或夸张金融科技光效。
- 不做真实支付、登录实名、支付密码、银行卡绑定、扫码、退款或持久化流水。
- 不用弹窗、浏览器提示框或仅短暂出现的提示打断核对；错误与恢复操作留在流程内。
- 不把波纹做成干扰金额阅读的复杂背景，也不以动画作为唯一状态反馈。

## 复刻提示词

设计“涟漪钱包”中文移动转账原型：深海蓝底、水波青操作、同心圆波纹贯穿余额与成功凭证，常用联系人双列排布，来源与金额始终清楚；确认页内呈现余额不足和差额，并提供降低金额、切换来源两条恢复路径。气质安静、可信、精致，避免蓝白银行模板。
