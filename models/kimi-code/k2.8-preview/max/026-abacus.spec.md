# 026 账单

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`026-abacus.html`
- 复现范围：单页账单台（当前方案卡、扣款方式卡、六个月账页流水表与发票浮层），不含登录、报表、归档与设置子页。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 240–300 ms ease，逐行 40 ms 递延 | 六笔流水自下而上淡入；方案卡「现行之印」240 ms 缩放盖章落定 | 动画整体关闭，行与印章直接呈现 |
| 点击筛选签 | 即时（无过渡） | 行显隐、计数/合计/大写即时重算，激活签反色 | 无变化（本就不依赖动画） |
| 打开/关闭发票浮层 | 即时显示 | 遮罩出现、焦点移入关闭钮；关闭后焦点还原到触发链接 | 无变化 |
| 换绑成功 | 240 ms 上移淡入 | 批注 Toast 弹出，2600 ms 后淡出；扣款卡名称、尾号、划款方与绑定说明四处文案同步改写 | Toast 过渡关闭，文字照常出现消失 |
| 行悬停 / 按钮悬停 | ≤ 160 ms 颜色过渡 | 行底变黄、按钮反色或加深 | 无变化（颜色反馈保留） |
