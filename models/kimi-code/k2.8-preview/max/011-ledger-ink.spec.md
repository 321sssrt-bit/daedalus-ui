# 011 数据看板

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`011-ledger-ink.html`
- 复现范围：单页桌面数据看板，含关键数字条、手绘折线主图、账目明细表与日/周/月粒度切换，不含登录、导出与下钻页面。

## 画布与区域布局

页面为流体单列，内容最大宽度 1280 px，左右各留 24 px 页边距；整体纵向自上而下排布，区域之间间距 16 px。

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 | 宽 = 视口宽（最大 1280 px），高由内容撑开（约 780 px），外边距 0 auto，内边距 24 px | 单列块级流；背景 `#f3ecdb` | 无固定定位，无横向滚动 |
| 页眉 | 最小高 64 px，宽 = 内容宽（1280 视口下 1232 px），下间距 16 px | flex，两端对齐：左侧店名 + 账期行，右侧 46×46 px 朱印 + 粒度按钮组（组内按钮间距 8 px，距印 18 px） | 静态；页眉允许换行 |
| 关键数字条 | 4 列等宽网格，列间距 16 px，下间距 16 px；单卡最小高 108 px、内边距 16 px 20 px | CSS grid `repeat(4, 1fr)`；卡内纵向三段：标签（13 px）、大数字（30 px）、注脚（13 px） | 卡片 `#fbf7ea` 底、1 px `#d9cfb6` 边框、圆角 8 px、阴影 `0 2px 6px rgba(42,40,34,.08)` |
| 主图卡（左） | 自适应宽（1280 视口下约 816 px，flex `1 1 720px`），最小高 492 px，内边距 20 px | 卡头 24 px 高（标题 17 px + 图例两行样例），下方图表容器相对定位 | 图表 svg `viewBox 0 0 720 400`，宽 100% 随卡缩放；tooltip 绝对定位于容器内，z-index 3 |
| 账目表卡（右） | 固定宽 396 px，最小高 492 px，内边距 20 px，与主图卡间距 20 px | flex 行内右列；卡头下表格滚动区 | 表格滚动区 `max-height: 434px`、`overflow-y:auto`；表头 sticky 置顶 |

## 内容与数据

- 店名标题固定为「栖云茶食铺 · 流水总账」，账期行随粒度变为：日「账期：2026年6月8日–6月14日 · 按日结账」、周「账期：2026年4月20日–6月14日 · 共八周 · 按周结账」、月「账期：2025年7月–2026年6月 · 共十二月 · 按月结账」。
- KPI 四卡顺序与口径固定：区间流水（标签随粒度为「七日流水 / 八周流水 / 十二月流水」）、成交笔数、客单价（流水÷笔数取整）、环比上周期（相对上一账期 stored 基值 28940 / 219800 / 1215600，▲ 朱红、▼ 淡墨，保留 1 位小数）。
- 初始为「日」粒度：账期标签 06-08 至 06-14；流水 3260 / 4120 / 3890 / 4650 / 4380 / 5890 / 5120 元；峰值 06-13（¥5,890，朱批「旺」）；日合计 ¥31,310、938 笔。
- 账目表四列固定：账期 | 笔数 | 流水（元）| 朱批；朱批词表仅「平常 / 偏淡 / 旺 / 大旺」；合计行行首「合计」、末列「—」。
- 图表纵轴按量级自适应：满万显示「×.×万」，否则显示元值；横轴标签与表格账期一致（日 7 点、周 8 点、月 12 点）。
- 页脚固定文案：「账房先生注：每日打烊后对账一次，朱笔只批峰值与异常，墨笔不涂改。」
- 数字一律千分位；金额前缀 ¥；数据可整体替换，但三粒度数组长度须保持 7 / 8 / 12。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 620 ms `cubic-bezier(.33,.1,.2,1)` | 折线以描边 dashoffset 从 0 拉满一次 | 不播放，折线直接呈现 |
| 切换粒度按钮 | 数字 550 ms ease-out；线 620 ms 同上 | 三 KPI 数字滚动至新值；折线重画；表格整体换行；选中钮倾角与投影即时切换 | 数字直接落定，折线直接呈现 |
| 悬停图表 | 无过渡，即时 | 朱红十字线吸附最近账期点，tooltip 展示该点账期、流水、笔数、朱批 | 保留（必要反馈），行为不变 |
| 按钮悬停 / 焦点 | 150 ms ease | 边框变色 / 2 px 外描边 | 过渡时长压至 0.01 ms，状态色保留 |
