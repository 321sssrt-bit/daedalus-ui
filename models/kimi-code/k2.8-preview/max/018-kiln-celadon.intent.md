# 018 商品详情

## 设计意图

用青瓷灰绿的东方极简承托「盯着一件货决定买不买」的犹豫时刻：大图留白让器物自己说话，信息栏克制排布，把决策所需的名称、价格、规格、购买按钮依次递到眼前。克制的代价是不做促销弹窗与倒计时，靠规格联动的真实反馈赢得信任。

## 适用场景与目标用户

- 品类：手工茶器、陶瓷器皿、东方生活方式品牌的高客单单品页。
- 用户：25–45 岁、有饮茶习惯、愿为手作溢价买单的购买者；常在桌面端反复比较款色与规格后下单。
- 情境：从内容平台或店铺列表进入单品页，需要在 30 秒内确认款色、容量与到手价。

## 非目标

- 不采用促销弹窗、倒计时、满减条、红包浮层等促销风组件。
- 不做商品轮播多图、评价列表、相关推荐瀑布流。
- 不含购物车页与结算流程，加购仅以页内反馈条确认。
- 不使用外链图片或字体，器物图以内嵌 SVG 示意，不追求照片级质感。
