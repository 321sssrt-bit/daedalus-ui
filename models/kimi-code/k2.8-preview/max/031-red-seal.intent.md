# 031 发布确认

## 意图元数据

- 意图版本：1
- 对应规范：`031-red-seal.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把"不可逆发布"做成一纸公文盖印的仪式：宣纸底、白面纸、朱红顶边，所有注意力压向后果框里那一句红字。确认不是弹窗里的按钮，而是枚必须亲手"盖下去"的印——先勾选知悉才解锁，盖落瞬间圆戳砸在回执旁，让"收不回来"被看见。直角、衬线、字距拉开，气质偏公文而非互联网组件。

## 适用场景与目标用户

- 品类：文档协作、知识库、政务/企业公文、财报或公告类内容平台的发布前确认。
- 用户：内容定稿人、合规审核员——需要在按下发布前被强制停一秒、读一句后果的人。

## 非目标

- 不用常规 modal/对话框（题目要求避开），也不做双侧栏或多步向导。
- 不堆警示图标与红黄配色轰炸，不用圆角卡片化按钮削弱"印"的仪式感。
- 不含删除、编辑器等相邻能力；返回只做流程退出，不做浏览器级路由跳转。
- 不做连续动画背景或插画装饰，纸面保持安静。

## 复刻提示词

一页 1280×800 的桌面发布确认：米白纸纹底（#faf7f2）上居中一张 680px 白色公文纸，顶边 3px 朱砂红（#b2311f），衬线大标题《2026 年第一季度供应商交付报告》。纸内依次是文号行、一句加粗朱红后果（发布后不可编辑不可撤回）、一个自定义勾选框（选中后框底变朱红），勾选才解锁右侧「盖印发布」印钮（灰 #c9bfb2 禁用态）；左侧文字钮「返回继续修改」点击后以纸色虚线遮罩覆盖操作区并弹顶部深色通知条。点击盖印后印钮变深朱红并显示「已发布」，一枚 128px 毛边朱红圆戳（feTurbulence 滤镜）带星形和「已发布」字样盖落在回执旁，回执含发布编号与当前时间。全直角、零圆角、无外链资源、含 prefers-reduced-motion。
