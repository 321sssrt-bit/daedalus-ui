# 027 角色权限

## 意图元数据

- 意图版本：1
- 对应规范：`027-cast-call.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把枯燥的 RBAC 配置包进剧场语言：权限是「后台通行令」，角色是挂在布告板上的三张名牌，每个勾选决定一项「能不能登台」。预览不是表格 diff，而是把视角交给某个角色——聚光下亮起他能做的，其余沉入暗处。封存即盖印，回执当场面呈，全团即时生效。

## 适用场景与目标用户

- 中小剧团、Livehouse、驻场演出团队的内部管理后台，给团长配置「谁动得了排期、谁碰得了钱」。
- 目标用户是非技术出身的制作人与舞台监督：他们熟悉通告、名牌、装台这些词，不熟悉「角色-资源-动作」三元组。
- 也适合任何想把权限页做出场所气质的产品，如密室逃脱门店的员工排班权限、剧院票务组的工作台。

## 非目标

- 不做常规 RBAC 矩阵表格、不做左侧树加右侧复选框的管理后台布局。
- 不做用户-角色指派、角色复制、权限模板市场等扩展能力；本题只到「三角色 × 各自清单 × 预览 × 封存」。
- 不做真实后端持久化，封存回执是前端汇总呈现，不接登录与审计日志。
- 不引入任何外网字体、图片或图标库，全部内嵌系统字体与手写 SVG。

## 复刻提示词

一座紫红幕布垂落的剧场布告板：金边布告栏写着「后台通行令」，下面三张打孔票根式名牌（团长 / 舞台监督 / 演员），每张列 5 条可勾选权限并实时计数；底部预览舞台用聚光锥照亮当前视角下被允许的项、压暗被拒的项，tab 可切三种视角；点「封存此版布告」弹出纸面回执，分行汇总各角色生效项数并盖章，某角色零权限时回执转红并拦下。全程中文、系统字体、单文件离线。
