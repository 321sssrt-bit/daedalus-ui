# 025 账号设置

## 意图元数据

- 意图版本：1
- 对应规范：`025-switch-room.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把账号设置做成机舱开关室：密排拨杆、仪表灯与金属铭牌承载全部操作，改资料、保安全、管通知像巡检拨开关一样直接可信。取舍是以工业质感和信息密度优先，舍弃白底列表设置页的轻快感。

## 适用场景与目标用户

- 品类：航空运行控制、工业监控、运维平台等专业后台的账号中心，或任何工具型产品的设置页。
- 用户：习惯仪表盘与物理开关隐喻的一线操作员、系统管理员；在班次场景中需要快速确认「哪项开着、哪项关着」的人。
- 情境：工位台式机 1280 px 宽屏常驻页面，操作间隙扫一眼仪表灯即掌握账号安全态势。

## 非目标

- 不采用白底卡片、圆角小清新式通用设置页视觉。
- 不做移动端深度适配（仅保证 768 px 不破碎的单列堆叠）。
- 不做真实后端同步、多账号切换、账号注销与登录历史图表。
- 不引入任何外链图片、图标字体或插画资源，氛围全靠 CSS 质感。

## 复刻提示词

桌面端 1280×800 账号设置页，整体是深色机舱开关室气质：近黑蓝灰底 `#12151a`，三块金属面板（资料 / 安全 / 通知）等宽并排，各带铆钉金属铭牌头；设置行为 46 px 高密度行，点击行向下展开深色详情抽屉可编辑；通道用 46×24 px 拨杆开关 + 8 px 仪表灯（琥珀呼吸灯 = 通知，绿灯 = 安全），琥珀 `#ffb02e` 作为通电强调色；底部一条通讯记录条实时回显每次操作与时间戳；等宽字体显示 UID、时钟与备用码；支持总电门一键锁定全部通知通道；系统字体、纯内联 CSS、无外链资源。
