# 014 搜索无结果

## 意图元数据

- 意图版本：1
- 对应规范：`014-desert-radar.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「搜不到」比作雷达在沙海扫不到信号：沙色底、橄榄绿圈线、赭红扫描锥构成荒漠仪表感；搜索词始终留在画面里，改搜建议可直接点，把用户从死路引回货架。刻意避开蓝色系与插画式配图。

## 适用场景与目标用户

- 品类：户外装备电商、旅行用品商城、垂直内容检索（如装备库、路线库）的桌面端搜索空态。
- 用户：正在筹备沙漠、戈壁、高原行程的自助旅行者，习惯先搜具体装备名，搜不到时需要被引导到相近常备品。

## 非目标

- 不做分页、排序、筛选等完整搜索功能，仅空态 + 两个预置结果态。
- 不做自动补全、搜索历史、热门搜索榜单。
- 不使用蓝色系、不使用照片位图、不引入外链字体与图标库。
- 不模拟真实后端：结果只由页面内预置的关键词映射产生。

## 复刻提示词

桌面端装备商城的搜索无结果页：沙色荒漠底色，顶部 64 px 吸顶栏含居中搜索框；主视觉为 220 px 雷达圆，橄榄绿同心圆线加一道赭红 conic-gradient 扫描锥持续旋转；下方 720 px 卡片面板，显示「没有找到与『夜光帐篷』相关的装备」及三条可点击改搜建议 chip，点击建议真实切换到两个预置结果列表之一；全页避开蓝色，减少动态模式下扫描静止。
