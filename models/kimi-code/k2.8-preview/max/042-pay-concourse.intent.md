# 042 钱包支付产品

## 意图元数据

- 意图版本：1
- 对应规范：`042-pay-concourse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把转账做成一座老车站：穹顶绿给安全感，铜钟与检票口把确认变成仪式。「闸机只认余额」给余额不足一个物理隐喻——闸机不开，换来源或改金额才是进站的路，凭证则是一张盖章的进站票根。

## 适用场景与目标用户

熟人之间高频、小额的转账场景：每月房租、合租分摊、家用补贴、拼单回款。目标用户是把钱包当日常零用账户的中文手机用户——他们要的是「看得见的余额」和「转出去就安心」的确定性，而不是理财式复杂仪表盘。

## 非目标

- 不做电商收银台、收单二维码的商户气质。
- 不用荧光渐变、玻璃拟态的潮流金融视觉。
- 不做多账户资产管理、理财申购等相邻能力。
- 不做真实支付密码、指纹/人脸核验流程。
- 不为桌面宽屏单独设计布局，宽屏只是手机框展示。

## 复刻提示词

移动端单文件钱包转账原型，车站大厅气质：深绿穹顶（#0F3D2C→#1A5A40）+ 米白石面（#F5EFE1）+ 铜件（#B4763B/#D9A441）。四屏闭环——大厅选收款人（每人一个「检票口」标签）→ 大数字金额 + 底部键盘 → 票卡核对 + 闸机图示确认 → 进站凭证（盖章、票根缺口、条码）。余额不足＝闸机不开：红色面板列出可用余额与差额，可一键换零钱通或返回改金额后重试。全部状态共用同一套色板、字体与圆角制度。
