## 内容与数据

- 固定文案：「铅印工坊 LEAD TYPE STUDIO」「实时预览」「纸张规格」「显示出血线」「输出分辨率」「导出格式」「生成导出文件」「导出记录」「设置冲突 · 已阻止导出」。
- 图层初始数据：品红专色层（浓度 92、+1.5/−1 px）、青专色层（88、−1/+1）、黄专色层（90、+0.5/+1.5）、墨色文字层（100、0/0，不可删）。
- 纸张选项：A4 210×297、A5 148×210、方形 200×200（mm）；分辨率 300/150/72 dpi。
- 校验文案规则：必须点名冲突项——「作品含 N 个可见专色图层，『格式名』最多支持 / 仅支持 M 个」，提示行给出两个恢复方向（隐藏图层或换格式）。
- 成功卡字段顺序：文件名 → 格式 + dpi → 成品尺寸 + 色版数 → 大小 + 生成时间。
- 导出估算大小：四色 18.6 MB、双专色 9.4 MB、单色 5.2 MB、PNG 3.8 MB。

## 产品边界

实现：海报作品的图层可见性、删除、油墨浓度、横向/纵向套准编辑；纸张规格、出血线、分辨率参数；实时叠印预览与套准状态提示；四种导出格式的条件校验、模拟导出、成功回执与导出记录；重置作品。不包含：真实的画布绘制与文件写入、色版分离预览、多作品管理、协作与云存储、撤销/重做栈。

## 正常流程

1. 打开页面：四列图层、A4 纸张预览、四色印刷默认选中，校验横幅绿色，「生成导出文件」可用。
2. 修改参数：拖动「品红专色层」浓度滑杆到 60%——预览中品红「印」字即时变淡；把横向套准拉到 +5——「印」字右移且看样台头标签变黄「套准偏差 5px · 偏大」。
3. 查看实时预览：纸张、出血框、叠印混色、压力测试条上的专色名随操作即时更新。
4. 选择导出格式：点击「双专色印刷 PDF」之外的任意兼容格式（默认四色已选中），确认横幅为绿色。
5. 导出并看到结果：点击「生成导出文件」→ 进度条走满 → 成功卡显示「纸上工坊海报.pdf · 300 dpi · 210 × 297 mm」→ 导出记录新增绿色「成功」条目。

## 异常触发与恢复

触发：作品保持 3 个可见专色图层时，在导出格式区点击「双专色印刷 PDF」（或「单色印刷 PDF」）。反馈：校验横幅转红、图标变「!」，文案点名「作品含 3 个可见专色图层，『双专色印刷 PDF』最多支持 2 个」，提示行给出两个恢复方向；导出按钮禁用且文案变为「设置冲突 · 已阻止导出」，对应格式卡出现红色「超出 2 层上限」标签；无效导出被完全阻止，结果区不产生任何文件。恢复（两条路径均可）：
1. 改格式：点击「四色印刷 PDF」→ 横幅转绿、按钮恢复 → 点击导出 → 成功卡与记录出现。
2. 改作品：在图层区点「黄专色层」的「可见」按钮将其隐藏（可见专色 3→2）→ 双专色标签变绿「2 / 2 层」、按钮恢复 → 点击导出 → 成功。被隐藏图层的所有数据保留，重新点「隐藏」可恢复显示。

## 数据变化

- 可见专色数：初始 3；隐藏图层 −1、再显示 +1、删除 −1（不可恢复）；该数驱动校验横幅、格式卡标签、面板计数「可见专色 n / 3」与压力条专色名。
- 套准偏差：取所有可见图层的 max(|dx|,|dy|)，≥4 px 时状态由绿转黄；不阻断导出。
- 导出记录：仅成功导出写入，最新在顶部；异常阻断不产生记录；重置按钮清空记录与结果区。
- 文件名字段：空值回退为「纸上工坊海报」；扩展名随格式自动为 .pdf 或 .png。
- 异常期间不得提交的数据：文件名、分辨率、纸张在阻断时保持不变，恢复后直接复用。

## 人工验收步骤

正常闭环：
1. 双击打开 `047-print-shop.html`，确认中间纸张上有叠印「印」字与品红出血框。
2. 把「青专色层」浓度拖至 50%——预览青色块变淡，无页面刷新。
3. 把「黄专色层」纵向套准拖到 +5——黄色圆与色带下移，看样台头出现黄色「套准偏差 5px · 偏大」。
4. 确认右侧「四色印刷 PDF」选中、横幅绿色，点击「生成导出文件」。
5. 等待进度条走完，成功卡显示「纸上工坊海报.pdf」，导出记录出现第一条绿色「成功」。

异常与恢复（路径一，改格式）：
6. 点击「双专色印刷 PDF」→ 横幅变红、点名 3 个可见专色图层、按钮变灰且文案「设置冲突 · 已阻止导出」；此时点击按钮无反应。
7. 点击「四色印刷 PDF」→ 横幅转绿、按钮恢复 → 点击导出 → 成功卡与记录更新。

异常与恢复（路径二，改作品）：
8. 再次点「双专色印刷 PDF」触发冲突，然后点「黄专色层」的「可见」按钮 → 计数变「可见专色 2 / 3」、双专色标签变绿「2 / 2 层」、按钮恢复可用。
9. 点击「生成导出文件」→ 进度 → 成功卡显示双专色与对应大小，记录新增一条。
