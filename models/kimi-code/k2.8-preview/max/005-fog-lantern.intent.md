# 005 找回密码

## 意图元数据

- 意图版本：1
- 对应规范：`005-fog-lantern.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「进不去」翻译成视觉语言：雾灰夜色里只亮一盏琥珀灯笼，光是唯一向导。卡片收在灯下，像夜里唯一还开着的窗口。发送成功不庆祝，只把灯换成一只信封，用 60 秒倒计时代替催促，安抚而非催促用户。

## 适用场景与目标用户

面向有夜间使用习惯的账户型产品——工具 SaaS、独立 App、社区平台的登录辅助页；典型用户是密码遗忘、急切想拿回入口的老用户，情绪偏焦虑，需要在安静、低刺激的界面里完成一步操作并确认「邮件正在路上」。

## 非目标

- 不做多步向导（填邮箱 → 收邮件 → 设新密码拆成多页），本题只到「已发送」为止。
- 不用高饱和品牌色、不用插画人物、不做验证码图形或滑块。
- 不连接真实发信与真实登录跳转，等待态靠本地倒计时驱动。
- 不展示密码强度、不处理未注册账号的枚举提示（统一回复已发送）。

## 复刻提示词

雾灰黑的夜里挂一盏暖琥珀纸灯笼，光晕呼吸、灯身微摆；灯下一张 400px 深色卡片「找回密码」，单输入框收手机号或邮箱，琥珀渐变主按钮发送后切成等待面板：信封图标、掩码联系方式、60 秒倒计时重发按钮，底部「返回登录」。低饱和、全系统字体、单文件离线。
