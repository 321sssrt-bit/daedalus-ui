## 产品边界

实现：单账户钱包的转账主流程（收款人选择、金额输入、资金来源选择与切换、核对确认、成功凭证）、余额不足异常的阻断与恢复、大厅余额与最近同行记录的实时更新。不包含：添加/编辑收款人、转账备注与附言、红包与群收款、提现与充值、账单筛选与导出、支付密码/指纹核验、消息通知中心、多币种与汇率。

## 正常流程

1. 大厅查看余额与来源胶囊（默认零钱 ¥1,286.50）→ 点击收款人「妈妈」（检票口 A）→ 屏幕切至金额屏，顶部出现「向妈妈 转账」条，步骤条「收款人」打勾。
2. 键盘输入 500（或点快捷 ¥500）→ 金额显示 46px「500.00」、按钮解禁 → 点「核对并确认」→ 确认屏票卡列出收款人妈妈、金额 ¥500.00、来源零钱及可用余额、手续费免费、预计 2 小时内到账。
3. 点「确认转账 · 嘀，进站」→ 按钮变「闸机开启中…」，闸杆 700ms 内旋转 95° 变绿 → 900ms 后进入凭证屏：铜环绿勾、「转账成功 · 已进站」、38px 金额、「已到账」印章盖章、凭证号与时间生成、23 根条码线。
4. 点「回到大厅」→ 大厅余额变为 ¥786.50，最近同行记录顶部新增「妈妈 转账 · 今天 HH:MM −500.00」。

## 异常触发与恢复

- 触发：金额屏输入超过当前来源可用余额的金额（默认零钱 ¥1,286.50，输入 2000 即可），进入确认屏点「确认转账 · 嘀，进站」。金额屏阶段来源行下方已先有红色超支提示条。
- 反馈（阻断）：闸机保持关闭，确认屏弹出「余额不足 · 闸机未开」面板（#F7E3DC 底、红铃铛摆动）：文案列出本笔金额、当前来源可用余额与差额（本例还差 ¥713.50）；不生成凭证、余额与最近记录均不变。
- 恢复 A（换来源）：点面板内「换用零钱通支付（余额 ¥8,540.22）」→ 面板收起、来源行/票卡来源同步变为零钱通、弹 Toast「已换用零钱通」→ 再次点「确认转账 · 嘀，进站」→ 闸机开启 → 凭证可见，资金来源显示零钱通，零钱余额保持不变。
- 恢复 B（改金额）：点「返回修改金额」→ 回到金额屏且金额 2000 完整保留、金额数字震动提示 → 改输 1000（或点快捷 ¥1,000）→ 超支提示条消失 → 再点「核对并确认」→ 确认成功 → 凭证可见，零钱余额扣为 ¥286.50。

## 数据变化

- 成功转账：当前来源余额按转账额扣减（四舍五入到分）；最近同行记录列表头部插入一条 `{姓名, "转账 · 今天 HH:MM", -金额}`；生成一条含凭证号、检票口、来源、时间戳的凭证数据。
- 异常发生：任何来源余额、最近记录、凭证号都不得变化；已输入金额与收款人选择必须保留，可直接用于恢复操作。
- 资金来源切换：仅改变当前来源标记与各行可用余额显示，不产生任何扣款或记录。
- 金额输入约束：两位小数、整数位至多 6 位，避免脏数据进入确认屏。

## 人工验收步骤

正常闭环：
1. 打开页面 → 看到穹顶大厅：余额 ¥1,286.50、三个来源胶囊、4 位收款人、2 条最近记录。
2. 点「妈妈」→ 进入金额屏，顶部「向妈妈 转账 · 检票口 A」。
3. 点键盘 5、0、0 → 金额显示 500.00，底部按钮变铜色可点。
4. 点「核对并确认」→ 票卡金额 ¥500.00、来源零钱，点「确认转账 · 嘀，进站」→ 闸杆转绿 → 凭证屏出现，印章「已到账」。
5. 点「回到大厅」→ 余额 ¥786.50，最近记录首条为妈妈 −500.00。

异常与恢复（路径 A 换来源）：
1. 点「林小满」→ 输入 2000 → 来源行下出现红色超支提示。
2. 点「核对并确认」→ 点「确认转账 · 嘀，进站」→ 闸机不开，出现「余额不足 · 闸机未开」面板，显示可用 ¥1,286.50、还差 ¥713.50。
3. 点「换用零钱通支付」→ 面板消失、票卡来源变零钱通。
4. 再点「确认转账 · 嘀，进站」→ 闸机开启 → 凭证屏显示来源零钱通；回大厅可见零钱余额仍为 ¥786.50（未被异常扣动）。

异常与恢复（路径 B 改金额）：
1. 再点「陈房东」→ 输入 2000 → 确认 → 触发余额不足面板。
2. 点「返回修改金额」→ 金额 2000 保留、数字震动。
3. 点「清空」后输 1000 → 红色提示条消失 → 核对并确认 → 转账成功 → 凭证金额 ¥1,000.00；回大厅零钱余额为扣减后数值。
