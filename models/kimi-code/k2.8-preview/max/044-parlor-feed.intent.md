# 044 社交社区产品

## 意图元数据

- 意图版本：1
- 对应规范：`044-parlor-feed.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把动态做成夜间沙龙的墙：丝绒绿衬底，每条内容是一幅金框挂画，发布即挂上墙。衬线与楷体营造夜谈温度，三档可见范围对应厅堂、会员、密友的圈层距离；熄灯开关把发布失败演成打烊，草稿原样留住，重试即重新开灯。

## 适用场景与目标用户

- 品类：小而美的私密社区、读书会/夜谈类兴趣社群的移动端原型。
- 情境：夜间低频、重文字的浏览与发表，用户在意「说给谁听」的圈层感。
- 用户：愿意为内容选观众、反感广场式信息流的中文社区成员与运营者。

## 非目标

- 不做信息流大平台的无限滚动、算法推荐与多媒体混排。
- 不做点赞列表、评论楼层等二级页面，只留入口提示。
- 不用霓虹渐变色或玻璃拟态等现代风皮肤，保持墨绿与哑金的低饱和室内感。
- 不在原型内做真实网络请求与账号体系。

## 复刻提示词

移动端 390×844 的深夜沙龙社交原型：丝绒墨绿墙纸（#14291f），动态做成带挂钩的金框挂画（金 #d4a94e、奶油画布 #f3ead3），衬线品牌字 + 楷体题签；底部弹层撰写新内容，三档可见范围（公开厅堂/会员可见/仅密友）单选，发布成功新画框挂入墙顶；右上「熄灯演示」开关制造发布失败——红色警示、草稿与范围原样保留，重新开灯后可重试成功；宽屏装入圆角手机框，全状态共用同一套墨绿金设计系统。
