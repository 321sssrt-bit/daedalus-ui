# 037 列表空态

## 意图元数据

- 意图版本：1
- 对应规范：`037-greenhouse.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

空态不是「没有」，而是「还没种」：温室、幼苗与光晕把创建动作包装成培育的开始，降低空列表的挫败感；陶土与温室绿让农业隐喻可信不幼稚。

## 适用场景与目标用户

面向园艺、种植记录或任何「从空开始收集」的中文应用；适合首次进入、列表为空的时刻，引导用户创建第一条内容。

## 非目标

不做错误提示、不做引导蒙层教学、不做推荐内容填充；空态保持单一主行动，不堆功能入口。

## 复刻提示词

温室空态页：米白底 390px 圆角手机框，216px 光晕幼苗插画、标题「这里还空着」、「去创建」主按钮展开两个选项，底部四项导航当前项高亮，陶土与温室绿配色。
