# 029 文件上传

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`029-dock-crane.html`
- 复现范围：单页桌面端文件上传台，覆盖拖放/点击选择入列、文件大小与状态展示、删除（退运）与开始处理（批量进度推进）全流程，不含任何后端上传。

## 内容与数据

- 品牌与场景文案（必须保留）：「津港重工 JINGANG HEAVY · 单证吊装调度台」；吊装区标题「把文件拖到这里装船」；说明「支持 PDF / XLSX / DOCX / CSV，单箱不超过 50 MB」；按钮文案「从堆场选择文件」「启动吊装作业」；删除按钮「退运」。
- 队列初始数据（3 票，入列即「待装船」）：`Q4舱单-津海2298.xlsx` 3.6 MB、`报关委托书-PTC0412.pdf` 812 KB、`美西线CW7装箱单.csv` 128 KB；总大小合计 4.5 MB 显示在队列头部右侧。
- 卡片字段顺序：扩展名铭牌 → 文件名 → 大小（mono）→「 · 单证 JG-编号」→ 状态徽章 → 退运按钮；下排为进度轨。
- 状态机：`待装船 → 吊装中 x% → 已入舱`；「退运」即从队列移除（无二次确认）；全部删除后列表区显示占位文案「泊位空闲 · 暂无待装船单据」。
- 大小格式：≥ 1 MB 保留一位小数加「 MB」，否则四舍五入加「 KB」；作业栏估算文案按「票数 × 4 秒」刷新。
- 调度元信息：调度员 王工 / 泊位 A-07 / 夜班 22:00–06:00；吊装区底部统计：今日已入舱 128 票、平均吊装 4.2 秒/箱、泊位状态 空闲。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 吊装区悬停 / 拖入 | 160 ms ease（边框色、底色、内描边） | 边框变工业黄；dragover 额外出现 2 px 内描边与 `#2B333D` 底色 | 过渡移除，颜色反馈即时切换保留 |
| 启动吊装 | 即时（按钮禁用 + 文案切换） | 按钮变灰显「吊装作业进行中…」，各卡徽章变黄并开始计数 | 相同 |
| 进度推进 | 每 90 ms 步进 2–8%，进度条 width 过渡 180 ms linear | 填充条 0→100% 增长，徽章显示「吊装中 x%」，完成时左缘与徽章转绿 | 过渡移除，数值与填充仍即时更新（保留必要反馈） |
| 退运删除 | 200 ms ease（透明度 + 位移） | 卡片透明度降至 0 并右移 24 px 后从 DOM 移除，头部票数与总大小同步刷新 | 过渡移除，卡片直接消失，统计照常刷新 |
| 按钮按下 | 即时 | 主按钮下移 1 px、硬阴影由 2 px 变 1 px | 相同 |

## 复现验收清单

- [ ] 1280 × 800 下：顶栏高 64 px 且底边为 2 px 工业黄；主区为 420 px 吊装区 + 1fr 队列面板两列，容器最大宽 1160 px 居中
- [ ] 队列初始含 3 张文件卡片，每张均显示扩展名铭牌、文件名、大小（MB/KB）与「待装船」徽章，头部显示「3 票 · 共 4.5 MB」
- [ ] 点击吊装区任意处或「从堆场选择文件」可打开系统文件选择；把文件拖入吊装区时区域出现黄色内描边，松手后列表新增对应卡片
- [ ] 点击「启动吊装作业」：按钮立即禁用并显示「吊装作业进行中…」，各卡进度条真实推进、徽章经「吊装中 x%」变为「已入舱」，左缘与徽章变绿，作业栏显示「本批单据全部入舱，可以收工」
- [ ] 点击任一「退运」：按钮先变红，卡片在 200 ms 内淡出右移并移除；删除处理中的卡片会停止其进度；删光后列表显示「泊位空闲 · 暂无待装船单据」
- [ ] 视口缩至 768 px：布局变单列不横向滚动，吊装区高度约 300 px，卡片内按钮与徽章不重叠
- [ ] 操作系统开启「减少动态效果」后页面无过渡动画，但拖入高亮、进度数值与删除统计仍即时反馈
