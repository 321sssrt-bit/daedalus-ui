# 028 长表单

## 内容与数据

- 关键文案（必须保留语义，可微调措辞）：顶栏「卷宗 FOLIO / 项目立项申请 / 档案号 LX-2026-0187」；节签目录「卷 宗 目 录 · 共 4 节」；四节标题「基本信息 / 需求与范围 / 人员与排期 / 风险与确认」；必填星标「*」；按钮「保存草稿 / 提交申请 / 上一节 / 下一节：××× / 再填一份 / 继续编辑 / 清空草稿并重填」。
- 字段顺序与必填（共 11 项必填）：
  1. 第 1 节：项目名称*、申请部门*（下拉 5 项）、项目负责人*、期望启动日期*（date）、联系电话（选填，正则 `^[0-9+\-\s]{5,20}$`）。
  2. 第 2 节：项目背景与要解决的问题*（多行）、预期成果与衡量方式*（多行）、优先级预判（单选，默认「中 · 有资源就做」）、涉及系统或业务线（多选，可全不选）。
  3. 第 3 节：核心成员名单*（多行）、预估周期*（下拉 4 项）、首个里程碑日期*（date，不得早于期望启动日期）。
  4. 第 4 节：主要风险与依赖*（多行）、补充备注（选填）、信息真实性确认*（勾选框，文案含《内部数据管理办法》）。
- 校验错误文案规则：未填为「请填写 + 字段名」；勾选框为「提交前请勾选确认信息真实有效」；电话为「电话格式不正确，请检查」；里程碑早于启动日为「里程碑不能早于期望启动日期」。
- 示例值：部门选项（供应链中心/零售运营部/客户成功部/数据平台部/品牌市场部）；周期选项（2 周以内/1 个月左右/1 个季度/半年以上）；里程碑提示文案明确写出跨字段规则。
- 初始状态：全部必填为空、优先级默认选中「中」、草稿状态「尚未保存草稿」、总体完成度 0%、第 1 节激活、错误徽标全部隐藏。
- 草稿数据：localStorage 键 `folio-draft-v1`，存全部输入值 + 保存时间戳；载入页面自动恢复并显示「已恢复 HH:MM 的草稿」；保存覆盖旧草稿；清空删除键并复位表单。
- 提交成功回执行：项目名称、负责人 · 部门、期望启动、预估周期、首个里程碑、优先级，末尾附受理时间与档案号。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 切换节签 / 上一节 / 下一节 | 0.28s ease | 新面板从右侧 16px 处淡入位移归位（`pageIn`） | 动画取消，直接呈现 |
| 输入校验失败（提交或跨字段规则） | 0.18s ease | 控件红边红底 + 横向抖动 ±4px + 错误行文字，所在节签亮红色错误数徽标 | 抖动取消，保留颜色与文字 |

| 提交成功 | 遮罩 0.2s 淡入；卡片 0.3s 上移；印章 0.3s、延迟 0.18s，从 1.6 倍缩放并旋转 −12° 落下 | 双环红章「已受理」盖在回执卡右上角，完成度等状态保留 | 全部取消，印章静态呈现 |
