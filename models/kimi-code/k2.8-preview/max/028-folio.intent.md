# 028 长表单

## 意图元数据

- 意图版本：1
- 对应规范：`028-folio.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把长表单做成一只牛皮纸卷宗夹：左侧是分页签目录，右侧一次只摊开一页，用「翻页」代替「长滚动」。必填星标像公文批注一样醒目，提交成功盖一枚红章回执。取舍是信息密度偏高、视觉噪点克制，换取多节内容一眼可分、进度可量化。

## 适用场景与目标用户

企业内部中后台的多节登记表单：立项申请、采购审批、供应商入驻、入职资料、合规报备等一次要填十几项、分属不同主题的桌面端场景。主要用户是办公室职能人员（运营、财务、HR、项目经理），习惯在 1280 宽的办公屏上一次性填完或分多次补完，需要随时保存、下次续填、清楚知道还差几项。

## 非目标

- 不做移动优先：768px 只是不碎的兜底，不是目标体验。
- 不做步骤向导式的「锁定回退」（已完成节仍可随时跳回改）。
- 不做富文本、附件上传、多人协作与后端真实提交；提交是前端回执模拟。
- 不做浅色极简白底风、玻璃拟态或大面积插画；牛皮纸 + 档案章是核心气质，不随流行风格漂移。

## 复刻提示词

桌面端 1280×800 的牛皮纸卷宗风长表单：深棕桌面底上，左侧 264px 牛皮纸节签栏（4 枚可跳转分节签 + 完成度进度卡），右侧羊皮纸卷宗夹，外凸分节签、一次只显示一节，表单控件为米白填写格配 1px 棕边；红色 `#b23a2b` 只给必填星标、错误态、提交按钮与「已受理」圆形回执章；中文公文文案 + 衬线显示字，减少连续动画并尊重 prefers-reduced-motion。
