# 019 购物车

## 意图元数据

- 意图版本：1

## 设计意图

把购物车做成社区面包房的取货柜台：暖奶油底、软圆角卡片、糕点以 Flat 插画躺在浅碟色块里，价格用深焦糖突出。删除被比喻成「放回柜台」，先内联确认再 toast；免配送进度条把凑单变成盼头。代价是放弃冷色对比，换亲切感。

## 适用场景与目标用户

- 社区烘焙店、私房甜品店的线上预订购物车：用户已挑好几款现烤糕点，调整数量后等出炉配送或到店自提。
- 低频高情感的礼品型消费：肉桂卷、生吐司这类有季节感的商品，用户愿意凑免配送门槛。
- 主要用户：周边 3 公里内下单的家庭用户、为下午茶备货的上班族，以及把购物车当「待买清单」反复调整的回头客。

## 非目标

- 不做冷色硬核电商风：不出现纯黑导航、白底硬阴影、蓝色主按钮。
- 不做 SKU 规格矩阵（大小 / 口味 / 加料组合选择），规格只是一行描述文字。
- 不做优惠券、积分、会员价体系，促销只保留「满 ¥128 免配送费」一条规则。
- 不做真实支付、地址与配送时段选择，结算止于模拟确认浮层。
- 不做推荐商品、猜你喜欢等加购模块，购物车保持只处理已选商品。

## 复刻提示词
