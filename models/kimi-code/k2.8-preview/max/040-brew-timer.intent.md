# 040 等候

## 意图元数据

- 意图版本：1
- 对应规范：`040-brew-timer.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「系统处理中」的等待换成一壶手冲的计时：闷蒸、注水两个阶段让时间有形状，液面与咖啡色系给等待一个可预期的终点；放到一边与取消给了等待中的掌控感。

## 适用场景与目标用户

面向慢生活、手冲咖啡爱好者或使用提交后等待场景（如下单冲煮、预约制作）的中文应用；适合把机械等待转化为有仪式感的倒计时的产品。

## 非目标

不做真实设备物联控制、不做通用 loading 旋转圈、不做多任务队列；等待只承载单次冲煮流程，避免游戏化积分。

## 复刻提示词

手冲等候页：奶咖底 390px 手机框，冲煮卡含 180px 壶与液面动画、44px 倒计时、三阶段步骤条；可放到一边成迷你进度条、取消需确认、完成出绿色印章回执。
