# 047 创作工具产品

## 意图元数据

- 意图版本：1
- 对应规范：`047-print-shop.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把界面做成一间活版印刷工坊：铅字架分格收纳图层，油墨黑为骨、品红青黄专色为肉，预览用叠印混合模拟真实套印，导出即开印。取舍：不做像素级设计器，只让参数—预览—导出的闭环像校样一样可信，异常像师傅拍红章一样被当面拦下。

## 适用场景与目标用户

独立印刷工作室、riso/活版工作坊与纸品设计师：接单后排版海报、传单与卡片，需要一边调油墨浓度与套准一边确认印效，再按成本选择四色、双专色或单色输出并交付印厂文件。也适合品牌方市场人员自助出一张活动海报的印刷稿。

## 非目标

- 不是通用平面设计工具：无自由绘制、无素材库、无多画布。
- 不做真实文件编码与色彩管理模拟，导出为可信的前端回执。
- 不采用深色 IDE 风或玻璃拟态等流行套路，保持工坊纸墨质感。
- 不含协作、版本历史与云端能力。

## 复刻提示词

桌面三栏创作工具「铅印工坊」：油墨黑顶栏，左右铅字架式纸色面板带 4px 木边分格；中间看样台用 multiply 叠印渲染品红「印」字、青块、黄圆海报，带品红出血虚线框与套准十字；左栏四个图层卡各配浓度与横/纵套准滑杆，右栏四张导出格式单选卡实时校验可见专色数，冲突时朱砂红横幅点名阻断、按钮禁用，恢复后导出成功卡与记录写入同一套纸墨设计系统。
