# 043 即时通讯产品

## 意图元数据

- 意图版本：1
- 对应规范：`043-wire-room.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把即时通讯装进一间老式电报室：消息是打孔纸条，发送是黄铜电键，开关是断线闸刀。送达回执沿用单勾到双勾的电报语感，让"线路中断—重发"的失败演练有实体依托，复古质感同时保证每一步状态可读、可点、可恢复。

## 适用场景与目标用户

- 有情怀滤镜的通讯类 App 概念原型、复古主题设计探索、线下沉浸式交互展的界面借景。
- 主要用户：喜欢蒸汽/电报时代美学的怀旧型用户，以及需要演示"发送—送达—失败—重试"完整状态机的产品与开发评审者。

## 非目标

- 不追求一比一复刻真实电报机操作，闸刀与电键是可点控件而非物理仿真。
- 不使用牛皮纸泛黄的脏旧滤镜做旧到影响文字可读性；纸张只做轻倾斜与打孔带暗示。
- 不引入表情、贴纸、语音、群聊等现代通讯能力，避免稀释电报室的单一气质。
- 不做暗色/浅色双主题，深木色 + 黄铜 + 纸条纸色即唯一设计系统。

## 复刻提示词

一间老式西关电报局里的即时通讯原型：深木炭木墙底，消息做成微微倾斜的打孔纸条（我方米白、对方牛皮），顶部黄铜报头配摩尔斯徽章与线路信号灯，发送是一枚 52px 黄铜电键，底部有一把「线路检修」黄铜闸刀；扳下后下一条消息盖红色「线路中断」章并可重试恢复，单勾到双勾即拍发回执。
