# 033 钱包首页

## 意图元数据

- 意图版本：1
- 对应规范：`033-coin-pocket.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把电子钱包做成一只旧皮夹：皮革卡面、缝线、黄铜件传递「钱被妥善收着」的触感，暖棕色系与传统账本呼应，让数字余额有实体温度。

## 适用场景与目标用户

面向 30–50 岁、习惯记账与现金管理的中文用户；用于日常查看余额、转出收款的个人钱包首页，适合注重资产安全感的产品。

## 非目标

不做深色金融大屏、不做卡券营销位、不引入加密货币元素；扫码收款的二维码只是示意图案，不承载真实编码。

## 复刻提示词

旧皮夹手机钱包：米色底上 390px 手机框，皮革缝线钱包卡配 40px 余额大字与黄铜强调，快捷槽、流水列表、底部导航齐备，暖棕皮革质感贯穿。
