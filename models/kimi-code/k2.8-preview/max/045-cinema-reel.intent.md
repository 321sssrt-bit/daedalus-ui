# 045 音视频平台

## 意图元数据

- 意图版本：1
- 对应规范：`045-cinema-reel.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「看片」从工具行为还原成进放映厅的仪式感：深红绒幕围合银幕、金色光束自上而下、胶片齿孔与齿轮点题，整个原型像一座夜间小影院。队列与状态卡借用大堂告示牌的排版，让断网中断像放映事故一样醒目、可恢复，取舍是牺牲信息密度换沉浸感与三态可读性。

## 适用场景与目标用户

- 品类：长视频 / 点播影院类桌面端产品，尤其是主打片单放映、合集连播的文艺向平台。
- 情境：用户在宽屏桌面上挑片、排队连播、临时中断后接着看。
- 用户：把观影当仪式而非刷信息流的人；需要明确「我看到哪了」并随时续播的重度追片者。

## 非目标

- 不做竖屏移动端、不做真实视频流、播放/缓冲仅为页面内模拟。
- 不采用信息流瀑布、卡片无限加载等短视频式套路。
- 不含账号、评论、弹幕、推荐算法等相邻能力。
- 视觉上刻意不用霓虹渐变、玻璃拟态、圆胖图标等通用模板。

## 复刻提示词

一座深夜放映厅式的桌面音视频平台：暖黑底、深红绒幕包裹 16:9 银幕、顶部金色光束与胶片齿孔、底部绒座大堂跑马灯；左片库右队列与状态卡，中间控制条含进度滑杆、「断网演练」红钮与「保存进度」金钮；断网时银幕浮出红边中断卡并可「重新连接」从原进度续播，全部状态共用同一套红金放映厅设计系统。
