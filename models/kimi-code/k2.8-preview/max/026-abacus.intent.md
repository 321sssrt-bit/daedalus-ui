# 026 账单

## 意图元数据

- 意图版本：1
- 对应规范：`026-abacus.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把账单做成翻得开的账册而非极简列表：枣红印泥定信用，米黄账页载流水，双实线封账、金额蓝黑大写封顶，「现行之印」与发票朱红章让每笔都被落印确认。方案卡整版朱红抬出档位，换绑以批注留痕，如账房先生提笔。

## 适用场景与目标用户

面向中小店铺、作坊、老字号进销存软件（本题设定为"流水册"）的经营者与账房：每月核一次月钱与加购费用，需要向店里或税务交回单发票，偶尔更换扣款钱庄。用户习惯"看见纸、看见章才安心"，对金额大写、单号留痕敏感。

## 非目标

- 不做现代极简风：纯白底、无边框表格、幽灵按钮一律不取。
- 不追求图表可视化：本题无趋势图、占比环，用量仅以进度条点到为止。
- 不含支付流程本身：换绑只确认扣款账户，不出现输卡号、短信校验等真实收单环节。
- 不做多端适配：以桌面 1280 px 为主，768 px 仅保证不碎，不为手机重做交互。
- 不用插画与照片：全部气质靠字体、描边、印章与排版撑起。

## 复刻提示词

中式算盘账册气质的桌面账单页：米黄账页底（#f3e9cf）铺竖栏线，枣红（#8a1f1f）作印泥主色；左栏一张朱红"现行方案"卡带圆形"现行之印"与金色用量条，下接可展开换绑的扣款方式卡；右侧账页表双实线封边、蓝黑等宽金额、大写合计，六笔流水可筛选、可下载回单、可开带朱红章的发票浮层；楷体显示字 + 宋体正文 + 等宽数字，全部离线内嵌。
