# 008 权限请求

## 意图元数据

- 意图版本：1
- 对应规范：`008-glass-shield.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

权限弹窗常被做成红色警告，制造不必要的紧张。本题用中性蓝磨砂玻璃卡片，压暗但不遮断背后的产品界面，让人记得自己在哪；允许为实心主按钮、仅此一次为描边次按钮、拒绝退为文字链，用层级而非颜色表达推荐顺序。

## 适用场景与目标用户

桌面端效率工具与内容创作软件的首次能力申请，具体如笔记/文档工具的麦克风与通知授权、设计工具的相册读取、日历应用的提醒权限。主要用户是把这类软件当生产工具的知识工作者：他们需要看懂"要什么、为什么"，并保留"只给一次"的中间选项，而不是被强迫二选一。

## 非目标

- 不使用红色告警色或警示图标，拒绝不是错误。
- 不做全屏遮挡的强制阻断式弹窗，用户始终能看到背后的产品。
- 不实现系统级设置页、真实录音采集与权限持久化存储，仅做请求与结果反馈界面。
- 不加倒计时、二次确认等施压手段。

## 复刻提示词

桌面效率软件场景下的系统权限请求浮层：柔和中性蓝渐变底上，一张 480 px 宽的磨砂玻璃拟态卡片居中悬浮（背景 rgba 白色 + 22 px 背景模糊），背后应用界面被 34% 深蓝灰遮罩轻微压暗但仍可辨认；卡片含 48 px 应用图标、权限徽章、"为什么需要"说明和可展开的访问范围列表；操作分三层——实心蓝主按钮"允许"、白底描边次按钮"仅此一次"、灰字下划线文字链"暂不授权"；三种选择各自切换为带圆形图标的结果面板，并联动改变背后工具栏的麦克风按钮状态。
