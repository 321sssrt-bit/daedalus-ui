# 015 通知中心

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`015-switchboard.html`
- 复现范围：鸣铃工作台桌面端「通知总机」单页，含六条不同类型通知的已读/未读灯态、单条展开话单、逐条灭灯与「全部标已读」拨杆；不含通知偏好设置与真实推送通道。

## 内容与数据

- 六条话单固定顺序与 jack 编号：J-01 告警·构建失败（未读）、J-02 指派·陈屿指派任务（未读）、J-03 批注·沈青回复（未读）、J-04 公告·平台例行维护（未读，初始展开，含「登记为值守人」按钮）、J-05 里程碑·进度 90%（已读）、J-06 新人·梁照加入（已读）。
- 类牌二字固定：告警 / 指派 / 批注 / 公告 / 里程 / 新人，字体为衬线、黄铜底、`#33200a` 字。
- 每条展开话单的「标签：内容」行数与内容固定（如 J-04 的公告含维护窗口、影响范围、值班工程师三行 + 值守按钮）；数据可替换，但标签列宽 76 px、`#7a5623` 色的层级不变。
- 表盘文案结构固定：小标签（值班日期 / 值机时钟 / 待亮灯）+ 等宽大数字；待亮灯数字后带「盏」字。
- 图例六项灯色与类牌一一对应；机身编号行固定为「机身编号 ML-015 · 值班台 №3」。
- 空态文案固定：「所有灯都灭了，总机暂无话务」，上方配一盏灭灯圆点。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 未读灯常亮 | 3.6 s 循环关键帧 `lampflicker`（opacity 在 7% 处降至 0.5、44% 处 0.82） | 霓虹灯轻微闪烁，六色光晕脉动 | 闪烁动画整体移除，灯保持常亮 |
| 点击话单行或 chevron 铜钮 | 280 ms ease（`max-height`）+ 220 ms ease（chevron 旋转） | 话单纸自 0 顶出至内容全高，纸面格线与「标签：内容」显露，chevron 转 180° | 过渡归零，展开/收起即时完成 |
| 点击灭灯铜钮 | 300 ms ease（灯色过渡） | 霓虹灯熄灭回 `#3d3a33`，行描边变淡、标题转灰，待亮灯数字 −1 | 过渡归零，灯瞬时熄灭 |
| 点击「全部标已读」拨杆 | 每条间隔 110 ms 依次灭灯（JS 定时） | 未读灯从 J-01 起逐盏熄灭，数字表盘随每次灭灯递减，最后拨杆转为「灯已全灭」并禁用 | 间隔归零，所有灯同帧熄灭 |
| 按下拨杆/铜钮 | 100–120 ms ease | 键程效果：translateY(2–3 px)、底部实心阴影收短 | 过渡归零，仅留瞬时变色 |
| 切换「只看待亮灯」 | 180 ms ease（铜柄位移）+ 200 ms ease（跑道底色） | 铜柄滑至右端，已读行整行隐藏；再拨回则全部恢复 | 过渡归零，过滤即时生效 |
