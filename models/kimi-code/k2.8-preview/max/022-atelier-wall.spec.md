# 022 个人主页

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`022-atelier-wall.html`
- 复现范围：单页个人主页的全部可见区域与交互——顶栏、悬挂大画布头部、可筛选作品墙、近期动态便签、作品详情浮层、联系浮层与复制轻提示。

## 组件规格与状态

| 组件 | 结构与尺寸 | 默认样式 | 状态变化 |
| --- | --- | --- | --- |
| 关注主按钮（头部） | 胶囊按钮，padding 11px 28px，内含加号图标 + 文字 | 填充 `--accent`，文字 `#FFF9F0`，图标 currentColor | 悬停：底色加深为 #9C3D1D、上移 1px 并加投影；按下 scale(.97)；点击后进入“已关注”态：透明底、1.5px `--accent` 描边、`--accent` 文字，加号图标换成对勾，文字变“已关注”，`aria-pressed=true`，关注者计数 +1；再点退回默认态并计数 -1 |
| 写信联系按钮（头部）与导航“联系” | 同尺寸胶囊按钮 | 透明底、1.5px rgba(47,40,30,.35) 描边、`--ink` 文字 | 悬停：描边变 `--ink`、铺 5% 墨色底；点击打开联系浮层 |
| 媒介筛选 chip | 胶囊，padding 7px 16px，13px 文字 | 纸面底、1px `--line` 描边；首项“全部 · 8”默认激活 | 悬停描边变 `--muted`；激活态：底色 `--ink`、文字 `--paper`、描边 `--ink`，`aria-pressed=true`；点击后作品墙只显示匹配 `data-cat` 的卡片，其余加 `is-hidden`（display:none） |
| 画作卡片 | 整卡可点（button 语义），纸面衬底 padding 14px 14px 16px，上方居中 13px 挂钉 | 微旋转（-1.9deg~1.8deg 按位置循环）、卡片阴影 | 悬停：translateY(-6px) 且旋转回 0°、阴影加深；点击打开作品详情浮层（大图 + 标题 + 媒介尺寸年份 + 创作陈述 + 收藏价 + “咨询收藏这幅”按钮）；被筛掉时 display:none |
| 联系/详情浮层 | 遮罩 + 居中面板（10px 木框、关闭按钮 36px 圆形） | 打开时遮罩淡入 0.2s、面板 0.24s 上移浮入 | 关闭按钮 / 点击遮罩 / Esc 均可关闭，关闭后恢复页面滚动；联系面板内“复制”按钮复制邮箱或微信并弹轻提示，详情面板内“咨询收藏这幅”切换到联系面板 |

焦点态：所有可点元素 `:focus-visible` 为 2px `--accent` 描边 + 2px 外偏移。禁用态、错误态、加载态：本页不使用，不适用。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 0.5s ease（cardIn） | 作品卡与便签淡入 | 时长压至 0.01ms，仅保留淡入结果帧 |
| 悬停画作卡 | 0.25s ease | 上浮 6px、旋转回正、阴影加深 | 同压至 0.01ms |
| 点击关注 | 0.2s ease | 按钮换描边态、图标加号变对勾、计数即时跳动 | 状态切换本身保留（非动画），过渡时长压至 0.01ms |
| 打开浮层 | 遮罩 0.2s、面板 0.24s ease | 遮罩淡入、面板上移并轻微放大浮入 | 压至 0.01ms，浮层直接呈现 |
| 复制成功 | 0.25s ease | 底部 toast 淡入上移，2.2s 后淡出 | 压至 0.01ms |
