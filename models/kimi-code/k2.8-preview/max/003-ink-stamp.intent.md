# 003 邀请进入

## 意图元数据

- 意图版本：1
- 对应规范：`003-ink-stamp.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「受邀入内」做成一次钤印仪式：宣纸为底、朱砂为印，邀请码不是表单字段而是印面，核对即落印——失败砸下「核验未过」红戳，成功落「准入」方印。全部反馈收进纸与印两种材料，不借现代组件语言。

## 适用场景与目标用户

- 会员制私藏读物平台的受邀落地页：出版社内部样书审读、古籍数字阅览室、独立书店会员内测等，只有持函者可进的场景
- 用户是收到纸质函件或邮件邀请的受邀者，页面只承担「验函—放行」一件事，不承担招募与解释
- 1280×800 桌面端单页，作为产品大门或活动入口存在

## 非目标

- 公开注册、找回、自助申请等任何「没有邀请也能进」的旁路
- 霓虹光效、玻璃拟态、渐变糖果色等现代流行视觉
- 营销拉新式落地页结构（卖点罗列、定价表、社保证言）
- 移动端优先与多语言；移动端仅保证不碎版

## 复刻提示词

中式编辑气质的邀请制入门页：宣纸底色配纤维纹理，朱砂印章作主色与反馈语言，竖排文字做点缀。左侧一张竖排邀函卡片（含贴签字号 BPS-1897），右侧把邀请码输入框做成 200px 见方的印面，下接朱砂「核对」按钮；核验失败时砸落一枚旋转的圆形「核验未过」红戳并让印面抖动，成功时落下白文「准入」方印、浮现描边「登堂开卷」按钮。 serif 中文字体、印章式硬投影、克制动画。
