# 046 团队协作产品

## 意图元数据

- 意图版本：1
- 对应规范：`046-site-office.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把协作台做成挂在板房墙上的活图纸：图纸蓝打底、纸面卡片当工单，推进即盖图章，权限拒绝开成红章退件单。安全橙只给主操作与警示，用工地粗粝秩序替代 SaaS 圆润柔和，活动记录如施工日志逐行落墨。

## 适用场景与目标用户

- 产品品类：工程/施工项目的现场任务协作、报验流转工具（也可迁移到监理、装修队的工单协作）。
- 使用情境：板房晨会后分派当天工序、旁站验收后推进状态、资料员追结算归档进度；权限场景是财务专用环节对非财务角色的可见但不可办。
- 主要用户：施工员、资料员、安全员、预算员与项目财务，信息密度按「一眼扫完整层进度」设计。

## 非目标

- 不做登录与多角色切换（身份固定为韩江 · 施工员，用文案与徽章表达）。
- 不用圆角卡片 + 渐变的通用 SaaS 风，不用插画与头像照片。
- 不含评论、附件、通知、统计图表等多余能力；权限申请只做前端登记反馈，不接审批流。

## 复刻提示词

工地办公室气质的桌面协作看板：图纸蓝网格底、米白纸面任务卡、安全橙主按钮、图章红/蓝圆章标记状态；四列任务流（待处理/进行中/待验收/已归档）+ 右侧施工日志式活动记录 + 底部图纸图签栏；权限不足弹窗做成红色「无权操作」退件单，可申请权限或安全返回后完成有权限的推进。
