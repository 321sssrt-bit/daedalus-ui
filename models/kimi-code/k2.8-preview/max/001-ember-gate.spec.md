# 001 登录

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`001-ember-gate.html`

## 内容与数据

- 关键文案（须原样保留）：标题「欢迎回到夜岗」；副文案「验证身份后进入值守台。连续输错 3 次将锁定 15 分钟。」；主按钮「进入值守台」；次操作「忘记密码？」「在此设备上记住我」；脚注「账号由值班调度统一下发 · 遇到问题请联系值班调度 400-820-0147」；成功态「验证通过 / 闸门已开，欢迎回到夜岗。」
- 字段顺序：密码模式 = 账号 → 密码 →（记住我 + 忘记密码）→ 错误区 → 主按钮；验证码模式 = 手机号 → 验证码（内嵌获取按钮）→ 错误区 → 主按钮。
- 示例占位：账号「工号或邮箱，如 qi.chen」；手机号「注册时使用的 11 位手机号」；验证码「6 位数字」；邮箱「如 qi.chen@nightops.cn」。
- 校验规则：账号非空；密码非空；手机号匹配 `^1\d{10}$`；验证码匹配 `^\d{6}$`；邮箱需含 @ 与域名。错误文案逐条对应（如「手机号格式不正确，应为 11 位数字」）。
- 初始状态：密码登录面板可见、验证码面板 hidden；「记住我」勾选；错误区 hidden；成功面板 hidden；弹层 hidden。
- 数据可替换，但信息层级（标题 > 表单 > 次操作 > 脚注）不得漂移。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 0.5s ease-out | 卡片自下方 14px 淡入上移（fadeUp） | 停用，卡片直接呈现 |
| 连续环境动画 | 光柱高光段 4.5s 线性无限下行；光晕 4s 呼吸；状态灯 2.6s、呼吸灯 3.2s 明暗 | 夜航灯语：光点沿柱身循环、橙光呼吸 | 全部停用，保留静态光柱与常亮状态灯 |
| 输入聚焦 | 0.18s | 边框转橙 + 3px 橙色外环 | 保留（瞬时状态反馈） |
| 表单校验失败 | 卡片 shake 0.4s + 错误区即时出现 | 抖动 + 红色错误文案 + 对应输入框红描边 | 抖动停用，错误文案与描边保留 |
| 提交加载 | 0.7s 线性旋转 | 主按钮文字隐藏、显示深色转圈，按钮禁用 | 转圈停用，结果照常呈现 |
| 登录成功 | 0.35s 弹出 | 绿色对勾环放大淡入，整卡切到成功文案 | 弹出停用，成功面板直接显示 |
| 弹层开合 | 0.25s 上浮淡入 | 遮罩模糊 + 卡片上移 12px | 停用，直接显示/隐藏 |
