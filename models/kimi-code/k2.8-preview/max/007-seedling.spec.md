# 007 欢迎空态

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`007-seedling.html`
- 复现范围：仅复现桌面端「新用户首次进入、内容为空」的欢迎空态单页，含主按钮、次要行动按钮、内嵌 SVG 小苗插画与一次成长进度交互。

## 内容与数据

关键中文文案（顺序不可漂移）：

1. eyebrow：`青芽空间 · 新起点`
2. 标题：`欢迎，这里还空空如也`
3. 描述：`你刚刚来到青芽空间，还没有属于自己的作品。别紧张——每个充实的主页都始于一次点击。先种下第一颗种子，它会替你记住成长的过程。`
4. 主按钮初始文案：`种下第一颗种子`；点 1 次后：`继续浇水`；满 3 后：`重新开始`
5. 次要按钮：`导入已有作品`
6. 导入选项：`从本地文档导入`（辅助 `.md / .docx`）、`从剪贴板粘贴`（辅助 `自动识别结构`）
7. 进度标签初始：`成长值 0 / 3`；满值：`成长值 3 / 3 · 种子发芽了`
8. 插画说明：`小苗刚刚破土` / `每完成一次记录，它就长高一点。`

数据规则：成长值 step 初始 0，点击主按钮 +1，到 3 后再点重置为 0 并还原插画；进度条宽度 = step ÷ 3 × 100%。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | .6s ease-out（卡片延迟 .12s） | 左列与右卡片从下方 16px 处淡入上移 | 动画禁用，直接呈现终态 |
| 点击主按钮 | 进度条 .8s cubic-bezier(.22,.9,.3,1)；新叶 .5s/.6s 延迟过渡 | 进度条前进一格；成长值满 2 后新叶展开、土壤变深绿；按钮悬停上移 1px、阴影加深 | 过渡时长压到 .01ms，仅保留即时状态切换 |
| 点击次要按钮 | .35s ease max-height 展开 | 导入面板从上向下展开，按钮边框变绿 | 同上，直接切换展开状态 |
| 选中导入选项 | .15s ease | 行项绿框 + 浅绿底 + 行尾 ✓ | 同上 |
