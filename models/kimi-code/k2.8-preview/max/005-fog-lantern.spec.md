## 内容与数据

- 品牌行：「雾港通行证」（12px、字距 .32em、居中）。
- 主标题：「找回密码」；副标题：「输入注册时使用的手机号或邮箱，我们把重置入口发给你。」
- 输入标签「手机号或邮箱」，placeholder「例如 name@example.com 或 138 0000 0000」；提交前去除所有空白字符再校验。
- 校验规则：手机号 `/^1[3-9]\d{9}$/` 或邮箱 `/^[\w.+-]+@[\w-]+(\.[\w-]+)+$/；失败文案「请输入有效的 11 位手机号或邮箱地址」。
- 说明小字：「重置入口 15 分钟内有效；为保障账户安全，每小时最多发送 3 次。」
- 等待态正文：「我们已向 {掩码联系方式} 发送重置入口，请在 15 分钟内按提示完成重置。没收到的话，先去垃圾邮件里看看。」掩码规则：手机号保留前 3 后 4（`138****0000`）；邮箱保留首字符 + `***` + 末字符 + 域名（`n***e@example.com`，用户名 ≤2 位时为首字符 + `***` + 域名）。
- 倒计时初值 60 秒，按钮文案「N 秒后可重新发送」；归零后文案「重新发送」。
- 返回登录点击后提示条文案固定为「本题仅演示找回流程，未连接登录页」，停留 2600ms 后淡出。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 无入场动画，静态渲染 | 灯笼以 6s ease-in-out infinite alternate 绕顶 ±1.4deg 摆动；光晕 3.4s 同曲线 opacity .72 → 1 呼吸 | 摆动与呼吸全部停用，灯笼静止、光晕常亮 |
| 输入聚焦 | 0.18s ease | 描边变琥珀色并外扩 3px 焦点环 | 过渡取消，状态瞬变 |
| 提交发送 | 900ms 伪发送延迟 | 按钮进入 loading：文案「发送中…」+ 15px 旋转环（0.7s linear 无限），随后切换到等待面板 | 旋转环停用，文案与切换照常 |
| 切换到等待态 | 0.34s ease | 面板 fadeUp：opacity 0→1、translateY 8px→0 | 动画取消，直接呈现 |
| 重发倒计时 | 每 1000ms 一跳 | 按钮文案从「60 秒…」递减，归零解除禁用 | 不受影响（非动画） |
| 返回登录 / 重发成功 | 0.22s ease | 底部提示条淡入并上移 12px，2600ms 后淡出 | 过渡取消，直接显隐 |

## 复现验收清单

- [ ] 1280 × 800 下，灯笼 SVG（200 × 196 px）位于视口顶部中线，400px 卡片水平垂直居中，页脚贴底居中，页面无纵向滚动条。
- [ ] 输入框聚焦时描边变为 `#d9934a` 并出现 3px 琥珀焦点环；输入非法内容提交后出现 `#c26d5a` 错误描边与错误文字，开始输入后错误态消失。
- [ ] 提交合法手机号或邮箱后，按钮先显示「发送中…」约 900ms，随后表单面板消失、等待面板淡入，正文中的联系方式按规则掩码显示。
- [ ] 等待态重发按钮从「60 秒后可重新发送」起每秒递减，期间不可点击；归零后变为可点的「重新发送」，点击后重新倒计时并弹出提示条。
- [ ] 两个「← 返回登录」点击后均在底部弹出提示条，2600ms 后自动消失。
- [ ] 视口缩至 768px 宽：卡片占满减去 40px 边距、大标题降为 24px、灯笼缩小，布局无横向滚动、无元素重叠。
- [ ] 系统开启减少动态效果后，灯笼摆动、光晕呼吸、按钮旋转环全部停止，点击与状态切换仍可用。
