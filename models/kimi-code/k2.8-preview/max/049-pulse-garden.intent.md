# 049 健康习惯产品

## 意图元数据

- 意图版本：1
- 对应规范：`049-pulse-garden.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把每日活动种成一座花园：心率玫瑰线代替冷冰冰的圆环，完成度对应植物生长话术，草木绿定安静基调、玫瑰粉负责心跳时刻。校验不弹窗打断，而是原地标红、保留全部进度，让修正成为顺手的下一步。

## 适用场景与目标用户

面向活动量大的年轻白领的每日健康打卡：通勤步行、午间跑步、晚间拉伸后随手补记，目标是当日步数达标与一周节奏自查。信息一屏可录、三 tab 可查，适合碎片时间单手操作。

## 非目标

- 不用深色运动仪表风（荧光绿、数据墙），避免健身房的压迫感。
- 不做多目标、饮食记录、睡眠心率接入、社交排行。
- 不用弹窗模态承载错误反馈，不用 toast 承担校验说明。
- 历史日期补登、记录编辑删除不在原型范围。

## 复刻提示词

移动端健康习惯单页原型「青屿 · 脉动花园」：雾绿纸面 `#edf3ea` + 白卡，草木绿 `#22784a` 为主、玫瑰粉 `#e14c7c` 心跳线点睛；中心八瓣玫瑰线进度环 + 巡游光点；底部三 tab（花园/趋势/记录）；录入步数与用时，越界保存时字段红框抖动并保留进度，纠正后重算。宽屏套居中手机框（刘海 + home 条）。
