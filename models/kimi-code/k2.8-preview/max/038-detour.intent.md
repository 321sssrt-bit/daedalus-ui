# 038 故障

## 意图元数据

- 意图版本：1
- 对应规范：`038-detour.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把报错页做成路边的施工改道牌：黄黑条纹、路障、工单号让人立刻明白「暂时不通但有人管」；重试与回首页给了两条明确出路，避免错误页的绝望感。

## 适用场景与目标用户

面向中文移动应用的临时故障（网络、维护、区域停用）场景；适合需要向用户解释「为什么不行、什么时候好、找谁问」的产品。

## 非目标

不做 404 页面、不做全站维护公告、不堆技术错误堆栈；警示只用在关键操作处，避免红色恐怖氛围。

## 复刻提示词

施工改道故障页：深底 414px 手机框顶置黄黑斜纹，路障插画、GD-2026 工单票卡可一键复制，重试按钮带真实处理态与恢复成功面板，回首页次级按钮。
