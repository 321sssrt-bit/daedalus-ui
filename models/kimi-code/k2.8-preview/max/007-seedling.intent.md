# 007 欢迎空态

## 意图元数据

- 意图版本：1
- 对应规范：`007-seedling.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「空」翻译成「还没开始生长」：淡嫩绿底 + 大量留白让小苗成为唯一视觉焦点，主按钮用实心绿、次要行动用描边绿拉开层级，避免任何信息密度。成长进度条把一次性空态变成有回应的邀请，点三次小苗真的长高，呼应「种下第一颗种子」的隐喻。

## 适用场景与目标用户

面向轻量创作/记录类工具（个人知识库、作品集、种植日记、读书笔记）的新用户首次进入页。典型用户是刚注册、尚无内容、需要被温和引导完成第一个动作的人，而不是寻找复杂功能的老用户。

## 非目标

- 不做数据看板、图表或统计（空态不需要信息密度）。
- 不做深色模式、不做多主题切换。
- 不做真实文件解析或网络导入——导入面板只是入口示意。
- 不采用插画铺满全屏的大图风格，保持桌面端留白呼吸感。

## 复刻提示词

桌面 1280×800 的欢迎空态页：淡嫩绿背景 #f5faf2、超大留白，左列是 eyebrow「青芽空间 · 新起点」、标题「欢迎，这里还空空如也」、温和中文描述、实心绿主按钮「种下第一颗种子」+ 描边次要按钮「导入已有作品」，按钮下方一根 160px 成长进度条；右列白卡片内嵌一株两叶小苗 SVG。点击主按钮三次，进度条走满、SVG 长出新叶、土壤变深绿；点次要按钮展开导入选项面板。全部系统字体、内嵌 CSS/JS、单文件离线。
