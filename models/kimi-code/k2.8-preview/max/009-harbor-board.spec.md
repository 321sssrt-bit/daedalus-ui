# 009 工作台总览

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`009-harbor-board.html`
- 复现范围：仅复现「潮信控制台」桌面端工作台首页，含左侧导航、今日数字仪表行、作业队列、告警与气象侧栏，以及同页内船期队列 / 告警舱 / 吞吐海图三个可切换视图。

## 画布与区域布局

页面为 100vh 高的横向 flex 应用骨架，整体不随页面滚动，仅中间内容区 `#content` 纵向滚动。

| 区域 | 边界与尺寸 | 布局与对齐 | 层级与滚动 |
| --- | --- | --- | --- |
| 页面画布 `#app` | 视口 100% × 100vh，最小适配宽度 768 px | `display: flex` 横排 | 背景为 `#0a1424` 叠加 56 px 间隔经纬网格线 |
| 左侧导航 `#sidebar` | 宽 216 px，全高，内边距 18px 12px 14px | 纵向 flex：品牌区 / 导航列 / 底部值班卡 | 固定不滚动；右边线 1px `#27405f`；≤900px 时收窄为 64 px 图标栏 |
| 顶栏 `#topbar` | 高 60 px，左右内边距 24px | 横向 flex：面包屑 / 班次气象 / 右侧搜索框（240px）+ 铃铛 + 头像 | 固定不滚动；下边线 1px `#27405f` |
| 内容区 `#content` | 顶栏下方剩余高度，内边距 20px 24px 28px | 纵向堆叠视图，`.view.active` 时才显示 | `overflow-y: auto` 单独滚动 |
| 数字仪表行 `#stat-grid` | 四列等宽 grid（`repeat(4, 1fr)`），列距 14px，卡片最小高 158px | 每卡内纵向排：标签 / 大数字 / 涨跌 / 底部 sparkline 与注记 | 卡片四角有 12px 黄铜直角刻度（伪元素实现） |
| 下方双栏 `#dash-lower` | 网格 `minmax(0,1fr) 330px`，间距 14px，上距 14px | 左为作业队列面板，右为 330px 仪表栏（罗盘 / 告警速览 / 值班日志纵向堆叠） | 两栏各自随 `#content` 滚动 |
| 队列行 `.qrow` | 最小高 58px，内边距 0 16px | grid 六列：96px / 1.3fr / 60px / 62px / minmax(110px,0.9fr) / 92px，列距 12px | 行底 1px `#1c3050` 分隔线，末行无 |

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 视图切换（导航 / 面包屑联动） | 0.22s ease 淡入上移 | 新视图整体从透明度 0、translateY(6px) 进入 | 时长压至 0.01ms，直接呈现 |
| 罗经针摆动 | 每 4s 触发，单次 1.2s `cubic-bezier(.3,.9,.3,1)` | 指南针在 135° 基准左右 ±20° 内缓慢偏转 | 定时器不启动，针静止 |
| 「校准罗经」重算吞吐 | 0.6s 数字滚动，帧间隔 40ms | 今日吞吐从旧值滚动到新值，海图今日柱高度重排（0.5s） | 数字直接跳变，无滚动 |
| 行内状态操作（确认靠泊 / 结办 / 改排） | 进度条 0.4s ease | 状态点颜色与文案切换、进度条宽度增长、按钮文案随之改变 | 过渡压至瞬时 |
| 悬停（导航、行、chip、按钮） | 0.15–0.18s ease | 底色与边框颜色过渡 | 过渡压至瞬时 |
