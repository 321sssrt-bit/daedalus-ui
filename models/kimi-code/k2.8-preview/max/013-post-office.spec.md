# 013 收件箱

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`013-post-office.html`
- 复现范围：桌面端「驿邮工作台」内部来信分拣台单页——左侧分拣格口筛选、中间来件信封卡列表、右侧拆信阅读区，含未读过滤、星标切换、归档与还原交互；不含写信回复与真实收发。

## 内容与数据

- 初始 8 封信，字段顺序固定：发件人 · 部门、时间、主题、预览、标签；标签取值限于：出版 / 财务 / 系统 / 客户 / 人事 / 外部 / 行政。
- 初始未读 5 封（m1–m5）、星标 2 封（m4 客户、星洲物流）、已归档 0；首封 m1 自动拆读并即时置为已读，故界面初始显示未读 4 封。
- 顶栏胶囊格式固定：「未读 N 封」，N 为未读且未归档数量；四格口计数分别为未归档总数 / 未读 / 星标 / 已归档。
- 信纸信头固定结构：标签 chip → 主题（衬线 24 px）→ meta 行「发件人 · 部门 ｜ 完整时间 ｜ 编号 驿-0913-NN」；右上邮票（「内部 / 邮 / 1.20」）与红色虚线邮戳（「驿邮 / 09·13」）为装饰。
- 信体为 2 段业务正文 + 右对齐署名「—— 发件人 · 部门」；操作足右侧状态注：归档前「此信在分拣序列中」，归档后「此信已归档 · 可在此还原」。
- 空态文案按格口固定：全部「格口已清空」、未读「没有未读来件」、星标「还没有星标信」、归档「归档格口是空的」；读信区空态固定「待取件 / 从左侧来件序列里点一封信，在这里拆读」。
- 信件正文、发件人、时间为示例数据可替换，但编号格式「驿-0913-NN」、字段顺序与信息层级不得漂移。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 打开一封信 | 280 ms ease（paperIn 关键帧） | 信纸卡从下方 6 px、35% 透明度淡入至完整 | 动画禁用，信纸直接呈现 |
| 卡片悬停 | 180 ms ease | 上移 1 px、投影由 0 1 2 升至 0 6 14、描边变浅棕 #c3b183 | 过渡归零，仅静态变色 |
| 按钮悬停 / 按下 | 180 ms ease / 120 ms ease | 底色与描边渐变；按下下沉 1 px | 过渡归零 |
| 星标 / 归档切换 | 即时（无过渡） | 金星立即填充或消退；归档后卡片从当前序列消失、读信区回到「待取件」空态、吐司弹出 | 同左 |
| 吐司出现 / 消失 | 250 ms ease | 底部居中淡入并上浮 16 px，2400 ms 后淡出 | 瞬时显示与隐藏 |
