# 009 工作台总览

## 意图元数据

- 意图版本：1
- 对应规范：`009-harbor-board.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把"今日全局"装进一艘船的驾驶台：墨蓝夜色打底、黄铜仪表读数，数字像罗经测深一样被逐一扫过；队列与告警压在中左，气象日志收在右栏，值班调度一屏看完全天，不靠大留白装从容。取舍是密度优先于呼吸感，用刻度线、菱形记号和等宽数字维持秩序。

## 适用场景与目标用户

- 港口、航运、物流调度类产品的当班工作台首页，使用者是坐进调度室就要先扫一眼全局的值班主任与调度员。
- 也适配能源监控、园区运营等"数字仪表 + 待办队列"节奏的值守型后台。
- 典型情境：交接班后 30 秒内确认今日靠离泊、在港作业、告警与气象，再决定是否点进队列逐条处置。

## 非目标

- 不用白底卡片 + 左侧深色导航的常规后台模板，也不做营销式大 Hero 与插画。
- 不引入真实地图、图表库与远程数据，海图与 sparkline 均为静态内嵌示意。
- 不做移动端专属重构（仅 768px 不碎的折行兜底），不做暗/亮主题切换。
- 不覆盖下单、审批流等相邻产品能力，队列操作只到"确认 / 结办 / 改排"为止。

## 复刻提示词

桌面端 1280×800 的港口调度工作台，航海日志气质：墨蓝夜色背景（#0a1424）叠经纬细网格，黄铜（#c9a445）做仪表与状态强调；左侧 216px 深色导航含品牌罗盘与值班卡，顶栏面包屑 + 搜索 + 告警铃铛；主区四枚带刻度的数字仪表卡（靠泊 / 离泊 / 在港作业 / 吞吐，等宽大数字 + sparkline），下方左为可筛选的船期作业队列（状态点、进度条、行内操作按钮），右为罗盘气象仪、告警速览、值班日志；同页可切到全宽队列、告警舱与 7 日吞吐海图，全部交互在单文件内完成。
