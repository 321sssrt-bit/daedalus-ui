## 内容与数据

- 商品名称：`「听泉」斗笠盏`；eyebrow：`龙泉青瓷 · 全手工`；署名行：`128 位茶友收藏 · 累计售出 326 只 · 匠人 林见山 手作`。
- 价格规则：容量基准价 80 ml = ¥328、120 ml = ¥368、160 ml = ¥428；月白釉加价 ¥40，粉青釉与梅子青釉不加价；单价 = 容量基准价 + 款色加价；合计 = 单价 × 数量（初始 1，范围 1–9）。
- 款色三选：粉青釉（不加价）、梅子青釉（不加价）、月白釉（+¥40），默认选中粉青釉。
- 容量三选：`80 ml 独酌 ¥328`、`120 ml 对饮 ¥368`、`160 ml 小聚 ¥428`，默认选中 120 ml。
- 初始渲染：单价 ¥368，合计 ¥368；款色/容量/数量任一变化后价格区与合计立即重算，左侧图卡说明行与 SVG 釉色同步变化。
- 服务说明固定三条：顺丰陆运包邮 / 破损包赔，签收 24 小时内登记 / 七天无理由退换。
