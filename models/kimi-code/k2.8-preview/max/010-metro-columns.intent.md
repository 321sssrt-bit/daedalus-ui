# 010 看板

## 意图元数据

- 意图版本：1
- 对应规范：`010-metro-columns.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把看板做成一份摊开的城市周刊：刊头刊号、衬线栏号、实线框与硬阴影取自纸媒栅格，四栏用高饱和撞色标记工序状态，让"事情在列间走"读起来像稿件在编辑部流转——可核对、可计数、有截止日。刻意避开圆角白板与柔影，用印刷感的边界和编号建立秩序。

## 适用场景与目标用户

- 内容生产型团队的主线流转：周刊/公众号选题会、出版社编务、电视台栏目制片，记者与责编按"采→写→校→刊"推进条目。
- 小型创意工作室的稿件/工单看板：设计、文案、客户改稿按工序列流转，负责人在刊头一眼看到在办与已交付数量。
- 需要向客户演示流程进度的场合：编号 + 截稿日 + 计数胶囊让进度可点名核对，而非模糊感受。

## 非目标

- 不做 Trello 式圆角卡片白板、柔和投影与拖拽手柄，也不实现真实的拖拽排序。
- 不做多视图切换（列表/日历/时间轴）、成员筛选、标签过滤与搜索。
- 不做多项目管理、评论协作与通知；数据仅存在于当前页面会话，刷新即还原为初始 9 卡。
- 不做移动端优先布局，窄屏只是把四栏折成两列，不改成单栏时间线。

## 复刻提示词

一张杂志栅格风的四栏任务看板：米纸底色 #F5F1E8，顶部刊头仿周刊刊号（衬线大标题 + 通栏分隔条）；四栏栏头为 76px 高撞色实心块（朱红/钴蓝/琥珀/松绿），左侧衬线大栏号 01–04 配白色计数胶囊；卡片白底 1px 黑框、左缘 4px 列色条，悬停时 −1px 位移加 3px 硬阴影；点击卡片右侧滑入 380px 详情抽屉可推进/退回栏目，栏底「＋ 登记新选题」内联表单新建卡片至栏顶；全程实线描边、小圆角 2px，无圆角白板气质。
