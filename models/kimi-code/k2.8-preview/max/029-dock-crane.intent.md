# 029 文件上传

## 意图元数据

- 意图版本：1
- 对应规范：`029-dock-crane.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把上传类比为码头吊装作业：文件是集装箱，队列是舱单，处理就是吊装入舱。工业黄与钢灰、虚线泊位、警示斜纹和箱体卡片构成重量感，左缘色条与进度轨让「待装船—吊装中—已入舱」的批次状态一眼可辨；刻意不做云盘小清新，优先传达排期、作业与可撤回的工业秩序。

## 适用场景与目标用户

港口物流、货代、关务类系统的单证批量上传界面。典型用户是码头调度员和单证员：夜间班在桌面工作站上批量递交舱单、报关委托书、装箱单等货运单据，需要清楚看到队列里有几票、多大、处理到百分之几，以及误传入列的文件能不能立即退运撤回。

## 非目标

- 云盘式的圆角卡片小清新、插画化空状态与渐变气泡风。
- 分片续传、秒传、文件夹上传、图片预览、断网重试等真实传输能力。
- 移动端优先的交互设计（本题仅要求缩到 768 px 不碎）。
- 多队列并行、优先级调度等调度台高级功能。

## 复刻提示词

桌面端单文件上传台，码头吊运工业风：炭黑钢灰底 `#14171C`，工业黄 `#F2B100` 主色；顶栏 64 px 带 2 px 黄色底边与吊机品牌标；左侧 420 px 虚线泊位拖放区（警示斜纹、门座起重机 SVG、黄色主按钮、三栏作业统计），右侧舱单面板内三张集装箱式文件卡——左缘 4 px 箱号色条、黄色扩展名铭牌、文件名 + mono 大小 + 状态徽章 + 红色「退运」按钮，底部 6 px 进度轨；底部 76 px 作业栏放「启动吊装作业」黄色主按钮；状态机「待装船 → 吊装中 x% → 已入舱」，点击启动后进度真实推进；系统字体栈，全部离线内嵌，中文真实文案。
