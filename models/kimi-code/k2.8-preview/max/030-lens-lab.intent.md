# 030 筛选检索

## 意图元数据

- 意图版本：1
- 对应规范：`030-lens-lab.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把检索页做成一间镜头实验室：冷灰工作台承载全部条件，镀膜蓝紫的 conic 光环只留给镜片与选中态，让「每叠加一个条件就是旋入一片滤镜」。筛选台横置在结果上方而非左侧栏，条件与结果在同一视线里联动，计数像仪器读数一样即时跳动。取舍：不做排序、分页与详情，把注意力全部压窄到「收窄—计数—复位」这一闭环。

## 适用场景与目标用户

- 摄影器材电商、租赁或二手平台的滤镜/镜头选品目录页。
- 光学仪器、精密元件的选型检索页（同款「条件台 + 档案卡」骨架可平移）。
- 主要用户：按需选配的摄影师与摄像师、整理器材库存的租赁店选品员——他们目标明确，习惯用口径、类型、镀膜等硬参数快速收窄候选。

## 非目标

- 不做电商左侧栏布局，也不用面包屑、排序、分页、收藏等目录页常见模块。
- 不加载真实商品图：镜片一律用 CSS 光环隐喻，保持离线单文件。
- 不做移动端专属重构，只保证 768px 不碎；不做详情页、对比与加购流程。
- 不使用阴影层级体系，刻意只用边框与渐变区分层次。

## 复刻提示词

桌面端暗色检索页「镜头实验室」：冷灰 (#1b1e23/#24282f) 画布，蓝紫镀膜渐变 (#7c6cf5/#5cc8ff/#b48cff) 只用于选中态与镜片光环；顶部 64px 顶栏，其下 14px 圆角「配镜台」面板横置 4 组条件（多选 chip、价格滑杆、现货开关），下方结果工具条实时显示「匹配 N / 10」，4 列结果卡各带 120px conic 渐变镜片圆；条件变化即时过滤并重渲染，含空状态与清除复位，尊重 prefers-reduced-motion。
