# 025 账号设置

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`025-switch-room.html`
- 复现范围：单页账号设置台，含身份行、资料/安全/通知三组开关面板、行内展开详情与全部本地生效的开关交互。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 1280 px | 三列面板等宽排布，身份行单行 | 全部控件原始尺寸 |
| 窄于 1024 px（含 768 px） | 面板组降为单列纵向堆叠；顶栏自动换行、高度由 56 px 转自适应；身份行允许换行，右侧状态区移到下一行 | 行高、拨杆、仪表灯尺寸不变；详情抽屉宽度随面板通栏 |

## 内容与数据

- 身份行固定字段顺序：头像（昵称首字）→ 姓名 + 角色徽章「高级巡检员」→ 等宽 UID「UID 8842-0917」→ 部门 → 右侧在线灯与「上次登录 2026-09-28 21:14 · 上海」。
- 三组设置固定顺序：资料（昵称 林澈 / 个人简介 / 所属部门 运行控制部 · 二组）、安全（登录密码 已设置 180 天 / 两步验证 已启用 / 登录设备 3 台在用）、通知（总电门 / 邮件 lin@airops.cn / 短信 138****6621 / 站内推送 塔台工作台 / 提醒频率 每小时）。
- 初始开关状态：总电门开、两条验证与三条通知通道全开，所有灯按通道语义点亮（绿=安全，琥珀=通知）。
- 校验规则：昵称、简介非空（12 / 60 字上限）；新密码 ≥ 8 位且两次一致、原密码必填；设备「本机」不可下线。
- 通讯记录条初始文案「系统就绪 · 全部开关状态已同步」，之后逐条替换为最近操作 + 当前时间戳。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 无进入动画 | 时钟从加载起每秒刷新 | 不受影响，保留 |
| 点击设置行 | max-height / padding 260 ms ease | 详情抽屉滑出，chevron 旋转 200 ms，行标签转琥珀 | 时长压至 0.01 ms，展开仍可用 |
| 拨动拨杆 | 旋钮位移 180 ms ease，滑轨变色 200 ms | 旋钮滑到对侧，灯亮灭与 glow 同步，记录条追加操作日志 | 位移即时完成，灯状态保留 |
| 按钮悬停 / 按下 | 120 ms 亮度、按下位移 1 px | 金属按钮明暗与下沉反馈 | 即时反馈保留 |
| 琥珀灯常亮 | 2.4 s ease-in-out 无限呼吸 | 琥珀灯 1 ↔ 0.55 透明度循环 | 动画关闭，灯保持常亮 |
