# 021 内容目录

## 意图元数据

- 意图版本：1

## 设计意图

把"先看目录"做成一座小型文库的检索台：深咖啡底、横躺的书脊条目、左侧分类色带与米黄摘要卡，让读者像在书架上抽书一样浏览——先看书脊索书号，抽出来才看到摘要。刻意压低装饰密度，用印刷感衬线与 mono 索书号传达"可信赖的馆藏索引"，而非编辑推荐流。

## 适用场景与目标用户

- 独立书店、社区文库、编辑部资料室的馆藏/在架目录页。
- 目标用户：到店先查目录的读者（想快速知道某类有什么、在不在架）、负责整架与登记入藏的图书管理员。
- 也适合文学杂志、出版社把历年篇目做成可检索的线上总目。

## 非目标

- 不做博客/资讯信息流卡片：无封面图、无点赞评论、无"推荐阅读"算法位。
- 不做真实后端检索与登录、借阅台账流程（本页为纯前端过滤与状态演示）。
- 不采用明亮白底、圆角大卡、玻璃拟态等现代消费级阅读器气质。
- 不做移动端优先设计（本题 desktop），900px 以下仅为不碎的降级排布。

## 复刻提示词

一座深棕褐色调的私人文库检索页：深咖啡页面背景，左侧 216px 分类栏（随笔/小说/评论/访谈/译注，各带条目计数与左侧 3px 激活色条），右侧嵌 recessed 阴影的"书架板"上横躺 8 条书脊式条目——每条左侧 6px 分类色带、虚线框 mono 索书号、衬线书名、"作者 · 来源 · 分类"一行、在架/借出圆点。点击书脊像抽书一样在下方展开米黄纸质感摘要卡（左侧 4px 铜色边、关键词胶囊、馆藏位置与"预约借阅"反色按钮），单开手风琴；顶部有真实可用的关键词检索与计数。Georgia/宋体系衬线 + system-ui 正文 + mono 索书号，160–220ms 轻动效，尊重 prefers-reduced-motion。
