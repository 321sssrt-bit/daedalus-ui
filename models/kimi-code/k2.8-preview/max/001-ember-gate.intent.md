# 001 登录

## 意图元数据

- 意图版本：1
- 对应规范：`001-ember-gate.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把登录做成一次"接班上岗"：近黑 Navy 哑光底上只点一处余烬橙，居中登录卡如闸门，两侧光柱呼应夜航灯语。刻意弃用蓝白 SaaS 的明亮可亲和，用低亮度、单一暖 accent、中低密度换取夜班控制台般的专注与仪式感。

## 适用场景与目标用户

面向 7×24 值守类内网系统的登录入口：运维监控、安防调度、能源集控、夜班客服指挥台等。主要用户是夜间值班工程师与调度员——环境照度低、希望界面不刺眼；动作路径要短，登录是唯一任务，不被营销内容打断。

## 非目标

- 不采用蓝白渐变、玻璃拟态的通用 SaaS 登录风。
- 不放注册引导 Banner、第三方扫码登录、社交账号入口（账号由调度统一下发）。
- 不做高信息密度的仪表盘式首屏，不在登录页堆状态数据。
- 不接入真实后端：校验、倒计时、成功态均为前端演示逻辑。

## 复刻提示词

深夜哑光近黑 Navy 底（#0a0f18），余烬橙（#ff7a1a）作唯一暖 accent；居中 400px 登录卡如闸门，左右各一根 2px 竖直光柱，光点缓慢下流、顶部一枚呼吸灯；系统字体中文真实文案；密码/验证码双 Tab、密码可见切换、60 秒验证码倒计时、忘记密码弹层、登录成功面板；中低密度、夜航灯气质，避免常规蓝白 SaaS 登录。
