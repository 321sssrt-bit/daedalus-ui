# 032 危险删除

## 意图元数据

- 意图版本：1
- 对应规范：`032-black-box.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把「删除整库」做成黑匣子记录仪的最后一页：近黑底、白字、hairline，琥珀色只给警示灯与确认词；压迫感靠 64px 大字而非红色。关键取舍是让「取消」当视觉主角——更高更亮、排首位，删除锁在确认词之后。

## 适用场景与目标用户

- 品类：团队协作 SaaS（设计资产库、研发项目库、团队知识库）PC 端设置页中的「危险操作」区；同样适用于云控制台的数据库整库销毁、存储桶清档等运维删除页。
- 用户：工作区所有者或系统管理员——清理僵尸团队、合并账号、下线旧系统前的最后一次确认；操作者往往带着情绪或赶时间，界面必须替他减速。
- 情境：不可逆操作前的强制阅读页，需要让当事人逐条看到会失去什么，并用输入确认词证明「我知道我在做什么」，同时永远给出一条比删除更显眼的退路。

## 非目标

- 不采用大面积红色、血滴、骷髅等恐怖式警示，也不用倒计时催促。
- 不做回收站、冷却期、软删除等可恢复能力——本题场景就是「真的没有后悔药」。
- 不做多工作区批量删除、权限校验、二次密码输入等流程分叉。
- 不做移动端优先布局，不为本题引入外链图标字体或插画，警示与图标全部内嵌 SVG 线框。

## 复刻提示词

黑盒记录仪气质的桌面危险删除页：近黑底 `#0b0c0f`，hairline `#2a2e36` 分区，白字大字标题 64px，琥珀 `#f2b53c` 只用于呼吸警示灯、DELETE 确认词芯片与解锁态；左侧警示条加五行「你将失去」清单（项目文件/协作网络/版本历史/自动化/第三方集成，等宽数字右对齐，合计 48 GB），右侧 384px 吸顶确认面板：等宽输入框键入 DELETE 实时解锁删除按钮，纸白实心高 54px 的「取消，保留我的工作区」排在 46px 描边删除按钮之上且更醒目；点击删除弹 FINAL CHECK 弹层，确认后 1.2s 旋转圈处理进入全屏「已删除」终态，取消进入「已取消」终态，均可一键重开。系统字体、单文件离线。
