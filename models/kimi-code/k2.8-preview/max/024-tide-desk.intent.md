# 024 结账

## 设计意图

用潮汐蓝绿把「付钱前最后一眼」做成清爽的夏日收银台：左侧逐行列清商品、收货与配送，右侧合计栏吸顶，应付总额以 40px 大字钉住注意力，支付方式用单选卡呈现。刻意避开深黑金融风——金额强调靠字号与青绿深度而非金红，成功后以一张干净回执同页交付。

## 适用场景与目标用户

- 品类：生活方式电商（家居香氛、轻户外、咖啡冲调等客单价 300–1500 元的实物商品）的 PC 端收银台。
- 用户：25–40 岁、习惯网页大屏下单的女性与家庭采购者；在办公间隙完成付款，需要快速核对金额与收货信息、不愿被促销信息干扰。
- 情境：大促凑单后进入最终确认页，希望一屏看清「买了什么、寄到哪、付多少」，并用常用方式一键付清。

## 非目标

- 不采用深黑底 + 金色描边的金融理财式收银视觉，也不用红色警报式促销倒计时。
- 不做多步表单、地址编辑、优惠券叠加等下单前流程；本页只覆盖提交付款前的确认与支付。
- 不做真实支付网关对接、二维码弹层与短信验证；支付处理与成功回执为同页模拟。
- 不引入外链图标字体或商品照片，商品形象只用内嵌线框 SVG 暗示。

## 复刻提示词

潮汐蓝绿清爽风桌面收银台：左侧白卡订单摘要（4 件商品行，64px 圆形线框 SVG 缩略图、单价与小计右对齐，底部收货/配送/发票信息），右侧 400px 吸顶合计卡（明细三行后接 40px 青绿大字应付总额、三张支付方式单选卡带选中描边与光晕、积分抵扣开关可实时改价、52px 主按钮点击后 1.4s 处理态再同页弹出成功回执）。背景 #eaf5f1→#e0efea 渐变，主色 #0d9384，文字 #123f3b，辅助 #63807c，全部系统字体、离线单文件。
