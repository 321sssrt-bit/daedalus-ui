# 012 日历

## 意图元数据

- 意图版本：1
- 对应规范：`012-season-scroll.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把行事历做成一轴手卷：纸面、轴头、朱印与节气小签营造“顺时记事”的东方质感；事件按四季设色，看颜色即知此事在播种、执行、交付还是规划。刻意避开纯色方块日历，用纸纹与衬线留住温度。

## 适用场景与目标用户

- 电商与服饰品牌内部团队的排期历：上新、拍摄、大促复盘、备货等跨部门安排按季节节奏铺开。
- 小型工作室与创意团队的项目月历：用"四季"隐喻项目阶段，团队一眼识别每件事的性质。
- 注重文化气质的文创、茶、生活方式品牌：对内协作工具也要与品牌调性一致。

## 非目标

- 不做周视图、日视图与时间轴视图，只有月网格。
- 不做事件新建、编辑、拖拽改期；交互只到"查看详情 + 翻月"。
- 不做谷歌式白底方块 + 纯色事件条的工业化皮肤；不用圆角彩色整块事件。
- 不做提醒、邀请他人、多时区等协作能力。
- 不做真实农历全量换算，仅点缀可考的关键日（八月初一、中秋）。

## 复刻提示词

一张中式手卷质感的桌面月历行事历：深褐背景上悬挂米色卷轴，上下木纹轴头带装饰轴头；卷首一枚朱红印章与衬线大月题，左右绫绢竖条。月视图 7 列网格，周末列微染色，今日朱底圆徽，节气日带朱色小签。事件按四季分类设色（春柳绿、夏榴红、秋桂金、冬黛蓝），签条为浅底加左侧时令色边线；点击事件签弹出纸上详情浮层，含日期、时间、地点、时令与备注，右上角朱印角标。翻月按钮在卷首右侧，图例与本月总计在卷尾。
