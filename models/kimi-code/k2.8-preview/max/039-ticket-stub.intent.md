# 039 成功回执

## 意图元数据

- 意图版本：1
- 对应规范：`039-ticket-stub.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把成功回执做成一张撕下来的票根：打孔、撕角、等宽编号让它值得被保存；朱砂与米纸像老式戏票，完成动作轻量，明细折叠保持票面干净。

## 适用场景与目标用户

面向购票、预约、支付完成的中文移动场景；适合需要给用户一张「拿得走」的凭证、事后凭编号核对的产品。

## 非目标

不做电子发票、不做分享炫耀卡、不做积分营销；回执只承载凭证信息，避免红包金的喜庆套路。

## 复刻提示词

票根成功回执页：深色舞台中 390px 手机框，米白纸票卡带撕角打孔与等宽编号 NO. A-2026-0911-038，四字段区、可展开交易明细与朱砂完成按钮。
