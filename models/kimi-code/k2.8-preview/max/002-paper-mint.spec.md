# 002 注册

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`002-paper-mint.html`
- 复现范围：桌面端单页注册界面，含左栏品牌区与右栏表单区，以及提交成功后的同页成功面板；不含真实后端收发信。

## 内容与数据

- 品牌区文案（不可漂移）：品牌名「苔径」+ 英文「MOSSWAY」；主标题「把日常，走成 / 一条安静的小径。」；副文案「苔径是一本放在口袋里的生活手账。写下今天想完成的三件小事，看日子一点一点长出青苔与光。」；脚注「© 2026 苔径工作室」「让每一件小事都算数」。
- 表单字段顺序与占位：① 怎么称呼你（placeholder「例如：林晚」，maxlength 24，规则 2–12 字）；② 邮箱（placeholder「you@example.com」）；③ 设置密码（placeholder「至少 8 位，包含字母和数字」）。
- 校验文案原文：「告诉我们怎么称呼你」「称呼需要 2–12 个字符」「邮箱是必填的」「邮箱格式好像不太对，再检查一下」「设置一个密码吧」「密码至少 8 位」「密码需要同时包含字母和数字」。
- 条款行：「我已阅读并同意《服务条款》和《隐私政策》」；门控提示：「勾选同意后，「立即注册」就可以点击了。」
- 主按钮文案：默认「立即注册」→ 加载「正在创建…」；成功面板标题「注册成功」，正文「验证邮件已发送到 {邮箱}，点击邮件中的链接，就能正式踏上苔径。」
- 初始状态：三个输入框为空、条款未勾选、主按钮禁用、强度条 data-level=0、成功面板 hidden。
- 示例数据可替换，但字段顺序、校验阈值（2–12 字 / 邮箱正则 / 8 位含字母数字 / 30s 倒计时）不可变。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | .5s `cubic-bezier(.2,.7,.2,1)` 上浮 14px 淡入 | 表单卡片入场；成功面板再现时为 .45s 同曲线 | 时长压至 .01ms，直接呈现最终态 |
| 悬停 / 焦点 | .16–.18s ease | 输入框描边变色、按钮变色 + translateY(-1px) + 投影、眼睛按钮底色 | 保留颜色变化，位移与投影瞬变（时长 .01ms） |
| 用户输入与校验 | 实时；错误文案即时替换 | 强度条三段按 level 变色 + 建议语；错误字段红描边 + 红底 + 13px 文案 | 全部保留（非连续动画） |
| 提交 | 900ms 模拟网络 | 按钮 loading 态（spinner 16px 旋转 + 文案「正在创建…」）后切换成功面板 | spinner 动画压至单帧，文案反馈保留 |
| 倒计时 | 每 1000ms 一步 | 重发按钮文案「重新发送验证邮件（Ns）」逐秒递减至 0 后恢复 | 逐秒文案保留 |
