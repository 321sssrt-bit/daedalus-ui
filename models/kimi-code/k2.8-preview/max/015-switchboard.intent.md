# 015 通知中心

## 意图元数据

- 意图版本：1
- 对应规范：`015-switchboard.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

通知中心最常见的做法是白色卡片列表加未读小红点，本题刻意反着走：把每条通知当成总机面板上的一路灯——别人刚发生的事，就是刚刚亮起的灯。深色木机台托住黄铜铭牌与按钮，六类通知用六种霓虹灯色区分，已读即灭灯，展开即抽出话单纸。「全部标已读」做成一根要按下键程的大拨杆，让清理动作有扳动机械的笃定感，而不是轻飘飘的链接。

## 适用场景与目标用户

小型工作室与班组协作工具的通知汇总页，具体如设计工作室的派单与批注回执、运维班组的构建告警与维护公告、剧组或展厅制作团队的人事与里程碑播报。主要用户是守着工作台值机的人：他需要一眼扫过面板就知道「哪几盏灯亮着、哪件事最急」，然后逐条接线处理或一把全部灭灯，而不是在滚动列表里找红点。

## 非目标

- 不做白底卡片流、头像列表或小红点徽章，避免与现代通知中心撞脸。
- 不实现通知偏好设置、免打扰时段与真实推送通道，只做工位上的接收与处置。
- 不做按类型筛选的多选 chips——面板上只有一枚「只看待亮灯」闸刀，过滤是电工式的通断，不是查询条件。
- 不使用 emoji 图标；灯色、类牌与 jack 编号承担全部类型区分。
- 不模拟电话接线功能，拨杆、插孔、话单纸都只是通知隐喻的真实交互件。

## 复刻提示词

深色木面板上的老式电话总机通知中心：木纹机台四角嵌黄铜螺丝，顶部阴刻黄铜铭牌「通知总机」，右侧内凹黑表盘显示日期、实时时钟与「待亮灯 N 盏」，再加一根黄铜大拨杆「全部标已读」和一枚 64 px 闸刀开关「只看待亮灯」；主体是六条通栏话单，每条行首是一盏 11 px 霓虹指示灯（告警红/指派琥珀/批注青/公告绿/里程碑紫/新人玫瑰，未读带三层同色光晕并轻微闪烁，已读熄灭成暗灰）嵌在铜芯插孔里，旁钉二字黄铜类牌、标题摘要与等宽 jack 编号；点击行可顶出一张带 27 px 棕色格线的米色话单纸展示详情，公告那张纸里有「登记为值守人」按钮；行尾两颗 30 px 圆形铜钮分别负责展开与灭灯已读，灭灯时灯熄、行转灰、表盘数字递减；拨杆全灭时灯从 J-01 起每 110 ms 依次熄灭，最后拨杆变「灯已全灭」禁用。
