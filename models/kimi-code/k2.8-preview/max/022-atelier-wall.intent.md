# 022 个人主页

## 意图元数据

- 意图版本：1
- 对应规范：`022-atelier-wall.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把个人主页做成一面真实的画室墙：暖灰泥墙为底，头部是一幅挂起来的大画布，作品像画一样钉在墙上、各有歪斜；关注与联系是来访者自然的动作，而不是社交_feed_里的数字游戏。刻意回避信息流三栏，让“一个人”而非“一条时间线”被记住。

## 适用场景与目标用户

- 独立插画师、摄影师、手作艺人的对外个人主页：需要同时展示“我是谁、我做过什么、怎么找到我”。
- 画廊寄卖、杂志约稿、品牌合作的初步接触页：对方能在 30 秒内看到作品气质并拿到联系方式。
- 小型工作室的招聘/接洽入口，偏重作品陈列而非即时聊天。

## 非目标

- 不做社交信息流：无评论、转发、点赞瀑布、 infinite scroll。
- 不做站内私信系统：联系止步于复制邮箱 / 微信，对话发生在站外。
- 不做在线商店：作品只标收藏价与咨询入口，不下单、不支付。
- 不做暗黑模式与多主题：画室墙只有一种光线。

## 复刻提示词

一面暖灰泥墙质感的个人主页：实木框大画布挂在头部，内有自画像、衬线大姓名、身份句、统计与“关注 / 写信联系”按钮；下方作品以纸面小卡钉在墙上，带挂钉、微旋转与媒介筛选；动态是几张便签；关注按钮在“关注 ⇄ 已关注”间真实切换并联动计数；点击作品开木框浮层看详情与收藏价，可跳到联系浮层复制邮箱。赭红点缀、衬线标题、克制投影，全程中文真实文案。
