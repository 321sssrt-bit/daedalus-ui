# 036 编辑发布

## 意图元数据

- 意图版本：1
- 对应规范：`036-memo-rain.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把手机写作做成一张贴在玻璃窗边的便签：雨灰底色、纸胶带、手账式字距，让「写完发出去」这个动作轻得像撕下一张便签；字数约束和草稿时间戳保留工具感。

## 适用场景与目标用户

面向喜欢随笔、日记体发布的中文用户；用于手机上快速记录并发布短内容，适合轻博客、手账社区类产品。

## 非目标

不做富文本编辑器、不做话题/@提及、不做多图排版；保持单卡便签形态，避免社交信息流的噪声元素。

## 复刻提示词

雨灰便签写作页：雨幕渐变中 390px 手机框，纸胶带便签卡含标题与正文输入、实时字数、存草稿药丸与发布主按钮，成功后有回执面板。
