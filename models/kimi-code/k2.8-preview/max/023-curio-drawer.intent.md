# 023 收藏夹

## 意图元数据

- 意图版本：1
- 对应规范：`023-curio-drawer.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把收藏夹做成一只深色木质珍玩柜：密排小格、黄铜抽屉签、绒布格签，让"自己攒下来的东西"有陈列与占有欲的满足感。取物有缩小淡出的实感，腾空一格有兜底，整体克制不花哨。

## 适用场景与目标用户

面向个人资料囤积型产品的收藏页：设计资源夹、读书笔记柜、素材库、工具箱式的"我的收藏"。典型用户是长期按主题归档网页、工具与灵感的个体创作者或研究员，习惯打开收藏夹快速定位、定期清掉失效条目，而不是被动刷信息流。

## 非目标

- 不做明亮极简书签页，不用白底大卡加彩色图标。
- 不做搜索、排序、批量编辑、拖拽整理等管理功能。
- 不做账号、登录、云端同步与分享。
- 不做缩略图墙；卡片信息以文字层级为主，不配内容截图。
- 不做无限滚动与分页，12 格一屏排开。

## 复刻提示词

一只深色木质珍玩柜风格的收藏夹桌面页：近黑胡桃木底、黄铜抽屉标签、绒布绿格签，密排小格收藏卡（格签、衬线标题、两行注释、格号与日期）。顶部分类标签真实过滤网格，卡片「× 取出」带缩小淡出动画并可撤销放回，某分类取光后出现虚线空屉兜底并可一键放回全部。暗色、陈列感、克制。
