## 内容与数据

- 品牌：「丝绒会客厅」，副题「今晚的墙 · 留一面给你」；栏题「今 夜 墙 面」。
- 初始四条动态（顺序固定）：沈青梧·15 分钟前·公开厅堂；陆停云·1 小时前·会员可见；顾棠·昨天 23:41·仅密友；白鹭洲·昨天 20:05·公开厅堂。正文必须保留 `<em>` 高亮句。
- 可见范围三选项固定：公开厅堂（所有人可见）/ 会员可见（仅挂牌会员）/ 仅密友（三位密友）。
- 输入框：占位文案「写点什么，今晚的墙留一面给你。」，上限 140 字，实时计数「n / 140」。
- 失败文案固定：「上墙未完成 —— 沙龙已熄灯」「灯灭期间墙面暂停接待，这条内容没有挂出去。你的正文与所选可见范围都原样保留，随时能重试。」
- 状态栏时间取本机时钟，格式 HH:MM。
- 数据可替换，但作者名、时间、范围标签与正文层级不得漂移。

## 产品边界

本原型实现：移动端单屏的社交社区「墙面」——浏览动态、撰写并发布新内容、三档可见范围选择、发布成功上墙、熄灯导致的发布失败与重试恢复。不包含：登录注册、评论展开、私信茶话、名册与个人主页（点击仅提示）、真实的网络请求与本地持久化（草稿仅存于本次页面会话）。

## 状态地图

| 状态 | 触发操作 | 呈现 |
| --- | --- | --- |
| 正常浏览 | 打开页面 | 头部 + 四条画框动态 + 底部导航 |
| 撰写中 | 点「上墙说话」或 FAB | 底部弹层升起，草稿区、范围单选、双按钮 |
| 发布进行 | 点「挂上墙」 | 按钮变「上墙中…」并禁用，约 900 ms |
| 发布成功 | 灯亮时发布完成 | 弹层关闭，新卡片挂入墙顶 + toast |
| 发布失败 | 熄灯时发布完成 | 弹层内红色警示出现，草稿与范围保留，按钮变「重试上墙」 |
| 熄灯氛围 | 拨「熄灯演示」至关 | 整屏变暗、灯光晕消失、toast 提示 |
| 恢复可发布 | 拨回开灯 | 亮度恢复，警示仍在，可直接重试 |

## 正常流程

1. 打开页面：看到四条画框动态，可上下滑动浏览。
2. 点右下角「上墙说话」：遮罩渐显，撰写弹层升起。
3. 在草稿区输入文字（计数随动，上限 140 字）。
4. 在「这面话，说给谁听」中点选范围（默认公开厅堂），选中行高亮。
5. 点「挂上墙」：按钮变「上墙中…」；约 900 ms 后弹层关闭、toast 显示「已挂上墙面」，新画框带「新挂上」角标出现在墙顶。

## 异常触发与恢复

- 触发：拨动头部右上「熄灯演示」开关至关（页面变暗、toast 提示「沙龙已熄灯 · 发布将失败」），再按正常流程撰写并点「挂上墙」。
- 失败反馈：约 900 ms 后弹层内出现红色警示「上墙未完成 —— 沙龙已熄灯」，说明内容未挂出；草稿正文一字未丢、字数计数不变、所选可见范围行仍保持选中。
- 恢复：按警示内提示拨回开关（灯亮、toast「灯亮了 · 可以重试上墙」），点变为「重试上墙」的主按钮；同一草稿成功上墙，新画框出现在墙顶。

## 数据变化

- 发布成功：动态墙卡片数 +1（新卡片插到栏题之下第一位），新卡片赞同/回话计数为 0，范围标签为发布时所选档。
- 发布失败：动态墙卡片数不变；草稿对象 `{ text, scope }` 保持失败前内容；警示面板计数不重置。
- 重试成功：草稿对象清空，计数归零，墙顶新增卡片。
- 赞同 chip：计数按点按 ±1 在 0 以上浮动（初始卡片在其预置值上增减）。
- 熄灯开关只改变发布判定与视觉氛围，不改写任何草稿或动态数据。

## 人工验收步骤

正常闭环：
1. 打开 `044-parlor-feed.html`（宽屏看到手机框，390 宽直接全屏）→ 应见四条金框动态。
2. 点「上墙说话」→ 弹层升起，主按钮灰置。
3. 输入一段文字 → 计数增加，按钮变金。
4. 点选「仅密友」→ 该行金边高亮。
5. 点「挂上墙」→ 按钮显示「上墙中…」→ 弹层关闭、toast 出现、墙顶新卡片带「新挂上」角标。

异常恢复：
1. 拨头部「熄灯演示」至关 → 页面变暗、toast 提示发布将失败。
2. 点「上墙说话」，输入另一段文字，选择「会员可见」，点「挂上墙」。
3. 约 1 秒后 → 弹层内红色警示出现，正文、计数、「会员可见」选中态全部原样。
4. 拨回开关至开 → 灯亮提示出现。
5. 点「重试上墙」→ 弹层关闭、toast 出现、墙顶出现该内容的新卡片。
