# 034 正在播放

## 意图元数据

- 意图版本：1
- 对应规范：`034-vinyl-night.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把手机播放器还原为一台黑胶唱机：密纹唱盘随音乐转动、唱针落下，进度与队列围绕「唱机」组织而非列表控件；夜紫与粉紫渐变给深夜听歌的场景一个安静的空间。

## 适用场景与目标用户

面向深夜聆听、专辑导向的中文音乐用户；适合强调沉浸播放而非刷歌单的音乐产品播放页。

## 非目标

不做歌词滚动、不做评论互动、不做均衡器可视化；封面以唱片标签呈现，不引入真实专辑图库。

## 复刻提示词

黑胶夜紫播放页：深紫舞台中 390px 手机框，288px 密纹唱盘带中心标签与金色唱针，播放/暂停真实驱动旋转，可点进度条、音量与三行待播队列。
