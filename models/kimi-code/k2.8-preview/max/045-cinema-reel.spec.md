## 规范元数据

## 内容与数据

- 品牌：银幕后 / CINEMA REEL；导航：片库（选中）、放映厅、我的片单（后两项为静态入口）。
- 片库数据字段顺序：片名 → 年份 · 类型 · 时长 → 一句话简介 → 评分（海报左下角「★ 8.7」）。8 部示例影片为《雾港夜航》《铁轨以西》《午夜电台》《海边来信》《放映师》《云端之城》《昨日公园》《无声证词》，时长 89–121 分钟。
- 队列条目字段顺序：两位序号 → 片名 → 总时长 → 操作按钮组（▶/❚❚、↑、↓、✕）。
- 播放状态卡字段顺序：状态徽章 → 当前影片 → 当前进度 → 剩余时长 → 保存块（含「已保存」徽章、片名+进度、保存时刻、「回到此进度继续」按钮）。
- 必保留文案：「断网演练」「重新连接」「网络连接已中断」「◆ 保存进度」「网络在线 / 网络离线」「已保存播放状态」。
- 初始状态：未选片、队列为空、徽章「待机」、银幕占位文案「从左侧片库选择一部影片，开始今日放映」、全部播放控件禁用。
- 时间格式：满 1 小时为 `h:mm:ss`，否则 `mm:ss`，全部补零；进度以 1 秒为步进模拟真实播放。

## 产品边界

实现内容：片库发现与选片、模拟播放（1 秒步进）、进度拖动定位、放映队列的添加/移除/上下移/切播、播放状态保存与回到保存点、断网演练触发 → 中断反馈 → 重连恢复三态闭环。不包含：真实音视频流与编解码、服务端/账号/登录、评论弹幕与社交、移动端专用界面、真实网络探测（断网为页面内显式模拟）。

## 状态地图

同一 HTML 内的状态与触发操作：

1. 待机（初始）——未选片，控件全禁用。
2. 待放映——点击影片卡或队列 ▶ 载入影片，进度归零，未播放。
3. 播放中——点击「▶ 播放」或队列 ▶，计时器每秒推进。
4. 已暂停——点击「❚❚ 暂停」，进度保留。
5. 网络中断——播放中（或暂停中）点击「断网演练」，浮层遮罩出现，徽章/pill 变红，队列操作锁定。
6. 重连中——点击浮层「重新连接」，按钮转圈禁用约 1600ms。
7. 恢复（回到播放中或已暂停）——重连成功，从中断进度继续；若中断前正在播放则自动续播。
8. 已保存——点击「◆ 保存进度」出现保存块（与 2–7 任意状态并存）；点击「回到此进度继续」跳转播放。
9. 放映结束——进度走到总时长；队列有下一部则 1200ms 后自动切播，否则停在结束态。
10. 全局提示条与顶栏网络 pill 为伴随状态，随时反馈最近操作。

## 正常流程

1. 在左侧片库点击《雾港夜航》卡片 → 银幕切换为该片大字海报与元信息，影片自动进入放映队列，卡片获得金色选中框，状态徽章变「待放映」，控件启用。
2. 点击控制条「▶ 播放」→ 徽章变绿点「播放中」，银幕出现循环扫光，时间码从 00:00 每秒递增，滑杆金色填充同步右移。
3. 拖动进度滑杆到约中点 → 「当前进度 / 剩余时长」立即刷新，松手后播放从新位置继续（不中断计时）。
4. 点击队列中另一部的「↑」将其前移、「✕」移除一部非当前影片 → 队列顺序与序号即时重排。
5. 点击「◆ 保存进度」→ 底部提示「已保存播放状态：《雾港夜航》 mm:ss」，状态卡出现含片名、进度、保存时刻的金色保存块。
6. 点击保存块内「回到此进度继续」→ 播放跳转并续播，提示条确认；此时发现→播放→调整→保存→显示的完整闭环走通。

## 异常触发与恢复

- 触发：在播放（或暂停）状态下点击控制条红色描边「断网演练」按钮。
- 失败反馈：播放立即停止，计时冻结；银幕被遮罩覆盖并浮出红边卡片「网络连接已中断」，写明「中断前进度已保留在 mm:ss」；状态徽章与顶栏网络 pill 变红；保存、播放、滑杆与全部队列操作禁用，防止中断期间改动状态。
- 恢复操作：点击浮层内金色「重新连接」→ 按钮进入约 1600ms 的旋转重连态。
- 重新成功：浮层关闭，pill 恢复「网络在线」；若中断前正在播放，自动从保留的 mm:ss 继续计时并提示「已恢复连接，从 mm:ss 继续播放」；若中断前是暂停态，则保持暂停并提示进度已保留，可再点「▶ 播放」续播。队列、已存档位与进度数值在中断全程不丢失。

## 数据变化

- 选片：队列长度 0 → 1，当前影片 null → 《雾港夜航》，进度归零。
- 播放：进度按 1s/s 递增，剩余时长同步递减；影片播完时进度定格在总时长（5880s 等）。
- 队列调整：↑↓ 交换相邻序号（01↔02 等），✕ 使队列长度 −1；当前影片不可被移除。
- 保存：生成快照 `{影片, 进度, 保存时刻}`；重复保存覆盖旧快照，保存块时间戳更新。
- 断网：进度数值冻结不变；恢复后从冻结值继续，无跳变、无清零。
- 中断期间唯一允许的写操作是「重新连接」；保存与队列修改入口均被禁用，避免脏数据。

## 人工验收步骤

正常闭环：

1. 打开页面，确认三栏布局、待机徽章、银幕占位文案、控件禁用。
2. 点击片库《铁轨以西》→ 期望：银幕载入该片、队列出现条目、徽章「待放映」。
3. 点「▶ 播放」→ 期望：徽章转绿「播放中」，时间码每秒 +1，扫光出现。
4. 拖滑杆至约 1/2 处 → 期望：进度/剩余时长立即变化且继续计时。
5. 队列里对另一部点 ↑ 与 ✕ → 期望：序号重排、条目消失。
6. 点「◆ 保存进度」→ 期望：提示条确认 + 状态卡出现金色保存块；点块内「回到此进度继续」→ 期望：跳转并续播。

异常恢复：

1. 播放中点击「断网演练」→ 期望：播放骤停，浮层显示与当前时间码一致的保留进度，徽章/pill 变红。
2. 尝试拖动滑杆或点队列 ✕ → 期望：全部禁用不可操作。
3. 点击「重新连接」→ 期望：按钮转圈约 1.6s。
4. 期望：浮层消失，提示「已恢复连接，从 mm:ss 继续播放」，时间码从保留值继续 +1，徽章回绿。
5. （可选）在暂停态重复 1–4 → 期望：恢复后保持暂停、进度不丢，点「▶ 播放」续播。
