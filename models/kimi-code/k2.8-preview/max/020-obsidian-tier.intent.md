# 020 定价

## 意图元数据

- 意图版本：1
- 对应规范：`020-obsidian-tier.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

定价页卖的是长期承诺,不是冲动消费。取黑曜石般沉静的近黑底色,以单一金色线索贯穿三柱,用细线与衬线数字营造会员制的仪式感；推荐档只做克制的放大与徽标,把注意力引向权益递进。

## 适用场景与目标用户

- 产品品类：付费设计资产库(字体、样机、模板)、专业知识库或会员制创作工具的订阅定价页。
- 使用情境：官网公开定价页,用户已了解产品,正在对比档位做购买决策；销售驱动的旗舰档承接对公采购。
- 主要用户：独立设计师、小型设计工作室负责人,以及为企业团队评估采购的设计管理者。

## 非目标

- 不做浅色底 + 彩色三柱的彩虹式 SaaS 定价页,不使用高饱和渐变按钮。
- 不放对比表格、用户评价、Logo 墙或 FAQ 展开区,保持单屏决策结构。
- 不实现真实的支付下单、登录或结算流程,按钮仅表达选择与联系动作。
- 不使用表情符号式图标或插画,图标仅限几何菱形与线框图形。

## 复刻提示词

黑曜石近黑背景(#0b0b10)上的高端会员定价页：单一金线(#c9a86a)贯穿三柱,衬线大字价格,菱形 SVG 权益图标；中间推荐档金色边框、放大 1.03、顶部「最受欢迎」徽标；胶囊控件切换月付/年付(年付省 20%)并联动价格数字；幽灵按钮与实心金按钮,克制的悬停上抬与金色焦点描边。
