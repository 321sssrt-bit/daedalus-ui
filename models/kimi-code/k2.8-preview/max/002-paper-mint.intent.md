# 002 注册

## 意图元数据

- 意图版本：1
- 对应规范：`002-paper-mint.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把注册放进一张浅薄荷纸：左栏是带细噪点与植物线稿的品牌页，右栏只在需要时给出提示。大留白降低填写压力，薄荷绿传递新生感，衬线标题给数字表单一点纸的温度。取舍：不做深色科技风与分步表单，用条款勾选门控主按钮换取明确的禁用状态。

## 适用场景与目标用户

- 产品品类：生活记录、习惯养成、轻量记账等自然/生活方式气质的 Web 产品官网注册页。
- 使用情境：新用户从官网首页点「注册」后进入的独立落地页，桌面端为主。
- 主要用户：25–35 岁、偏好清爽自然风格、对隐私条款敏感的互联网产品新用户；填写时希望界面安静、提示克制。

## 非目标

- 深色模式与深色科技风界面。
- 微信/谷歌等第三方一键登录与多步骤分步表单。
- 营销向长滚动落地页、图片头图与真实邮件发送能力。
- 手机端优先的构图（本题为 desktop 题，仅保证 768px 不碎）。

## 复刻提示词

浅薄荷纸面质感的桌面注册页：左 40% 为薄荷绿渐变纸面（细噪点 + 植物线稿 + 衬线大标题），右 60% 白底居中 460px 表单卡片；系统字体，薄荷绿主按钮（高 52px、圆角 14px），输入框 48px 高、12px 圆角；大留白、轻盈投影、焦点环反馈，含密码可见切换与三段强度条。
