# 017 商店首页

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px
- 对应页面：`017-night-market.html`
- 复现范围：夜市霓虹气质商店首页的分类筛选、搜索过滤与「加入灯篮」加购交互，不含结算、下单与详情页流程。

## 响应式规则

| 条件 | 布局变化 | 组件变化 |
| --- | --- | --- |
| 主视口 ≥ 1280px 宽 | 页眉一行：品牌 + 搜索框 + 灯篮；网格 4 列；hero 标题 44px | 全部尺寸按上表 |
| 窄于 768px | `.header-inner` 换行、搜索框占满整行（`flex-basis: 100%`）；hero 纵向堆叠；网格降为 2 列、间隙 14px；结果行靠左 | hero 标题 30px；字牌区高 110px、单字 54px；商品名 16px |

## 内容与数据

- 店名：「灯河夜市」，英文副标 `DENGHÉ NIGHT MART`，缺一不可。
- hero 主标：「今晚的摊位都亮着」，其中「都亮着」三字为品色强调；说明段固定为「沿河五十四个摊位……统一到河湾口取货」。
- 分类顺序固定：全部 / 吃食 / 玩物 / 日用 / 手作，共 5 个标签。
- 商品数据为 8 条，字段顺序固定：摊位名（含号数）· 分类 → 商品名 → 一句话描述 → 价格（`¥` + 整数）→ 加购按钮。初始价格示例：12 / 8 / 36 / 18 / 15 / 22 / 28 / 16 元。
- 单字霓虹字牌与卡身品色按粉 / 青 / 黄循环分配，数据可替换但每条必须保留一个品色。
- 结果行格式固定：「今晚出摊 N 件货品」，选中非全部分类时追加「· 分类名」，N 为当前过滤后的件数。
- 页脚三句：「灯河夜市 · 天亮收摊」「货品文案为示例，价格为演示价」「取货点：河湾口 3 号灯柱下」。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面进入 | 不适用（无入场动画） | 静态霓虹排版 | 品牌名 `signFlicker` 灯管闪烁动画被禁用 |
| 点击加购 / 再点移除 | 状态切换过渡 .18s ease；徽章 bump 0.3s ease | 按钮变「已加入 ✓」薄荷态或还原；徽章数字增减并弹一下；底部 toast 淡入上浮 .22s 后 1.6s 自动消失 | 所有过渡压至 .01ms，状态色保留，bump 与闪烁禁用 |
| 悬停卡片 / 标签 / 按钮 | .2s / .18s ease | 卡片上浮 4px 并换品色描边；标签与按钮变色发光 | 过渡压至 .01ms，颜色结果保留 |
| 切换分类 / 输入搜索 | 即时重渲染，无过渡 | 网格只显示命中货品，结果行件数同步变化 | 同左，无动画可减 |
