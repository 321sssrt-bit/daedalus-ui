# 011 数据看板

## 意图元数据

- 意图版本：1
- 对应规范：`011-ledger-ink.spec.md`
- 说明：本文件不参与结构、尺寸、状态或交互验收。

## 设计意图

把数据看板做成一本手工流水账：宣纸底、楷体墨字、格线如账册栏线，趋势用一根手绘抖动的墨线折线，峰值与批注落朱笔，数字则是账房先生每日对出的四柱。日/周/月粒度像翻账册换账期，切换时图表、表格与关键数字一起换。刻意不用霓虹大屏、渐变玻璃和圆环图，让「看趋势」回到「对账」的安静动作。

## 适用场景与目标用户

- 品类：单体门店与小微连锁的经营日报——茶食铺、书店、小酒馆、手作坊等重「每日流水」的业态。
- 用户：店主本人或账房角色，非数据分析师；使用情境是打烊后或晨会前花两分钟对一眼：今天多少、比上周如何、哪天最旺。
- 也适合任何想把经营数据「人格化」、强调可信与手工温度的品牌内网报表。

## 非目标

- 不做现代 BI 大屏：无霓虹色、无发光卡片、无深色玻璃拟态、无圆环/漏斗图。
- 不做多维下钻、筛选器组合、导出下载与自定义时间范围；粒度只给日/周/月三档。
- 不做实时刷新与动画数字雨；数字滚动只在切换粒度时出现一次。
- 不做移动端优先布局，仅保证 768 px 不碎。

## 复刻提示词

手工中式账册风数据看板：宣纸米黄底（#f3ecdb）、墨黑楷体文字、朱批红（#b03a2e）只批峰值与涨跌；顶部店名账期与「日/周/月」印钮切换，四张关键数字卡（流水、笔数、客单价、环比），左侧主图为带轻微手绘抖动的单根墨线折线加墨渍面积洗，峰点朱圈朱字标注，右侧为格线账目表（账期/笔数/流水/朱批，含合计行）；切粒度时折线重画、数字滚动、整表换数据，悬停出朱红十字线与账房批注 tooltip；1280 桌面双栏，768 堆叠。
