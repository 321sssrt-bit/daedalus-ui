# 027 角色权限

## 规范元数据

- 规范版本：2
- 主视口：1280 × 800 px

## 内容与数据

- 布告标题：「后台通行令」；副题：「长夜剧团 · 角色权限布告 · 第 4 版」（封存成功后版号 +1）。
- 三个角色及权限清单（默认勾选状态以「√」标注）：
  1. 团长 DIRECTOR · 全局统筹：√审批演出排期、√发布招募公告、√管理成员名单、√查看财务报表、导出观众数据（共 4/5）。
  2. 舞台监督 STAGE MANAGER · 技术总管：√编辑演出排期、√安排装台拆台、√调试灯光音控、申请物料采购、查看财务报表（共 3/5）。
  3. 演员 PERFORMER · 台前演出：√查看演出排期、√下载排练资料、提交请假申请、查看个人报酬、√参与剧组讨论（共 3/5）。
- 预览台默认「团长视角」，右侧计数「此视角下，后台将开放 4 项操作」。
- 页脚：「现行有效：第 3 版 · 上次封存于 2026-03-12 22:08 · 封存后全团后台即时生效」，封存成功后更新为刚封存版号与当前时间。
- 封存回执分行列出三角色各自生效项数与全团合计，时间精确到秒；若任一角色 0 项，回执转失败样式并点名该角色，不推进版号。
- 字段顺序不可调换：角色名 → 定位 → 权限清单 → 卡脚操作。

## 动效与反馈

| 触发 | 时长与缓动 | 可见反馈 | `prefers-reduced-motion` |
| --- | --- | --- | --- |
| 页面或组件进入 | 灯泡带 2.6s ease-in-out infinite 呼吸；聚光锥 7s ease-in-out infinite alternate 左右摆动 | 跑马灯明暗与锥光漂移 | 动画停止，灯带与锥光保持静态 |
| 勾选权限 | 12–14ms ease（方框与对勾） | 对勾弹出、文字在实色与删除线间切换；卡片计数与预览清单同步刷新 | 仅保留终态色，对勾不做缩放 |
| 悬停卡片 / 按钮 | 0.15–0.18s ease | 卡片 translateY(-4px)、按钮 translateY(-2px) 且阴影加深 | 位移取消，仅保留阴影变化 |
| 切换预览 tab | 约 120ms | 激活 tab 金底发光，清单按新角色重排亮/暗项 | 仅切换终态 |
| 封存提交 | 回执 0.3s ease 滑入 | 右下角纸面回执带倾斜 -7° 印章；失败时卡面泛红并 5.2s 后自动收起 | 滑入取消，直接出现 |

## 复现验收清单

- [ ] 1280px 宽下，布告栏、三列角色名牌、预览舞台自上而下依次排布，三卡同排等宽（约 384px），预览舞台 min-height 238px。
- [ ] 三张名牌各含 5 条权限行与「已启用 x/5」计数，初始分别为 4/5、3/5、3/5；勾选块为 18×18px、2px 描边。
- [ ] 点击任一权限行文字或方框，该行文字与删除线、卡片计数、预览舞台亮/暗项即时同步；页面出现「有未封存改动」虚线徽章。
- [ ] 点击三个视角 tab 或卡片上的「以此视角预览」，预览区角色名与清单切换，激活 tab 为金底 `--ink` 字并带外发光。
- [ ] 把某角色 5 项全部取消后点「封存此版布告」，该卡外框变红、出现红色错误条，回执呈失败样式且不推进版号；补勾后重新封存，回执列出三角色分项与全组合计并推进版号。
- [ ] 视口缩至 768px，名牌改单列纵向堆叠，布告栏改纵向，回执改通栏浮底，无横向滚动条。
- [ ] 系统开启减少动态效果后，灯泡呼吸与聚光摆动停止，勾选与回执仍保留颜色状态反馈。
