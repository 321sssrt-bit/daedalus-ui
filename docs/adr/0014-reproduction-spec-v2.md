# ADR 0014：复现规范与设计意图分离

- 状态：已接受
- 日期：2026-08-15

## 背景

旧版 `.spec.md` 同时包含气质描述、适用产品、视觉值、产品流程和复刻提示词。它更像提示词集合，无法稳定回答区域多大、组件有哪些状态、断点如何变化，也不适合作为其他人复现作品时的验收依据。

## 决策

1. `.spec.md` 升级为规范版本 2，只记录可量测、可操作、可观察的复现规则。
2. 每题新增同名 `.intent.md`，单独记录设计意图、适用场景、非目标和辅助复刻提示词；它不参与结构、尺寸或交互验收。
3. `model.json` 升级为 schemaVersion 4，并声明 `specVersion: 2`；每个 piece 显式登记 `intent` 文件。
4. 展厅将“查看规范”和“设计意图”分成两个入口；一键导出只包含 `.spec.md`。
5. 验证器检查规范章节、精确值、可观察验收项及色值与 HTML 的一致性，但不把自动合规冒充人工体验验收。

## 后果

复现者可以把 `.spec.md` 当施工合同使用，提示词不再稀释验收标准。现有当前规则答卷需要一次性迁移；项目尚处早期，直接升级比长期兼容两套含义更清楚。
