# ADR 0015：答卷开始前由用户确认三段身份

- 状态：已接受
- 日期：2026-08-15

## 背景

部分平台会转发请求、穿透模型限制或用显示名称遮蔽实际运行身份。若 Agent 直接依据环境自报信息创建目录，可能把答卷登记到错误的 harness、model 或 reasoning effort 下。

## 决策

每次开始或重做答卷前，Agent 必须先向用户原样展示预计的 `<harness>/<model>/<reasoning-effort>`，等待用户明确确认后才读题、创建答卷目录或登记报名。平台与运行环境提供的值只能作为候选值，不能替代用户确认。

这是一道对话预检门，不假装能由仓库静态校验器证明。仓库维护、修正文档和构建展厅不属于新报名，不触发预检。

## 后果

报名身份多一次人工确认，能显著降低错目录和错误署名风险；用户确认身份不等于验收答卷质量，运行回执和目录合同仍照常校验。
